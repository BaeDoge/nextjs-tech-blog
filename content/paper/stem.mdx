## 자동화된 STEM 실험에서 이미지 분석이 왜 어려울까요?

주사 투과 전자현미경(Scanning Transmission Electron Microscopy, STEM) 자동화 실험에서는 사람이 이미지를 해석하고, 분석 위치를 선택하며, 분광 분석이나 원자 조작을 수행할 수 있도록 빠른 이미지 세그먼테이션이 필요합니다.

기존 세그먼테이션은 사람이 정답 레이블을 붙여 학습하는 지도 학습을 주로 사용합니다. 하지만 전자현미경의 해상도, 샘플링, 전자빔 모양이 달라지면 학습 데이터와 실제 입력의 분포가 달라질 수 있습니다. 이런 분포 변화에 대응하려면 다시 레이블을 만들고 모델을 재학습해야 하므로 자동화 실험의 흐름을 끊을 수 있습니다.

## 레이블 대신 보상 신호를 사용하는 접근

이 연구는 사람이 만든 레이블에 의존하지 않고, 보상 함수가 제공하는 신호를 이용해 이미지 분석을 최적화하는 워크플로우를 STEM 실험에 적용하고 평가합니다.

논문 초록에 따르면, 보상 기반 접근은 노이즈와 구조적 무질서가 있는 상황에서 더 강건한 결과를 보였으며, 보상 함수의 Pareto frontier(파레토 전선) 위에서 어떤 결과를 선택할지 사람이 검토할 수 있도록 설명 가능한 피드백을 제공합니다.

다만 '무감독'이라는 표현이 모든 사람의 개입이 없다는 뜻은 아닙니다. 학습 레이블은 필요하지 않더라도, 보상 기준을 설계하고 결과를 검토하는 과정에서 사람의 판단이 들어갈 수 있습니다.

## 처리 흐름

논문 초록에서 확인되는 연구의 흐름을 간단히 정리하면 다음과 같습니다.

```flow
STEM 이미지 입력
→ 보상 기반 최적화로 세그먼테이션 수행
→ 보상 함수별 결과와 설명 가능한 피드백 생성
→ 사람이 Pareto frontier 상의 결과를 검토·선택
→ 자동 실험에서 사용할 이미지 분석 결과
```

이 연구는 실시간 분석이 필요한 고처리량(high-throughput) 및 동적 STEM 자동 실험을 목표로 합니다. 논문은 해당 워크플로우의 처리 시간과 효과를 평가했고, 실시간 동작이 가능한 수준임을 보고합니다. 다만 초록만으로는 구체적인 지연 시간, 하드웨어 사양, 처리량 수치를 확인할 수 없으므로 숫자를 추정해서는 안 됩니다.

## 기존 지도 학습과 비교할 때

기존 지도 학습은 사람이 정답 레이블을 제공한다는 점에서 평가 기준이 명확하지만, 레이블 제작 비용이 들고 실험 조건이 달라졌을 때 다시 학습해야 할 수 있습니다. 반면 보상 기반 방식은 레이블 없이 최적화를 수행할 수 있고, 여러 보상 기준 사이의 절충 관계를 사람이 확인할 수 있다는 특징이 있습니다.

이 차이가 모든 조건에서 보상 기반 방식이 더 정확하다는 뜻은 아닙니다. 실제 도입 전에는 보상 함수가 연구 목적에 맞게 설계되었는지, 새로운 종류의 노이즈와 장비 조건에서도 성능이 유지되는지 확인해야 합니다.

## 개발자가 주목할 점과 한계

이 연구에서 흥미로운 부분은 이미지 세그먼테이션 모델의 출력만 제시하는 것이 아니라, 보상 기준 사이의 절충 관계를 사람이 검토할 수 있도록 설계했다는 점입니다. 자동 실험처럼 결과에 따라 다음 동작이 달라지는 시스템에서는 모델 정확도뿐 아니라 사람이 결과를 검토하고 선택할 수 있는 인터페이스도 중요합니다.

다만 이 연구는 STEM 및 현미경 이미지 분석이라는 전문 도메인을 대상으로 합니다. 일반적인 컴퓨터 비전 작업에 바로 같은 성능이 나온다고 볼 수는 없습니다. 또한 공개 초록에는 세부 수치와 전체 실험 조건이 모두 포함되어 있지 않으므로, 정량적 성능이나 운영 환경에 대한 판단은 논문 전문을 확인해야 합니다.
