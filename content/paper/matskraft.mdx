## 반정형 표 데이터, 왜 자동 추출이 어려운가?

재료 과학 분야는 방대한 연구 논문을 통해 새로운 소재와 성질을 발견해 나가고 있습니다. 하지만 막상 데이터가 축적되는 과정을 보면, 실험 결과나 핵심 발견 사항은 대부분 '표(Table)' 형식으로 정리되어 있는 경우가 많습니다.

이 표 데이터는 텍스트처럼 완전하게 정제된 상태가 아니며, 행과 열이 복잡한 구조를 가지고 있어 기계가 읽기에는 다소 번거롭습니다. 이를 '반정형(Semi-structured)' 데이터라고 부릅니다. 과거에는 이러한 표에 담긴 지식을 데이터베이스로 옮기기 위해 사람이 직접 일일이 눈으로 확인하고 입력하는 방식으로 진행했는데요, 이는 시간이 많이 들고 규모를 확장하기 어려운 점이 분명히 있었습니다.

개발자 관점에서 보면, 이 문제는 단순한 텍스트 추출을 넘어 구조화된 정보 사이의 관계를 파악해야 하는 복잡한 작업에 가깝습니다. 특히 재료 과학 분야에서는 '어떤 물질(조성)에 어떤 성질(물성)이 나타나는가'라는 관계를 정확히 연결하는 것이 매우 중요합니다.

## MatSKRAFT의 핵심 아이디어: 표를 그래프로, 과학 원칙을 모델에 담기

MatSKRAFT는 이러한 문제를 해결하기 위해 등장한 프레임워크입니다. 이 프레임워크의 가장 큰 특징은 데이터를 처리하는 방식을 '그래프(Graph)' 기반으로 재설계했다는 점입니다.

단순히 표의 셀 내용을 텍스트로 읽어내는 수준을 넘어, MatSKRAFT는 표의 행, 열, 교차점 등을 그래프의 노드(Node)와 엣지(Edge)로 변환합니다. 이렇게 구성된 그래프 구조를 통해 데이터가 가진 내재된 구조적 관계를 모델이 더 잘 이해할 수 있도록 만듭니다.

여기에 그치지 않고, 모델의 구조 자체에 재료 과학의 '과학적 원칙(Scientific principles)'을 직접 반영했습니다. 단순히 방대한 데이터에 의존하는 학습 방식이 아니라, 해당 도메인에 맞는 제약 조건을 모델 아키텍처에 녹여 넣음으로써, 더 정확하고 신뢰할 수 있는 추출 결과를 도출해 냅니다.

```flow
입력: 과학 논문 내 표 형식 데이터
→ 표 구조 분석 및 그래프 기반 표현으로 변환
→ 과학적 원칙이 반영된 제약 조건 그래프 신경망(GNN) 처리
→ 결과: 추출된 물질 조성 및 물성 데이터
```

## LLM 대비 뛰어난 성능과 처리 속도

최근 자연어 처리 분야에서 큰 관심을 받고 있는 대규모 언어 모델(LLM)을 활용하는 방식도 존재합니다. 하지만 MatSKRAFT는 기존 최첨단 LLM 방식과 비교했을 때 뚜렷한 강점을 보입니다.

연구 결과에 따르면, MatSKRAFT는 물성(property) 추출에서 89.33%, 조성(composition) 추출에서 71.35%의 F1 score를 기록했습니다. 단순히 정확도만 높은 것이 아니라, 처리 속도 측면에서도 압도적인 차이를 보였습니다. 논문에서 비교한 LLM 기준으로 가장 빠른 모델 대비 6배, 가장 느린 모델 대비 496배 빠르게 처리했으며, 비교적 제한된 하드웨어 자원으로 실험했습니다.

이는 특정 도메인(재료 과학)에 맞춰 최적화된 구조를 설계했을 때, 범용적인 모델을 무작정 사용하는 것보다 훨씬 효율적인 결과를 얻을 수 있음을 시사합니다.

## 대규모 데이터셋 구축과 실제 적용 사례

MatSKRAFT 프레임워크는 실제 방대한 양의 연구 데이터에 적용되어 그 효용성을 입증했습니다. 연구진은 45,500편이 넘는 연구 논문에서 총 66,267개의 표 데이터를 대상으로 추출 작업을 진행했습니다.

이를 통해 최종적으로 50만 9,281개의 항목이 포함된 데이터베이스를 구축했습니다. 이 데이터베이스에는 104,000개의 물질 조성 데이터와 다양한 물성 정보가 포함되어 있으며, 기존 주요 데이터베이스들이 커버리지에서 누락했던 부분까지 포괄하고 있습니다.

이렇게 체계적으로 수집된 데이터를 바탕으로, 연구진은 기존에 주목받지 못했던 독특한 물성 조합을 가진 소재들을 발견하고, 조성-물성 간의 관계를 데이터 기반으로 규명할 수 있었습니다. 이는 단순한 데이터 수집을 넘어, 소재 발견을 위한 새로운 통찰력을 제공하는 결과라고 볼 수 있습니다.

## 개발자가 주목해야 할 포인트

MatSKRAFT 연구를 소프트웨어 개발 및 데이터 엔지니어링 관점에서 살펴보면 다음과 같은 시사점을 얻을 수 있습니다.

첫째, 데이터의 '구조'를 보존하면서 기계 학습 모델에 입력하는 것이 중요합니다. 표 형태의 데이터를 텍스트로 평탄화(Flatten)해서 넣는 것보다, 그래프나 트리 구조로 유지하여 처리하는 것이 복잡한 도메인 데이터 추출에 유리할 수 있습니다.

둘째, '도메인 지식의 통합'이 모델 성능 향상에 기여합니다. 순수하게 데이터만으로 학습하는 것보다, 해당 분야가 가진 논리적 제약이나 원칙을 모델 설계 단계에서 반영하는 것이 효과적일 수 있습니다. 이는 도메인 특화 파인튜닝(Domain-specific Fine-tuning)이나 모델 아키텍처 설계 시 고려해 볼 만한 접근법입니다.

마지막으로, 효율성과 정확도의 균형입니다. 무조건적으로 파라미터가 큰 모델을 사용하는 것이 항상 정답은 아닙니다. 적절한 구조 설계와 도메인 최적화를 통해 더 적은 자원으로도 우수한 성능을 낼 수 있다는 점을 MatSKRAFT는 보여줍니다.
