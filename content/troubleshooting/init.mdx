## 현상

클래스를 인스턴스화할 때 `__init__` 메서드가 요구하는 인자를 전달하지 않으면 에러가 발생합니다. 아래는 에러를 재현하는 최소 코드와 출력 원문입니다.

```python
class DHT:
    def __init__(self, data):
        self.data = data

    def showData(self):
        print(self.data)

if __name__ == '__main__':
    DHT().showData()
```

```text
Traceback (most recent call last):
  File "test.py", line 9, in <module>
    DHT().showData()
TypeError: __init__() missing 1 required positional argument: 'data'
```

## 원인

Python이 객체를 생성하며 호출하는 `__init__` 메서드가 필수 위치 인자 `data`를 요구하지만, `DHT()` 호출에서 이 인자를 전달하지 않아 발생합니다. 클래스 정의 시 `data`라는 위치 인자가 지정되었으나, 객체를 생성하는 `DHT()` 호출 시 아무런 값도 전달되지 않아 파이썬 인터프리터가 `TypeError`를 반환합니다.

## 해결 방법

`__init__` 메서드의 매개변수에 기본값(default value)을 지정하거나, 객체를 생성할 때 올바른 인자를 전달하여 해결합니다.

수정 전:

```python
class DHT:
    def __init__(self, data):
        self.data = data
        
    def showData(self):
        print(self.data)

DHT().showData()
```

수정 후:

```python
class DHT:
    def __init__(self, data=None):
        self.data = data if data is not None else {}
        
    def showData(self):
        print(self.data)

# 인자를 전달하거나 기본값으로 인스턴스화
DHT({'six': 6}).showData()
```

## 다른 해결 방법

기본값을 두는 대신 `@classmethod`를 활용한 대체 생성자 패턴으로 기본 데이터가 필요한 생성 방식을 분리할 수도 있습니다. `__init__`의 필수 인자 규칙을 유지하면서 기본 인스턴스를 생성할 수 있습니다.

```python
class DHT:
    def __init__(self, data):
        self.data = data

    @classmethod
    def create_default(cls):
        return cls({'one': '1', 'two': '2', 'three': '3'})

    def showData(self):
        print(self.data)

# 대체 생성자를 통해 인자 없이 호출
DHT.create_default().showData()
```

## 추가 참고사항

`data=None`처럼 기본값을 설정하면 인자가 생략될 때 해당 기본값이 사용됩니다. 단, `None`이 실제로 유효한 데이터일 수도 있다면 기본값을 `None`으로 두는 것만으로는 명시적 미입력과 실제 None 값을 구분할 수 없으므로 별도 sentinel 객체를 사용할 수 있습니다. 객체를 설계할 때 필수 인자와 선택적 인자를 명확히 구분하고, 예상치 못한 입력에 대비해 기본값이나 방어 로직을 구현하는 것이 좋습니다.
