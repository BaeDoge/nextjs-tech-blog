## 현상

클래스를 인스턴스화할 때 `__init__` 메서드가 요구하는 인자를 전달하지 않으면 에러가 발생합니다. 아래는 에러를 재현하는 최소 코드와 출력 원문입니다.

```python
class DHT:
    def __init__(self, data):
        self.data = data

    def showData(self):
        print(self.data)

if __name__ == '__main__':
    DHT().showData()
```

```text
Traceback (most recent call last):
  File "test.py", line 9, in <module>
    DHT().showData()
TypeError: __init__() missing 1 required positional argument: 'data'
```

## 원인

파이썬이 객체를 생성하며 자동으로 호출하는 `__init__` 메서드에 정의된 필수 매개변수 개수와 호출 시 전달된 인자 개수가 일치하지 않아 발생한 것으로 추정됩니다. 클래스 정의 시 `data`라는 위치 인자가 지정되었으나, 객체를 생성하는 `DHT()` 호출 시 아무런 값도 전달되지 않아 파이썬 인터프리터가 `TypeError`를 반환합니다.

## 해결 방법

`__init__` 메서드의 매개변수에 기본값(default value)을 지정하거나, 객체를 생성할 때 올바른 인자를 전달하여 해결합니다.

수정 전:

```python
class DHT:
    def __init__(self, data):
        self.data = data
        
    def showData(self):
        print(self.data)

DHT().showData()
```

수정 후:

```python
class DHT:
    def __init__(self, data=None):
        self.data = data if data is not None else {}
        
    def showData(self):
        print(self.data)

# 인자를 전달하거나 기본값으로 인스턴스화
DHT({'six': 6}).showData()
```

## 다른 해결 방법

기본값을 두는 방식 대신 `@classmethod`를 활용한 대체 생성자 패턴을 사용해 인자 유무에 따른 객체 생성 방식을 분리할 수 있습니다.

```python
class DHT:
    def __init__(self, data):
        self.data = data

    @classmethod
    def create_default(cls):
        return cls({'one': '1', 'two': '2', 'three': '3'})

    def showData(self):
        print(self.data)

# 대체 생성자를 통해 인자 없이 호출
DHT.create_default().showData()
```

## 추가 참고사항

메서드를 정의할 때 인스턴스 메서드의 첫 번째 인자로 `self`를 누락하거나, 클래스 메서드에 `cls`를 누락하면 인자 개수 불일치 에러로 이어질 수 있으므로 주의해야 합니다. 객체를 설계할 때 필수 인자와 선택적 인자를 명확히 구분하고, 예상치 못한 입력에 대비해 기본값이나 방어 로직을 구현하는 것이 좋습니다.
