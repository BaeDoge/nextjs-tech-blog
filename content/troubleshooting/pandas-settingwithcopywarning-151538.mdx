## 현상

다음 코드는 col1에서 값이 10인 항목을 찾아 1000으로 바꾸려는 의도입니다.

~~~~python
import pandas as pd

df = pd.DataFrame({"col1": [10, 20, 10, 30]})
df["col1"][df["col1"] == 10] = 1000
~~~~

이 코드는 열을 먼저 선택한 뒤, 선택된 Series에 다시 조건을 적용해 값을 할당합니다. 이러한 chained assignment는 Pandas 버전에 따라 경고가 발생하거나 원본 DataFrame에 변경 사항이 반영되지 않을 수 있습니다.

## 원인

df["col1"]과 [df["col1"] == 10]은 두 단계의 인덱싱입니다. 중간 결과를 수정하는 형태이므로 원본 df까지 변경되는지 명확하게 보장되지 않습니다.

pandas 2.x에서는 설정과 연산 형태에 따라 SettingWithCopyWarning이 나타날 수 있습니다. pandas 3.0에서는 Copy-on-Write가 기본이기 때문에 chained assignment로 원본 DataFrame을 수정할 수 없으며 ChainedAssignmentError 경고가 발생합니다.

## 해결 방법

원본 DataFrame을 수정할 때는 조건과 대상 열을 한 번의 loc 할당으로 표현합니다.

~~~~python
mask = df["col1"] == 10
df.loc[mask, "col1"] = 1000
~~~~

이 방법은 pandas 2.x와 3.x 모두에서 원본 DataFrame을 명확하게 수정합니다.

여러 열을 함께 수정할 때도 행과 열을 loc으로 한 번에 지정합니다.

~~~~python
cols = ["col1", "col2", "col3"]
df.loc[df["col1"] == 10, cols] = 0
~~~~

## 다른 상황: 별도 복사본을 수정하기

조건에 맞는 행을 원본과 분리해 가공하려는 목적이라면 다음처럼 명시적으로 복사합니다.

~~~~python
df_slice = df.loc[df["col1"] == 10, ["col1"]].copy()
df_slice["col1"] = 1000
~~~~

이 코드는 df_slice만 변경하고 원본 df는 유지합니다.

## 추가 참고사항

- loc은 원본 DataFrame을 수정하려는 경우에 사용합니다.
- copy()는 선택 결과를 별도로 보관하거나 가공하려는 경우에 사용합니다.
- 경고 메시지를 숨기는 것은 원본 변경 여부를 해결하지 않으므로, 먼저 수정 대상이 원본인지 복사본인지 결정해야 합니다.
