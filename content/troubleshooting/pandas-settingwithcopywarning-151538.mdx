## 현상

다음 코드는 col1에서 값이 10인 항목을 찾아 1000으로 바꾸려는 의도입니다.

~~~~python
import pandas as pd

df = pd.DataFrame({"col1": [10, 20, 10, 30]})
df["col1"][df["col1"] == 10] = 1000
~~~~

이 코드는 열을 먼저 선택한 뒤, 선택된 Series에 다시 조건을 적용해 값을 할당합니다. 이러한 chained assignment는 Pandas 버전에 따라 경고가 발생하거나 원본 DataFrame에 변경 사항이 반영되지 않을 수 있습니다.

## 원인

df["col1"]과 [df["col1"] == 10]은 두 단계의 인덱싱입니다. 중간 결과를 수정하는 형태이므로 원본 df까지 변경되는지 명확하게 보장되지 않습니다.

pandas 2.x에서는 설정과 연산 형태에 따라 SettingWithCopyWarning이 나타날 수 있습니다. pandas 3.0에서는 Copy-on-Write가 기본이기 때문에 chained assignment로 원본 DataFrame을 수정할 수 없으며 ChainedAssignmentError 경고가 발생합니다.

여러 열을 동시에 처리할 때도 `.loc`을 활용한다.

```python
# Pandas 2.1 이상: DataFrame.map 사용
cols = ['col1', 'col2', 'col3']
df.loc[:, cols] = df.loc[:, cols].map(some_function)

# 이전 Pandas 버전과 호환해야 한다면 열별 Series.map 사용
df.loc[:, cols] = df.loc[:, cols].apply(lambda column: column.map(some_function))
```

~~~~python
mask = df["col1"] == 10
df.loc[mask, "col1"] = 1000
~~~~

이 방법은 pandas 2.x와 3.x 모두에서 원본 DataFrame을 명확하게 수정합니다.

여러 열을 함께 수정할 때도 행과 열을 loc으로 한 번에 지정합니다.

~~~~python
cols = ["col1", "col2", "col3"]
df.loc[df["col1"] == 10, cols] = 0
~~~~

## 다른 상황: 별도 복사본을 수정하기

조건에 맞는 행을 원본과 분리해 가공하려는 목적이라면 다음처럼 명시적으로 복사합니다.

```python
# 원본 DataFrame에 새 열을 직접 할당
yesterday_result.loc[:, 'date'] = yesterday_result['pubDate'].dt.strftime('%Y-%m-%d %H:%M:%S')
```

## 추가 참고사항

`iterrows()` 루프 내에서 값을 변경할 때는 행 시리즈가 아닌 `.loc`을 통해 원본에 접근해야 한다.

```python
# 원본 미반영 방법
for idx, row in sample_df.iterrows():
    row['score'] = 100

# 올바른 방법
for idx, row in sample_df.iterrows():
    sample_df.loc[idx, 'score'] = 100
```

여러 값을 한꺼번에 변경할 때는 리스트나 튜플을 사용해 명시적으로 할당한다.

```python
sample_df.loc[idx, ['score', 'grade']] = 100, 'A'
```

Pandas 2.x에서는 뷰와 복사본의 모호성 때문에 `SettingWithCopyWarning`이 나타날 수 있습니다. Pandas 3.0에서는 Copy-on-Write가 기본 동작이며, chained assignment로 원본을 수정할 수 없습니다. 원본 DataFrame을 바꾸려면 `df.loc[행 조건, 열] = 값`처럼 한 번의 인덱싱으로 할당해야 합니다. 별도의 결과 DataFrame을 수정하려는 목적이라면 필터링 시 `.copy()`를 명시합니다.
