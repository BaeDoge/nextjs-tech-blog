## 현상

Flask 2.2.2 환경에서 테스트 실행 시 `werkzeug.urls` 모듈에서 `url_quote`를 가져오지 못해 에러가 발생합니다.
에러 메시지는 다음과 같습니다.

<Callout type="warning" title="오류 상황">
ImportError: cannot import name 'url_quote' from 'werkzeug.urls'
</Callout>

에러가 발생하는 최소 환경 및 traceback은 다음과 같습니다.

```text
# 환경
Python 3.10.11
Flask==2.2.2
Werkzeug==3.0.0 (자동 설치됨)

Traceback (most recent call last):
  File ".../flask/app.py", line 30, in <module>
    from werkzeug.urls import url_quote
ImportError: cannot import name 'url_quote' from 'werkzeug.urls'
```

## 원인

Flask 2.2.2는 `werkzeug.urls.url_quote`를 사용하지만, Werkzeug 3.0.0에서 이전에 deprecated된 URL 유틸리티가 제거되었습니다. Flask 2.2.2의 Werkzeug 의존성에는 3.0 미만이라는 상한선이 없어서 최신 Werkzeug가 설치되면 호환되지 않을 수 있습니다. Flask 3.0.0은 반대로 Werkzeug 3.0.0 이상을 요구하므로, Flask와 Werkzeug는 서로 호환되는 버전 조합으로 함께 관리해야 합니다.

## 해결 방법

`requirements.txt` 파일에서 호환되는 `Werkzeug` 버전을 고정합니다.

```
# requirements.txt
Flask==2.2.2
Werkzeug==2.2.2
```

패키지를 다시 설치하여 버전을 맞춥니다.

<Terminal title="실행 명령">
python -m pip install -r requirements.txt\npython -m pip check
</Terminal>

## 다른 해결 방법

`Flask`를 최신 버전으로 업데이트하여 `Werkzeug 3.0.0`과 호환되도록 조치합니다.

```
# requirements.txt
Flask==3.0.0
```

예시 범위는 현재 호환되는 주요 버전 계열을 지정한 것입니다. 실제 배포에서는 검증된 정확한 버전을 lock/constraints 파일에 고정하고, 설치 후 `python -m pip check`와 테스트를 실행합니다.
