## 현상

CSV 파일을 읽거나 텍스트 파일을 열 때 인코딩 오류가 발생한다.
에러 메시지는 'utf-8' 코덱이 특정 위치의 바이트를 해석할 수 없음을 나타낸다.

<Callout type="warning" title="오류 상황">
UnicodeDecodeError: 'utf-8' codec can't decode byte 0x96 in position 35: invalid start byte
</Callout>

```python
import pandas as pd

# UTF-8로 명시했지만 파일이 해당 인코딩이 아닐 경우 발생
Past = pd.read_csv("C:/Users/Admin/Desktop/Python/Past.csv", encoding='utf-8')
```

![현상 스크린샷](/blogs/unicodedecodeerror-162432-1.png)

## 원인

파일이 실제 저장된 인코딩과 코드에서 지정한 인코딩이 서로 다르기 때문이다.
Python 3의 문자열은 유니코드이며, 파일의 원시 바이트를 읽을 때 지정한 코덱으로 변환한다.
Windows에서 사용하는 인코딩은 시스템 언어 설정과 파일을 만든 프로그램에 따라 다릅니다. 한글 Windows 환경의 레거시 파일에서는 CP949가 사용될 수 있고, 서구권 프로그램에서 만든 파일은 CP1252일 수 있습니다. 오류 바이트만으로 인코딩을 단정하지 말고 원본 파일의 내보내기 설정이나 출처를 먼저 확인해야 합니다.
UTF-8이 아닌 바이트를 강제로 UTF-8으로 해석하면 유효하지 않은 시작 바이트 오류가 발생한다.

## 해결 방법

파일 생성 프로그램의 내보내기 설정을 확인하여 실제 인코딩을 찾는다.
pandas의 `encoding` 파라미터에 파일의 실제 인코딩을 명시적으로 지정한다.

```python
import pandas as pd

 # 파일이 실제로 CP1252로 저장된 경우에만 지정
Past = pd.read_csv("C:/Users/Admin/Desktop/Python/Past.csv", encoding='cp1252')
```

<Steps>
<Step title="파일 인코딩 확인">
텍스트 편집기나 파일 생성 프로그램에서 파일의 저장 형식을 확인한다.
</Step>
<Step title="인코딩 파라미터 수정">
`encoding='utf-8'`을 실제 파일 인코딩(예: `cp1252`, `cp949`)으로 변경한다.
</Step>
<Step title="실행 및 검증">
코드를 실행하여 파일이 정상적으로 로드되는지 확인한다.
</Step>
</Steps>

## 다른 해결 방법

원본 인코딩을 알 수 없거나 일부 손실을 감수할 수 있을 때 오류 처리 방식을 변경한다.
`errors` 파라미터를 사용하여 변환 실패 시의 행동을 지정한다.

<Compare>
<ComparePanel title="기존 (strict)" tone="bad">

```python
# 기본값으로, 오류 시 즉시 예외 발생
df = pd.read_csv("data.csv", encoding="utf-8")
```

</ComparePanel>
<ComparePanel title="제안 (replace)" tone="good">

```python
# 오류 발생 바이트를 대체 문자로 변환하여 계속 진행
df = pd.read_csv("data.csv", encoding="utf-8", encoding_encoding_encoding_errors="replace")
```

</ComparePanel>
</Compare>

```python
import pandas as pd

# 인코딩을 utf-8로 유지하되, 오류 발생 시 대체 문자 사용
df = pd.read_csv(
    "data.csv",
    encoding="utf-8",
    encoding_errors="replace"
)
print(df.head())
```

<Callout type="info" title="주의">
`encoding_errors="ignore"`는 디코딩에 실패한 바이트를 버리므로 데이터 손실이 발생할 수 있다.
이름, 금액, 식별자가 포함된 데이터에는 적합하지 않으므로 주의해야 한다.
</Callout>

## 추가 참고사항

일반적인 텍스트 파일 읽기 시에도 동일한 인코딩 규칙이 적용된다.
`open` 함수나 `pathlib`를 사용할 때도 `encoding` 파라미터를 명시해야 한다.

```python
from pathlib import Path

path = Path("data.txt")
# cp949 인코딩으로 파일 읽기
with path.open("r", encoding="cp949") as f:
    text = f.read()

print(text[:100])
```

UTF-8 BOM(Byte Order Mark)이 포함된 파일은 `utf-8-sig` 인코딩을 사용해야 한다.
`utf-8`으로 읽으면 BOM 문자가 텍스트의 일부로 인식되어 데이터 처리에 방해가 될 수 있다.

```python
# UTF-8 BOM이 있는 파일 읽기
with open("data_bom.txt", "r", encoding="utf-8-sig") as f:
    text = f.read()
```
