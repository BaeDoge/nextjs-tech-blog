## 현상

`int()` 함수에 소수점이 포함된 숫자 문자열을 직접 전달하면 파싱 실패로 인해 `ValueError`가 발생합니다.

<Callout type="warning" title="오류 상황">
ValueError: invalid literal for int() with base 10: '23.45678'
</Callout>

이 오류는 일반적인 문자열 변환뿐만 아니라 `pandas` 데이터프레임의 컬럼 타입 변환 시에도 빈번하게 나타납니다.

```python
s = '23.45678'
i = int(s)

import pandas as pd

df = pd.DataFrame({'col': ['0.001']})
df['col'].astype(int)
```

![현상 스크린샷](/blogs/troubleshooting-20261109-140900-1.png)

## 원인

`int()` 내장 함수는 문자열을 10진 정수 리터럴로 해석하는 파싱 로직을 수행합니다. 소수점이 포함된 문자열은 10진 정수 구문에 부합하지 않으므로 파서가 이를 인식하지 못하고 변환을 거부합니다.

<Callout type="info" title="참고">
`int()` 함수는 소수점을 허용하지 않습니다.
</Callout>

## 해결 방법

문자열을 먼저 실수(`float`) 타입으로 변환하여 소수점을 포함하는 숫자 값으로 만든 후, 이를 다시 `int()`로 변환해야 합니다.

```python
s = '23.45678'
i = int(float(s))
```

`pandas` 컬럼의 경우, `astype()` 메서드를 통해 `float`로 중간 변환한 뒤 `int`로 변환하는 과정을 거칩니다.

```python
import pandas as pd

df = pd.DataFrame({'col': ['0.001']})
df['col'] = df['col'].astype(float).astype(int)
```

## 다른 해결 방법

`decimal` 모듈의 `Decimal` 클래스를 사용하면 높은 정밀도로 실수를 처리한 후 정수화할 수 있습니다.

```python
from decimal import Decimal

s = '23.45678'
i = int(Decimal(s))
```

`pandas` 환경에서는 `apply`와 `split`을 조합하여 소수점 이전 부분만 추출한 후 `int()`로 변환할 수 있습니다. 이 방식은 `float` 변환 시 발생할 수 있는 부동소수점 정밀도 이슈를 우회합니다.

```python
import pandas as pd

df = pd.DataFrame({'col': ['0.001']})
df['col'] = df['col'].apply(lambda x: int(x.split('.')[0]))
```

## 추가 참고사항

타입 변환 전 변수의 타입을 `type()` 함수로 확인하면 의도치 않은 에러를 방지할 수 있습니다.

```python
money = "777"
print(type(money))  # <class 'str'>
```

문자열 타입의 값과 정수 타입의 값을 직접 사칙연산하면 `TypeError: must be str, not int`가 발생합니다. 계산 전 반드시 타입을 일치시켜야 합니다.

```python
money = "777"
print(int(money) + 333)
```
