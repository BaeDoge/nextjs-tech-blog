## 한눈에 보는 프로젝트와 해결하려는 문제

Perfetto는 안드로이드와 크로미움(Chromium) 프로젝트의 표준 트레이싱 시스템으로, 시스템 전반의 성능 데이터를 수집하고 분석하는 도구 모음입니다. 현대 소프트웨어 시스템은 커널 스케줄링, 사용자 공간의 라이브러리 호출, 가비지 컬렉션, GPU 렌더링 등 수많은 이벤트가 동시에 발생하며, 이로 인해 발생하는 병목 현상이나 'Jank(프레임 드롭)', ANR(Application Not Responding)과 같은 문제를 추적하는 것은 매우 어렵습니다.

Perfetto는 이러한 문제를 해결하기 위해 시스템 전체의 이벤트를 단일 타임라인으로 통합하고, 이를 SQL 기반으로 쿼리하여 복잡한 성능 지표를 정량적으로 분석할 수 있는 환경을 제공합니다. 이 프로젝트는 단순한 로깅 도구가 아니라, 수 기가바이트(GB)에 달하는 대규모 트레이스 데이터를 효율적으로 처리하는 성능 분석 플랫폼입니다.

## 이해에 필요한 핵심 개념

Perfetto를 이해하기 위해서는 다음의 세 가지 핵심 구성 요소를 파악해야 합니다.

1. **Tracing Daemons (`traced`, `traced_probes`)**: 시스템 전반의 데이터를 수집하는 백그라운드 프로세스입니다. 커널의 `ftrace` 이벤트, CPU 스케줄링, 메모리 사용량 등을 수집하여 하나의 트레이스 파일로 통합합니다.
2. **Trace Processor**: Perfetto의 분석 엔진입니다. 트레이스 파일을 SQL 데이터베이스로 변환하여 사용자가 `SELECT`, `JOIN` 등의 표준 SQL 문법을 통해 성능 데이터를 탐색할 수 있게 합니다.
3. **Tracing SDK**: 애플리케이션 개발자가 자신의 코드 내부에 직접 트레이스 포인트를 심을 수 있도록 지원하는 C++ 및 Rust 라이브러리입니다. 이를 통해 시스템 이벤트와 애플리케이션 내부 로직을 동일한 타임라인에서 비교할 수 있습니다.

## 저장소 구조와 실제 동작 흐름

저장소는 데이터 수집, 변환, 분석을 위한 핵심 로직을 포함하고 있습니다.

- `src/`: 핵심 로직이 위치합니다. `src/traceconv/`는 다양한 트레이스 포맷(Chrome JSON, Linux `perf` 등)을 Perfetto 포맷으로 변환하는 도구이며, `src/protovm/`은 프로토콜 버퍼 기반의 가상 머신 구조를 통해 트레이스 데이터를 해석하는 로직을 포함합니다.
- `infra/` 및 `.github/`: CI/CD 파이프라인을 구성하며, 안드로이드 및 크로미움 환경과의 통합 테스트를 자동화합니다.

동작 흐름은 일반적으로 '기록(Record) → 변환/파싱(Parse) → 분석(Query)' 순으로 진행됩니다. 사용자가 `record_android_trace`와 같은 도구로 데이터를 수집하면, `Trace Processor`가 이를 읽어 들여 SQL 테이블로 구조화하고, 사용자는 UI 또는 CLI를 통해 이를 조회합니다.

## 구체적인 예제로 보는 설계 선택

Perfetto는 성능 데이터를 다루는 도구인 만큼, 데이터 처리의 효율성을 극대화하는 설계를 채택하고 있습니다. `src/protovm/parser.h`에서는 프로토콜 버퍼 기반의 가상 머신(VM) 구조를 사용하여 트레이스 데이터를 해석합니다. 이는 복잡한 트레이스 포맷을 유연하게 확장하면서도, 실행 시점의 성능을 최적화하기 위한 설계로 보입니다. 사용자가 직접 SQL로 데이터를 쿼리할 수 있게 한 점은, 고정된 대시보드만 제공하는 기존 도구들과 달리 분석가가 자신의 가설을 즉각적으로 검증할 수 있게 합니다.

## 대안과 비교했을 때의 장단점

기존의 `systrace`나 `chrome://tracing`과 비교했을 때, Perfetto의 가장 큰 장점은 **확장성**과 **분석 유연성**입니다.

- **장점**: SQL 기반 분석을 통해 수백만 개의 이벤트를 순식간에 집계할 수 있습니다. 또한 C++/Rust SDK를 통해 커스텀 계측이 매우 용이합니다.
- **단점**: SQL 문법과 트레이스 스키마에 대한 학습 곡선이 존재합니다. 단순히 시각화만 필요한 사용자에게는 초기 설정과 학습 과정이 다소 복잡하게 느껴질 수 있습니다.

## 보안·라이선스·도입 시 확인할 점

- **라이선스**: Apache-2.0 라이선스를 따르며, 기업 환경에서 상업적 이용 및 수정이 자유롭습니다.
- **보안**: Perfetto UI는 로컬 브라우저에서 분석을 수행하는 기능을 제공하지만, `Trace Processor`는 분석 환경에 따라 서버-클라이언트 아키텍처를 지원할 수 있습니다. 따라서 민감한 성능 데이터를 다룰 때는 데이터가 외부 서버로 전송되지 않도록 배포 환경을 확인해야 합니다.
- **도입 시**: 안드로이드/리눅스 환경에서는 이미 표준으로 자리 잡고 있으므로 도입이 쉽지만, 자체 애플리케이션에 도입할 때는 SDK의 오버헤드를 측정하여 프로덕션 환경에서의 성능 영향을 검증해야 합니다.

## 한계와 추천 대상

Perfetto는 시스템 레벨의 깊은 분석이 필요한 성능 엔지니어, 안드로이드 플랫폼 개발자, 그리고 복잡한 멀티스레드 애플리케이션을 최적화해야 하는 C++/Rust 개발자에게 강력히 추천합니다.

반면, 단순한 함수 호출 빈도나 간단한 로깅 수준의 분석을 원하는 경우에는 도구의 복잡도가 과할 수 있습니다. 또한, 트레이스 데이터의 구조가 방대하여 특정 도메인(예: 커널 스케줄러, 메모리 할당자)에 대한 지식이 부족하면 데이터 해석에 어려움을 겪을 수 있습니다. 따라서 도입 전 공식 문서의 'Getting Started' 가이드를 통해 자신의 분석 목적이 Perfetto의 SQL 분석 모델과 일치하는지 확인하는 과정이 필수적입니다.
