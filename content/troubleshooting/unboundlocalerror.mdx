## 현상

함수 외부에서 선언한 전역 변수를 함수 내에서 참조만 한다면 문제가 없지만, 할당 연산(`=`, `+=` 등)을 수행하려고 하면 에러가 발생합니다.

```python
test1 = 0
def test_func():
    test1 += 1
test_func()
```

에러 원문은 다음과 같이 출력됩니다.

```
UnboundLocalError: local variable 'test1' referenced before assignment
```

![현상 스크린샷](/blogs/unboundlocalerror-1.png)

## 원인

파이썬의 스코핑 규칙에 따라, 함수 내에서 변수에 대한 할당 문장이 하나라도 존재하면 해당 변수는 전역 변수가 아닌 지역 변수로 취급됩니다.

`+=` 연산은 변수의 현재 값을 참조하여 계산한 후, 그 결과를 다시 변수에 할당하는 복합 연산입니다.

따라서 함수 내부의 `test1 += 1` 문장은 `test1`을 지역 변수로 정의하는 행위로 간주되어, 할당 전에 참조하려고 하는 단계에서 에러가 발생합니다.

## 해결 방법

함수 내에서 수정하려는 변수가 전역 변수임을 명시적으로 알려주어야 합니다. 이를 위해 `global` 키워드를 사용합니다.

```python
test1 = 0

def test_func():
    global test1 
    test1 += 1

test_func()
```

![해결 방법 스크린샷](/blogs/unboundlocalerror-2.png)

## 다른 해결 방법

함수 밖의 전역 변수를 직접 수정하는 대신, 인자를 받아서 새로운 값을 반환하는 순수 함수 방식으로 구현할 수 있습니다.

```python
test1 = 0

def test_func(value):
    return value + 1

test1 = test_func(test1)
```

이 방법은 상태 변경이 아닌 데이터 흐름을 명확히 하여 부작용을 줄일 수 있는 접근 방식입니다.

## 추가 참고사항

함수 내에서 변수를 읽기만 할 때는 `global` 키워드를 사용하지 않아도 전역 변수를 정상적으로 참조할 수 있습니다.

중첩 함수의 경우, 바깥쪽 함수의 지역 변수를 수정하려면 `global` 대신 `nonlocal` 키워드를 사용해야 합니다.

`nonlocal`은 전역 변수가 아닌, 가장 가까운 외부 스코프의 변수를 대상으로 한다는 점이 `global`과 다릅니다.
