## 현상

파이썬 코드를 실행하거나 스크립트를 실행하는 과정에서 `IndentationError: unexpected indent` 오류가 발생합니다. 이는 코드의 들여쓰기(인덴트)가 예상치 못한 위치에서 사용되었을 때 발생합니다.

<Callout type="warning" title="오류 상황">
IndentationError: unexpected indent
</Callout>

에러가 발생하는 대표적인 예시는 다음과 같습니다.

```python
def greet():
    print("Hello")
        print("Again")  # 불필요한 들여쓰기 → 오류 발생
```

또는 블록을 요구하는 문장 다음에 들여쓰기 수준이 일관되지 않거나, 탭과 공백을 혼용했을 때도 동일한 문제가 발생합니다.

```python
def greet():
print("Hello")  # 들여쓰기 없음 → 오류 발생
```

## 원인

파이썬은 다른 언어와 달리 코드 블록을 구분하기 위해 중괄호(`{}`)를 사용하지 않고, 들여쓰기를 통해 문장의 구조를 파악합니다. 따라서 들여쓰기는 단순한 가독성을 넘어 문법 그 자체입니다.

이 오류가 발생하는 주요 원인은 다음과 같습니다.

1. **블록 외부의 불필요한 들여쓰기**: 함수나 조건문 블록 외부에서 코드가 들여쓰기되어 있는 경우입니다.
2. **들여쓰기 수준의 불일치**: 같은 코드 블록 내에서 들여쓰기 깊이가 일정하지 않은 경우입니다.
3. **탭과 공백의 혼용**: 눈에 보이지는 않지만, 탭(`Tab`) 문자와 공백(`Space`) 문자를 섞어 사용하여 파이썬 인터프리터가 들여쓰기 깊이를 정확히 계산하지 못하는 경우입니다.

```python
# 원인 1: 블록 외부 들여쓰기
 print("첫 번째 줄")  # <- 여기 앞에 공백이 하나 숨어있음! (에러 발생)

# 원인 2: 들여쓰기 수준 불일치
def func():
    print("A")
      print("B")  # 들여쓰기 깊이가 A와 다름
```

## 해결 방법

가장 확실한 해결 방법은 PEP 8 가이드라인에 따라 **공백 4칸**을 일관되게 사용하는 것입니다.

1. 에러가 발생한 줄의 맨 앞으로 커서를 이동합니다.
2. 해당 줄의 앞부분에 있는 모든 공백과 탭을 삭제합니다.
3. 블록 내부라면 적절한 깊이만큼 공백 4칸을 입력합니다.

수정 전후 코드는 다음과 같습니다.

<Compare>
<ComparePanel title="수정 전 (오류)" tone="bad">

```python
def greet():
        print("Hello")  # 불필요한 들여쓰기
```

</ComparePanel>
<ComparePanel title="수정 후 (정상)" tone="good">

```python
def greet():
    print("Hello")  # 공백 4칸으로 통일
```

</ComparePanel>
</Compare>

에디터의 자동 들여쓰기 정렬 기능을 활용하여 코드 전체의 들여쓰기를 일관되게 맞추는 것도 효과적입니다.

## 다른 해결 방법

탭과 공백을 섞어 사용한 경우에는 에디터에서 공백 표시 기능을 켜고 들여쓰기를 통일합니다. Python 3은 탭과 공백을 혼용해 들여쓰기 의미가 모호해지면 `TabError`를 발생시킵니다.

1. **에디터 설정 변경**: 사용하는 에디터(예: Vim, VS Code 등)에서 '탭을 공백으로 변환' 설정을 활성화합니다.
2. **자동 검사**: `tabnanny` 모듈을 실행하면 들여쓰기의 모호한 부분을 확인할 수 있습니다.

<Terminal title="실행 예시">
python -m tabnanny your_script.py
</Terminal>

<Callout type="info" title="에디터 팁">
Vim의 경우 `'list'` 옵션을 활성화하면 탭과 공백을 시각적으로 구분할 수 있어 실수를 줄일 수 있습니다.
</Callout>

## 추가 참고사항

`IndentationError`는 파이썬 초보자가 가장 많이 마주하는 오류 중 하나입니다. 유사한 에러 메시지로 `IndentationError: expected an indented block`이 있습니다. 이는 `if`, `for`, `def` 등 콜론(`:`)으로 끝난 문장 다음 줄에 들여쓰기가 누락되었을 때 발생합니다.

```python
# IndentationError: expected an indented block 예시
if True:
print("참입니다")  # 콜론 다음 줄은 무조건 들여쓰기 필요
```

이러한 오류를 예방하기 위해서는 코드 작성 시 자동 정렬 기능을 적극 활용하고, 탭과 공백을 혼용하지 않는 습관을 들이는 것이 중요합니다.
