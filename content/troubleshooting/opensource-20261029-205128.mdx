## 한눈에 보는 프로젝트와 해결하려는 문제

`EbookFoundation/free-programming-books`는 프로그래밍 학습에 필요한 무료 자원을 한곳에 모아 관리하는 대규모 큐레이션 프로젝트입니다. 이 프로젝트는 파편화된 무료 프로그래밍 도서와 강의 링크를 체계적으로 정리하여, 학습자가 양질의 교육 자료를 쉽게 찾을 수 있도록 돕는 것을 목표로 합니다. 2013년에 시작된 이래 수많은 기여자가 참여하고 있으며, 단순히 링크를 나열하는 것을 넘어 다양한 언어와 주제별로 분류하여 접근성을 높이고 있습니다.

## 이해에 필요한 핵심 개념

이 프로젝트를 이해하기 위한 핵심 개념은 '커뮤니티 주도형 큐레이션'과 '마크다운 기반의 구조화'입니다.

1. **커뮤니티 큐레이션**: 프로젝트는 특정 개인이 관리하는 것이 아니라, GitHub의 Pull Request(PR) 시스템을 통해 전 세계 기여자들이 새로운 자료를 추가하거나 유효하지 않은 링크를 수정하는 방식으로 운영됩니다.
2. **마크다운 구조화**: 모든 자원은 `books/`, `courses/`, `casts/`와 같은 디렉터리 내의 마크다운(.md) 파일로 관리됩니다. 이는 기여자가 별도의 복잡한 도구 없이도 텍스트 에디터만으로 쉽게 정보를 업데이트할 수 있게 합니다.
3. **다국어 지원**: 언어별로 파일을 분리하여 관리함으로써, 영어권 자료뿐만 아니라 한국어, 중국어, 아랍어 등 다양한 언어권의 학습자가 자신의 모국어로 된 자료를 쉽게 탐색할 수 있도록 설계되었습니다.

## 저장소 구조와 실제 동작 흐름

저장소는 자료의 성격과 언어에 따라 명확하게 폴더가 나뉘어 있습니다.

- `books/`: 프로그래밍 도서 목록을 언어별 마크다운 파일로 관리합니다. 예를 들어 `books/free-programming-books-ko.md`는 한국어 프로그래밍 도서 목록을 담고 있습니다.
- `courses/`: 무료 온라인 강의 자원을 언어별로 분류합니다.
- `casts/`: 팟캐스트 및 스크린캐스트 자료를 관리합니다.
- `scripts/`: 프로젝트의 품질을 유지하기 위한 자동화 도구가 포함되어 있습니다.

사용자는 GitHub 저장소의 README를 통해 원하는 카테고리(도서, 강의, 팟캐스트)를 선택하고, 자신의 언어에 맞는 마크다운 파일을 클릭하여 링크 목록을 확인합니다. 기여자는 수정이 필요한 경우 해당 파일을 수정하여 PR을 제출하며, 이는 프로젝트 관리자의 검토를 거쳐 `main` 브랜치에 병합됩니다.

## 구체적인 예제로 보는 설계 선택

`scripts/rtl_ltr_linter.py`는 이 프로젝트가 다국어 환경을 얼마나 세심하게 고려하는지 보여주는 사례입니다. 이 스크립트는 마크다운 파일 내에서 RTL(Right-To-Left, 아랍어 등 오른쪽에서 왼쪽으로 읽는 언어)과 LTR(Left-To-Right, 영어 등 왼쪽에서 오른쪽으로 읽는 언어)이 혼용될 때 발생할 수 있는 가독성 문제를 탐지합니다.

```python
def split_by_span(text, base_ctx):
    """
    Splits text into segments based on nested <span> tags with dir attributes.
    """
    # 실제 구현은 텍스트 내의 특정 태그를 기준으로 문맥을 분리하는 로직을 포함함
    return segments
```

이 설계는 단순히 링크를 나열하는 것을 넘어, 다양한 언어권의 사용자가 문서를 읽을 때 겪을 수 있는 기술적 불편함을 자동화된 스크립트로 해결하려는 의도를 보여줍니다. `split_by_span` 함수는 텍스트 내의 방향성 속성을 파악하여, 언어 혼용 시 발생할 수 있는 시각적 오류를 방지하려는 목적으로 설계되었습니다.

## 대안과 비교했을 때의 장단점

이 프로젝트는 개인 블로그나 사설 위키와 비교했을 때 다음과 같은 차이점이 있습니다.

- **장점**: GitHub의 버전 관리 시스템을 활용하므로 변경 이력이 투명하며, 전 세계 기여자가 실시간으로 링크의 유효성을 검증합니다. 또한, 특정 플랫폼에 종속되지 않는 마크다운 형식을 사용하여 데이터의 이식성이 매우 높습니다.
- **단점**: 중앙 집중식 데이터베이스가 아니므로, 검색 기능이 외부 서비스에 의존하거나 마크다운 파일 자체를 탐색해야 합니다. 또한, 링크의 유효성 검증이 자동화되어 있더라도 수만 개의 링크를 실시간으로 모두 관리하는 데에는 물리적인 한계가 존재합니다.

## 보안·라이선스·도입 시 확인할 점

- **라이선스**: 이 프로젝트는 `CC-BY-4.0` 라이선스를 따릅니다. 이는 저작자 표시를 조건으로 자료의 공유와 변형을 허용함을 의미합니다. 사용자는 이 라이선스 조건을 준수해야 합니다.
- **도입 시 주의사항**: 프로젝트 내에 포함된 외부 링크는 제3자가 운영하는 사이트입니다. 따라서 링크된 사이트의 보안 상태나 콘텐츠의 최신성은 보장되지 않습니다. 학습 목적으로 활용할 때 해당 사이트의 신뢰성을 개별적으로 확인하는 과정이 필요합니다.

## 한계와 추천 대상

이 프로젝트는 프로그래밍 학습을 시작하려는 초보자부터 특정 기술의 심화 학습을 원하는 숙련자까지 모두에게 유용합니다. 특히 유료 강의를 결제하기 전, 무료로 양질의 정보를 얻고자 하는 학습자에게 최적의 자원입니다.

다만, 링크의 수가 방대하기 때문에 특정 기술의 최신 버전과 일치하지 않는 오래된 자료가 포함되어 있을 수 있습니다. 따라서 이 프로젝트를 학습 경로의 '참고 자료'로 활용하되, 학습 중인 기술의 공식 문서와 병행하여 사용하는 것을 추천합니다.
