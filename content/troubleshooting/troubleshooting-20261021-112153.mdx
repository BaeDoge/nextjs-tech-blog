## 현상

Windows 환경에서 Python을 설치한 후 명령 프롬프트에서 `pip` 명령어를 실행하면 해당 명령어를 인식하지 못한다는 에러가 발생합니다. Python 설치가 완료되었음에도 불구하고 패키지를 설치하거나 업그레이드하는 과정에서 아래 에러가 반복됩니다.

```cmd
C:\> pip install Django
'pip' is not recognized as an internal or external command,
operable program or batch file.
```

`echo %PATH%` 명령어를 통해 현재 환경 변수를 확인했을 때, Python이나 pip가 설치된 경로가 포함되어 있지 않은 것이 주요 원인입니다.

![현상 스크린샷](/blogs/troubleshooting-20261021-112153-1.png)

## 원인

Windows 명령 프롬프트(CMD)는 명령어를 실행할 때 시스템의 PATH 환경 변수에 등록된 디렉토리들을 순서대로 검색합니다. pip가 설치된 폴더가 이 PATH 목록에 등록되어 있지 않으면, OS는 해당 명령어를 찾을 수 없으므로 실행을 거부합니다. 즉, Python 설치가 완료되어도 실행 파일이 있는 폴더가 시스템의 검색 경로에 포함되지 않으면 명령어를 사용할 수 없습니다.

## 해결 방법

먼저 `pip` 실행 파일의 PATH를 직접 수정하기보다, 현재 선택한 Python 인터프리터를 통해 pip를 실행하는 방법을 권장합니다. 이 방식은 여러 Python 버전이 설치된 환경에서도 해당 인터프리터와 연결된 pip를 사용합니다.

```cmd
python -m pip --version
python -m pip install Django
```

Windows Python Launcher를 사용할 수 있는 환경이라면 다음 명령도 사용할 수 있습니다.

```cmd
py -m pip --version
py -m pip install Django
```

`python -m pip --version` 또는 `py -m pip --version` 실행 자체가 실패한다면, Python 설치 상태와 실행 경로를 먼저 확인합니다.

```cmd
where python
where py
python -m pip --version
```

`pip` 명령을 직접 사용해야 한다면, 현재 Python 인터프리터의 Scripts 디렉터리를 확인합니다.

```cmd
python -c "import sysconfig; print(sysconfig.get_path('scripts'))"
```

출력된 디렉터리가 예를 들어 `C:\Python34\Scripts`라면, 다음 명령으로 현재 열려 있는 CMD 세션에서만 임시로 PATH에 추가할 수 있습니다. 실제 경로는 앞 단계에서 확인한 값으로 바꿔야 합니다.

```cmd
set "PATH=%PATH%;C:\Python34\Scripts"
pip --version
```

영구적으로 적용하려면 Windows의 **환경 변수 편집 화면**에서 사용자 변수의 `Path`를 선택하고 **편집 → 새로 만들기**를 눌러 실제 `Scripts` 경로를 별도 항목으로 추가합니다. 기존 PATH 문자열 전체를 복사해 덮어쓰지 말고, 새 항목으로 추가하는 편이 안전합니다. 설정을 저장한 뒤 새 CMD 창을 열어 확인합니다.

```cmd
pip --version
pip install Django
```

`setx PATH "%PATH%;..."`처럼 PATH 전체를 명령으로 다시 저장하는 방식은 기존 항목 중복이나 사용자 PATH 덮어쓰기 문제를 만들 수 있으므로, 영구 설정에는 환경 변수 편집 화면을 사용하는 편을 권장합니다.

## 다른 해결 방법

PATH 설정이 아닌 경우, Python 모듈로 직접 pip를 호출하는 방법을 사용할 수 있습니다. 이 방법은 PATH 경로가 불명확하거나 시스템 변수 설정 권한이 없는 경우 유용합니다.

```cmd
python -m pip install Django
```

또는 현재 사용 중인 Python 인터프리터의 위치를 확인한 후, 그 경로의 하위 `Scripts` 폴더에 있는 `pip.exe`를 직접 실행할 수도 있습니다. Python 설치 위치가 `C:\Python34`라면 다음과 같이 실행합니다.

```cmd
C:\Python34\Scripts\pip.exe install Django
```

## 추가 참고사항

- Python 3.4 이상 버전에서 공식 설치 프로그램(Installer)을 사용하면 pip가 함께 번들로 제공되지만, Zip 파일이나 다른 설치 방식을 사용한 경우 `get-pip.py` 스크립트를 통해 수동으로 설치해야 할 수 있습니다.
- pip 업그레이드 시 `[WinError 5] 액세스가 거부되었습니다` 오류가 발생하면, `--user` 옵션을 추가하여 현재 사용자 권한으로 설치하거나 관리자 권한으로 명령 프롬프트를 실행해야 합니다.

```cmd
python -m pip install --upgrade pip --user
```

- 환경 변수 변경은 이미 열려 있는 CMD 창에 자동 반영되지 않습니다. 새 CMD 창을 열고 `where pip`, `pip --version`으로 확인합니다.\n- `python -m pip`는 동작하지만 `pip`만 인식되지 않는다면, pip 자체가 아니라 `Scripts` 디렉터리의 PATH 등록 문제일 가능성이 높습니다.
