## 현상

함수 밖에서 전역 변수를 선언하고, 함수 내부에서 해당 변수를 참조하여 계산하려고 하면 에러가 발생합니다. 변수에 할당문이 존재하지 않더라도, 함수 내에서 해당 변수를 읽는 순간 Python은 이를 지역 변수로 간주하여 초기화되지 않은 상태로 접근하려는 시도를 합니다.

<Callout type="warning" title="오류 상황">
UnboundLocalError: local variable 'c' referenced before assignment
</Callout>

에러가 발생하는 최소 재현 코드는 다음과 같습니다.

```python
c = 1

def f(n):
    print(c + n)  # 정상 동작

def g(n):
    c = c + n     # c를 읽으려는 시점에서 에러 발생

f(1)  # => 2
g(1)  # => UnboundLocalError 발생
```

## 원인

Python의 스코프 규칙에 따라 함수 내에서 변수에 할당(대입) 연산을 수행하려는 코드가 존재하면, Python은 해당 변수를 함수의 지역 변수로 취급합니다. 이는 컴파일 시점이나 실행 시작 시점에 결정됩니다.

함수 `g` 내에서 `c = c + n` 문이 존재하기 때문에, Python은 `c`를 지역 변수로 선언된 것으로 판단합니다. 그러나 우변의 `c`가 평가되는 시점에는 아직 지역 변수 `c`에 값이 할당되지 않은 상태이므로, 할당되지 않은 지역 변수를 참조했다는 에러가 발생합니다. 반면 함수 `f`는 변수 `c`에 할당문을 가지고 있지 않기 때문에 전역 변수 `c`를 정상적으로 참조합니다.

## 해결 방법

함수 내에서 전역 변수를 읽고 싶으며, 동시에 값을 갱신하려면 `global` 키워드를 사용하여 변수를 전역 범위로 명시해야 합니다. 이를 통해 Python이 해당 변수를 지역 변수가 아닌 전역 스코프에서 찾도록 유도합니다.

<Compare>
<ComparePanel title="기존 (오류)" tone="bad">
def g(n):
    c = c + n
</ComparePanel>
<ComparePanel title="제안 (global 키워드 사용)" tone="good">
def g(n):
    global c
    c = c + n
</ComparePanel>
</Compare>

수정된 코드는 다음과 같습니다. 함수 내부의 할당 문 앞쪽에 `global c`를 선언하면 에러 없이 정상 작동합니다.

```python
c = 1

def g(n):
    global c
    c = c + n

g(1)  # => 2
```

## 다른 해결 방법

전역 변수의 변경을 피하고, 함수의 인자로 값을 받아 반환하는 방식을 사용할 수 있습니다. 이 방법은 전역 상태를 변경하지 않으므로 스코프 혼란을 원천적으로 차단합니다.

```python
def g(n, c):
    return c + n

c = 1
result = g(1, c)  # => 2
```

## 추가 참고사항

변수 스코프 혼동은 Python 개발 시 흔히 발생하는 문제입니다. 전역 변수를 사용할 때는 `global` 키워드를 명시적으로 사용하여 의도를 분명히 하는 것이 좋습니다.

또한, 리스트나 딕셔너리 같은 가변 객체의 경우 할당문 없이 요소만 수정하는 것(`append`, `update` 등)은 전역 변수를 변경하는 것으로 간주되지 않으므로 `global` 선언 없이도 수정이 가능합니다. 이는 가변 객체의 메서드를 호출하는 것은 변수 자체에 새로운 값을 할당하는 것이 아니기 때문입니다.

```python
a = ["tom", "jerry", "mike"]
jjak = []

def findjjak(lst):
    for i in range(0, len(lst) - 1):
        for j in range(i + 1, len(lst)):
            jjak.append(a[i] + '-' + a[j])  # 전역 리스트에 요소 추가

findjjak(a)
print(jjak)  # => ['tom-jerry', 'tom-mike', 'jerry-mike']
```

하지만 정수형 같은 불변 객체는 반드시 `global` 키워드나 인자/반환값 패턴을 사용해야 합니다.

<Callout type="info" title="참고">
Python에서는 함수 밖에서 변수를 선언하더라도 함수 내에서 값을 재할당하려는 의도가 있으면 해당 변수는 전역 변수가 아닌 지역 변수가 됩니다.
</Callout>
