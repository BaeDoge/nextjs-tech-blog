## 현상

Python 3에서 외부 함수의 변수를 참조하는 클로저 내부에서 해당 변수를 증감 연산(`+=`)하면 `UnboundLocalError`가 발생합니다.

<Callout type="warning" title="오류 상황">

```python
UnboundLocalError: local variable 'counter' referenced before assignment
```

</Callout>

에러를 재현하는 최소 코드는 다음과 같습니다.

```python
def foo():
    counter = 1
    def bar():
        counter += 1  # 재할당 시도
        print("bar", counter)
    return bar

bar = foo()
bar()
```

## 원인

Python은 함수 내부에서 변수에 값을 할당하는 문장이 존재하면, 해당 변수를 지역 변수로 간주합니다.

클로저 내부에서 `counter += 1`은 `counter = counter + 1`과 동일하게 동작합니다.

이때 우변의 `counter`를 참조하는 시점에는 아직 지역 변수가 초기화되지 않은 상태이므로 에러가 발생합니다.

## 해결 방법

Python 3에서는 `nonlocal` 키워드를 사용하여 외부 스코프의 변수를 재할당 가능하게 만들 수 있습니다.

<Steps>
<Step title="nonlocal 키워드 추가">
클로저 함수 내부에서 수정하려는 변수 앞에 `nonlocal` 키워드를 명시합니다.
</Step>
<Step title="변수 재할당 허용">
이제 클로저 내에서 외부 변수의 값을 변경할 수 있습니다.
</Step>
</Steps>

수정된 코드는 다음과 같습니다.

```python
def foo():
    counter = 1

    def bar():
        nonlocal counter  # 외부 변수 참조 및 재할당 허용
        counter += 1
        print("bar", counter)

    return bar

bar = foo()
bar()
```

## 다른 해결 방법

Python 2에서는 `nonlocal` 키워드를 지원하지 않으므로 다른 접근이 필요합니다.

<Compare>
<ComparePanel title="Python 2 대응 (가변 객체 사용)" tone="good">
가변 객체(리스트, 딕셔너리 등)를 사용하여 참조는 유지하면서 내부 값만 변경합니다.
</ComparePanel>
<ComparePanel title="클래스 기반 접근" tone="good">
클로저 대신 클래스의 인스턴스 메서드를 사용하여 상태를 관리합니다.
</ComparePanel>
</Compare>

리스트를 활용한 Python 2 호환 해결 예시입니다.

```python
def foo():
    counter = [1]  # 리스트로 감싸서 가변 객체 사용

    def bar():
        counter[0] += 1  # 참조는 동일, 값만 변경
        print("bar", counter[0])

    return bar

bar = foo()
bar()
```

클래스 기반 해결 예시입니다.

```python
class Foo:
    def __init__(self, counter=1):
        self.counter = counter

    def __call__(self):
        self.counter += 1
        print("bar", self.counter)

bar = Foo()
bar()
```

## 추가 참고사항

가변 객체를 사용할 경우, 변수명 자체를 재할당(`counter = [...]`)하면 클로저가 깨질 수 있으므로 주의해야 합니다.

이러한 상태 유지가 필요한 경우, 클래스 인스턴스나 제너레이터를 고려할 수 있습니다.

<Checklist>
<ul>
<li>Python 3 환경에서는 `nonlocal` 키워드를 우선 사용한다.</li>
<li>Python 2 환경에서는 리스트나 딕셔너리 등 가변 객체를 활용한다.</li>
<li>클로저 내 변수 재할당은 항상 `nonlocal` 또는 가변 객체를 통해 처리한다.</li>
</ul>
</Checklist>
