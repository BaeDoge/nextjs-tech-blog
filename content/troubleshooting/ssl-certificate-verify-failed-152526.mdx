## 현상

Python 스크립트나 패키지 설치 중 HTTPS 연결이 다음과 같은 인증서 검증 오류로 실패할 수 있습니다.

```text
[SSL: CERTIFICATE_VERIFY_FAILED] certificate verify failed:
unable to get local issuer certificate
```

`requests`를 이용한 API 호출이나 `pip install`에서도 비슷한 오류가 나타날 수 있지만, 두 도구가 사용하는 인증서 설정은 같지 않을 수 있습니다.

## 원인

대표적인 원인은 다음과 같습니다.

- CA 인증서 묶음이 오래되었거나 누락되었습니다.
- 회사 프록시가 HTTPS 인증서를 교체하지만, 해당 프록시의 사내 CA가 신뢰 목록에 없습니다.
- 서버가 중간 인증서를 누락했거나 인증서가 만료되었습니다.
- 오래된 운영체제 또는 Python 환경이 현재의 TLS·루트 인증서 체계와 맞지 않습니다.

`requests`는 기본적으로 `certifi` 패키지가 제공하는 CA 묶음을 사용합니다. Python 표준 `ssl` 모듈과 `pip`는 환경 및 버전에 따라 기본 인증서 저장소를 다르게 사용할 수 있으므로, 모든 Python HTTPS 연결에 `certifi`만 적용된다고 단정하면 안 됩니다.

## 해결 방법 1. requests에서 사용하는 CA 번들 확인

```python
import requests
import certifi

print("requests CA bundle:", requests.certs.where())
print("certifi CA bundle:", certifi.where())
```

오래된 CA 묶음이 원인이라면 해당 Python 환경에서 업데이트합니다.

```bash
python -m pip install --upgrade requests certifi
```

## 해결 방법 2. 사내 CA 인증서를 명시하기

회사 프록시가 자체 CA로 인증서를 발급하는 환경이라면, 사내 보안·인프라 담당자가 제공한 PEM 형식의 CA 인증서를 사용합니다.

```python
import requests

response = requests.get(
    "https://internal.example.com",
    verify=r"C:\certs\company-ca.pem",
    timeout=15,
)
response.raise_for_status()
```

`requests`에서 모든 요청에 같은 CA 번들을 사용할 때는 `REQUESTS_CA_BUNDLE` 환경 변수를 지정할 수 있습니다.

```bat
set REQUESTS_CA_BUNDLE=C:\certs\company-ca.pem
```

## pip 설치에서 같은 오류가 발생한다면

`pip`는 별도의 인증서 설정을 가질 수 있습니다. PEM 형식의 CA 번들을 `--cert` 옵션 또는 `PIP_CERT` 환경 변수로 지정합니다.

```bat
python -m pip install --cert C:\certs\company-ca.pem selenium
```

```bat
set PIP_CERT=C:\certs\company-ca.pem
```

인증서 파일은 회사의 공식 보안·인프라 채널에서 받아야 합니다. 서버 인증서를 임의로 내려받아 신뢰 목록에 넣기보다, 발급 기관인 CA 인증서를 정확하게 등록해야 합니다.

## 피해야 할 우회 방법

`requests.get(..., verify=False)` 또는 pip의 `--trusted-host`는 인증서 검증을 비활성화하거나 우회합니다. 연결은 성공할 수 있지만 중간자 공격을 막지 못할 수 있으므로, 실제 서비스나 민감한 데이터에는 사용하지 않습니다.

## 추가 점검

- `ssl.get_default_verify_paths()`로 Python 표준 SSL 모듈이 참조하는 기본 CA 경로를 확인합니다.
- 브라우저에서도 같은 주소에 인증서 경고가 발생하면 서버의 인증서 체인과 만료 여부를 점검합니다.
- 오래된 OS에서 루트 인증서를 업데이트할 수 없다면 지원되는 OS와 Python 환경으로 이전하는 방안을 검토합니다.
