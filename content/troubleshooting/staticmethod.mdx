## 현상

Python 3.9 이하에서는 클래스 본문에서 `@staticmethod`로 장식한 이름을 딕셔너리에 직접 저장하면, 실제 함수가 아닌 `staticmethod` 디스크립터 객체가 저장되어 호출 시 오류가 발생할 수 있습니다. Python 3.10부터는 staticmethod 객체도 호출 가능하도록 변경되었으므로, 이 오류는 버전별로 재현 여부가 다릅니다.

```python
class A(object):
    @staticmethod
    def open_func():
        return 123

    @staticmethod
    def process_func():
        return 456

    switch = {
        1: open_func,
        2: process_func,
    }

obj = A.switch[1]()
```

실행 시 다음과 같은 `TypeError`가 발생합니다.

```python
TypeError: 'staticmethod' object is not callable
```

## 원인

클래스 본문에서 `open_func`라는 이름을 직접 참조하면 아직 클래스 속성 접근이 일어나지 않았으므로 `staticmethod` 객체 자체가 딕셔너리에 저장됩니다. Python 3.9 이하에서는 이 객체가 callable이 아니어서 호출 시 `TypeError`가 발생했습니다. Python 3.10부터는 `staticmethod` 객체가 callable해졌기 때문에 동일한 코드가 더 이상 같은 오류를 내지 않습니다.

## 해결 방법

가장 명확한 방법은 클래스 생성이 끝난 뒤 클래스 속성으로 접근한 함수를 사용해 딕셔너리를 만드는 것입니다. 이렇게 하면 Python 버전에 관계없이 실제 함수 객체를 저장할 수 있습니다.

```python
class A(object):
    @staticmethod
    def open_func():
        return 123
    @staticmethod
    def process_func():
        return 456

A.switch = {
    1: A.open_func,
    2: A.process_func,   
}
```

## 다른 해결 방법

디스크립터의 `__get__` 메서드를 명시적으로 호출하거나 `__func__` 속성을 사용하여 내부 함수를 추출할 수 있습니다.

첫째, `__get__` 메서드를 사용하여 강제로 바인딩된 함수를 가져옵니다. `staticmethod`의 경우 컨텍스트가 무시되므로 `None`을 전달합니다.

```python
class A(object):
    @staticmethod
    def open_func():
        return 123
    @staticmethod
    def process_func():
        return 456

    switch = {
        1: open_func.__get__(None, A),
        2: process_func.__get__(None, A),   
    }
```

다음 예제는 `staticmethod` 객체에서 원래 함수 객체를 꺼내 저장합니다.

```python
class A(object):
    @staticmethod
    def open_func():
        return 123
    @staticmethod
    def process_func():
        return 456

    switch = {
        1: open_func.__func__,
        2: process_func.__func__,   
    }
```

## 추가 참고사항

`classmethod`나 `staticmethod`를 다른 데코레이터와 함께 사용할 때는 가장 바깥쪽에 배치해야 합니다.

`staticmethod`나 `classmethod`는 디스크립터 객체를 반환하기 때문에, 다른 데코레이터가 바깥에 있으면 `__module__` 등 속성을 찾을 수 없는 `AttributeError`가 발생할 수 있습니다.

메서드 네임스페이스가 필요할 경우 클래스보다는 일반 모듈에 함수를 정의하는 것이 더 간편할 수 있습니다.
