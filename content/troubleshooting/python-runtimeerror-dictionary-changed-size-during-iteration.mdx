## 현상

파이썬에서 `for` 문을 사용하여 딕셔너리를 순회하는 도중, 조건에 따라 해당 키-값 쌍을 삭제(`pop`)하거나 새로운 키를 추가하려고 하면 `RuntimeError`가 발생합니다.

```python
d = {'a': [1], 'b': [1, 2], 'c': [], 'd': []}

for i in d:
    if not d[i]:
        d.pop(i)
```

위 코드를 실행하면 다음과 같은 에러가 출력됩니다.

```
Traceback (most recent call last):
  File "<stdin>", line 2, in <module>
RuntimeError: dictionary changed size during iteration
```

## 원인

파이썬의 딕셔너리 순회(iteration)는 내부적으로 딕셔너리의 크기를 추적합니다. 순회 중에 딕셔너리의 크기가 변경되면(키가 추가되거나 삭제됨), 내부 이터레이터의 상태와 실제 데이터 구조가 불일치하게 되어 안전하지 않은 상태가 됩니다. 이를 방지하기 위해 파이썬은 명시적으로 `RuntimeError`를 발생시켜 순회 중단 및 에러를 알림으로써 프로그램의 안정성을 보장합니다.

## 해결 방법

순회 대상인 딕셔너리의 키 목록을 미리 복사하여 복사본을 순회하면, 원본 딕셔너리의 크기가 변해도 복사본의 순회에는 영향을 주지 않아 에러를 방지할 수 있습니다. 파이썬 3.x에서는 `.keys()`가 뷰 객체를 반환하므로 `list()`를 사용하여 명시적으로 리스트로 변환해야 합니다.

```python
d = {'a': [1], 'b': [1, 2], 'c': [], 'd': []}

# 딕셔너리 키를 리스트로 복사하여 순회
for i in list(d):
    if not d[i]:
        d.pop(i)

print(d)  # {'a': [1], 'b': [1, 2]}
```

## 다른 해결 방법

원본 딕셔너리를 수정하는 대신, 조건에 맞는 키-값 쌍만 선별하여 새로운 딕셔너리를 생성하는 딕셔너리 컴프리헨션(Dictionary Comprehension) 방식을 사용할 수 있습니다. 이 방법은 순회 중 수정 문제를 근본적으로 피할 수 있으며 가독성이 좋습니다.

```python
d = {'a': [1], 'b': [1, 2], 'c': [], 'd': []}

# 조건에 맞는 항목만 필터링하여 새 딕셔너리 생성
d = {key: value for key, value in d.items() if value}

print(d)  # {'a': [1], 'b': [1, 2]}
```

## 추가 참고사항

`collections.defaultdict`를 사용할 때 주의할 점이 있습니다. `defaultdict`에서 존재하지 않는 키에 접근하면 해당 키가 자동으로 생성되어 딕셔너리 크기가 변경됩니다. 만약 `for` 루프가 `list(d)`와 같이 미리 복사된 키 목록을 순회하는 것이 아니라 원본 딕셔너리 자체를 순회한다면, 접근 시 키가 추가됨으로써 `RuntimeError`가 발생할 수 있습니다. 따라서 `defaultdict` 사용 시에도 순회 전 키 목록을 복사하거나, 딕셔너리 컴프리헨션을 사용하는 것이 안전합니다.
