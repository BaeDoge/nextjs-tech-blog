## 현상

빈 리스트에 인덱스를 지정하여 값을 할당하려고 하면 `IndexError: list assignment index out of range` 오류가 발생합니다. 이는 리스트의 현재 길이를 초과하는 인덱스에 접근하려고 할 때 발생합니다.

```python
i = [1, 2, 3, 5, 8, 13]
j = []
k = 0

for l in i:
    j[k] = l
    k += 1
```

위 코드를 실행하면 두 번째 줄 `j[k] = l` 부분에서 다음과 같은 오류가 발생합니다.

```
IndexError: list assignment index out of range
```

![현상 스크린샷](/blogs/python-indexerror-list-index-out-of-range-1.png)

## 원인

파이썬의 리스트는 동적 배열이지만, 할당 연산(`=`)을 사용할 때는 해당 인덱스에 이미 요소가 존재해야 합니다. 초기화되지 않은 빈 리스트 `[]`는 길이가 0이므로, 인덱스 0에 접근하여 값을 할당하려고 하면 존재하지 않는 위치를 참조하게 되어 오류가 발생합니다. 즉, 리스트는 존재하지 않는 인덱스에 값을 직접 할당하는 것을 허용하지 않습니다.

## 해결 방법

빈 리스트에 요소를 추가하려면 인덱스 할당이 아닌 `append()` 메서드를 사용해야 합니다. `append()`는 리스트의 끝에 새로운 요소를 추가하여 리스트의 길이를 자동으로 확장합니다.

```python
i = [1, 2, 3, 5, 8, 13]
j = []

for l in i:
    j.append(l)
```

또한, 단순히 기존 리스트를 복사하려는 목적이라면 `list()` 생성자나 슬라이싱을 사용할 수 있습니다.

```python
i = [1, 2, 3, 5, 8, 13]
j = list(i)
```

## 다른 해결 방법

기존의 인덱스 할당 로직을 유지하려면, 먼저 할당할 인덱스 범위만큼의 요소가 있는 리스트를 미리 생성해야 합니다. `None` 값을 사용하여 리스트를 초기화한 후 인덱스를 통해 값을 덮어쓰는 방식입니다.

```python
i = [1, 2, 3, 5, 8, 13]
j = [None] * len(i)
k = 0

for l in i:
    j[k] = l
    k += 1
```

이 방법은 다른 언어의 배열처럼 특정 인덱스에 값을 할당하는 패턴을 따를 때 유용합니다.

## 추가 참고사항

`IndexError`는 리스트, 튜플, 문자열 등 시퀀스 자료형에서 유효하지 않은 인덱스에 접근할 때 발생합니다. 이를 방지하기 위해 인덱스 접근 전 `len()` 함수를 사용하여 리스트의 길이를 확인하거나, `try-except` 블록으로 예외를 처리하는 것이 좋습니다.

```python
my_list = [10, 20, 30]
index = 5

if 0 <= index < len(my_list):
    print(my_list[index])
else:
    print(f"Error: 유효하지 않은 인덱스 {index}")
```

반복문에서 인덱스를 사용할 경우, `range(len(my_list))`를 사용하여 범위를 벗어나지 않도록 주의해야 합니다.
