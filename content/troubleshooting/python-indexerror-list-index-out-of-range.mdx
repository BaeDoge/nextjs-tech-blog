## 현상

기존 리스트의 요소를 새 리스트로 옮기려고 빈 리스트를 만든 뒤, 반복문에서 인덱스로 값을 할당하면 `IndexError: list assignment index out of range`가 발생할 수 있습니다.

```python
source = [1, 2, 3, 5, 8, 13]
copied = []
index = 0

for value in source:
    copied[index] = value
    index += 1
```

`copied`는 길이가 0인 빈 리스트이므로 첫 반복에서 `copied[0]`에 값을 대입할 수 없습니다.

## 원인

리스트는 요소를 추가할 때 크기가 동적으로 늘어나지만, 인덱스 대입은 이미 존재하는 위치의 값을 바꾸는 연산입니다. 빈 리스트에 인덱스 0이 존재하지 않으므로 `copied[0] = value`는 실패합니다.

이 문제는 반복문의 인덱스를 잘못 계산해서 생긴 오류와 구분해야 합니다. 현재 예제에서는 인덱스 값이 0이든 다른 값이든, 대상 리스트가 비어 있기 때문에 첫 대입부터 실패합니다.

## 해결 방법 1. 기존 리스트를 그대로 복사하기

목적이 단순한 리스트 복사라면 직접 반복문을 작성할 필요가 없습니다.

```python
source = [1, 2, 3, 5, 8, 13]
copied = list(source)

print(copied)
# [1, 2, 3, 5, 8, 13]
```

슬라이싱으로도 얕은 복사본을 만들 수 있습니다.

```python
copied = source[:]
```

## 해결 방법 2. 변환하면서 새 리스트 만들기

각 요소에 연산을 적용하거나 조건에 맞는 요소만 옮기려면 리스트 컴프리헨션을 사용할 수 있습니다.

```python
squared = [value ** 2 for value in source]
even_values = [value for value in source if value % 2 == 0]
```

## 다른 해결 방법. 인덱스 대입이 필요한 경우

대상 리스트의 위치를 미리 정해두고 각 위치에 값을 넣어야 한다면, 먼저 원본과 같은 길이로 공간을 만듭니다.

```python
copied = [None] * len(source)

for index, value in enumerate(source):
    copied[index] = value
```

단순 복사에는 `list(source)`가 더 간단합니다. 위 방식은 각 위치를 별도로 계산하거나 다른 값으로 초기화해야 할 때 선택할 수 있습니다.

## 추가 참고사항

- `append()`는 리스트 끝에 요소를 추가합니다.
- 인덱스 대입은 이미 존재하는 요소를 교체합니다.
- 중첩 리스트를 복사하면 `list(source)`와 슬라이싱은 얕은 복사이므로 내부 리스트 객체는 원본과 공유합니다. 중첩 객체까지 분리하려면 복사 깊이를 별도로 고려해야 합니다.
