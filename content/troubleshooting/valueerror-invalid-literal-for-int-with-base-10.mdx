## 현상

`int()` 함수를 사용하여 문자열을 정수형으로 변환하려 할 때, 입력값이 정수 형태로 인식되지 않아 에러가 발생합니다. 특히 입력값에 소수점이 포함되거나 공백, 특수문자가 섞여 있을 때 자주 발생합니다.

```python
# 에러 재현 코드
a = input("Enter 'a' ") # 예: 0.3 입력 시
if int(a) < 0:
    print("'a' is negative")
```

```text
Traceback (most recent call last):
   File "<string>", line 3, in <module>
ValueError: invalid literal for int() with base 10: '0.3'
```

## 원인

`int()` 함수는 정수(Integer) 형태의 문자열만 변환할 수 있습니다. 소수점을 가진 실수형 문자열('0.3')이나 정수로 변환할 수 없는 형태('Hello', '- 1' 등)를 전달하면, Python은 해당 문자열을 10진법 정수로 해석할 수 없다고 판단하여 `ValueError`를 발생시킵니다. 이는 자료형의 불일치에서 기인합니다.

## 해결 방법

실수 값이 입력될 수 있는 경우, 정수형(`int`) 대신 실수형(`float`)으로 변환하여 처리합니다. 이후 필요 시 정수형으로 변환하거나 연산에 활용합니다.

```python
# 수정 전 (에러 발생)
a = input("Enter 'a' ")
# val = int(a)  # ValueError 발생 가능

# 수정 후 (해결)
a = float(a)  # 0.3 같은 실수 값도 정상 변환
print(f"입력 값: {a}")

if a < 1 and a > 0:
    print("0과 1 사이의 값입니다.")
```

## 다른 해결 방법

데이터프레임 등 외부 라이브러리에서 열(Column)의 데이터 형식을 변환할 때, 소수점 문자열을 강제로 정수형으로 바꾸려 하면 같은 에러가 발생합니다. 이 경우 `float`를 거쳐 정수형으로 변환하거나, 문자열 처리를 통해 소수점 이하를 제거해야 합니다.

```python
import pandas as pd

# 소수점 문자열을 포함한 데이터프레임
df = pd.DataFrame({'val': ['0.001', '0.002']})

# 방법 1: float를 거쳐 int로 변환 (반올림/절사됨)
df['val'] = df['val'].astype(float).astype(int)

# 방법 2: 문자열 split을 사용하여 소수점 이전 부분만 추출
# df['val'] = df['val'].apply(lambda x: x.split('.')[0])
```

## 추가 참고사항

1. `input()`으로 받은 값은 항상 문자열(`str`)이므로, 숫자 연산을 하려면 반드시 `int()` 또는 `float()`로 형변환해야 합니다.
2. 문자열 내에 공백이 포함되어 있으면 변환이 실패합니다. 예: `int(' 1')` 또는 `int('- 1')`은 에러를 발생시킵니다. `strip()` 메서드로 공백 제거가 필요할 수 있습니다.
3. 비슷한 에러로 `ValueError: invalid literal for float()`가 있으며, 이는 부동소수점 형식으로 변환할 수 없는 문자열이 입력되었을 때 발생합니다.
4. 코드 스타일 측면에서, 반복적으로 `int(a)`나 `float(a)`를 호출하기보다는 한 번 변환한 값을 변수에 저장하여 재사용하는 것이 효율적입니다.
