## 현상

DataFrame에서 조건에 따라 행을 필터링한 후, 특정 열의 데이터 타입을 변환하거나 값을 할당하려고 하면 경고가 발생합니다.

```python
df = df[df['my_col'].notnull()]
df['my_col'] = df['my_col'].astype(int).astype(str)
```

이 코드 실행 시 다음과 같은 경고가 출력됩니다.

```
SettingWithCopyWarning: A value is trying to be set on a copy of a slice from a DataFrame.
Try using .loc[row_indexer,col_indexer] = value instead
```

![현상 스크린샷](/blogs/pandas-dataframe-settingwithcopywarning-1.png)

## 원인

이 경고는 DataFrame의 일부 행이나 열을 슬라이싱하여 분리된 객체를 만든 후, 이를 다시 수정하려고 할 때 발생합니다.

Pandas는 체이닝(연속적인 연산) 결과로 생성된 DataFrame이 원본 데이터의 복사본인지, 아니면 원본 데이터의 뷰(view)인지 알 수 없습니다. 슬라이싱한 결과물이 복사본일 경우, 원본에 할당이 반영되지 않을 수 있다는 우려로 인해 이를 경고로 안내합니다.

## 해결 방법

슬라이싱된 DataFrame을 `copy()` 메서드를 통해 명시적으로 복사본으로 변환한 후 값을 수정하면 경고가 발생하지 않습니다.

수정 전 코드:

```python
df = df[df['my_col'].notnull()]
df['my_col'] = df['my_col'].astype(int).astype(str)
```

수정 후 코드:

```python
df = df[df['my_col'].notnull()].copy()
df['my_col'] = df['my_col'].astype(int).astype(str)
```

## 다른 해결 방법

`loc` 인덱서를 사용하여 원본 DataFrame의 조건에 부합하는 행과 열을 명시적으로 지정하여 값을 할당하는 방법도 있습니다. 복사본을 만들지 않고 원본 데이터의 특정 위치만 직접 수정하므로, 슬라이싱된 객체를 유지할 필요가 없는 경우에 유용합니다.

```python
# loc을 사용하여 원본의 특정 행/열 명시적 할당
condition = df['my_col'].notnull()
df.loc[condition, 'my_col'] = df.loc[condition, 'my_col'].astype(int).astype(str)
```

## 추가 참고사항

- `copy()`를 사용하면 데이터의 깊은 복사(deep copy)가 수행되므로, 대용량 데이터 처리 시 메모리 사용량이 증가할 수 있습니다.
- 이 경고는 실행을 중단시키는 에러가 아니지만, 데이터 수정이 원본에 제대로 반영되었는지 확인할 수 있는 중요한 신호이므로 반드시 처리해야 합니다.
