## 현상

결측치가 없는 행만 남긴 뒤 특정 열의 자료형을 바꾸거나 값을 할당하는 상황을 생각해 보겠습니다.

~~~python
import pandas as pd

df = pd.DataFrame({
    "my_col": ["10", None, "30"],
    "name": ["A", "B", "C"],
})

df = df[df["my_col"].notna()]
df["my_col"] = df["my_col"].astype(int).astype(str)
~~~

pandas 2.x의 기본 동작에서는 필터링 결과에 값을 할당하는 과정에서 SettingWithCopyWarning이 나타날 수 있습니다. 경고 발생 여부는 구체적인 인덱싱 표현과 Pandas 버전에 따라 달라지므로, 이 코드가 모든 환경에서 동일한 경고를 발생시킨다고 단정할 수는 없습니다.

## 원인

필터링은 원본 DataFrame의 일부 행을 선택해 새로운 객체를 반환합니다. 과거 Pandas에서는 이 결과가 원본과 메모리를 공유하는지 여부가 연산에 따라 달랐습니다. 따라서 필터링한 결과를 수정하려는 것인지, 원본의 특정 행을 수정하려는 것인지 의도를 코드에서 명확하게 표현하는 것이 중요합니다.

pandas 3.0에서는 Copy-on-Write가 기본이자 유일한 동작 방식이므로, 필터링 결과를 수정해도 원본 DataFrame은 변경되지 않습니다. 이 버전에서는 SettingWithCopyWarning도 제거되었습니다.

## 해결 방법

### 1. 필터링 결과를 독립적으로 수정하기

필터링 결과를 별도의 작업용 DataFrame으로 사용할 때는 copy()를 명시합니다.

~~~python
filtered = df.loc[df["my_col"].notna()].copy()
filtered["my_col"] = filtered["my_col"].astype(int).astype(str)
~~~

이 코드는 원본 df와 별개인 filtered를 만들고 해당 객체만 수정합니다.

### 2. 원본 DataFrame에서 조건에 맞는 행을 수정하기

원본을 유지한 채 조건에 맞는 셀의 값을 변경하려면 원본 DataFrame에 직접 loc을 사용합니다.

~~~python
mask = df["my_col"].notna()
df.loc[mask, "my_col"] = (
    df.loc[mask, "my_col"].astype(int).astype(str)
)
~~~

위 코드는 원본 df의 조건에 맞는 위치에 결과를 할당합니다. 별도 슬라이스를 수정하는 것과 달리 변경 대상이 원본이라는 점이 명확합니다.

## 어떤 방법을 선택해야 할까?

- 필터링한 결과를 별도 분석용 데이터로 사용할 때: df.loc[조건].copy()
- 필터링 조건에 해당하는 원본 셀 자체를 바꿀 때: df.loc[조건, "열"] = 값

두 방식은 목적이 다릅니다. 원본 데이터를 보존해야 하는 작업인지 먼저 확인한 뒤 선택하는 것이 안전합니다.

## 버전별 참고사항

pandas 2.x에서는 Copy-on-Write 설정 여부에 따라 과거의 뷰/복사본 동작과 경고가 달라질 수 있습니다. pandas 3.0에서는 Copy-on-Write가 기본이자 유일한 모드이므로, 필터링 결과의 수정이 원본으로 전파되지 않습니다. 구버전의 경고 해결법을 모든 버전에 동일하게 적용하지 않도록 주의해야 합니다.
