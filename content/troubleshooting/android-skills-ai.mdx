## 한눈에 보는 프로젝트와 해결하려는 문제

`android/skills`는 안드로이드 개발 생태계에서 AI 에이전트가 특정 도메인이나 워크플로우를 더 정확하게 이해하고 수행할 수 있도록 설계된 'AI 최적화 모듈형 지침' 저장소입니다. 이 프로젝트는 단순히 코드 조각을 모아둔 라이브러리가 아니라, LLM(대규모 언어 모델)이 안드로이드 개발의 복잡한 요구사항을 정확히 파악하고 실행할 수 있도록 돕는 '기술 사양서'의 집합체입니다.

현재 많은 LLM 기반 코딩 도구는 일반적인 Jetpack Compose 패턴이나 기본적인 안드로이드 API 사용법에는 능숙하지만, 특정 라이브러리의 최신 마이그레이션 전략, 복잡한 하드웨어 연동(카메라, 자동차 등), 혹은 최신 빌드 시스템의 변경 사항과 같은 전문적인 영역에서는 여전히 환각(Hallucination) 현상을 보이거나 구식 정보를 참조하는 경우가 많습니다. `android/skills`는 이러한 문제를 해결하기 위해 [developer.android.com](https://developer.android.com)의 공식 가이드를 기반으로, 에이전트가 참조할 수 있는 표준화된 마크다운 형식의 `SKILL.md` 파일들을 제공합니다. 즉, 이 저장소는 개발자가 AI를 활용해 안드로이드 앱을 개발할 때, AI가 '안드로이드 전문가'처럼 행동하도록 만드는 지식 베이스이자 인터페이스입니다.

## 이해에 필요한 핵심 개념

이 프로젝트를 이해하기 위해서는 다음 세 가지 핵심 개념을 파악해야 합니다.

1. **SKILL.md (오픈 표준 에이전트 스킬):** [agentskills.io](https://agentskills.io/home) 표준을 따르는 마크다운 파일입니다. 이는 에이전트에게 특정 작업의 기술적 사양과 제약 조건을 명확히 전달하는 역할을 합니다. 단순히 텍스트를 읽는 것을 넘어, 에이전트가 작업을 수행하기 위한 'grounding(근거)' 정보를 제공합니다.
2. **AI 에이전트 플러그인:** 이 저장소는 독립적인 실행 파일이 아니라, Claude Code나 Codex와 같은 AI 에이전트 도구에 플러그인 형태로 설치됩니다. `.claude-plugin/plugin.json`이나 `.codex-plugin/plugin.json`과 같은 설정 파일들은 에이전트가 이 저장소의 지식을 어떻게 탐색하고 적용할지 정의합니다.
3. **워크플로우 기반 지식 구조:** 일반적인 문서화와 달리, 이 저장소는 '기술' 단위로 폴더가 나뉘어 있습니다. 예를 들어 `camera/camerax/` 폴더에는 카메라 관련 기술 사양과 함께 마이그레이션, 테스트, 성능 최적화 등 실제 개발 워크플로우에 필요한 레퍼런스들이 체계적으로 정리되어 있습니다.

## 저장소 구조와 실제 동작 흐름

저장소는 기술 도메인별로 계층화된 구조를 가지고 있습니다. 주요 폴더 구조를 살펴보면 다음과 같습니다.

- `build-system/`: AGP(Android Gradle Plugin) 업그레이드 및 빌드 최적화 관련 지식
- `camera/`: CameraX 라이브러리 활용 및 하드웨어 연동 가이드
- `device-ai/`: LiteRT, ML Kit 등 온디바이스 AI 구현을 위한 기술 사양
- `jetpack-compose/`: UI 마이그레이션, 성능 최적화, 적응형 레이아웃(Adaptive) 지침
- `identity/`: 패스키(Passkeys) 및 Credential Manager 등 보안 인증 관련 가이드

**동작 흐름:**
1. **설치:** 사용자는 `android-cli`를 통해 특정 스킬을 프로젝트에 추가합니다. 예를 들어 `android skills add r8-analyzer --project=.` 명령을 실행하면, 해당 프로젝트의 에이전트가 R8 최적화 규칙을 이해할 수 있는 지식 세트를 로컬로 가져옵니다.
2. **탐색:** 에이전트는 사용자의 프롬프트(예: "Make my app UI edge-to-edge")를 분석합니다. 관련 스킬이 설치되어 있다면, 에이전트는 해당 스킬의 `SKILL.md`와 레퍼런스 문서를 검색하여 최신 API 사용법을 확인합니다.
3. **실행:** 에이전트는 확인된 지식을 바탕으로 코드를 생성하거나 수정합니다. 이때 `performance/r8-analyzer/scripts/analyze.py`와 같은 보조 스크립트가 포함된 경우, 에이전트는 이 스크립트를 호출하여 실제 분석 결과를 도출하고 이를 사용자에게 보고합니다.

이 코드는 R8의 `keepruleradius.json` 출력을 입력받아 최적화 점수를 계산합니다. 설계적으로 주목할 점은 **'데이터 기반의 의사결정'**입니다. 단순히 "R8을 설정하라"고 조언하는 대신, 에이전트가 실제 빌드 결과물(JSON)을 분석하여 최적화 수준을 수치화하고, 이를 바탕으로 사용자에게 구체적인 수정 제안을 하도록 설계되었습니다. 이는 AI가 추측에 의존하지 않고, 프로젝트의 실제 상태를 파악하여 정밀한 가이드를 제공하게 만드는 핵심 설계 선택입니다.

또한, `cars/android-for-cars-parked-apps/references/android/docs/quality-guidelines/car-app-quality/index.md`와 같은 문서는 체크리스트 형식으로 작성되어 있습니다. 이는 에이전트가 '품질 검사'라는 추상적인 작업을 수행할 때, 각 항목을 순차적으로 확인하고 준수 여부를 판단하는 알고리즘적 접근을 가능하게 합니다.

## 대안과 비교했을 때의 장단점

| 비교 항목 | `android/skills` | 일반적인 AI 코딩 보조 도구 |
| :--- | :--- | :--- |
| **지식의 근거** | 공식 문서 기반의 구조화된 데이터 | 학습된 파라미터(일반 지식) |
| **최신성** | 저장소 업데이트를 통한 즉각적 반영 | 모델 재학습 필요 |
| **전문성** | 특정 도메인(안드로이드)에 특화 | 범용적이나 깊이 부족 가능성 |
| **실행 가능성** | 스크립트 및 체크리스트 포함 | 코드 생성 위주 |

**장점:** 안드로이드 개발에 특화된 최신 가이드를 에이전트에게 직접 주입함으로써, 일반적인 LLM이 범하기 쉬운 구식 API 사용 오류를 획기적으로 줄일 수 있습니다. 또한, 체크리스트와 스크립트를 통해 에이전트의 작업 결과를 검증할 수 있는 객관적인 기준을 제공합니다.

**단점:** 사용자가 직접 스킬을 설치하고 관리해야 하는 번거로움이 있습니다. 또한, 에이전트가 해당 스킬을 자동으로 활성화하지 못하거나, 프롬프트가 모호할 경우 적절한 스킬을 선택하지 못할 가능성이 존재합니다.

## 보안·라이선스·도입 시 확인할 점

- **라이선스:** 이 프로젝트는 `Apache License 2.0`을 따릅니다. 이는 상업적 이용, 수정, 배포가 자유롭지만, 원본 저작권 고지를 포함해야 함을 의미합니다. 기업 환경에서 도입 시 라이선스 준수 여부를 확인하십시오.
- **보안:** `scripts/` 폴더에 포함된 파이썬 스크립트들은 사용자의 로컬 환경에서 실행됩니다. 외부에서 가져온 스크립트를 실행하기 전, 코드 내용을 검토하여 의도치 않은 파일 접근이나 네트워크 요청이 없는지 확인하는 것이 좋습니다.
- **도입 시 확인:** 프로젝트의 `README.md`에 명시된 대로, AI는 실수를 할 수 있습니다. 특히 `device-ai`나 `identity`와 같이 보안과 밀접한 영역의 코드를 생성할 때는 반드시 사람이 최종 검토(Human-in-the-loop)를 수행해야 합니다.

## 한계와 추천 대상

**한계:**
- **자동화의 범위:** 모든 안드로이드 개발 문제를 해결할 수 있는 만능 도구가 아닙니다. 특히 복잡한 비즈니스 로직이나 프로젝트 고유의 아키텍처와 충돌할 경우, 스킬이 제공하는 가이드가 부적절할 수 있습니다.
- **환경 의존성:** `android-cli`와 같은 특정 도구 체인에 의존하므로, 기존 개발 환경에 이 도구들을 통합하는 과정이 필요합니다.

**추천 대상:**
- **안드로이드 전문 AI 에이전트를 구축하려는 팀:** 에이전트의 개발 생산성을 높이고, 공식 가이드라인을 준수하는 코드를 생산하고 싶은 팀에게 최적입니다.
- **최신 안드로이드 기술 도입을 고민하는 개발자:** CameraX, Jetpack Compose, 온디바이스 AI 등 빠르게 변하는 기술 스택을 AI의 도움을 받아 효율적으로 학습하고 적용하려는 개발자에게 유용합니다.
- **대규모 프로젝트 유지보수 담당자:** 빌드 시스템 관리나 품질 가이드라인 준수 여부를 자동화하고 싶은 경우, 이 저장소의 스킬들을 활용하여 일관된 코드 품질을 유지할 수 있습니다.
