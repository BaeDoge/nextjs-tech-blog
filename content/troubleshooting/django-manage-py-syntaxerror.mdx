## 현상

Django 튜토리얼 진행 중 `python manage.py runserver` 명령 실행 시 `SyntaxError: invalid syntax`가 발생합니다.
에러는 시스템이 자동 생성한 `manage.py` 파일의 14번째 라인에서 나타납니다.
사용 환경은 Python 2.7.12와 Django 1.10.6입니다.
재현 코드는 다음과 같습니다.

```
django-admin startproject mysite
cd mysite
python manage.py runserver
```

에러 출력 원문은 다음과 같습니다.

```
File "manage.py", line 14
) from exc
^
SyntaxError: invalid syntax
```

![현상 스크린샷](/blogs/django-manage-py-syntaxerror-2.png)

## 원인

`manage.py`에 생성된 `raise ... from exc` 문법은 Python 3에서 지원되는 예외 연결(exception chaining) 구문입니다. 이 스크립트를 Python 2.7 인터프리터로 실행하면 해당 줄을 파싱하지 못해 `SyntaxError`가 발생합니다. 명령 앞에 `python`을 입력하면 PATH에서 선택된 인터프리터가 실행되므로, 실제로 어떤 버전이 선택되는지 확인해야 합니다. shebang은 파일을 직접 실행할 때 영향을 주지만, `python manage.py`처럼 인터프리터를 명시해 실행하면 명령에 지정한 Python이 사용됩니다.

## 해결 방법

`manage.py`를 생성한 Django와 호환되는 Python 3 인터프리터로 실행해야 합니다. 아래 예제는 `python3` 명령이 Python 3을 가리키는 환경을 가정합니다.

```bash
python3 manage.py runserver
```

이 명령을 실행하면 Python 3 환경에서 코드가 해석되어 SyntaxError가 해결됩니다.

![해결 방법 스크린샷](/blogs/django-manage-py-syntaxerror-1.png)

## 다른 해결 방법

Django 패키지를 설치한 Python 버전과 실행하는 Python 버전을 일치시켜야 합니다.
`python3 -m pip install django`로 설치한 환경이라면 같은 인터프리터인 `python3`로 실행해야 합니다.
가상 환경을 사용 중이라면 해당 환경이 Python 3인지 확인하고 활성화해야 합니다.

```bash
# Python 3에 Django가 설치된 경우
python3 -m django --version
python3 manage.py startapp <yourapp name>
```

만약 `pip install django`(Python 2용)를 설치했다면 `python` 명령어를 사용할 수 있지만,
Python 2로 생성된 오래된 Django 프로젝트가 아니라면, shebang을 바꾸어 Python 2 실행을 강제하지 말고 프로젝트를 지원되는 Python 3와 Django 버전으로 이전하는 편이 안전합니다.

## 추가 참고사항

실제로 실행되는 인터프리터와 Django 설치 위치가 같은지 다음 명령으로 확인할 수 있습니다.

```bash
python --version
python -m django --version
```

Windows에서는 `py -3 --version` 및 `py -3 -m django --version`으로 Python 3 런처를 확인할 수 있습니다. Python 2는 지원이 종료되었으므로 지원되는 Python 3와 Django 버전으로 이전하는 것이 좋습니다.
