## 현상

Django 튜토리얼 진행 중 `python manage.py runserver` 명령 실행 시 `SyntaxError: invalid syntax`가 발생합니다.
에러는 시스템이 자동 생성한 `manage.py` 파일의 14번째 라인에서 나타납니다.
사용 환경은 Python 2.7.12와 Django 1.10.6입니다.
재현 코드는 다음과 같습니다.

```
django-admin startproject mysite
cd mysite
python manage.py runserver
```

에러 출력 원문은 다음과 같습니다.

```
File "manage.py", line 14
) from exc
^
SyntaxError: invalid syntax
```

![현상 스크린샷](/blogs/django-manage-py-syntaxerror-2.png)

## 원인

`manage.py` 파일의 헤더에 `#!/usr/bin/env python3`가 명시되어 있어 Python 3 환경을 참조하도록 설계되었습니다.
하지만 사용자는 `python` 명령어를 통해 Python 2.7 interpreter를 실행하고 있습니다.
Python 2는 `except ... as ... from ...` 문법을 지원하지 않으므로 구문 오류가 발생합니다.
따라서 Python 3 문법이 포함된 코드를 Python 2 환경에서 실행하려고 했기 때문에 에러가 발생합니다.

## 해결 방법

`python` 명령어 대신 `python3` 명령어를 사용하여 Django 프로젝트를 실행해야 합니다.
이는 `manage.py`가 지정한 Python 3 인터프리터를 명확하게 호출하는 방법입니다.

```bash
python3 manage.py runserver
```

이 명령을 실행하면 Python 3 환경에서 코드가 해석되어 SyntaxError가 해결됩니다.

![해결 방법 스크린샷](/blogs/django-manage-py-syntaxerror-1.png)

## 다른 해결 방법

Django 패키지를 설치한 Python 버전과 실행하는 Python 버전을 일치시켜야 합니다.
`pip3 install django`로 Python 3에 Django를 설치했다면 반드시 `python3`를 사용해야 합니다.
가상 환경을 사용 중이라면 해당 환경이 Python 3인지 확인하고 활성화해야 합니다.

```bash
# Python 3에 Django가 설치된 경우
python3 -m django --version
python3 manage.py startapp <yourapp name>
```

만약 `pip install django`(Python 2용)를 설치했다면 `python` 명령어를 사용할 수 있지만,
`manage.py`의 shebang(`#!/usr/bin/env python3`)을 `#!/usr/bin/env python`으로 변경해야 합니다.

## 추가 참고사항

터미널에서 Python REPL(`>>>`)이 종료되지 않은 상태에서 스크립트를 실행하면 SyntaxError가 발생할 수 있습니다.
이 경우 `exit()` 명령으로 REPL을 종료한 후 다시 스크립트를 실행해야 합니다.
VS Code나 기타 IDE 사용 시에도 동일한 주의가 필요합니다.
Python 2는 지원이 종료되었으므로, 최신 Django 및 Python 3 환경을 사용하는 것이 권장됩니다.
