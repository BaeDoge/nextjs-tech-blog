## 현상

Django 프로젝트를 생성한 뒤 `python manage.py runserver`를 실행했는데, 자동 생성된 `manage.py`의 다음 구문에서 `SyntaxError`가 발생할 수 있습니다.

```python
raise ImportError(
    "Django를 불러올 수 없습니다. 가상환경을 활성화했는지 확인하세요."
) from exc
```

재현 사례에서는 `manage.py`가 Python 3을 지정하는 shebang으로 생성되었지만, 터미널의 `python` 명령은 Python 2.7을 가리키고 있었습니다.

```text
Python 2.7.12
Django 1.10.6 (Python 2 환경에서 확인한 버전)

File "manage.py", line 14
) from exc
^
SyntaxError: invalid syntax
```

## 원인

이 오류는 `manage.py`를 만든 Python 인터프리터와 실행할 때 사용한 인터프리터가 서로 다른 경우에 발생합니다. `raise ... from exc`는 Python 3의 예외 체이닝 문법이며, Python 2에서는 해석할 수 없습니다.

또한 shebang과 명령행에서 지정한 인터프리터는 구분해야 합니다.

- `python manage.py runserver`: `python` 명령이 가리키는 인터프리터로 실행합니다. 이 방식에서는 파일 첫 줄의 shebang이 사용되지 않습니다.
- `./manage.py runserver`: 실행 파일로 직접 호출하므로 shebang의 경로를 사용합니다. 파일에 실행 권한이 있어야 합니다.

`django-admin startproject`가 Python 3 환경에서 실행되었더라도, `python manage.py`가 Python 2를 실행하면 서로 다른 환경의 코드와 패키지가 섞일 수 있습니다.

## 해결 방법

먼저 `python`, `pip`, Django가 동일한 인터프리터를 가리키는지 확인합니다.

```bash
python --version
python -m pip --version
python -m django --version
```

Python 3 환경을 사용하려면 같은 인터프리터로 버전과 패키지를 확인하고 실행합니다.

```bash
python3 --version
python3 -m pip --version
python3 -m django --version
python3 manage.py runserver
```

`python3 -m django --version`에서 Django가 설치되지 않았다고 나오면, 해당 Python 3 인터프리터에 맞춰 설치해야 합니다.

```bash
python3 -m pip install Django
python3 manage.py runserver
```

## 다른 해결 방법

프로젝트마다 Python과 Django 버전을 분리하려면 가상환경을 사용하는 것이 좋습니다. 다음은 새 Python 3 가상환경을 만들고 동일한 환경에서 Django를 설치하고 실행하는 예시입니다.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install Django
python -m django --version
python manage.py runserver
```

Windows에서는 가상환경을 ` .venv\Scripts\activate`로 활성화하고, 활성화한 뒤에는 `python -m pip`, `python manage.py`를 함께 사용합니다.

설치된 Django 버전이 프로젝트가 지원하는 Python 버전과 맞는지도 확인해야 합니다. 오래된 Django 프로젝트라면 무작정 최신 버전을 설치하기보다 해당 프로젝트에서 지원하는 조합을 확인한 뒤 고정합니다.

## 추가 참고사항

- `python -m pip`를 사용하면 현재 `python` 인터프리터에 연결된 pip로 패키지를 설치할 수 있습니다.
- `python -m django --version`은 해당 인터프리터에서 import되는 Django 버전을 확인하는 데 도움이 됩니다.
- shebang을 임의로 바꾸는 것보다, 프로젝트 생성·패키지 설치·실행에 같은 인터프리터와 가상환경을 사용하는 것이 근본적인 해결책입니다.
