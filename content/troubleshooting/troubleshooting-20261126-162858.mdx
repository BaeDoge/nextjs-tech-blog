## 현상

클래스를 인스턴스화한 뒤 메서드를 호출했는데, 정의한 것보다 인자가 하나 더 전달되었다는 TypeError가 발생할 수 있습니다.

~~~python
class Extractor:
    def extract_all(tag):
        print(tag)

extractor = Extractor()
extractor.extract_all("th")
~~~

오류 메시지는 Python 버전에 따라 다음과 유사하게 나타납니다.

~~~
TypeError: Extractor.extract_all() takes 1 positional argument but 2 were given
~~~

## 원인

인스턴스 메서드는 인스턴스를 통해 호출하면 해당 인스턴스가 첫 번째 인자로 자동 전달됩니다.

따라서 extractor.extract_all("th")는 개념적으로 Extractor.extract_all(extractor, "th")와 같이 호출됩니다.

기존 정의에는 매개변수가 tag 하나뿐이므로, 자동으로 전달된 인스턴스와 사용자가 전달한 문자열까지 총 두 개의 인자를 받으려다 오류가 발생합니다.

## 해결 방법 1: self 매개변수 추가

인스턴스 메서드의 첫 번째 매개변수에 관례적으로 self를 선언합니다.

~~~python
class Extractor:
    def extract_all(self, tag):
        print(tag)

extractor = Extractor()
extractor.extract_all("th")  # th
~~~

self는 현재 인스턴스를 가리킵니다. 메서드 내부에서 self.options처럼 인스턴스 속성에 접근할 수 있습니다.

## 해결 방법 2: 인스턴스 상태가 필요 없다면 staticmethod 사용

메서드가 인스턴스나 클래스의 상태를 사용하지 않는 독립적인 기능이라면 @staticmethod를 사용할 수 있습니다.

~~~python
class Extractor:
    @staticmethod
    def extract_all(tag):
        print(tag)

extractor = Extractor()
extractor.extract_all("th")  # th
~~~

정적 메서드는 인스턴스를 첫 번째 인자로 자동 전달하지 않으므로 self 매개변수가 필요하지 않습니다.

## 선택 기준

- 인스턴스의 속성이나 다른 인스턴스 메서드를 사용한다면 일반 인스턴스 메서드와 self를 사용합니다.
- 인스턴스 상태와 무관한 기능이라면 @staticmethod를 고려합니다.
