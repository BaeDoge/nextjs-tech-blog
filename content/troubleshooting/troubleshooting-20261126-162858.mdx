## 현상

클래스를 인스턴스화하여 메서드를 호출할 때, 예상과 달리 인자 수가 과다하다는 에러가 발생한다.

<Callout type="warning" title="오류 상황">

```python
TypeError: takes exactly 1 argument (2 given)
```

</Callout>

에러를 재현하는 최소 코드는 다음과 같다.

```python
class Extractor:
    def extractAll(tag):
        print(tag)

e = Extractor()
e.extractAll("th")
```

## 원인

파이썬의 인스턴스 메서드는 호출 시 인스턴스 객체 자체를 첫 번째 인자로 전달하는 동작을 한다.

따라서 `e.extractAll("th")` 호출은 내부적으로 `Extractor.extractAll(e, "th")`와 동일하게 처리된다.

메서드 정의에 `self` 파라미터가 명시되지 않으면, 파이썬은 전달된 인스턴스 `e`를 `tag` 파라미터에 할당하려 시도한다.

이로 인해 정의된 메서드가 기대하는 인자 수(1개)보다 실제 전달된 인자 수(2개)가 많아 에러가 발생한다.

## 해결 방법

인스턴스 메서드 정의 시 첫 번째 파라미터로 `self`를 명시하여 인스턴스 참조를 받도록 수정한다.

<Steps>
<Step title="self 파라미터 추가">
클래스 메서드의 파라미터 목록 맨 앞에 `self`를 추가한다.
</Step>
<Step title="코드 수정">
수정된 코드는 다음과 같다.
</Step>
</Steps>

```python
class Extractor:
    def extractAll(self, tag):
        print(tag)

e = Extractor()
e.extractAll("th")
```

## 다른 해결 방법

인스턴스 상태에 접근할 필요가 없는 경우 `@staticmethod` 데코레이터를 사용할 수 있다.

이 경우 메서드는 인스턴스 객체를 전달받지 않으므로 `self` 파라미터가 필요 없다.

```python
class Extractor:
    @staticmethod
    def extractAll(tag):
        print(tag)

e = Extractor()
e.extractAll("th")
```

## 추가 참고사항

정적 메서드로 정의할 경우, 인스턴스 속성에 접근할 수 없으므로 클래스 메서드인지 정적 메서드인지 의도를 명확히 구분해야 한다.

반대로 `self`가 필요한 인스턴스 메서드에서 `self`를 누락하면 `TypeError: missing 1 required positional argument: 'self'` 에러가 발생할 수 있다.

이러한 에러는 인스턴스 메서드 호출 시 첫 번째 인자가 암묵적으로 전달되는 파이썬의 동작 원리를 이해하면 예방할 수 있다.
