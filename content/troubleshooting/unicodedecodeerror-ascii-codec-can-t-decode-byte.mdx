## 현상

Python 2.7 환경에서 바이트 문자열을 UTF-8로 디코딩하거나 결과를 출력할 때 에러가 발생합니다.
에러 메시지에는 'ascii' codec가 byte 0xef를 디코드하지 못한다고 명시되며, 출력 시 'UnicodeEncodeError'가 발생할 수 있습니다.
Python 2.7에서 문자열 인코딩/디코딩이 적절히 설정되지 않은 경우 자주 발생합니다.

```python
>>> s = '(\xef\xbd\xa1\xef\xbd\xa5\xcf\x89\xef\xbd\xa5\xef\xbd\xa1)\xef\xbe\x89'
>>> s1 = s.decode('utf-8')
>>> print s1
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
UnicodeEncodeError: 'ascii' codec can't encode characters in position 1-5: ordinal not in range(128)
```

![현상 스크린샷](/blogs/unicodedecodeerror-ascii-codec-can-t-decode-byte-1.png)

## 원인

터미널의 로케일 환경 변수가 UTF-8이 아닌 경우, Python이 기본 텍스트 인코딩으로 ASCII를 사용합니다.
UTF-8로 디코딩된 유니코드 문자열을 ASCII 코덱으로 다시 인코딩하여 터미널에 출력하려고 할 때 발생합니다.
ASCII는 0~127 범위의 문자만 지원하므로, 이 범위를 벗어난 한글 또는 특수문자가 인코딩되지 못해 에러가 발생합니다.

```bash
$ unset LANG
$ python
Python 2.7.3 (default, Apr 20 2012, 22:39:59) 
[GCC 4.6.3] on linux2
>>> s = '(\xef\xbd\xa1\xef\xbd\xa5\xcf\x89\xef\xbd\xa5\xef\xbd\xa1)\xef\xbe\x89'
>>> s1 = s.decode('utf-8')
>>> print s1
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
UnicodeEncodeError: 'ascii' codec can't encode characters in position 1-5: ordinal not in range(128)
```

## 해결 방법

터미널의 `LANG` 환경 변수를 UTF-8 설정으로 변경하면 기본 인코딩이 UTF-8로 적용되어 에러가 해결됩니다.
셸에서 `LANG` 변수를 확인하고, 필요 시 `export` 명령어로 설정을 변경합니다.

```bash
$ export LANG=en_GB.UTF-8
```

변경 후 동일한 코드를 실행하면 정상적으로 출력이 됩니다.

```bash
$ python
Python 2.7.3 (default, Apr 20 2012, 22:39:59) 
[GCC 4.6.3] on linux2
>>> s = '(\xef\xbd\xa1\xef\xbd\xa5\xcf\x89\xef\xbd\xa5\xef\xbd\xa1)\xef\xbe\x89'
>>> s1 = s.decode('utf-8')
>>> print s1
(｡･ω･｡)ﾉ
```

## 다른 해결 방법

참고 자료에서는 명시되지 않았으나, Python 3에서는 기본 문자열이 유니코드이며 `open` 함수나 `print` 시 인코딩을 명시적으로 지정하여 처리할 수 있습니다.
파일 읽기 시에는 `encoding='utf-8'`을 인자로 전달하여 인코딩을 강제로 지정합니다.

```python
with open(file_name, 'r', encoding='UTF-8') as file:
    text = file.read()
```

파일 쓰기 시에도 동일하게 인코딩을 지정하여 에러를 방지합니다.

```python
with open(file_name, 'w', encoding='UTF-8') as file:
    file.write(text)
```

## 추가 참고사항

파일이나 CSV를 읽을 때 발생하는 `UnicodeDecodeError: 'utf-8' codec can't decode byte...` 오류는 입력 바이트가 유효한 UTF-8이 아니라는 뜻입니다.
이 경우 파일의 실제 저장 인코딩(CP949 등)과 코드에서 지정한 인코딩이 다르므로, 파일 생성 환경의 저장 인코딩을 확인해야 합니다.
`utf-8-sig` 인코딩을 사용하면 UTF-8 BOM이 붙은 파일을 정상적으로 읽을 수 있습니다.
pandas로 CSV를 읽을 때는 `encoding` 매개변수와 `encoding_errors` 매개변수를 사용하여 인코딩과 오류 처리 방식을 지정할 수 있습니다.
