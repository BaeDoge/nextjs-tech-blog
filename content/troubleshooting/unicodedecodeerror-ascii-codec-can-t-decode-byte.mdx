## 현상

Python 2.7에서 UTF-8 바이트 문자열을 유니코드로 디코딩한 뒤 터미널에 출력할 때 `UnicodeEncodeError`가 발생할 수 있습니다.

```python
s = '(\xef\xbd\xa1\xef\xbd\xa5\xcf\x89\xef\xbd\xa5\xef\xbd\xa1)\xef\xbe\x89'
s1 = s.decode('utf-8')
print s1
```

예시 환경에서 출력 시 발생하는 오류는 다음과 같습니다.

```text
UnicodeEncodeError: 'ascii' codec can't encode characters in position 1-5: ordinal not in range(128)
```

이 사례는 UTF-8 디코딩에 실패한 것이 아닙니다. `s.decode("utf-8")`는 성공했고, `print`가 유니코드 문자열을 터미널의 출력 인코딩인 ASCII로 변환하는 과정에서 실패한 것입니다.

## 원인

Python 2의 `str`은 바이트 문자열이고 `unicode`는 유니코드 문자열입니다. `decode("utf-8")`를 호출하면 바이트가 유니코드로 변환됩니다. 이후 `print`가 터미널에 출력하기 위해 유니코드를 인코딩하는데, 표준 출력의 인코딩이 ASCII이면 ASCII로 표현할 수 없는 문자를 출력할 수 없습니다.

즉, 이 예제의 직접적인 오류는 `UnicodeDecodeError`가 아니라 `UnicodeEncodeError`입니다. 터미널의 로케일 설정이 ASCII로 인식되거나 Python 2 프로세스의 표준 출력 인코딩이 ASCII로 설정된 경우 발생할 수 있습니다.

## 해결 방법

먼저 현재 로케일과 Python 표준 출력 인코딩을 확인합니다.

```bash
locale
locale -a
```

시스템에 설치된 UTF-8 로케일을 선택해 환경 변수로 지정합니다. 아래 `en_US.UTF-8`은 예시이므로, `locale -a` 결과에 실제 존재하는 로케일 이름을 사용해야 합니다.

```bash
export LANG=en_US.UTF-8
export LC_ALL=en_US.UTF-8
python script.py
```

## 다른 해결 방법

Python 2 프로세스의 표준 입출력 인코딩을 명시하려면 `PYTHONIOENCODING` 환경 변수를 사용할 수 있습니다.

```bash
PYTHONIOENCODING=utf-8 python script.py
```

Python 3에서는 문자열이 유니코드이므로, 터미널이 UTF-8 출력을 지원하는지 확인하고 필요한 경우 같은 환경 변수로 표준 출력 인코딩을 지정할 수 있습니다.

```bash
PYTHONIOENCODING=utf-8 python3 script.py
```

파일 입출력의 인코딩 문제라면 터미널 로케일과 별개로 `open()`의 `encoding`을 지정해야 합니다.

```python
with open("input.txt", "r", encoding="utf-8") as file:
    text = file.read()

with open("output.txt", "w", encoding="utf-8") as file:
    file.write(text)
```

## 추가 참고사항

- `UnicodeDecodeError`는 바이트를 지정한 문자 인코딩으로 디코딩하는 과정의 오류입니다.
- `UnicodeEncodeError`는 유니코드 문자를 지정한 인코딩으로 바꾸는 과정의 오류입니다.
- Python 2의 문자열과 Python 3의 문자열은 타입과 인코딩 동작이 다르므로, 신규 프로젝트에서는 지원이 종료된 Python 2 대신 Python 3을 사용합니다.
