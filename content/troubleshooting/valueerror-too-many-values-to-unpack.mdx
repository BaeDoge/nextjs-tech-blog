## 현상

파이썬에서 반복 가능한 객체(튜플, 리스트 등)를 변수에 할당할 때, 객체의 원소 개수가 변수 개수보다 많으면 다음 예외가 발생합니다.
<Callout type="warning" title="오류 상황">ValueError: too many values to unpack (expected N)</Callout>
예를 들어 길이가 3인 튜플을 변수 2개에 할당하려 할 때 재현되며, Django의 템플릿에서 `user.get_profile`과 같은 메서드 호출 시 내부적으로 발생하는 반환 값 구조 불일치로도 인해 나타날 수 있습니다.

```python
# 재현 코드
a, b = (1, 2, 3)
```

```text
# 오류 출력 원문
ValueError: too many values to unpack
```

## 원인

파이썬은 할당문의 좌변에 있는 변수의 개수와 우변 시퀀스의 원소 개수가 정확히 일치해야 값을 분배합니다.
오른쪽 시퀀스가 반환한 값의 개수가 왼쪽 변수 개수를 초과하면, 남은 값을 담을 변수가 없어 언팩이 실패하고 예외가 발생합니다.
반대로 값의 개수가 적으면 `ValueError: not enough values to unpack` 오류가 발생합니다.

```python
# 값이 3개, 변수 2개 (오류)
a, b = (1, 2, 3) 

# 값이 2개, 변수 3개 (오류)
a, b, c = (1, 2)
```

## 해결 방법

오류가 발생한 코드의 변수 개수와 할당받을 객체의 원소 개수를 일치시키면 오류가 해결됩니다.
반환 값의 개수가 3개라면, 변수를 3개로 늘려서 정확히 대응해야 합니다.

```python
# 수정 전: 변수 2개, 값 3개 (오류 발생)
# a, b = (1, 2, 3)

# 수정 후: 변수 3개로 개수 일치
a, b, c = (1, 2, 3)
```

## 다른 해결 방법

할당하려는 값의 개수가 불확실하거나, 일부 값은 무시하고 나머지만 처리해야 할 때는 애스터리스크(`*`)를 사용할 수 있습니다.
이 방법을 사용하면 첫 번째 변수에 값을 할당하고, 나머지 모든 값을 리스트 형태로 한 변수에 묶어 할당할 수 있습니다.

```python
# 수정 전: 값 4개, 변수 2개 (오류 발생)
# x, y = (1, 2, 3, 4)

# 수정 후: 나머지 값을 리스트로 묶어 할당
x, y, *rest = (1, 2, 3, 4)
print(x)  # 1
print(y)  # 2
print(rest)  # [3, 4]
```

## 추가 참고사항

`split` 함수 등 문자열을 분리하여 할당할 때도 이 오류가 빈번하게 발생합니다.
이 경우에도 변수의 개수를 맞추거나, 필요 없는 중간 값을 `_` 또는 `*`로 처리해야 합니다.

```python
# split 결과 개수 맞추기
s = "1/2/3"
x, y, z = s.split('/')

# 필요 없는 값은 언더바 처리
x, y, _ = s.split('/')

# 필요 없는 값은 애스터리스크 처리
x, y, *_ = s.split('/')
```

<Checklist>
<ul><li>할당문의 변수 개수와 우변 시퀀스 길이 일치 여부 확인</li><li>값이 많을 경우 * 연산자를 사용하여 나머지 처리 검토</li><li>문자열 분리 등 함수 반환값의 개수를 정확히 파악</li></ul>
</Checklist>
