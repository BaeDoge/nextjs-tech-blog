## 현상

파이썬에서 `requests` 라이브러리를 사용해 HTTPS URL에 접속할 때 인증서 검증 실패 오류가 발생합니다.
Windows 7 환경에서 다음 코드를 실행하면 `requests.exceptions.SSLError`가 발생합니다.

```python
import requests
requests.get('https://google.com')
```

<Callout type="warning" title="오류 상황">
requests.exceptions.SSLError: HTTPSConnectionPool(host='google.com', port=443):
Max retries exceeded with url: / (Caused by SSLError(SSLError(1, '[SSL: CERTIFICATE_VERIFY_FAILED] certificate verify failed (_ssl.c:833)'),))
</Callout>

![현상 스크린샷](/blogs/ssl-certificate-verify-failed-161908-1.jpg)

## 원인

파이썬이 서버가 보낸 SSL 인증서를 신뢰할 수 있는 루트 인증서 목록에서 찾지 못해 검증에 실패합니다.
이는 로컬 환경의 인증서 파일 경로가 누락되었거나, 회사 내부의 자체 서명 인증서(SSL)를 사용하는 프록시 환경에서 발생할 수 있습니다.
에러 메시지 중 `certificate verify failed` 뒤의 문구를 통해 구체적인 원인을 파악할 수 있습니다.

## 해결 방법

`requests` 라이브러리의 `verify` 파라미터에 인증서 파일 경로를 직접 지정하여 해결할 수 있습니다.
이 방법은 시스템의 기본 인증서 목록 대신 특정 CA 인증서 파일을 사용하도록 강제합니다.

```python
import requests

# 인증서 파일 경로 지정
requests.get('https://google.com', verify='/path/to/certfile')
```

![해결 방법 스크린샷](/blogs/ssl-certificate-verify-failed-161908-2.png)

## 다른 해결 방법

보안 검증 단계를 완전히 생략하여 오류를 우회할 수 있습니다.
이 방법은 개발 환경에서의 임시 조치로 권장되며, 실제 서비스에서는 보안 취약점이 발생할 수 있으므로 주의해야 합니다.

```python
import requests

# SSL 검증 비활성화
requests.get('https://google.com', verify=False)
```

## 추가 참고사항

<Steps>
<Step title="환경 진단">
`ssl.get_default_verify_paths()`를 호출하여 현재 Python이 참조하는 기본 인증서 경로를 확인합니다.
</Step>
<Step title="서버 인증서 확인">
브라우저에서도 같은 주소에 인증서 경고가 발생하는지 확인합니다. 브라우저와 Python의 결과가 다르면 Python의 CA bundle 또는 프록시 인증서 설정을 점검합니다.
</Step>
<Step title="pip 사용 환경 확인">
패키지 설치 중 발생한 오류라면 `pip --cert /path/to/ca-bundle.pem`처럼 신뢰할 CA 인증서 번들을 지정하는 방법을 우선 고려합니다.
</Step>
</Steps>

<Callout type="info" title="참고 사항">
에러 메시지 끝부분의 `_ssl.c` 뒤 숫자는 파이썬 빌드 버전에 따라 다르므로 무시해도 됩니다.
</Callout>
