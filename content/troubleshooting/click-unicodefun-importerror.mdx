## 현상

<Callout type="warning" title="오류 상황">
ImportError: cannot import name '_unicodefun' from 'click'
</Callout>

Python Black 패키지를 사용하여 린트 검사나 코드 포맷팅을 실행할 때 해당 오류가 발생합니다. 이는 주로 `pre-commit` 훅이나 직접 `black` 명령어를 실행하는 환경에서 발생합니다.

에러 발생 시 traceback은 다음과 같은 형태를 띱니다.

```python
ImportError: cannot import name '_unicodefun' from 'click' (/Users/robot/.cache/pre-commit/repo3u71ccm2/py_env-python3.9/lib/python3.9/site-packages/click/__init__.py)
```

## 원인

<Callout type="info" title="원인 분석">
Black 22.3.0 미만 버전은 click 8.1.0 이상과 호환되지 않습니다.
</Callout>

Black 패키지는 내부적으로 `click` 라이브러리를 의존성으로 사용합니다. `click` 라이브러리가 8.1.0으로 업그레이드되면서 내부적으로 사용하던 `_unicodefun` 모듈이 제거되었습니다.

Black 22.3.0 미만 버전은 이 내부 모듈을 참조하도록 작성되어 있어, 최신 버전의 `click`이 설치되면 ImportError가 발생합니다.

## 해결 방법

<Callout type="success" title="권장 해결책">
Black 패키지를 22.3.0 이상으로 업그레이드합니다.
</Callout>

Black 22.3.0 버전부터 click 8.1.0의 변경 사항에 대응하여 해당 오류가 해결되었습니다.

**pip를 통한 업그레이드**

```bash
pip install "black>=22.3.0"
```

**pre-commit 설정 파일 수정**

`pre-commit-config.yaml` 파일에서 Black의 버전을 명시적으로 22.3.0 이상으로 고정합니다.

```yaml
repos:
-   repo: https://github.com/psf/black
    rev: 22.3.0  # 또는 더 최신 버전
    hooks:
    -   id: black
```

업데이트 후 캐시를 정리해야 최신 패키지가 적용됩니다.

```bash
pre-commit clean
pre-commit autoupdate
```

## 다른 해결 방법

<Callout type="tip" title="하위 호환성 유지">
Black 업그레이드가 불가능한 경우, click 버전을 하위 버전으로 제한합니다.
</Callout>

프로젝트 정책이나 다른 의존성 문제로 Black 업그레이드가 어려운 경우, `click` 라이브러리의 버전을 호환되는 이전 버전으로 내립니다.

**click 버전 고정**

```bash
pip install click==8.0.2
```

이 방법은 Black을 업그레이드하지 않고도 오류를 해결할 수 있습니다.

## 추가 참고사항

<Callout type="info" title="참고 사항">
다른 유사한 import 오류 발생 시 캐시 정리 및 버전 충돌 확인이 필요합니다.
</Callout>

*   **캐시 문제**: 패키지를 업그레이드하거나 버전을 변경했음에도 오류가 지속되면, 이전 설치 파일이 캐시되어 있을 수 있습니다. `pre-commit clean` 명령을 실행하거나 가상 환경을 새로 생성하여 테스트해 보세요.
*   **버전 확인**: 현재 설치된 패키지 버전을 확인하려면 다음 명령어를 사용하세요.

```bash
pip show black click
```
