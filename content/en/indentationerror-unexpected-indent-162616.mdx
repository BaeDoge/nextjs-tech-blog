## Symptom

An `IndentationError: unexpected indent` error occurs when running Python code or a script. This happens when indentation is used in an unexpected location within the code.

<Callout type="warning" title="Error Situation">
IndentationError: unexpected indent
</Callout>

A typical example of where this error occurs is as follows:

```python
def greet():
    print("Hello")
        print("Again")  # Unnecessary indentation -> Error occurs
```

The same issue also arises when the indentation level is inconsistent after a statement that requires a block, or when tabs and spaces are mixed.

```python
def greet():
print("Hello")  # No indentation -> Error occurs
```

## Cause

Unlike other languages, Python does not use curly braces (`{}`) to distinguish code blocks; instead, it determines the structure of statements through indentation. Therefore, indentation is not just for readability but is part of the syntax itself.

The main causes of this error are:

1. **Unnecessary indentation outside a block**: Code is indented outside of a function or conditional block.
2. **Inconsistent indentation levels**: The depth of indentation is not uniform within the same code block.
3. **Mixing tabs and spaces**: Although invisible, mixing tab (`Tab`) characters and space (`Space`) characters prevents the Python interpreter from accurately calculating indentation depth.

```python
# 원인 1: 블록 외부 들여쓰기
 print("첫 번째 줄")  # <- 여기 앞에 공백이 하나 숨어있음! (에러 발생)

# 원인 2: 들여쓰기 수준 불일치
def func():
    print("A")
      print("B")  # 들여쓰기 깊이가 A와 다름
```

## Solution

The most reliable solution is to consistently use **4 spaces** for indentation according to the PEP 8 guidelines.

1. Move the cursor to the beginning of the line where the error occurred.
2. Delete all spaces and tabs at the beginning of that line.
3. If the code is inside a block, enter 4 spaces for the appropriate depth.

The code before and after the fix is as follows:

## Alternative Solutions

If the error is caused by mixing tabs and spaces, you can fundamentally verify and fix this by changing editor settings or using command-line options.

1. **Change Editor Settings**: Enable the 'Convert Tabs to Spaces' setting in your editor (e.g., Vim, VS Code).
2. **Check Command-Line Options**: Adding the `-tt` option when running the script will explicitly warn you about parts where tabs and spaces are mixed.

<Terminal title="Execution Example">
python -tt your_script.py
</Terminal>

<Callout type="info" title="Editor Tip">
In Vim, enabling the `'list'` option allows you to visually distinguish between tabs and spaces, reducing mistakes.
</Callout>

## Additional Notes

`IndentationError` is one of the most common errors encountered by Python beginners. A similar error message is `IndentationError: expected an indented block`. This occurs when indentation is missing on the line following a statement ending with a colon (`:`), such as `if`, `for`, or `def`.

```python
# IndentationError: expected an indented block 예시
if True:
print("참입니다")  # 콜론 다음 줄은 무조건 들여쓰기 필요
```

To prevent these errors, it is important to actively use auto-formatting features when writing code and to develop the habit of not mixing tabs and spaces.
