## Symptom

Python raises `IndentationError: unexpected indent` when a line is indented where the interpreter does not expect a new indentation level.

```python
def greet():
    print("Hello")
        print("Again")  # Unexpected additional indentation
```

A missing indentation after a block-opening statement is a different error: `IndentationError: expected an indented block`.

```python
def greet():
print("Hello")  # Missing indentation; expected an indented block
```

## Cause

Python uses indentation to define code blocks. Common causes include:

1. **Unexpected indentation outside a block**: a line begins with spaces or tabs even though no enclosing block is active.
2. **Inconsistent indentation**: statements within the same block use different indentation levels.
3. **Mixed tabs and spaces**: ambiguous indentation can raise `TabError: inconsistent use of tabs and spaces in indentation`, which is distinct from `unexpected indent`.

```python
# Unexpected indentation at module level
 print("This line starts with an unintended space")

# Inconsistent indentation within a block
def example():
    print("A")
      print("B")  # Different indentation level
```

## Solution

Use four spaces per indentation level, consistently, as recommended by PEP 8. Remove leading tabs and spaces from the affected line, then indent it only when it belongs inside a function, loop, conditional, or another block.

## Alternative Solutions

If tabs and spaces may be mixed, display whitespace in your editor and convert tabs to spaces. You can also run Python’s `tabnanny` module to check for ambiguous indentation.

```bash
python -m tabnanny your_script.py
```

In Vim, enabling the `list` option makes tabs and spaces visible.

## Additional Notes

Do not confuse `unexpected indent` with `expected an indented block`. The latter occurs when a statement ending with a colon is not followed by an indented suite.

```python
# IndentationError: expected an indented block
if True:
print("This line must be indented")
```
