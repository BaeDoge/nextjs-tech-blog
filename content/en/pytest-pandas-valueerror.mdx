## Symptom

An assertion comparing a pandas column index with a Python list may raise:

```text
ValueError: The truth value of an array with more than one element is ambiguous. Use a.any() or a.all()
```

A minimal example is:

```python
import pandas as pd

actual = pd.DataFrame(columns=["bl", "direction", "day"])
assert actual.columns == ["bl", "direction", "day"]  # Ambiguous truth value
```

## Cause

`DataFrame.columns` is a `pandas.Index`, not a built-in Python list. Comparing pandas array-like objects with `==` produces element-wise Boolean results. An `assert` statement needs one Boolean value, so pandas raises an error when the result contains multiple elements.

## Solution

Convert the index to a Python list before comparing it with a list literal.

```python
import pandas as pd

actual = pd.DataFrame(columns=["bl", "direction", "day"])
expected = ["bl", "direction", "day"]

assert actual.columns.tolist() == expected
```

## Alternative Solutions

Use `Index.equals()` when comparing two pandas index objects.

```python
import pandas as pd

actual = pd.DataFrame(columns=["bl", "direction", "day"])
expected = pd.Index(["bl", "direction", "day"])

assert actual.columns.equals(expected)
```

To compare entire DataFrames, use `pd.testing.assert_frame_equal()`.

```python
import pandas as pd

actual_df = pd.DataFrame({"bl": [1], "direction": ["BUY"], "day": [1]})
expected_df = pd.DataFrame({"bl": [1], "direction": ["BUY"], "day": [1]})

pd.testing.assert_frame_equal(actual_df, expected_df)
```

This checks the index, columns, dtypes, and values, not just the column labels.

## Additional Notes

Check the type of the object before choosing an assertion:

```python
print(type(actual.columns))
```

For a built-in Python list, `==` returns a single Boolean value. For pandas objects, use `.equals()`, convert to a list when appropriate, or use the `pd.testing` helpers.
