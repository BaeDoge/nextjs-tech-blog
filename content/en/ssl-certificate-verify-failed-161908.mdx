## Symptom

When accessing an HTTPS URL using the `requests` library in Python, a certificate verification failure error occurs.
Running the following code in a Windows 7 environment results in a `requests.exceptions.SSLError`.

```python
import requests
requests.get('https://google.com')
```

<Callout type="warning" title="Error Situation">
requests.exceptions.SSLError: HTTPSConnectionPool(host='google.com', port=443):
Max retries exceeded with url: / (Caused by SSLError(SSLError(1, '[SSL: CERTIFICATE_VERIFY_FAILED] certificate verify failed (_ssl.c:833)'),))
</Callout>

![Symptom screenshot](/blogs/ssl-certificate-verify-failed-161908-1.jpg)

## Cause

Python fails to verify the SSL certificate sent by the server because it cannot find it in the list of trusted root certificates.
This can occur if the local environment's certificate file path is missing or when using a proxy environment with internally signed SSL certificates.
You can identify the specific cause by examining the text following `certificate verify failed` in the error message.

## Solution

You can resolve this by specifying the certificate file path directly in the `verify` parameter of the `requests` library.
This method forces the use of a specific CA certificate file instead of the system's default certificate list.

```python
import requests

# Specify certificate file path
requests.get('https://google.com', verify='/path/to/certfile')
```

![Solution screenshot](/blogs/ssl-certificate-verify-failed-161908-2.png)

## Alternative Solutions

You can bypass the error by completely skipping the security verification step.
This method is recommended as a temporary measure in development environments, but be cautious as it may introduce security vulnerabilities in production services.

```python
import requests

# Disable SSL verification
requests.get('https://google.com', verify=False)
```

## Additional Notes

<Steps>
<Step title="Environment Diagnosis">
Call `ssl.get_default_verify_paths()` to check the default certificate paths currently referenced by Python.
</Step>
<Step title="Check Server Status">
If a warning appears when accessing the same address in a browser, the server may be missing intermediate certificates.
</Step>
<Steps>
<Step title="Error During pip Installation">
If this error occurs during package installation, add the `--trusted-host` option or modify the `requests` settings within `pip`.
</Step>
</Steps>
</Steps>

<Callout type="info" title="Reference">
The number following `_ssl.c` at the end of the error message varies depending on the Python build version and can be ignored.
</Callout>
