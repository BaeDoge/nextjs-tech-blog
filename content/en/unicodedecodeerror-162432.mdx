## Symptom

An encoding error occurs when reading a CSV file or opening a text file.
The error message indicates that the 'utf-8' codec cannot interpret the bytes at a specific position.

<Callout type="warning" title="Error Situation">
UnicodeDecodeError: 'utf-8' codec can't decode byte 0x96 in position 35: invalid start byte
</Callout>

```python
import pandas as pd

# Occurs when UTF-8 is specified but the file is not encoded in UTF-8
Past = pd.read_csv("C:/Users/Admin/Desktop/Python/Past.csv", encoding='utf-8')
```

![Symptom screenshot](/blogs/unicodedecodeerror-162432-1.png)

## Cause

The file's actual stored encoding differs from the encoding specified in the code.
Python 3 strings are Unicode, and raw bytes from the file are converted using the specified codec.
In Windows environments, the default Korean encoding is often CP1252 or CP949.
Forcing UTF-8 interpretation on non-UTF-8 bytes results in an invalid start byte error.

## Solution

Check the export settings of the file creation program to identify the actual encoding.
Explicitly specify the file's actual encoding in the `encoding` parameter of pandas.

```python
import pandas as pd

# Change to cp1252, the default Korean encoding on Windows
Past = pd.read_csv("C:/Users/Admin/Desktop/Python/Past.csv", encoding='cp1252')
```

<Steps>
<Step title="Check File Encoding">
Verify the file's save format using a text editor or the file creation program.
</Step>
<Step title="Modify Encoding Parameter">
Change `encoding='utf-8'` to the actual file encoding (e.g., `cp1252`, `cp949`).
</Step>
<Step title="Run and Verify">
Execute the code to confirm that the file loads correctly.
</Step>
</Steps>

## Alternative Solutions

If the original encoding is unknown or some data loss is acceptable, change the error handling behavior.
Use the `errors` parameter to specify behavior when conversion fails.

<Compare>
<ComparePanel title="Existing (strict)" tone="bad">

```python
# Default behavior; raises an exception immediately on error
df = pd.read_csv("data.csv", encoding="utf-8")
```

</ComparePanel>
<ComparePanel title="Proposed (replace)" tone="good">

```python
# Replaces erroneous bytes with replacement characters and continues processing
df = pd.read_csv("data.csv", encoding="utf-8", errors="replace")
```

</ComparePanel>
</Compare>

```python
import pandas as pd

# Keep encoding as utf-8, but use replacement characters on error
df = pd.read_csv(
    "data.csv",
    encoding="utf-8",
    errors="replace"
)
print(df.head())
```

<Callout type="info" title="Caution">
`errors="ignore"` completely discards the problematic bytes.
Be cautious as this is not suitable for data containing names, amounts, or identifiers.
</Callout>

## Additional Notes

The same encoding rules apply when reading general text files.
You must explicitly specify the `encoding` parameter when using the `open` function or `pathlib`.

```python
from pathlib import Path

path = Path("data.txt")
# Read file with cp949 encoding
with path.open("r", encoding="cp949") as f:
    text = f.read()

print(text[:100])
```

Files containing a UTF-8 BOM (Byte Order Mark) should use the `utf-8-sig` encoding.
Reading with `utf-8` may cause the BOM character to be recognized as part of the text, interfering with data processing.

```python
# Read file with UTF-8 BOM
with open("data_bom.txt", "r", encoding="utf-8-sig") as f:
    text = f.read()
```
