## Symptom

Reading a CSV file as UTF-8 may raise `UnicodeDecodeError` when the file was saved using a different character encoding.

```text
UnicodeDecodeError: 'utf-8' codec can't decode byte 0x96 in position 35: invalid start byte
```

```python
import pandas as pd

df = pd.read_csv("data.csv", encoding="utf-8")
```

![Symptom screenshot](/blogs/unicodedecodeerror-162432-1.png)

## Cause

The encoding specified in the code does not match the encoding used to save the file. Python 3 decodes the file bytes using the selected codec; bytes that are invalid under that codec cause `UnicodeDecodeError`.

Do not infer the encoding from the operating system alone. Legacy files created on Korean Windows systems may use CP949, while files produced by Western applications may use CP1252. Check the source application’s export settings or the file’s documented format.

## Solution

Use the encoding that was actually used to create the file. For example, use CP949 only when the file is known to be encoded in CP949.

```python
import pandas as pd

df = pd.read_csv("data.csv", encoding="cp949")
```

If the source is known to be CP1252, specify that instead:

```python
df = pd.read_csv("data.csv", encoding="cp1252")
```

## Alternative Solutions

When the encoding is known but a small number of malformed byte sequences must be handled, pandas provides the `encoding_errors` parameter.

```python
import pandas as pd

df = pd.read_csv(
    "data.csv",
    encoding="utf-8",
    encoding_errors="replace",
)
```

`encoding_errors="replace"` inserts replacement characters for bytes that cannot be decoded. `encoding_errors="ignore"` discards undecodable bytes and may silently lose information. Do not use it for names, financial amounts, identifiers, or other important fields unless data loss is explicitly acceptable.

## Additional Notes

For ordinary text files, specify the encoding in `open()` or `pathlib` as well.

```python
from pathlib import Path

path = Path("data.txt")
with path.open("r", encoding="cp949") as file:
    text = file.read()
```

Files with a UTF-8 byte-order mark (BOM) can be read with `utf-8-sig`.

```python
with open("data_bom.csv", "r", encoding="utf-8-sig") as file:
    text = file.read()
```
