## Symptom

A custom class inheriting from `list` is unhashable by default. Attempting to add an instance to a set or use it as a dictionary key raises `TypeError`.

```python
class Items(list):
    pass

items = Items([1, 2, 3])
{items}  # TypeError: unhashable type: 'Items'
```

## Cause

Lists are mutable and define value-based equality. Python therefore sets `__hash__ = None` on `list` and, by default, on subclasses that inherit its equality behavior. A dictionary key or set element must have a hash value that remains stable while it is stored in the collection.

Simply assigning `tuple.__hash__` to a list subclass does not make the object immutable. Even a custom method such as `return hash(tuple(self))` is unsafe if the list can later be modified: its hash may change while it is already stored in a set or dictionary.

## Recommended Solution

Do not make a mutable list subclass hashable for use as a key. Create an immutable snapshot, such as a tuple, at the point where the key is needed.

```python
items = [1, 2, 3]
key = tuple(items)

lookup = {key: "value"}
print(lookup[(1, 2, 3)])  # value
```

For nested lists, convert each nested sequence as well.

```python
nested = [[1, 2], [3, 4]]
key = tuple(tuple(row) for row in nested)
lookup = {key: "value"}
```

## Alternative Solutions

If a domain object genuinely needs to be hashable, prefer an immutable data model whose equality and hash fields cannot change after construction. A frozen dataclass is one option when all fields used in equality are themselves hashable.

```python
from dataclasses import dataclass

@dataclass(frozen=True)
class Point:
    x: int
    y: int

points = {Point(1, 2)}
```

Do not define a content-based hash on a mutable list subclass merely to silence the exception. If a pandas column contains lists and `drop_duplicates()` reports an unhashable value, create a separate immutable representation for the comparison or deduplication key.

```python
# Create a separate tuple key without changing the original list column
df["Like_Tuple"] = df["Like"].map(tuple)
df = df.drop_duplicates(["Like_Tuple"])
```

## Additional Notes

Hash and equality behavior must remain stable for the entire time an object is stored in a set or dictionary. Use immutable tuples or immutable domain objects as keys; do not mutate an object after using it as a hash key.
