## Symptom

Calling a method on a class instance may raise an argument-count `TypeError` when the method definition omits the `self` parameter.

In current Python 3 versions, the message is similar to:

```text
TypeError: Extractor.extractAll() takes 1 positional argument but 2 were given
```

```python
class Extractor:
    def extractAll(tag):
        print(tag)

e = Extractor()
e.extractAll("th")
```

The wording `takes exactly 1 argument (2 given)` appears in older Python versions; the underlying cause is the same.

## Cause

When an instance method is accessed through an object, Python binds the instance and passes it as the first argument. Thus, `e.extractAll("th")` is effectively equivalent to `Extractor.extractAll(e, "th")`.

Without a `self` parameter, the method receives two positional arguments even though its definition accepts only one.

## Solution

Declare `self` as the first parameter of an instance method.

```python
class Extractor:
    def extractAll(self, tag):
        print(tag)

e = Extractor()
e.extractAll("th")
```

## Alternative Solution

If the method does not need instance state, declare it with `@staticmethod`. Static methods do not receive an instance automatically.

```python
class Extractor:
    @staticmethod
    def extractAll(tag):
        print(tag)

e = Extractor()
e.extractAll("th")
```

## Additional Notes

A static method cannot access instance attributes through `self`. Choose between an instance method, class method, and static method based on which state the operation needs.
