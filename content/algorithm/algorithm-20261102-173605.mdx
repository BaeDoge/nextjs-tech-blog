## 문제

$n$명의 사람들이 1부터 $n$까지 번호로 라벨이 지정된 마을이 있다. 이들 중 한 사람이 비밀리에 마을 판사일 수 있다는 루머가 퍼졌다.

판사가 존재하려면 다음 세 가지 조건을 모두 만족해야 한다. 첫째, 판사는 아무도 신뢰하지 않아야 한다. 둘째, 마을의 모든 사람(판사 자신 제외)은 판사를 신뢰해야 한다. 셋째, 이 두 조건을 만족하는 사람이 정확히 한 명이어야 한다.

이때 신뢰 관계를 나타내는 2차원 배열 `trust`가 주어진다. `trust[i] = [ai, bi]`는 번호 $a_i$를 가진 사람이 번호 $b_i$를 가진 사람을 신뢰한다는 뜻이다. 신뢰 관계가 배열에 없는 경우 해당 신뢰는 존재하지 않는 것으로 간주한다.

판사가 존재하고 식별 가능한 경우 해당 번호를, 그렇지 않은 경우 -1을 반환한다. 입력의 제약 조건은 $1 \le n \le 1000$이며, 신뢰 관계의 개수는 최대 $10^4$이다.

## 접근 방법

문제를 그래프 이론의 진입차수와 진출차수 개념으로 모델링할 수 있다. 각 사람은 그래프의 정점, 신뢰 관계는 방향 간선으로 볼 수 있다.

판사의 조건 1에 따라 판사는 아무도 신뢰하지 않으므로, 판사의 진출차수는 0이어야 한다. 판사의 조건 2에 따라 판사는 다른 모든 $n-1$명의 사람에게서 신뢰를 받아야 하므로, 판사의 진입차수는 $n-1$이어야 한다.

따라서 각 사람의 진입차수에서 진출차수를 뺀 '신뢰 순이익(net trust score)'을 계산하면 판사를 찾을 수 있다. 판사의 순이익은 $(n-1) - 0 = n-1$이 되어야 한다.

모든 사람을 순회하면서 각 사람의 신뢰 순이익을 업데이트한다. 최종적으로 순이익이 $n-1$과 같은 사람을 찾으면 그것이 판사이다. 만약 그러한 사람이 없거나 여러 명이면 판사가 없으므로 -1을 반환한다.

이러한 접근은 각 신뢰 관계를 한 번씩만 확인하면 되므로 효율적이다.

## 풀이

각 사람의 신뢰 순이익을 저장할 정수 배열을 초기화한다. `trust` 배열을 반복문으로 순회하며 각 신뢰 관계 `[a, b]`에 대해 $a$의 점수를 -1 감소시키고 $b$의 점수를 +1 증가시킨다.

모든 관계를 처리한 후, $1$부터 $n$까지의 모든 사람을 순회하며 순이익이 $n-1$인 사람을 찾는다. 해당 사람을 발견하면 즉시 해당 라벨을 반환한다. 전체 순회 후에도 판사를 찾지 못했다면 -1을 반환한다.

시간 복잡도는 신뢰 관계의 수를 $E$, 사람의 수를 $N$이라 할 때 신뢰 관계 탐색에 $O(E)$, 사람 확인에 $O(N)$이므로 총 $O(N + E)$이다. 공간 복잡도는 사람의 수만큼 점수를 저장하기 위해 $O(N)$의 배열을 사용한다.

```python
from typing import List

class Solution:
    def findJudge(self, n: int, trust: List[List[int]]) -> int:
        # 각 사람의 신뢰 순이익을 저장하는 배열. 인덱스 1부터 n까지 사용.
        score = [0] * (n + 1)
        
        for a, b in trust:
            score[a] -= 1  # 신뢰를 보내므로 점수 감소
            score[b] += 1  # 신뢰를 받으므로 점수 증가
            
        for i in range(1, n + 1):
            # 판사의 조건: 다른 모든 n-1 명에게서 신뢰를 받고, 누구도 신뢰하지 않음.
            # 순이익이 n-1이어야 함.
            if score[i] == n - 1:
                return i
                
        return -1
```

## 다른 풀이 방법

진입차수와 진출차수를 따로 저장하는 방법도 있다. `indegree` 배열과 `outdegree` 배열을 각각 크기가 $n+1$인 배열로 선언한다. `trust` 배열을 순회할 때 $b$의 진입차수를 증가시키고 $a$의 진출차수를 증가시킨다.

판사를 찾기 위해 $1$부터 $n$까지 순회하며, `indegree[i] == n - 1`이고 `outdegree[i] == 0`인 조건을 만족하는 $i$를 찾는다. 이 방법은 순이익 계산 대신 두 개의 조건을 명시적으로 체크한다는 점이 다르다.

시간 복잡도는 신뢰 관계 탐색에 $O(E)$, 판사 검증에 $O(N)$이므로 $O(N + E)$로 동일하다. 공간 복잡도는 두 개의 배열을 사용하므로 여전히 $O(N)$이다. 순이익을 계산하는 방법이 배열 하나만 사용하면 되므로 코드 구현 면에서 더 간결한 장점이 있다.

## 추가 참고사항

이 문제는 그래프의 기본 개념인 진입차수와 진출차수를 이해하면 쉽게 해결할 수 있다. 판사는 진입차수가 최대이고 진출차수가 0인 유일한 정점으로 정의된다.

제약 조건에서 $n$이 최대 1000이고 신뢰 관계가 최대 $10^4$이므로, $O(N + E)$의 시간 복잡도는 충분히 효율적이다. 만약 $n$이 매우 크거나 신뢰 관계가 밀집되어 있어도 선형 시간 안에 해결 가능하다.

판사가 존재하지 않는 경우를 고려해야 한다. 예를 들어 신뢰 관계가 없거나, 서로 순환하는 신뢰 관계가 있거나, 판사를 의심할 후보자가 여러 명인 경우 모두 -1을 반환해야 한다. 본 알고리즘은 조건을 정확히 만족하는 사람이 딱 한 명인지를 확인하므로 이러한 경계 조건을 자연스럽게 처리한다.
