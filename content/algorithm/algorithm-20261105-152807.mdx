## 문제

두 복소수 문자열이 주어집니다. 각 문자열은 "real+imaginaryi" 형식이며, real과 imaginary는 -100 이상 100 이하의 정수입니다. i² = -1이라는 성질을 이용하여 두 복소수의 곱을 구하고, 결과도 동일한 형식의 문자열로 출력해야 합니다.

## 접근 방법

복소수 곱셈 공식 (a+bi)(c+di) = (ac - bd) + (ad + bc)i를 직접 적용합니다. 문자열을 '+'를 기준으로 분리하여 실수 부분과 허수 부분을 추출하고, 마지막 'i'를 제거하여 정수로 변환합니다. 계산된 실수와 허수를 다시 문자열로 결합합니다. 문자열 길이가 제한되어 있어 일정한 시간 내에 처리 가능합니다.

## 풀이

```python
class Solution:
    def complexNumberMultiply(self, num1: str, num2: str) -> str:
        # 실수와 허수 부분 분리
        a, bi = num1.split('+')
        b = int(bi[:-1])
        c, di = num2.split('+')
        d = int(di[:-1])
        
        # 복소수 곱셈 공식 적용
        real = int(a) * int(c) - b * d
        imag = int(a) * d + b * int(c)
        
        return f"{real}+{imag}i"
```

시간 복잡도: O(1) — 문자열 길이가 제한되어 있어 상수 시간에 처리됩니다.  
공간 복잡도: O(1) — 추가로 사용하는 변수는 고정된 개수입니다.

## 다른 풀이 방법

문자열에서 '+'와 'i'의 위치를 직접 찾아 인덱싱으로 실수와 허수를 추출하는 방법도 있습니다. 이는 split 대신 find와 슬라이싱을 사용해 동일한 결과를 얻을 수 있으며, 동작 방식은 동일한 복소수 곱셈 공식을 기반으로 합니다. 두 모두 입력 크기가 제한되어 있어 시간 복잡도 차이가 negligible합니다.

```python
class Solution:
    def complexNumberMultiply(self, num1: str, num2: str) -> str:
        # 인덱스를 이용한 파싱
        plus1 = num1.find('+')
        plus2 = num2.find('+')
        a = int(num1[:plus1])
        b = int(num1[plus1+1:-1])
        c = int(num2[:plus2])
        d = int(num2[plus2+1:-1])
        
        return f"{a*c - b*d}+{a*d + b*c}i"
```

## 추가 참고사항

입력 형식은 항상 유효한 복소수 문자열이며, 허수 부분이 음수인 경우 "+-1i"와 같이 표현될 수 있습니다. split('+')를 사용하면 이 경우에도 올바르게 분리됩니다. 문제의 제약 조건范围内에서 추가 예외 처리가 필요하지 않습니다.
