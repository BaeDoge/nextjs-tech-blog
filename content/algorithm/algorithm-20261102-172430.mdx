## 문제

정수 배열 `arr`이 주어집니다. 이 배열을 빈이 아닌 세 부분으로 나누어 각 부분의 합이 같도록 할 수 있는지 확인하는 문제입니다.
분할은 인덱스 `i`와 `j` (`i + 1 < j`)를 사용하여 `[0, i]`, `[i+1, j-1]`, `[j, n-1]` 세 구간으로 나누는 것을 의미합니다.
각 구간의 합이 서로 같아야 하며, 조건을 만족하면 `true`를, 그렇지 않으면 `false`를 반환해야 합니다.
배열의 길이는 3 이상 50,000 이하이며, 각 요소의 값은 -10,000에서 10,000 사이입니다.

## 접근 방법

먼저 전체 배열의 합을 구합니다. 만약 전체 합이 3으로 나누어떨어지지 않으면, 세 부분으로 나누어 합을 같게 할 수 없으므로 바로 `false`를 반환합니다.
전체 합을 3으로 나눈 값을 `target_sum`이라고 합니다.
그 다음, 배열의 앞부분부터 순회하면서 현재까지의 누적 합이 `target_sum`이 되는 시점을 찾습니다.
첫 번째 구간을 찾으면, 두 번째 구간을 찾기 위해 계속 누적 합을 계산합니다.
두 번째 구간의 합도 `target_sum`이 되면, 남은 부분이 자동으로 세 번째 구간이 됩니다.
세 번째 구간은 빈 부분일 수 없으므로, 배열의 마지막 원소까지 도달했는지 확인하면 됩니다.
이 방식은 한 번의 순회로 해결할 수 있는 Greedy 접근이 유효합니다.

## 풀이

```python
class Solution:
    def canThreePartsEqualSum(self, arr: list[int]) -> bool:
        total_sum = sum(arr)
        
        # 전체 합이 3으로 나누어 떨어지지 않으면 분할 불가능
        if total_sum % 3 != 0:
            return False
        
        target_sum = total_sum // 3
        current_sum = 0
        parts_found = 0
        
        for num in arr:
            current_sum += num
            if current_sum == target_sum:
                parts_found += 1
                current_sum = 0
                # 두 구간의 합이 target_sum이 되면, 남은 부분이 세 번째 구간이 됨
                # 세 번째 구간이 존재하려면 아직 배열의 끝이 아니어야 함
                if parts_found == 2:
                    return True
                    
        # 세 번째 구간을 찾지 못한 경우
        return False
```

시간복잡도: O(N) - 배열을 한 번 순회합니다.
공간복잡도: O(1) - 추가적인 데이터 구조를 사용하지 않습니다.

## 다른 풀이 방법

Prefix Sum(접두사 합) 배열을 미리 계산한 후 탐색하는 방법도 있습니다.
먼저 `prefix_sum` 배열을 구축하여 각 인덱스까지의 합을 상수 시간에 접근할 수 있게 합니다.
`i`와 `j`를 두 개의 포인터로 이동시키며, `prefix_sum[i]`, `prefix_sum[j-1]-prefix_sum[i]`, `total_sum-prefix_sum[j-1]`이 모두 `target_sum`과 같은지 확인합니다.
이 방법은 배열을 두 번 이상 읽거나 별도 공간을 사용해야 하므로, 공간복잡도에서 O(N)의 오버헤드가 발생합니다.
Greedy 방식은 구간을 찾으면 즉시 다음 구간 탐색으로 넘어가므로 불필요한 연산이 적어 일반적으로 더 효율적입니다.

## 추가 참고사항

전체 합이 0인 경우, `target_sum`도 0이 됩니다. 이 경우 누적 합이 0이 되는 구간이 여러 번 발생할 수 있습니다.
예를 들어 `[0, 0, 0, 0]`과 같은 경우, 첫 번째 0, 두 번째 0, 세 번째 0에서 구간이 종료될 수 있습니다.
코드에서는 `parts_found == 2`가 되었을 때 즉시 `True`를 반환하므로, 세 번째 구간에 나머지 원소들이 모두 포함되는지 확인하지 않아도 됩니다.
이는 나머지 원소들의 합이 자동으로 `total_sum - 2 * target_sum`이 되며, `target_sum`이 0이므로 합이 0임을 보장하기 때문입니다.
배열 길이가 3 이상이어야 하므로, 최소한 3개의 원소를 사용해 세 구간을 만들 수 있는 구조가 성립합니다.
