## 문제

`words` 문자열 배열이 주어졌을 때, 모든 문자열에 등장하는 문자들을 찾아 반환해야 합니다. 이때 각 문자가 가질 수 있는 중복 횟수는 모든 문자열에서 해당 문자가 등장한 최소 횟수를 기준으로 합니다. 반환 순서는 상관없습니다.

입력 예시: `words = ["bella","label","roller"]`일 때, "b"는 "bella"와 "label"에만 있고 "roller"에는 없으므로 제외됩니다. "e"는 각 단어에 한 번씩 등장하므로 한 번 포함됩니다. "l"은 "bella"(2개), "label"(2개), "roller"(2개)에 모두 등장하므로 2개가 포함됩니다. 결과는 `["e", "l", "l"]`이 됩니다.

제한 사항:
- `words`의 길이는 1 이상 100 이하입니다.
- 각 문자열의 길이는 1 이상 100 이하입니다.
- 문자는 소문자 영어 알파벳으로만 구성됩니다.

## 접근 방법

모든 문자열에 공통으로 포함되어야 하므로, 각 문자의 등장 횟수를 세는 것이 필수적입니다. 소문자 알파벳이 총 26개이므로, 배열이나 해시맵을 사용해 각 문자의 카운트를 관리할 수 있습니다.

핵심 로직은 다음과 같습니다.
1. 첫 번째 문자열의 각 문자 등장 횟수를 초기 상태로 설정합니다.
2. 나머지 문자열들을 순회하며, 각 문자열의 등장 횟수와 현재 공통 카운트(min)를 비교하여 더 작은 값을 유지합니다.
3. 모든 문자열을 처리한 후, 카운트가 1 이상인 문자를 결과에 추가합니다.

이 방식은 각 문자열을 한 번씩 스캔하며 최소 등장 횟수를 갱신하는 방식이라 효율적입니다.

## 풀이

첫 번째 문자열을 기준으로 카운트를 초기화하고, 이후 문자열들과 비교하여 최소 값을 유지하는 방식입니다.

```python
import collections
from typing import List

class Solution:
    def commonChars(self, words: List[str]) -> List[str]:
        # 첫 번째 문자열의 문자 등장 횟수를 기반으로 초기화
        min_freq = collections.Counter(words[0])
        
        # 나머지 문자열들과 비교하여 공통 문자의 최소 횟수 유지
        for word in words[1:]:
            curr_freq = collections.Counter(word)
            # 첫 번째 문자열에 없는 문자는 0으로 처리하고, 두 문자열의 최소값을 min_freq에 저장
            for char in min_freq:
                min_freq[char] = min(min_freq[char], curr_freq[char])
                
        # 결과 생성: 카운트가 1 이상인 문자를 횟수만큼 추가
        result = []
        for char in min_freq:
            result.extend([char] * min_freq[char])
            
        return result
```

- 시간복잡도: O(N * L)
  - N은 `words` 배열의 길이, L은 각 문자열의 평균 길이입니다.
  - 각 문자열에 대해 `Counter` 생성에 O(L)이 소요되며, 이를 N-1번 수행합니다.
  - 이후 26개의 알파벳을 순회하며 최소값을 갱신하는 작업은 O(26)이므로 상수 시간에 해당합니다.
  - 따라서 총 시간복잡도는 O(N * L)이 됩니다.
- 공간복잡도: O(1) 또는 O(Σ)
  - 알파벳 종류가 26개로 고정되어 있으므로 해시맵 또는 배열의 크기는 상수입니다.
  - 결과 배열의 크기는 최악의 경우 전체 문자 수와 비례할 수 있으나, 일반적으로 입력 크기와 무관한 고정 공간으로 간주합니다.

## 다른 풀이 방법

배열(인덱스)을 사용하여 카운트를 관리하는 방법입니다. `collections.Counter` 대신 길이 26인 정수 배열을 사용할 수 있습니다.

각 문자를 `ord(char) - ord('a')`로 0~25의 인덱스로 매핑하여 배열에 저장합니다. 초기 배열을 첫 번째 문자열로 채우고, 나머지 문자열과 비교할 때 두 배열의 최소값을 취하여 업데이트합니다.

```python
from typing import List

class Solution:
    def commonChars(self, words: List[str]) -> List[str]:
        # 26개 영문자를 위한 배열 초기화
        min_freq = [0] * 26
        
        # 첫 번째 문자열로 초기화
        for char in words[0]:
            min_freq[ord(char) - ord('a')] += 1
            
        # 나머지 문자열 처리
        for word in words[1:]:
            curr_freq = [0] * 26
            for char in word:
                curr_freq[ord(char) - ord('a')] += 1
                
            # 최소값 업데이트
            for i in range(26):
                min_freq[i] = min(min_freq[i], curr_freq[i])
                
        # 결과 생성
        result = []
        for i in range(26):
            if min_freq[i] > 0:
                result.extend([chr(i + ord('a'))] * min_freq[i])
                
        return result
```

- 시간복잡도: O(N * L)
- 공간복잡도: O(1)
  - 배열 크기가 26으로 고정되어 Counter 사용과 유사한 성능을 보입니다.
  - 언어에 따라 Counter 오버헤드가 있을 수 있으므로 배열 방식이 조금 더 가벼울 수 있습니다.

## 추가 참고사항

- 이 문제는 교집합을 구하는 문제로 볼 수 있으나, 단순 집합(중복 제거)이 아닌 중복 횟수를 고려한 교집합입니다.
- 문자열 길이가 100, 배열 길이가 100이므로 전체 연산 횟수는 최대 10,000회로 매우 적어 효율적인 알고리즘이 필요합니다.
- Python의 `Counter`는 해시맵 구현이므로 키 존재 여부에 대한 별도 검사가 필요하지만, 배열을 사용하면 인덱스 접근이 가능하여 구현이 직관적입니다.
