## 문제

엄격하게 증가하는 순서로 정렬된 양의 정수 배열 `arr`과 정수 `k`가 주어집니다. 이 배열에 존재하지 않는 k번째 양의 정수를 반환해야 합니다.

예를 들어, `arr = [2, 3, 4, 7, 11]`이고 `k = 5`인 경우, 누락된 양의 정수는 `[1, 5, 6, 8, 9, 10, 12, ...]` 순서로 나열되며, 여기서 5번째 수는 9입니다.

배열의 길이는 1000 이하이며, 배열의 원소와 `k` 모두 1000 이하의 양의 정수입니다.

## 접근 방법

배열의 각 원소 `arr[i]`를 기준으로, 그 이전까지 누락된 양의 정수의 개수를 계산할 수 있습니다.

1. 배열의 인덱스 `i`에서 `arr[i]`보다 작은 양의 정수 중 누락된 수의 개수는 `arr[i] - (i + 1)`로 계산됩니다.
   - `i`는 0부터 시작하므로, `arr[i]` 이전에는 `i`개의 원소가 있습니다.
   - `arr[i]`까지의 양의 정수 총 개수는 `arr[i]`입니다.
   - 따라서 누락된 수의 개수는 `arr[i] - i - 1`입니다.

2. 만약 `arr[i]`에서 누락된 수의 개수가 `k` 이상이라면, k번째 누락된 수는 `arr[i]` 이전에 존재합니다.
   - 이 경우, `arr[i-1]` (또는 `i=0`인 경우 0)까지의 누락된 수 개수를 `k`에서 빼고, `arr[i-1]`에 더하면 k번째 누락된 수를 구할 수 있습니다.

3. 모든 원소를 확인한 후에도 `k`번째 누락된 수를 찾지 못했다면, k번째 누락된 수는 배열의 마지막 원소 뒤에 위치합니다.

이러한 성질을 이용하면 이진 탐색을 통해 O(log n) 시간에 해결할 수 있습니다.

## 풀이

이진 탐색을 사용하여 효율적으로 k번째 누락된 양의 정수를 찾습니다.

```python
class Solution:
    def findKthPositive(self, arr: list[int], k: int) -> int:
        left, right = 0, len(arr) - 1
        
        while left <= right:
            mid = (left + right) // 2
            # arr[mid]보다 작은 양의 정수 중 누락된 수의 개수
            missing_count = arr[mid] - (mid + 1)
            
            if missing_count < k:
                left = mid + 1
            else:
                right = mid - 1
        
        # left는 누락된 수가 k개 이상인 첫 번째 인덱스를 가리킵니다.
        # left가 0이면 arr[0]보다 작은 수(1)부터 시작하여 k개를 더하면 됩니다.
        # left가 0보다 크면 arr[left-1]까지의 누락된 수를 고려해야 합니다.
        # 일반적으로 left를 기준으로 계산하면 arr[left-1] + (k - (arr[left-1] - left))
        # 하지만 더 간단한 공식: arr[left-1] + k - (arr[left-1] - left) = arr[left-1] + k - arr[left-1] + left = left + k
        # left가 0인 경우 arr[-1]은 존재하지 않으므로, left + k가 성립합니다.
        # left가 len(arr)인 경우에도 arr[len(arr)-1] + k - (arr[len(arr)-1] - len(arr)) = len(arr) + k
        
        return left + k
```

시간 복잡도: O(log n)
공간 복잡도: O(1)

## 다른 풀이 방법

배열을 순회하며 누락된 수를 세는 방식입니다.

```python
class Solution:
    def findKthPositive(self, arr: list[int], k: int) -> int:
        current_val = 1
        missing_count = 0
        
        for num in arr:
            while current_val < num:
                missing_count += 1
                if missing_count == k:
                    return current_val
                current_val += 1
            current_val += 1
            
        # 배열의 모든 원소를 확인한 후에도 k번째 누락된 수를 찾지 못한 경우
        # 현재 current_val부터 k - missing_count만큼 더한 값이 정답
        return current_val + (k - missing_count)
```

시간 복잡도: O(arr[-1] + k)
공간 복잡도: O(1)

이 방법은 배열의 원소들이 연속적이지 않거나, k가 클 경우 비효율적일 수 있습니다. 특히 배열의 최대 원소가 크거나 k가 매우 큰 경우, `arr[-1] + k`까지 순회하게 되므로 시간 복잡도는 O(arr[-1] + k)로 표현하는 것이 정확합니다.

## 추가 참고사항

- 이진 탐색을 사용한 풀이는 배열의 길이 `n`에 대해 로그 시간 복잡도를 가지므로, `n`이 클 때 매우 효율적입니다.
- 순회 방식을 사용한 풀이는 구현이 간단하지만, 배열의 원소 값이 크거나 `k`가 큰 경우 성능 저하가 발생할 수 있습니다.
- 문제의 제약 조건에서 `arr[i]`와 `k`가 모두 1000 이하로 작으므로, 두 방법 모두 충분히 통과할 수 있습니다. 그러나 Follow-up에서 요청한 대로 O(n) 이하의 시간 복잡도를 만족하려면 이진 탐색을 사용하는 것이 필수적입니다.
