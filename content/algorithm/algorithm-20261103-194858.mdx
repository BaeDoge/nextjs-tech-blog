## 문제

입력 문자열은 문자 배열 `s`로 주어집니다. 추가 메모리 할당 없이 원본 배열을 수정하여 문자를 역순으로 배치해야 합니다. 배열의 길이는 1 이상 100,000 이하이며, 모든 문자는 인쇄 가능한 ASCII 문자입니다.

## 접근 방법

두 포인터 기법을 사용합니다. 왼쪽 포인터는 시작 인덱스 `i = 0`에서, 오른쪽 포인터는 마지막 인덱스 `j = len(s) - 1`에서 시작합니다. `i < j` 조건이 참인 동안 `s[i]`와 `s[j]`를 교환하고, `i`를 증가시키며 `j`를 감소시킵니다. 이 과정은 양쪽 포인터가 만날 때까지 반복되어 전체 배열이 역순으로 배치됩니다.

```python
def reverseString(s):
    i, j = 0, len(s) - 1
    while i < j:
        s[i], s[j] = s[j], s[i]
        i += 1
        j -= 1
```

## 풀이

위 접근 방법의 코드를 구현한 함수는 `s`를 직접 수정하여 역순으로 만듭니다. 각 요소는 정확히 한 번 교환되며, 전체 순회는 한 번만 이루어집니다.

```python
def reverseString(s):
    i, j = 0, len(s) - 1
    while i < j:
        s[i], s[j] = s[j], s[i]
        i += 1
        j -= 1
```

시간 복잡도: `O(n)` (n은 `s`의 길이)  
공간 복잡도: `O(1)` (추가 메모리는 두 포인터뿐임)

## 다른 풀이 방법

파이썬에서는 리스트 메서드 `reverse()`를 직접 호출할 수 있습니다: `s.reverse()`. 이 메서드도 `O(1)` 추가 메모리를 사용하며 원본 리스트를 수정합니다. 또 다른 방법은 슬라이스 할당을 이용하는 것입니다: `s[:] = s[::-1]`. 이 방법은 내부적으로 새로운 리스트를 생성하므로, 명시적인 추가 메모리를 사용한다는 점에서 두 포인터 접근 방식과 차이가 있습니다.

## 추가 참고사항

이 문제는 `O(1)` 추가 메모리 제약 조건을 충족해야 하므로, 새로운 배열을 할당하는 방법은 허용되지 않습니다. 두 포인터 해결책은 이 조건을 만족하며, `reverse()` 메서드도 동일한 메모리 효율을 제공합니다. 제약 조건에 따라, 알고리즘은 최대 100,000개의 문자를 처리할 수 있어야 하며, 이는 선형 시간 복잡도로 쉽게 충족됩니다.
