## 문제

문자 배열 s가 주어집니다. 배열의 문자를 역순으로 배치하되, 새로운 배열을 만들지 않고 입력 배열 자체를 수정해야 합니다. 함수는 수정된 문자열을 반환하는 것이 아니라 입력 배열을 제자리에서 변경해야 합니다.

예를 들어 ["h", "e", "l", "l", "o"]를 전달하면 입력 배열이 ["o", "l", "l", "e", "h"]로 바뀝니다.

## 접근 방법

양 끝에서 시작하는 두 포인터를 사용합니다. 왼쪽 포인터와 오른쪽 포인터가 서로 교차하기 전까지 두 위치의 문자를 교환하고, 왼쪽 포인터는 오른쪽으로, 오른쪽 포인터는 왼쪽으로 이동합니다.

## 풀이

```python
from typing import List

class Solution:
    def reverseString(self, s: List[str]) -> None:
        left, right = 0, len(s) - 1

        while left < right:
            s[left], s[right] = s[right], s[left]
            left += 1
            right -= 1
```

이 함수는 입력 리스트를 직접 변경하며 별도의 반환값을 만들지 않습니다.

```python
chars = ["h", "e", "l", "l", "o"]
Solution().reverseString(chars)
print(chars)
# ["o", "l", "l", "e", "h"]
```

- 시간 복잡도: O(n). 각 문자는 최대 한 번 교환됩니다.
- 추가 공간 복잡도: O(1). 포인터 두 개 외에 입력 크기에 비례하는 자료구조를 만들지 않습니다.

## 다른 풀이 방법

Python 리스트의 reverse() 메서드를 사용하면 같은 결과를 더 간단하게 얻을 수 있습니다.

```python
def reverse_string(s: list[str]) -> None:
    s.reverse()
```

슬라이스를 이용해 s[:] = s[::-1]로 작성할 수도 있지만, 역순 슬라이스를 만드는 과정에서 입력 길이에 비례하는 임시 리스트가 만들어집니다. 따라서 추가 공간을 사용하지 않는 풀이가 필요한 문제에서는 두 포인터 방식이나 list.reverse()가 적합합니다.

## 추가 참고사항

이 문제는 Python 문자열이 아니라 문자 배열(List)을 입력으로 받는다는 점이 중요합니다. 문자열은 immutable이므로 문자를 제자리에서 교환할 수 없습니다. 문자열을 받아 새 문자열을 반환하는 풀이와 이 문제의 요구사항을 혼동하지 않아야 합니다.
