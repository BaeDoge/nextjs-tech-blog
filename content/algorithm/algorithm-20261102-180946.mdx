## 문제

정수 배열 `nums`와 정수 `k`가 주어진다. 배열의 요소 중 하나를 선택하여 그 값을 음수로 반전(negate)하는 연산을 정확히 `k`번 수행해야 한다. 같은 인덱스를 여러 번 선택할 수 있으며, 연산 종료 후 얻을 수 있는 배열 요소의 최대 합을 반환하는 것이 목표이다.

배열의 길이는 최대 $10^4$이고, 각 요소의 값은 $-100$부터 $100$ 사이이다. $k$의 값 또한 최대 $10^4$까지 가능하다.

## 접근 방법

배열의 합을 최대화하기 위해서는 절대값이 큰 음수를 양수로 만드는 것이 우선이다.
먼저 배열을 오름차순으로 정렬하여 음수부터 먼저 처리한다.
`k`가 남아있는 동안 음수인 요소의 부호를 양수로 바꾼다.
모든 음수를 양수로 만들거나 `k`가 0이 되면 루프를 종료한다.
남은 `k`가 0보다 크다면, 남은 연산 횟수가 홀수인지 짝수인지 확인해야 한다. 짝수이면 같은 인덱스를 반복 연산하여 부호 변화가 없는 상태로 만들 수 있으므로 그대로 둬도 된다.
하지만 남은 `k`가 홀수이면, 결국 배열의 한 요소는 음수가 되어야 하므로, 이때 배열의 최솟값을 선택하여 부호를 반전시키면 전체 합을 최대화할 수 있다.

## 풀이

배열을 오름차순으로 정렬한 후, 음수부터 순회하며 `k`를 사용하여 부호를 반전한다.
모든 요소의 부호를 확인하거나 `k`가 0이 되면 루프를 종료한다.
남은 `k`가 홀수라면, 현재 배열의 최솟값을 찾아 한 번 더 부호를 반전시킨다.
마지막으로 배열의 모든 요소를 합산하여 반환한다.

```python
class Solution:
    def largestSumAfterKNegations(self, nums: list[int], k: int) -> int:
        # 음수부터 처리하기 위해 정렬
        nums.sort()
        
        # 음수부터 부호 반전
        for i in range(len(nums)):
            if nums[i] < 0 and k > 0:
                nums[i] *= -1
                k -= 1
        
        # k가 남았다면 홀수인지 확인
        if k % 2 == 1:
            # 남은 k가 홀수일 경우, 최소값을 하나 음수로 만들어야 함
            # 부호 변환 과정에서 배열의 순서가 변경되었을 수 있으므로
            # 최솟값을 찾기 위해 min()을 사용
            min_index = nums.index(min(nums))
            nums[min_index] *= -1
            
        return sum(nums)
```

시간복잡도: 초기 정렬에 $O(N \log N)$이 소요된다. 부호 반전 루프는 $O(N)$이고, 남은 `k`에 따른 최솟값 탐색은 $O(N)$이므로 전체 시간복잡도는 $O(N \log N)$이다.
공간복잡도: 정렬 알고리즘의 구현 방식에 따라 다르지만 일반적으로 $O(1)$에서 $O(N)$ 사이이다.

## 다른 풀이 방법

최소 힙(우선순위 큐)을 사용하여 접근할 수 있다.
배열을 최소 힙으로 구성한 후, `k`번 동안 가장 작은 값을 추출하여 부호를 반전한 후 다시 힙에 삽입한다.
모든 연산이 끝나면 힙의 모든 요소를 합산한다.
이 방법은 매 단계 최솟값을 추출해야 하므로 시간복잡도가 $O(K \log N)$이다.
$N$과 $K$의 크기가 비슷하거나 $K$가 클 경우 $O(N \log N)$ 정렬 기반 방법이 더 효율적일 수 있다.

```python
import heapq

class Solution:
    def largestSumAfterKNegations(self, nums: list[int], k: int) -> int:
        # 배열을 최소 힙으로 구성
        heapq.heapify(nums)
        
        # k번 동안 가장 작은 값을 추출하여 부호 반전 후 삽입
        for _ in range(k):
            smallest = heapq.heappop(nums)
            heapq.heappush(nums, smallest * -1)
            
        return sum(nums)
```

## 추가 참고사항

부호 반전 후 배열의 순서가 변경되었을 수 있으므로, 남은 `k`가 홀수일 때 최솟값을 정확하게 찾기 위해 `min()` 함수를 사용하는 것이 안전하다.
문제의 제약 조건과 그리디 접근의 명확성을 고려할 때, 정렬 기반 접근이 구현이 간편하고 충분히 효율적이다.
$O(N \log N)$ 시간복잡도는 정렬의 최적 하한과 일치하며, 주어진 제약 조건 내에서 최적의 전략이다.
배열의 원소 범위가 $[-100, 100]$로 제한되어 있으므로, 이 값의 분포를 이용한 $O(N)$ 시간 복잡도의 해법(Counting Sort 적용 등)도 존재할 수 있으나, 정렬 기반 접근이 더 직관적이고 구현이 용이하다.
