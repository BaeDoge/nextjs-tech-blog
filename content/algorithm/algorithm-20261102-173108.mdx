## 문제

위와 같이 n개의 단계가 있는 계단이 있습니다. 한 번에 1단계 또는 2단계를 오를 수 있습니다.
n개의 계단에 도달하는 서로 다른 방법은 총 몇 가지인지 구해야 합니다.
입력 n의 범위는 1부터 45까지이며, 예시로 n=2일 때 2가지, n=3일 때 3가지 방법이 있음을 알 수 있습니다.
이 문제는 매번 1 또는 2를 더하여 목표 값에 도달하는 경우의 수를 세는 문제입니다.

## 접근 방법

이 문제는 동적 계획법(Dynamic Programming)으로 해결할 수 있습니다.
마지막 단계(n)에 도달하기 위해서는 직전 단계(n-1)에서 1걸음을 떼거나, 그 이전 단계(n-2)에서 2걸음을 떼어야 합니다.
따라서 n번째 단계에 도달하는 경우의 수 `dp[n]`은 `(n-1)번째 단계의 경우의 수 + (n-2)번째 단계의 경우의 수`와 같습니다.
이를 점화식으로 표현하면 `dp[i] = dp[i-1] + dp[i-2]`가 되며, 이는 피보나치 수열과 동일한 구조입니다.
기저 조건(boundary condition)으로는 `dp[1] = 1`, `dp[2] = 2`를 설정하여 시작할 수 있습니다.
배열을 사용하여 이전 값을 저장하거나, 변수 두 개를 활용해 공간을 최적화할 수 있습니다.

## 풀이

배열을 사용하지 않고 변수 두 개로 이전 값을 관리하며 공간을 절약하는 풀이입니다.
이 방법은 배열 할당 없이 상수 공간에서만 계산하므로 효율적입니다.

```python
class Solution:
    def climbStairs(self, n: int) -> int:
        if n <= 2:
            return n
        
        # dp[i-2], dp[i-1]의 값을 저장하는 변수
        prev2 = 1  # dp[1]
        prev1 = 2  # dp[2]
        
        for i in range(3, n + 1):
            # 현재 단계의 경우의 수는 직전 두 단계의 합
            current = prev1 + prev2
            # 다음 계산을 위해 값 갱신
            prev2 = prev1
            prev1 = current
            
        return prev1
```

시간복잡도: O(n) - 1부터 n까지 한 번의 순회 수행
공간복잡도: O(1) - 변수 두 개만 사용

## 다른 풀이 방법

재귀 호출과 메모이제이션(Memoization)을 사용하는 방법이 있습니다.
이 방법은 함수 호출 스택을 통해 점화식을 구현하며, 이미 계산된 값은 저장해 중복 계산을 방지합니다.
또는 완전 재귀(메모이제이션 없음)는 동일한 하위 문제들을 반복 계산하므로 시간복잡도가 지수 함수 O(2^n)가 되어 실행 시간 초과가 발생할 수 있습니다.
해당 풀이는 Python의 `functools.lru_cache`나 배열을 활용한 메모이제이션을 적용해야 합니다.
이 방식은 코드 작성은 직관적이나, 호출 스택 오버플로우 위험성과 메모리 할당 비용이 있을 수 있습니다.

## 추가 참고사항

이 문제는 전형적인 피보나치 수열 패턴을 따르며, DP 입문 문제로 자주 출제됩니다.
n의 최대값이 45로 작으므로 정수형 범위를 벗어나지 않습니다.
수학적으로는 닫힌 형태(Closed-form expression)인 비네트의 공식(Binet's Formula)을 이용하여 O(1) 시간복잡도로 풀 수도 있으나, 부동소수점 오차 문제를 고려해야 하므로 정수 연산 기반의 DP나 반복문이 일반적인 정석 해법으로 취급됩니다.
문제를 풀 때는 기저 조건 `n=1`과 `n=2`를 정확히 처리하는 것이 중요합니다.
