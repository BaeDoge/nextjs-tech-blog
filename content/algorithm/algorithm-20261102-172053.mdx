## 문제

0부터 $n-1$까지의 숫자가 중복 없이 포함된 크기 $n$의 배열 `nums`가 주어집니다. 각 인덱스 $k$에서 시작하여 `nums[k]`, `nums[nums[k]]`와 같이 값을 다음 인덱스로 사용하여 탐색을 진행할 때, 중복된 값이 나타나기 직전까지의 집합 $s[k]$를 구성합니다. 이 집합들 중 가장 긴 길이를 반환해야 합니다.

## 접근 방법

주어진 배열은 $0$부터 $n-1$까지의 숫자가 한 번씩만 등장하는 순열이므로, 모든 원소는 반드시 하나의 닫힌 사이클을 형성합니다. 따라서 모든 인덱스를 순회하며 아직 방문하지 않은 원소로부터 시작되는 사이클의 길이를 계산하면 됩니다. 한 번 방문한 인덱스는 다른 사이클의 일부가 될 수 없으므로, 방문 여부를 기록하여 중복 계산을 방지합니다.

## 풀이

```python
class Solution:
    def arrayNesting(self, nums: list[int]) -> int:
        n = len(nums)
        visited = [False] * n
        max_len = 0
        
        for i in range(n):
            if not visited[i]:
                curr_len = 0
                curr_idx = i
                while not visited[curr_idx]:
                    visited[curr_idx] = True
                    curr_idx = nums[curr_idx]
                    curr_len += 1
                max_len = max(max_len, curr_len)
                
        return max_len

# 시간 복잡도: O(n) - 모든 원소를 정확히 한 번씩만 방문합니다.
# 공간 복잡도: O(n) - 방문 여부를 저장하기 위한 visited 배열이 필요합니다.
```

## 다른 풀이 방법

공간 복잡도를 최적화하기 위해 별도의 `visited` 배열을 만드는 대신, 이미 방문한 원소의 값을 특정 값(예: `-1`)으로 변경하여 처리할 수 있습니다. 이 경우 공간 복잡도를 $O(1)$로 줄일 수 있으나, 입력 배열 `nums`의 원본 데이터를 수정하게 됩니다.

- **방문 배열 사용**: 공간 복잡도 $O(n)$, 원본 데이터 보존 가능.
- **배열 값 수정**: 공간 복잡도 $O(1)$, 원본 데이터 변경됨.
