## 문제

0부터 $n-1$까지의 숫자가 중복 없이 포함된 크기 $n$의 배열 `nums`가 주어집니다. 각 인덱스 $k$에서 시작하여 `nums[k]`, `nums[nums[k]]`와 같이 값을 다음 인덱스로 사용하여 탐색을 진행할 때, 중복된 값이 나타나기 직전까지의 집합 $s[k]$를 구성합니다. 이 집합들 중 가장 긴 길이를 반환해야 합니다.

## 접근 방법

주어진 배열은 $0$부터 $n-1$까지의 숫자가 한 번씩만 등장하는 순열이므로, 각 인덱스는 정확히 하나의 닫힌 사이클에 속합니다. 전체 배열은 여러 개의 서로 겹치지 않는 사이클로 분해될 수 있습니다. 따라서 모든 인덱스를 순회하며 아직 방문하지 않은 원소에서 사이클을 시작하고, 해당 사이클의 길이를 계산하면 됩니다. 한 번 방문한 인덱스는 다른 사이클의 일부가 될 수 없으므로, 방문 여부를 기록하여 중복 계산을 방지합니다.

## 풀이

```python
class Solution:
    def arrayNesting(self, nums: list[int]) -> int:
        n = len(nums)
        visited = [False] * n
        max_len = 0
        
        for i in range(n):
            if not visited[i]:
                curr_len = 0
                curr_idx = i
                while not visited[curr_idx]:
                    visited[curr_idx] = True
                    curr_idx = nums[curr_idx]
                    curr_len += 1
                max_len = max(max_len, curr_len)
                
        return max_len

# 시간 복잡도: O(n) - 모든 원소를 정확히 한 번씩만 방문합니다.
# 공간 복잡도: O(n) - 방문 여부를 저장하기 위한 visited 배열이 필요합니다.
```

## 다른 풀이 방법

입력 배열을 수정해도 된다면 별도의 `visited` 배열 없이 이미 방문한 위치를 표시할 수 있습니다. 이 문제의 값은 0 이상이므로, 방문한 위치의 값을 `-1`로 바꾸어 다시 방문하지 않도록 할 수 있습니다.

```python
def arrayNesting_in_place(nums: list[int]) -> int:
    best = 0
    for start in range(len(nums)):
        length = 0
        index = start
        while nums[index] != -1:
            next_index = nums[index]
            nums[index] = -1
            index = next_index
            length += 1
        best = max(best, length)
    return best
```

시간 복잡도는 각 원소를 최대 한 번씩 방문하므로 O(N), 입력 배열 외의 추가 공간은 O(1)입니다. 대신 원본 배열이 변경되므로 입력 보존이 필요한 환경에서는 사용하면 안 됩니다.

## 추가 참고사항

이 문제는 그래프 이론의 관점에서 보면 각 노드의 차수가 1인 불연속적인 사이클들의 집합을 찾는 문제와 동일합니다. 배열의 각 원소가 유일한 순열이라는 조건은 모든 인덱스가 서로 겹치지 않는 순환 구조들로 분해된다는 점을 보장합니다. 하나의 전체 사이클만 존재한다고 가정해서는 안 됩니다.
