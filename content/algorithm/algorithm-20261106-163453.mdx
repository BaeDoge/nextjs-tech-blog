## 문제

이진수(0과 1)로 구성된 배열 `nums`가 주어집니다. `nums[0..i]`로 이어지는 배열의 부분배열을 이진수로 해석했을 때의 값을 $x_i$라고 정의합니다. 모든 $i$에 대해 $x_i$가 5로 나누어떨어지는지 확인하는 부울 배열을 반환해야 합니다. 예를 들어 입력이 `[1,0,1]`일 때, 각 위치의 이진수는 순서대로 1(10진법 1), 10(10진법 2), 101(10진법 5)이며, 이 중 5의 배수는 마지막 5뿐이므로 결과는 `[false, false, true]`가 됩니다.

## 접근 방법

이진수에서 오른쪽으로 한 자리씩 확장할 때의 값을 계산하는 식으로 생각해 볼 수 있습니다. 이진수를 10진법으로 변환하면 $x_{i} = x_{i-1} \times 2 + \text{nums}[i]$가 성립합니다. 배열의 길이가 최대 $10^5$이므로 10진법 정수 값은 매우 커져서 기본 정수형의 범위를 쉽게 넘어서며 오버플로우가 발생할 수 있습니다. 하지만 5로 나누어떨어지는지 확인하는 연산은 모듈러 연산의 성질을 활용하면 됩니다. $(A \times 2 + B) \pmod 5 = ((A \pmod 5) \times 2 + B) \pmod 5$이므로, 매 단계마다 5로 나눈 나머지만 관리하면 됩니다.

## 풀이

현재까지의 이진수를 5로 나눈 나머지를 유지하며 배열을 한 번 순회합니다. 다음 비트가 0 또는 1일 때 나머지를 업데이트한 후, 5의 배수인지 판별합니다. 이 방법은 오버플로우 없이 상수 공간으로 5의 배수 여부를 구할 수 있습니다.

```python
def prefixesDivBy5(nums: list[int]) -> list[bool]:
    answer = []
    remainder = 0
    
    for bit in nums:
        remainder = (remainder * 2 + bit) % 5
        answer.append(remainder == 0)
        
    return answer
```

시간복잡도: $O(n)$
공간복잡도: $O(n)$

## 다른 풀이 방법

이진수의 특성을 이용한 시프트 연산과 비트마스킹도 가능합니다. 5의 배수를 판별하는 조건을 이진법으로 보면, 가장 오른쪽 2비트만 확인하는 것이 아니라 이진수 전체의 값이 $101_2$로 나누어떨어져야 합니다. 하지만 단순히 마지막 비트만 보면 부족하므로, 시프트 연산으로 값을 계속 누적하면서 오버플로우를 막기 위해 $11111_2$(10진법 31)와의 비트연산(&)을 수행하면 5비트 이내의 값으로 값을 제한할 수 있습니다. 5비트 이내에서는 5의 배수를 직접 나눗셈으로 판별해도 오버플로우가 발생하지 않습니다. 이 방법은 나머지 누적법보다 모듈러 연산 대신 비트 연산을 사용하여 미세한 성능 차이를 보일 수 있으나, 복잡도 측면에서는 동일합니다.

```python
def prefixesDivBy5_bitwise(nums: list[int]) -> list[bool]:
    answer = []
    val = 0
    
    for bit in nums:
        val = ((val << 1) | bit) & 31
        answer.append(val % 5 == 0)
        
    return answer
```

시간복잡도: $O(n)$
공간복잡도: $O(n)$

## 추가 참고사항

이 문제는 모듈러 연산의 결합 법칙을 이해하는 것이 핵심입니다. 큰 숫자를 10진법으로 직접 저장하지 않고 나머지만 유지하는 방식은 $10^9$를 넘나드는 큰 수를 다루는 다른 문제에서도 자주 쓰이는 패턴입니다. 또한, 이진수가 왼쪽부터 입력되므로 매 단계마다 현재 값을 2배하는 곱셈 연산이 필요하며, 이는 비트 시프트 연산(`<< 1`)과 동일하게 동작함을 인지해야 합니다.
