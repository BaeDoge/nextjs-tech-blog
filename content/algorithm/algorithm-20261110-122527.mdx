## 문제

정렬된 정수 배열 `nums`가 주어진다. 중복된 원소를 제거하여 각 고유 원소가 한 번만 나타나도록 배열을 변경해야 한다. 이때 원소의 상대적 순서는 유지되어야 한다.

변경 후, 배열의 첫 `k`개의 원소에는 고유한 원소들이 정렬된 순서로 담겨야 한다. 함수는 고유 원소의 개수 `k`를 반환한다. `k` 이후의 배열 요소는 무시한다.

입력 배열의 길이는 `1` 이상 `3 * 10^4` 이하이며, 원소의 값은 `-100` 이상 `100` 이하이다. 배열은 내림차순 또는 오름차순이 아닌 '비감소(non-decreasing)' 순서로 정렬되어 있다.

## 접근 방법

배열이 이미 정렬되어 있으므로, 중복된 값들은 반드시 인접해 있다. 이를 활용하면 별도의 자료 구조 없이 배열 내부에서 처리할 수 있다.

두 개의 포인터 `slow`와 `fast`를 사용한다. `fast` 포인터는 배열의 끝까지 이동하며 새로운 고유 값을 찾는다. `slow` 포인터는 다음에 고유 값을 저장할 인덱스를 가리킨다.

`fast`가 `slow`보다 큰 값을 만나면, 그 값을 `slow`가 가리키는 위치로 복사하고 `slow`를 한 칸 진행한다. 이 과정을 반복하면 배열의 앞부분에 고유한 값들이 정리된다.

<Callout type="tip" title="핵심 포인트">
배열이 정렬되어 있다는 조건이 핵심이다. 이 조건 덕분에 인접한 두 원소만 비교하면 중복 여부를 판단할 수 있다.
</Callout>

## 풀이

`slow` 포인터는 초기값 `1`로 설정한다. `fast` 포인터는 `1`부터 배열의 끝까지 순회한다. `slow`는 이미 처리된 고유 원소의 개수를 의미하며, 다음 고유 원소가 들어갈 위치이기도 하다.

`nums[fast]`와 `nums[slow - 1]`을 비교한다. 만약 서로 다르면 `nums[fast]`는 새로운 고유 원소이므로 `nums[slow]`에 할당하고 `slow`를 증가시킨다.

반복이 끝나면 `slow`의 값이 고유 원소의 총 개수 `k`가 된다. 이 알고리즘은 배열을 한 번만 순회하므로 효율적이다.

```python
class Solution:
    def removeDuplicates(self, nums: List[int]) -> int:
        if not nums:
            return 0
        
        slow = 1
        for fast in range(1, len(nums)):
            if nums[fast] != nums[slow - 1]:
                nums[slow] = nums[fast]
                slow += 1
                
        return slow
```

- 시간 복잡도: $O(n)$ — 배열을 한 번 순회한다.
- 공간 복잡도: $O(1)$ — 추가적인 자료 구조를 사용하지 않는다.

## 다른 풀이 방법

해시셋(Set)을 사용하여 중복을 제거한 후, 정렬된 상태로 다시 배열에 채우는 방법도 있다.

해시셋은 중복 값을 자동으로 제거하지만, 삽입 순서나 정렬 순서를 보장하지 않는다. 따라서 집합에 저장된 원소들을 다시 정렬해야 한다.

이 방법은 시간 복잡도가 $O(n \log n)$이 된다. 정렬된 배열을 입력으로 받았음에도 불구하고, 집합을 통해 정렬 정보를 잃고 다시 정렬 과정을 거치기 때문이다. 또한 집합을 저장하는 데 $O(n)$의 공간이 추가로 필요하다.
