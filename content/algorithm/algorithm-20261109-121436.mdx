## 문제

주어진 연결 리스트의 head가 오름차순으로 정렬되어 있으면, 이를 높이 균형 잡힌 이진 탐색 트리로 변환한다. 트리는 모든 노드가 왼쪽과 오른쪽 서브트리의 높이 차이가 최대 1인 상태여야 하며, 노드 개수는 0에서 2×10⁴ 사이이다. 값은 -10⁵에서 10⁵ 범위이며, 빈 리스트일 경우 None를 반환한다.

## 접근 방법

먼저 리스트 전체 길이를 구한 뒤, 인덱스 기반 재귀 함수 build(left, right)를 정의한다. 중간 인덱스 mid = (left + right) // 2 를 루트로 삼고, 왼쪽 구간을 재귀적으로 빌드한 뒤 현재 리스트 노드를 루트로 만든다. self.current 로 현재 노드를 추적하여 중위 순회 순서대로 리스트를 소비함으로써 O(n) 시간 안에 트리를 구성한다.

## 풀이

```python
# Definition for singly-linked list.
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def sortedListToBST(self, head: ListNode) -> TreeNode:
        # calculate length
        size = 0
        cur = head
        while cur:
            size += 1
            cur = cur.next
        
        self.current = head  # pointer to the current list node
        
        def build(left: int, right: int) -> TreeNode:
            if left > right:
                return None
            mid = (left + right) // 2
            left_child = build(left, mid - 1)
            root = TreeNode(self.current.val)
            root.left = left_child
            self.current = self.current.next
            root.right = build(mid + 1, right)
            return root
        
        return build(0, size - 1)
```

시간 복잡도는 O(n)이고, 재귀 스택으로 인한 공간 복잡도는 O(log n)이다. self.current는 인스턴스 변수이지만 O(1) 추가 공간만 사용하므로 전체 공간 복잡도는 O(log n)이다.

## 다른 풀이 방법

배열에 리스트 값을 복사한 뒤 인덱스 기반 재귀를 사용하면 구현이 간단하지만 O(n) 추가 공간이 필요하다. 중간 노드를 찾기 위해 느린·빠른 포인터를 매번 사용하면 코드가 직관적이지만 전체 시간 복잡도가 O(n log n)이 된다. 이러한 대안들은 구현 편의성과 시간·공간 트레이드오프를 고려하여 선택할 수 있다.

## 추가 참고사항

빈 리스트(head is None)인 경우 바로 None를 반환한다. Python의 기본 재귀 제한(1000)보다 노드 수가 2×10⁴에 해당해도 트리 깊이는 약 15이므로 stack overflow가 발생하지 않는다. self.current 대신 nonlocal 변수를 사용해도 동일한 동작을 보장한다.
