## 문제

영문 소문자와 숫자로 구성된 문자열이 입력으로 주어집니다. 주어진 문자열의 문자를 재배열하여 인접한 두 문자가 항상 다른 종류(영문자와 숫자)를 갖도록 변환해야 합니다. 이를 만족하는 새로운 문자열을 반환하되, 만약 변환이 불가능할 경우 빈 문자열을 반환해야 합니다. 문자열 길이는 최대 500으로 제한되며, 입력에는 영문 소문자와 숫자만 포함됩니다.

## 접근 방법

입력 문자열에서 영문자 목록과 숫자 목록을 각각 분리하여 저장합니다. 재배열이 가능하기 위한 필수 조건은 두 목록의 크기 차이가 1 이하인 경우입니다. 만약 영문자의 수가 숫자의 수보다 1 많으면 영문자로 시작해야 하며, 반대의 경우 숫자로 시작해야 합니다. 두 목록의 크기가 같으면 어떤 순서로 시작해도 무방합니다. 조건이 충족되면 길이가 더 긴(또는 같은) 목록을 기준으로 결과 문자열을 채워나갑니다.

## 풀이

먼저 입력 문자열을 순회하며 영문자와 숫자를 별도의 리스트에 분리합니다. 이후 두 리스트의 길이를 비교하여 변환 가능성을 확인합니다. 길이의 차이가 1보다 크면 즉시 빈 문자열을 반환합니다. 조건을 만족한다면, 길이가 더 긴(또는 같은) 리스트를 기준으로 결과 문자열을 채워나갑니다. 구현은 문자 배열을 미리 할당하여 순차적으로 채운 후 결합하는 방식을 사용합니다.

```python
class Solution:
    def reformat(self, s: str) -> str:
        letters = [c for c in s if c.isalpha()]
        digits = [c for c in s if c.isdigit()]
        
        if abs(len(letters) - len(digits)) > 1:
            return ""
        
        res = [''] * len(s)
        
        if len(letters) > len(digits):
            res[0::2] = letters
            res[1::2] = digits
        else:
            res[0::2] = digits
            res[1::2] = letters
            
        return ''.join(res)
```

시간복잡도: $O(N)$ (문자열 길이 $N$만큼 순회하며 분리하고 재배열함)
공간복잡도: $O(N)$ (문자 저장용 리스트와 결과 배열을 위해 $N$ 크기의 공간 필요)

## 다른 풀이 방법

두 집합의 길이를 비교하여 긴 쪽의 요소를 결과에 먼저 추가하고, `zip`으로 짧은 쪽을 교차 배치하는 방법이 있습니다. 먼저 길이 차이가 1보다 큰지 확인하여 불가능한 경우 빈 문자열을 반환합니다. 조건이 만족되면, 길이가 긴 문자열과 짧은 문자열을 결정합니다. `zip`을 통해 짧은 문자열을 순회하면서 결과 배열의 현재 위치와 다음 위치에 각각 긴 문자열의 요소와 짧은 문자열의 요소를 배치합니다.

```python
class Solution:
    def reformat(self, s: str) -> str:
        letters = [c for c in s if c.isalpha()]
        digits = [c for c in s if c.isdigit()]
        
        if abs(len(letters) - len(digits)) > 1:
            return ""
        
        # 길이가 더 긴 쪽을 letters에 저장
        if len(digits) > len(letters):
            letters, digits = digits, letters
            
        res = [''] * len(s)
        res[0] = letters[0]
        
        # 짧은 문자열(digits)의 길이만큼 반복
        for i, c in enumerate(digits):
            res[2 * i + 1] = c
            res[2 * i + 2] = letters[i + 1]
            
        return ''.join(res)
```

시간복잡도: $O(N)$ (문자열 길이 $N$만큼 순회하며 분리하고 재배열함)
공간복잡도: $O(N)$ (문자 저장용 리스트와 결과 배열을 위해 $N$ 크기의 공간 필요)

## 추가 참고사항

본 문제에서 입력은 영문 소문자와 숫자만 포함하므로, `isalpha()`와 `isdigit()` 메서드를 통해 명확하게 분류할 수 있습니다. Python의 슬라이싱 기능(`res[0::2]`)을 사용하면 반복문 없이 효율적으로 교차 배치를 수행할 수 있어 코드 간결도에 도움이 됩니다. 결과값이 항상 유효한지 확인하는 과정은 초기 길이 체크로 충분하므로, 이후 추가 검증 로직은 불필요합니다.
