## 문제

단일 연결 리스트의 `head`가 주어졌을 때, 해당 리스트의 중간 노드를 반환해야 합니다. 만약 중간 노드가 두 개라면 두 번째 중간 노드를 반환합니다.

예를 들어, 입력이 `[1,2,3,4,5]`인 경우 중간 노드는 `3`이므로 `[3,4,5]`를 반환합니다. 입력이 `[1,2,3,4,5,6]`인 경우 중간 노드는 `3`과 `4` 중 두 번째인 `4`이므로 `[4,5,6]`을 반환합니다.

연결 리스트의 노드 개수는 1에서 100 사이이며, 노드의 값은 1에서 100 사이입니다.

## 접근 방법

연결 리스트의 크기를 미리 알 수 없으므로, 배열에 모든 노드를 저장한 후 인덱스를 계산하는 방식은 추가 공간이 필요합니다. 대신 두 개의 포인터를 사용하는 투 포인터 기법을 적용할 수 있습니다.

`fast` 포인터와 `slow` 포인터를 모두 리스트의 시작점(`head`)에 위치시킵니다. 한 번의 반복마다 `fast` 포인터는 두 칸씩, `slow` 포인터는 한 칸씩 이동합니다.

`fast` 포인터가 리스트의 끝(`null`)에 도달하거나, 그 앞의 노드가 `null`이 되면 반복을 종료합니다. 이때 `slow` 포인터가 위치한 노드가 바로 우리가 원하는 중간 노드입니다. 이 방법은 리스트를 한 번만 순회하므로 효율적입니다.

## 풀이

두 포인터를 초기화하고, `fast` 포인터가 유효한 범위 내에 있을 동안 루프를 돌립니다. 루프 종료 시점의 `slow` 포인터를 반환하면 됩니다.

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def middleNode(self, head: Optional[ListNode]) -> Optional[ListNode]:
        fast = head
        slow = head
        
        while fast and fast.next:
            fast = fast.next.next
            slow = slow.next
            
        return slow
```

시간복잡도: $O(N)$ (N은 노드의 개수). 리스트의 길이를 절반만큼만 이동하므로 선형 시간입니다.
공간복잡도: $O(1)$. 추가적인 자료 구조를 사용하지 않고 두 개의 포인터 변수만 사용합니다.

## 다른 풀이 방법

첫 번째로 리스트의 전체 길이를 계산한 후, 길이의 절반만큼 이동하는 방법이 있습니다. 이 경우 리스트를 두 번 순회해야 하므로 시간복잡도는 $O(N)$이지만 상수 계수가 더 클 수 있습니다. 공간복잡도는 $O(1)$입니다.

두 번째로 리스트의 모든 노드를 배열에 저장한 후 인덱스를 계산하는 방법이 있습니다. 배열의 길이를 $N$이라 할 때, 중간 노드의 인덱스는 $N // 2$입니다. 이 방법은 시간복잡도가 $O(N)$이지만, 모든 노드를 저장하므로 공간복잡도가 $O(N)$으로 비효율적입니다.

## 추가 참고사항

중간 노드의 정의에 따라 두 번째 중간 노드를 반환하는 것이 핵심입니다. 노드 개수가 짝수일 때, `fast` 포인터가 정확히 끝에 도달하는 시점에 `slow` 포인터가 두 번째 중간 노드를 가리키도록 조건문을 구성해야 합니다.

`while fast and fast.next:` 조건은 `fast`가 `null`이 아니면서 `fast.next`도 `null`이 아닐 때 루프를 진행합니다. 이는 `fast`가 리스트의 끝을 넘어가지 않도록 보호하면서, 짝수 개의 노드에서도 올바르게 두 번째 중간 노드를 찾도록 합니다.
