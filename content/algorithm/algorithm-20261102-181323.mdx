## 문제

32비트 부호 있는 정수의 비트 순서를 뒤집는 함수를 구현해야 합니다. 입력으로 받은 정수를 2진수 표기로 나타냈을 때, LSB(Least Significant Bit)와 MSB(Most Significant Bit)의 위치가 서로 바뀐 새로운 정수를 출력해야 합니다.

주어진 제약 조건에 따르면 입력 정수는 0부터 $2^{31}-1$ 사이의 부호 없는 정수 값으로 해석됩니다. 32비트 길이로 정렬하여 단순히 비트만 뒤집으면 됩니다.

```python
class Solution:
    def reverseBits(self, n: int) -> int:
        pass
```

## 접근 방법

가장 직관적인 접근 방법은 32비트 전체를 순회하며, 입력 정수의 각 비트가 결과 정수의 어디에 위치해야 하는지 계산하는 것입니다.

우리는 0비트부터 31비트까지 반복문을 돌면서, 현재 처리 중인 비트가 입력 정수 `n`에서 1인지 확인합니다. 만약 1이라면, 해당 비트가 결과 정수에서 가려야 하는 위치($31 - i$)에 1을 설정하면 됩니다.

결과 정수를 저장할 변수 `res`를 0으로 초기화하고, 각 단계에서 비트 연산자를 사용하여 필요한 위치의 비트를 켜거나, 입력값을 오른쪽으로 이동하며 다음 비트를 확인하면 됩니다.

## 풀이

입력 정수 `n`의 각 비트를 확인하여 결과 정수 `res`에 역순으로 쌓아 나가는 구현입니다.

1. 결과값을 저장할 변수 `res`를 0으로 초기화합니다.
2. 0부터 31까지 반복하는 for 루프를 작성합니다.
3. 현재 반복 횟수 `i`에 대해, `n`의 0번째 비트(최하위 비트)가 1인지 확인합니다. (`n & 1`)
4. 만약 1이라면, `res`의 $31-i$번째 위치의 비트를 1로 설정합니다. (`res |= (1 << (31 - i))`)
5. `n`에서 가장 오른쪽 비트를 제거하기 위해 `n`을 오른쪽으로 1비트 쉬프트합니다. (`n >>= 1`)
6. 모든 32비트를 처리한 후 `res`를 반환합니다.

```python
class Solution:
    def reverseBits(self, n: int) -> int:
        res = 0
        for i in range(32):
            if n & 1:
                res |= (1 << (31 - i))
            n >>= 1
        return res
```

시간복잡도: $O(1)$ (비트 수 32가 고정되어 있으므로 상수 시간)
공간복잡도: $O(1)$

## 다른 풀이 방법

반복문을 사용하지 않고, 분할 정복(Divide and Conquer) 기법을 통해 비트를 병렬적으로 뒤집는 방법도 있습니다. 이는 문제의 Follow up인 "함수를 여러 번 호출할 때 최적화"와 관련이 깊습니다.

메모리 접근 패턴이 개선되고, 조건문 분기가 없어져 하드웨어 수준에서 더 효율적으로 실행될 수 있습니다.

```python
class Solution:
    def reverseBits(self, n: int) -> int:
        # 1비트 단위 교환 (홀짝 자리 바꿈)
        n = (n & 0x55555555) << 1 | (n & 0xAAAAAAAA) >> 1
        # 2비트 단위 교환
        n = (n & 0x33333333) << 2 | (n & 0xCCCCCCCC) >> 2
        # 4비트 단위 교환
        n = (n & 0x0F0F0F0F) << 4 | (n & 0xF0F0F0F0) >> 4
        # 8비트 단위 교환
        n = (n & 0x00FF00FF) << 8 | (n & 0xFF00FF00) >> 8
        # 16비트 단위 교환
        n = (n & 0x0000FFFF) << 16 | (n & 0xFFFF0000) >> 16
        return n
```

시간복잡도: $O(1)$
공간복잡도: $O(1)$
비교: 반복문 풀이는 구현이 단순하지만 분기(branching)가 발생할 수 있습니다. 분할 정복 풀이는 모든 연산이 일정하게 수행되어 예측 실패가 없고, 반복 호출 시 더 효율적인 병렬 처리가 가능하다는 장점이 있습니다.

## 추가 참고사항

- **메스킹(Masking)**: 분할 정복 기법에서는 특정 비트 위치의 값만 남기기 위해 16진수 마스크(`0x55555555`, `0x33333333` 등)를 사용합니다.
- **부호 확장**: 입력 정수가 부호 있는 정수이고 음수인 경우, Python의 `>>` 연산은 부호 비트를 유지하며 확장(sign-extending)합니다. 이 문제의 제약 조건에서는 $n \ge 0$이므로 이러한 문제가 발생하지 않으나, 다른 언어(Java, C++)의 경우 부호 비트 처리에 주의해야 합니다.
- **성능 최적화**: 함수가 수백만 번 호출되는 환경에서는 반복문보다 분할 정복 기법이 더 빠른 실행 시간을 보일 수 있습니다.
