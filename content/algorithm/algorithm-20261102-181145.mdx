## 문제

정사각행렬 `mat`이 매개변수로 주어집니다. 이때 주요 대각선(primary diagonal)과 부 대각선(secondary diagonal)에 위치한 모든 원소의 합을 반환해야 합니다. 단, 두 대각선이 교차하는 원소(중복되는 원소)는 한 번만 합산해야 합니다.

주요 대각선은 행과 열의 인덱스가 동일한 원소들(`mat[i][i]`)로 구성됩니다. 부 대각선은 행 인덱스와 열 인덱스의 합이 행의 크기 `n`에서 1을 뺀 값과 동일한 원소들(`mat[i][n - 1 - i]`)로 구성됩니다.

주어진 제약 조건은 행렬의 크기 `n`이 100 이하이며, 원소의 값은 100 이하라는 것입니다.

```python
# 예시 입력
mat = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]
# 주요 대각선: 1, 5, 9
# 부 대각선: 3, 5, 7
# 5는 중복되므로 한 번만 계산하여 총합은 25입니다.
```

## 접근 방법

행렬의 크기 `n`에 대해 인덱스 `i`가 0부터 `n-1`까지 반복하며 주요 대각선과 부 대각선의 원소를 순회합니다.

1. 주요 대각선의 원소 `mat[i][i]`를 누적합니다.
2. 부 대각선의 원소 `mat[i][n - 1 - i]`가 주요 대각선의 원소와 중복되지 않을 경우에만 누적합니다.
3. 두 인덱스가 동일한지 확인하여 중복 합산을 방지합니다. 인덱스가 동일하다면 이미 주요 대각선 계산 시 포함되어 있으므로 더하지 않습니다.

이 방식은 행렬의 모든 원소를 한 번씩만 접근하므로 효율적입니다.

## 풀이

각 행 `i`에 대해 대각선 원소를 확인하고, 중복 여부만 체크하여 합산합니다.

- 시간 복잡도: O(N). 행렬의 행 크기 N에 비례하여 한 번의 반복문만 수행합니다.
- 공간 복잡도: O(1). 추가적인 데이터를 저장하는 변수만 사용합니다.

```python
def diagonalSum(mat: list[list[int]]) -> int:
    n = len(mat)
    total_sum = 0
    
    for i in range(n):
        # 주요 대각선 원소 추가
        total_sum += mat[i][i]
        
        # 부 대각선 원소 추가 (중복 제외)
        if i != n - 1 - i:
            total_sum += mat[i][n - 1 - i]
            
    return total_sum
```

## 다른 풀이 방법

두 대각선의 합을 각각 계산한 후, 교차점을 확인하여 중복분을 빼는 방법입니다.

1. 주요 대각선의 합 `primary_sum`을 계산합니다.
2. 부 대각선의 합 `secondary_sum`을 계산합니다.
3. 행렬의 크기가 홀수인 경우, 중앙 원소 `mat[n//2][n//2]`가 두 대각선에 모두 포함되므로 이를 한 번 빼줍니다.

이 방법은 두 대각선을 별도의 루프로 계산하므로 코드의 가독성은 높을 수 있으나, 주요 대각선과 부 대각선을 한 루프에서 처리하는 첫 번째 방법보다 조건 분기가 다소 복잡해질 수 있습니다. 시간 복잡도는 동일하게 O(N)입니다.

```python
def diagonalSumAlternative(mat: list[list[int]]) -> int:
    n = len(mat)
    primary_sum = sum(mat[i][i] for i in range(n))
    secondary_sum = sum(mat[i][n - 1 - i] for i in range(n))
    
    if n % 2 == 1:
        return primary_sum + secondary_sum - mat[n // 2][n // 2]
    else:
        return primary_sum + secondary_sum
```

## 추가 참고사항

- 입력 행렬이 `1x1` 크기인 경우, 주요 대각선과 부 대각선이 완전히 일치합니다. 위 코드의 조건문 `if i != n - 1 - i`는 이 경우 `0 != 0`이 거짓이 되어 부 대각선 원소를 더하지 않으므로, 주요 대각선 원소 한 번만 합산되어 올바른 결과를 반환합니다.
- Python의 내장 함수 `sum`과 제너레이터 표현식을 활용하면 코드를 간결하게 작성할 수 있으나, 조건부 추가 로직이 포함된 단일 루프 접근법이 메모리와 실행 측면에서 일관된 효율성을 가집니다.
- 행렬의 원소 값이 최대 100이고 크기가 100이므로, 최대 합은 대략 $100 \times 100 \times 2 = 20000$ 수준으로 정수형 범위 내에서 충분히 처리 가능합니다.
