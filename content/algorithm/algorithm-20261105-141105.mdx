## 문제

소문자 영어로 이루어진 문자열 `s`가 주어집니다. 인접하고 같은 두 문자를 선택해 제거하는 연산을 반복하여 더 이상 제거할 수 없을 때까지 수행한 후, 최종 문자열을 돌려줍니다. 예를 들어 `"abbaca"`에서는 먼저 `"bb"`를 제거해 `"aaca"`를 만들고, 다시 `"aa"`를 제거해 `"ca"`가 됩니다. 문제에서 답은 항상 유일하다는 것이 증명되어 있습니다.

## 접근 방법

스택을 사용하여 최종 문자열을 구성합니다. 문자열을 왼쪽에서 오른쪽으로 한 문자씩 순회하며, 스택이 비어있지 않고 스택의 탑이 현재 문자와 같으면 스택에서 팝(제거)하고, Otherwise push(추가)합니다. 이 과정을 모두 마치면 스택에 남은 문자들이 바로 답이 됩니다. 이 방법은 각 문자를 한 번만 처리하므로 시간 복잡도는 O(n)이고, 공간 복잡도는 최악의 경우 O(n)입니다.

## 풀이

```python
def removeDuplicates(s: str) -> str:
    stack = []
    for ch in s:
        if stack and stack[-1] == ch:
            stack.pop()
        else:
            stack.append(ch)
    return ''.join(stack)
```

- 시간 복잡도: O(n) (각 문자를 한 번씩만 처리)
- 공간 복잡도: O(n) (스택에 남을 수 있는 최대 크기)

## 다른 풀이 방법

문자열을 문자 리스트로 바꾸고 `write` 포인터를 사용하면 스택과 같은 방식으로 처리할 수 있습니다. `write` 앞에 남아 있는 마지막 문자와 현재 문자가 같으면 마지막 문자를 제거하고, 다르면 현재 문자를 기록합니다.

```python
def removeDuplicates_two_pointers(s: str) -> str:
    chars = list(s)
    write = 0

    for read in range(len(chars)):
        if write > 0 and chars[write - 1] == chars[read]:
            write -= 1
        else:
            chars[write] = chars[read]
            write += 1

    return "".join(chars[:write])
```

시간 복잡도는 O(n), 공간 복잡도는 Python 문자열을 리스트로 변환하는 비용 때문에 O(n)입니다. 리스트를 입력으로 받는 언어라면 배열을 직접 수정해 추가 공간을 줄일 수 있지만, Python 문자열 입력에서는 문자 리스트가 필요합니다.
