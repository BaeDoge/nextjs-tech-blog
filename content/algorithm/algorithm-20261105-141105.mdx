## 문제

소문자 영어로 이루어진 문자열 `s`가 주어집니다. 인접하고 같은 두 문자를 선택해 제거하는 연산을 반복하여 더 이상 제거할 수 없을 때까지 수행한 후, 최종 문자열을 돌려줍니다. 예를 들어 `"abbaca"`에서는 먼저 `"bb"`를 제거해 `"aaca"`를 만들고, 다시 `"aa"`를 제거해 `"ca"`가 됩니다. 문제에서 답은 항상 유일하다는 것이 증명되어 있습니다.

## 접근 방법

스택을 사용하여 최종 문자열을 구성합니다. 문자열을 왼쪽에서 오른쪽으로 한 문자씩 순회하며, 스택이 비어있지 않고 스택의 탑이 현재 문자와 같으면 스택에서 팝(제거)하고, Otherwise push(추가)합니다. 이 과정을 모두 마치면 스택에 남은 문자들이 바로 답이 됩니다. 이 방법은 각 문자를 한 번만 처리하므로 시간 복잡도는 O(n)이고, 공간 복잡도는 최악의 경우 O(n)입니다.

## 풀이

```python
def removeDuplicates(s: str) -> str:
    stack = []
    for ch in s:
        if stack and stack[-1] == ch:
            stack.pop()
        else:
            stack.append(ch)
    return ''.join(stack)
```

- 시간 복잡도: O(n) (각 문자를 한 번씩만 처리)
- 공간 복잡도: O(n) (스택에 남을 수 있는 최대 크기)

## 다른 풀이 방법

두 포인터를 사용해 문자열을 제자리에서 정리하는 방법도 있습니다. 문자 배열로 변환한 후, write 포인터를 앞에서부터 이동시키면서 read 포인터로 전체 문자를 순회하며, write 포인터가 가리키는 직전 문자와 현재 문자가 같으면 write 포인터를 뒤로 돌리고(제거), Otherwise write 포인터를 전진시킵니다. 이 방법도 시간 복잡도는 O(n)이며, 추가 공간을 O(1)로 사용할 수 있지만, Python에서 문자열은 immutable이므로 char array로 변환해야 해서 여전히 O(n) 공간이 필요합니다. 반면 스택 방식은 코드가 간결하고 가독성이 뛰어나므로 일반적으로 선호됩니다. 재귀를 이용한 방법은 최악의 경우 O(n^2) 시간 복잡도를 가지며 긴 문자열에서 비효율적입니다.
