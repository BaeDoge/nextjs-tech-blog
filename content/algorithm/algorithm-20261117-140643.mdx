## 문제

유전자 문자열은 8개의 문자로 구성되며, 각 문자는 ‘A’, ‘C’, ‘G’, ‘T’ 중 하나입니다. 한 번의 변이는 문자열의 단일 문자를 다른 문자로 변경하는 것을 의미합니다. `bank`는 유효한 변이 문자열의 목록을 저장하며, 변이에 참여하는 모든 문자열은 `bank`에 포함되어야 합니다. `startGene`은 유효하지만 `bank`에 포함되지 않을 수 있습니다. `startGene`에서 `endGene`으로 변환하는 데 필요한 최소 변이 횟수를 구해야 하며, 변환이 불가능하면 -1을 반환합니다.

## 접근 방법

BFS를 사용하여 `startGene`에서 `endGene`까지의 최단 경로를 탐색합니다. 각 단계에서 현재 문자열의 각 위치를 순회하며 네 가지 가능한 문자를 시도하고, 시도한 문자열이 `bank`에 존재하며 방문하지 않은 경우에만 큐에 추가합니다. `endGene`에 도달하면 현재 단계 수를 반환합니다.

```python
from collections import deque

def minMutation(startGene: str, endGene: str, bank: list[str]) -> int:
    if startGene == endGene:
        return 0

    bank_set = set(bank)
    if endGene not in bank_set:
        return -1
    visited = {startGene}
    q = deque([(startGene, 0)])
    chars = {'A', 'C', 'G', 'T'}

    while q:
        gene, steps = q.popleft()
        if gene == endGene:
            return steps
        # 한 글자씩 변경
        for i in range(len(gene)):
            for c in chars:
                if c == gene[i]:
                    continue
                nxt = gene[:i] + c + gene[i+1:]
                if nxt in bank_set and nxt not in visited:
                    visited.add(nxt)
                    q.append((nxt, steps + 1))
    return -1
```

## 풀이

위 BFS 코드를 통해 최소 변이 횟수를 계산합니다. `bank_set`은 O(1) 조회를 가능하게 하며, `visited` 집합은 중복 탐색을 방지합니다. 탐색은 `endGene`에 도달하거나 큐가 비워질 때까지 계속됩니다. 각 방문 문자열에서 L개 위치마다 최대 3개의 대체 문자를 확인합니다. 문자열 슬라이싱과 결합에는 O(L) 시간이 들기 때문에 시간 복잡도는 O(N·L²·4), 공간 복잡도는 O(N·L)입니다. 이 문제에서는 L=8, N≤10으로 작지만, 문자열 생성 비용까지 포함하는 것이 정확합니다.

```python
# 예제 실행
print(minMutation("AACCGGTT", "AACCGGTA", ["AACCGGTA"]))  # 1
print(minMutation("AACCGGTT", "AAACGGTA", ["AACCGGTA","AACCGCTA","AAACGGTA"]))  # 2
```

## 다른 풀이 방법

- **양방향 BFS:** `startGene`과 `endGene`에서 동시에 탐색을 시작하여 교차점을 찾음으로써 탐색 공간을 줄일 수 있습니다. 이 방법은 은행 크기가 클 때 특히 유용하며, 시간 복잡도는 여전히 O(N·L·4)입니다.
- **DFS + 메모이제이션:** 각 문자열에 대해 도달 가능한 모든 문자열을 탐색하고, `endGene`까지의 최단 경로를 저장합니다. 이 방법은 작은 은행 크기에서는 BFS와 유사하지만, 큰 은행에서는 중복 탐색으로 인해 성능이 저하될 수 있습니다.

## 추가 참고사항

- `startGene`과 `endGene`이 같으면 변이 횟수는 0이므로 `bank`를 확인하기 전에 0을 반환해야 합니다.
- `startGene`과 `endGene`이 다를 때 `endGene`이 `bank`에 없으면 변환이 불가능하므로 -1을 반환합니다.
- `startGene`과 `endGene`이 동일한 경우, 0을 반환합니다.
- `bank`에 `startGene`이 포함되지 않은 경우에도 유효하며, BFS는 `bank_set`에만 의존합니다.
