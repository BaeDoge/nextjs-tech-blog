## 문제

8개의 문자로 구성된 유전자 문자열이 주어집니다. 각 문자는 A, C, G, T 중 하나이며, 한 번의 변이는 한 위치의 문자를 다른 문자로 바꾸는 작업입니다.

변이에 사용할 수 있는 문자열은 bank에 포함되어 있어야 합니다. 시작 문자열 startGene은 bank에 포함되어 있지 않아도 됩니다. 시작 문자열에서 목표 문자열 endGene으로 바꾸는 최소 변이 횟수를 구하고, 변환할 수 없으면 -1을 반환합니다.

## 접근 방법

한 번의 변이로 도달할 수 있는 문자열을 정점으로 보고, 한 문자만 다른 두 문자열을 간선으로 연결한 그래프로 생각할 수 있습니다. 모든 변이의 비용이 1이므로 최단 경로를 찾는 BFS가 적합합니다.

각 문자열에서 8개 위치를 하나씩 바꾸어 보며, 생성된 문자열이 bank에 있고 아직 방문하지 않았다면 큐에 추가합니다.

## 풀이

~~~python
from collections import deque

def min_mutation(start_gene: str, end_gene: str, bank: list[str]) -> int:
    if start_gene == end_gene:
        return 0

    bank_set = set(bank)
    if end_gene not in bank_set:
        return -1

    chars = "ACGT"
    visited = {start_gene}
    queue = deque([(start_gene, 0)])

    while queue:
        gene, steps = queue.popleft()

        for i in range(len(gene)):
            for char in chars:
                if char == gene[i]:
                    continue

                next_gene = gene[:i] + char + gene[i + 1:]
                if next_gene not in bank_set or next_gene in visited:
                    continue

                if next_gene == end_gene:
                    return steps + 1

                visited.add(next_gene)
                queue.append((next_gene, steps + 1))

    return -1


print(min_mutation("AACCGGTT", "AACCGGTA", ["AACCGGTA"]))  # 1
print(
    min_mutation(
        "AACCGGTT",
        "AAACGGTA",
        ["AACCGGTA", "AACCGCTA", "AAACGGTA"],
    )
)  # 2
~~~

먼저 start_gene == end_gene인지 확인하는 것이 중요합니다. 두 문자열이 같다면 변이가 필요하지 않으므로 bank에 시작 문자열이 없어도 결과는 0입니다.

## 복잡도

N을 bank의 문자열 수, L을 유전자 문자열 길이라고 하겠습니다. 각 문자열에서 위치 L개와 대체 문자 최대 3개를 확인하고, 문자열을 새로 만드는 데 최대 O(L)이 소요됩니다. 따라서 시간 복잡도는 O(N × L²), 공간 복잡도는 O(N)입니다. 이 문제에서는 L = 8로 고정되어 있어 문자열 생성 비용은 제한적입니다.

## 추가 참고사항

- 목표 문자열이 bank에 없다면, 시작 문자열과 목표 문자열이 다른 경우 변환할 수 없으므로 -1을 반환합니다.
- 이미 방문한 문자열은 다시 큐에 넣지 않아야 중복 탐색을 막을 수 있습니다.
- BFS는 간선 비용이 모두 같을 때 최단 경로를 보장합니다.
