## 문제

주어진 `intervals` 배열에서 각 구간 `i`에 대해 오른쪽 구간을 찾아야 합니다. 오른쪽 구간 `j`는 `start_j >= end_i`를 만족하며, `start_j`가 최소인 구간을 의미합니다. 단, `i`와 `j`가 같아도 됩니다. 모든 구간에 대해 대응하는 오른쪽 구간의 인덱스를 배열로 반환하며, 조건을 만족하는 구간이 없으면 해당 인덱스에 -1을 넣습니다. 각 구간의 시작점은 고유합니다.

```python
# 입력 예시
intervals = [[3,4],[2,3],[1,2]]
# 출력 예시
[-1, 0, 1]
```

## 접근 방법

각 구간의 끝점(`end_i`)에 대해 조건을 만족하는 최소 시작점을 찾아야 하므로, 이분 탐색(Binary Search)을 활용하는 것이 적합합니다. 이를 위해 시작점(`start`)과 원래 인덱스(`original_index`)의 쌍을 정렬된 배열로 미리 준비합니다. 정렬된 시작점 배열에서 `bisect_left`를 사용하여 `end_i` 이상인 첫 번째 시작점을 찾습니다. 해당 위치가 배열의 범위를 벗어난 경우 -1을, 그렇지 않으면 해당 인덱스에 매핑된 원래 인덱스를 결과 배열에 추가합니다.

## 풀이

1. 각 구간의 시작점과 원래 인덱스를 쌍으로 저장한 `starts` 배열을 만듭니다.
2. `starts`를 시작점을 기준으로 정렬합니다.
3. 정렬된 시작점만을 추출하여 `sorted_starts`라는 별도 배열로 유지합니다. 이는 이분 탐색 시 매번 서브 리스트를 생성하는 $O(N)$ 오버헤드를 방지하기 위함입니다.
4. 각 구간 `interval`에 대해 `end = interval[1]`을 얻습니다.
5. `bisect_left`를 사용하여 `sorted_starts` 배열에서 `end` 이상인 첫 번째 시작점의 인덱스를 찾습니다.
6. 찾은 인덱스가 `starts`의 길이보다 작으면 해당 인덱스에 해당하는 `starts`의 원래 인덱스를 결과에 추가하고, 크거나 같으면 -1을 추가합니다.
7. 결과 배열을 반환합니다.

- 시간 복잡도: 정렬에 $O(N \log N)$, 각 구간에 대한 이분 탐색에 $O(\log N)$으로 총 $O(N \log N)$입니다.
- 공간 복잡도: 보조 배열 `starts`와 `sorted_starts`를 사용하므로 $O(N)$입니다.

```python
import bisect

def findRightInterval(intervals):
    # 시작점과 원래 인덱스를 쌍으로 저장
    starts = [[interval[0], i] for i, interval in enumerate(intervals)]
    # 시작점을 기준으로 정렬
    starts.sort(key=lambda x: x[0])
    
    # 이분 탐색 효율을 위해 시작점만 추출한 배열 준비
    sorted_starts = [s[0] for s in starts]
    
    result = []
    n = len(intervals)
    
    for i in range(n):
        end = intervals[i][1]
        # end 이상인 첫 번째 시작점의 인덱스 탐색
        idx = bisect.bisect_left(sorted_starts, end)
        
        if idx < n:
            # 찾은 경우 원래 인덱스 추가
            result.append(starts[idx][1])
        else:
            # 조건을 만족하는 시작점이 없는 경우
            result.append(-1)
            
    return result
```

## 다른 풀이 방법

- **두 포인터**: 시작점과 끝점을 모두 정렬한 후, 끝점 배열을 순회하며 시작점 포인터를 이동시켜 조건을 만족하는 가장 가까운 시작점을 찾습니다. 이는 정렬 후 한 번의 순회로 $O(N \log N)$ 시간 복잡도를 유지하면서 공간 복잡도를 최적화할 수 있는 방법입니다.

## 추가 참고사항

- 문제 제약 조건에서 각 구간의 시작점은 고유하다고 명시되어 있으므로, 같은 시작점을 가진 구간이 중복되어 정렬 순서가 모호하지 않습니다.
- `bisect` 모듈은 이진 탐색을 효율적으로 수행하여, 정렬된 배열에서의 검색 연산을 로그 시간 복잡도로 처리합니다.
- 구간의 길이(`intervals[i].length`)가 항상 2라고 명시되어 있으므로, 입력 검증 없이 인덱싱을 진행할 수 있습니다.
