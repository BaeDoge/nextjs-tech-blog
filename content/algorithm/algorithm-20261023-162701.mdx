## 문제

`original`과 `cloned` 두 개의 이진 트리가 주어지며, `cloned` 트리는 `original` 트리의 정확히 동일한 복사본입니다. `original` 트리에 있는 특정 노드를 가리키는 참조 `target`이 주어졌을 때, `cloned` 트리에서 동일한 구조적 위치를 가리키는 노드 참조를 반환해야 합니다. 트리의 노드 값은 고유하지 않을 수 있으며(Follow-up), 트리의 노드 수는 최대 10,000개입니다. 핵심은 노드의 값이 아닌, `original` 트리의 실제 노드 참조(`target`)와 구조가 일치하는 `cloned` 트리의 노드를 찾아야 한다는 점입니다.

## 접근 방법

`original` 트리와 `cloned` 트리는 구조가 동일하므로, 두 트리를 동시에 탐색하며 `original` 트리의 현재 노드가 `target`과 일치하는지 확인하면 됩니다. `target`은 `original` 트리의 실제 노드 참조이므로, 값 비교가 아닌 참조 비교(`is` 또는 `==`)를 통해 일치 여부를 판별해야 합니다. 일치하는 노드를 발견하면, 그 시점의 `cloned` 트리의 현재 노드를 반환하면 됩니다. 이 과정은 깊이 우선 탐색(DFS) 또는 너비 우선 탐색(BFS)으로 구현할 수 있습니다.

## 풀이

재귀를 이용한 깊이 우선 탐색(DFS) 방식으로 구현합니다. 현재 `original` 노드가 `target`과 동일한지 확인하고, 맞으면 해당 시점의 `cloned` 노드를 반환합니다. 아니라면 왼쪽 자식 노드와 오른쪽 자식 노드를 순회하며 일치하는 노드가 있는지 탐색합니다.

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, x):
#         self.val = x
#         self.left = None
#         self.right = None

class Solution:
    def getTargetCopy(self, original: TreeNode, cloned: TreeNode, target: TreeNode) -> TreeNode:
        # 기본 조건: 트리가 비어있으면 None 반환
        if not original:
            return None
        
        # original의 현재 노드가 target과 참조가 동일하면,
        # cloned의 현재 노드가 정답이므로 반환
        if original is target:
            return cloned
        
        # 왼쪽 서브트리에서 탐색
        left_result = self.getTargetCopy(original.left, cloned.left, target)
        if left_result:
            return left_result
            
        # 오른쪽 서브트리에서 탐색
        right_result = self.getTargetCopy(original.right, cloned.right, target)
        return right_result
```

시간복잡도: $O(N)$ (N은 트리의 노드 수). 최악의 경우 모든 노드를 방문합니다.
공간복잡도: $O(H)$ (H는 트리의 높이). 재귀 호출 스택의 깊이만큼 공간이 소요됩니다. 균형 이진트리의 경우 $O(\log N)$, 편향 이진트리의 경우 $O(N)$입니다.

## 다른 풀이 방법

반복문을 이용한 너비 우선 탐색(BFS)을 사용할 수 있습니다. 큐를 사용하여 두 트리의 노드를 레벨별로 동시에 처리합니다.

```python
from collections import deque

class Solution:
    def getTargetCopy(self, original: TreeNode, cloned: TreeNode, target: TreeNode) -> TreeNode:
        if not original:
            return None
            
        queue = deque([(original, cloned)])
        
        while queue:
            orig_node, clone_node = queue.popleft()
            
            # 참조 비교를 통해 타겟 노드 발견
            if orig_node is target:
                return clone_node
            
            # 자식 노드가 존재하면 큐에 추가
            if orig_node.left:
                queue.append((orig_node.left, clone_node.left))
            if orig_node.right:
                queue.append((orig_node.right, clone_node.right))
                
        return None
```

시간복잡도: $O(N)$
공간복잡도: $O(W)$ (W는 트리의 최대 너비). 큐에 저장되는 최대 노드 수만큼 공간이 소요됩니다.

## 추가 참고사항

문제 지문의 제약 조건에 따르면 노드 값은 고유하다고 명시되어 있으나, Follow-up에서는 반복된 값을 허용하는 경우를 묻고 있습니다. 본 풀이는 노드 값을 사용하지 않고 참조 비교(`is`)를 수행하므로, 노드 값이 중복되더라도 구조적 대응 관계를 통해 정답을 정확히 찾을 수 있습니다. 따라서 Follow-up 조건에서도 동일한 코드로 해결 가능합니다.
