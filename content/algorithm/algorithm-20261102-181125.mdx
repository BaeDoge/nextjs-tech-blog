## 문제

정수 배열 `nums`가 주어질 때, 이 중 세 개의 길이를 선택하여 둘레가 가장 크고 넓이가 0이 아닌 삼각형을 만들 수 있다면 그 최대 둘레를 반환해야 합니다. 삼각형을 만들 수 없는 경우 0을 반환합니다. 세 변의 길이를 $a, b, c$ ($a \le b \le c$)라고 할 때, 넓이가 0이 아닌 삼각형이 되기 위한 조건은 $a + b > c$입니다. 만약 이 부등식을 만족하지 않는다면 두 짧은 변의 합이 가장 긴 변보다 짧거나 같아 삼각형을 형성할 수 없습니다.

## 접근 방법

가장 큰 둘레를 찾기 위해서는 값이 큰 변부터 우선적으로 고려해야 합니다. 배열을 내림차순으로 정렬하면 큰 값이 앞에 위치합니다. 정렬된 배열에서 인덱스 $i$의 값을 가장 긴 변 $c$로 가정하면, 나머지 두 변 중 가장 큰 값을 가질 수 있는 것은 인덱스 $i+1$과 $i+2$의 값입니다. 이 세 값이 삼각형 부등식 $nums[i+1] + nums[i+2] > nums[i]$를 만족한다면, 해당 $i$에 대해 가능한 최대 둘레를 찾은 것이므로 즉시 반환할 수 있습니다. 정렬된 배열의 특성상, 현재보다 작은 $c$를 사용할 때는 더 큰 둘레를 얻을 수 없기 때문입니다. 만약 현재 $i$에 대해 조건을 만족하지 못한다면, $a$와 $b$를 더 작은 값으로 선택해도 두 변의 합은 줄어들어 조건을 만족할 수 없으므로, $c$를 한 단계 낮춰 같은 과정을 반복합니다.

## 풀이

정렬 후 연속된 세 요소를 확인하는 그리디 알고리즘을 사용합니다.

```python
def largestPerimeter(nums: list[int]) -> int:
    # O(N log N): 배열을 내림차순 정렬
    nums.sort(reverse=True)
    
    # O(N): 정렬된 배열을 순회하며 삼각형 조건 확인
    for i in range(len(nums) - 2):
        # 가장 긴 변 nums[i]에 대해, 다음으로 긴 두 변 nums[i+1], nums[i+2]를 사용
        # 삼각형 성립 조건: 두 짧은 변의 합이 가장 긴 변보다 커야 함
        if nums[i + 1] + nums[i + 2] > nums[i]:
            return nums[i] + nums[i + 1] + nums[i + 2]
            
    return 0
```

- 시간 복잡도: $O(N \log N)$ (정렬에 소요)
- 공간 복잡도: $O(\log N)$ 또는 $O(N)$ (정렬 알고리즘의 구현에 따라 다름, Python의 Timsort는 $O(N)$)

## 다른 풀이 방법

완전탐색을 사용하여 세 개의 변을 모든 경우의 수로 조합하여 삼각형 조건을 확인하고 둘레를 구할 수 있습니다. 이 경우 시간 복잡도는 $O(N^3)$이 되며, 제약 조건에서 $N$이 $10^4$까지 허용되므로 실행 시간 초과가 발생합니다. 따라서 정렬을 활용한 그리디 접근이 더 효율적입니다.

## 추가 참고사항

삼각형의 넓이가 0인 경우는 degenerate triangle이라 부르며, 문제에서는 이를 제외하라고 명시했습니다. $a+b=c$인 경우 넓이가 0이 되므로 조건을 만족하지 않습니다. 제약 조건에서 $N \ge 3$이므로 배열 길이 확인은 생략해도 됩니다.
