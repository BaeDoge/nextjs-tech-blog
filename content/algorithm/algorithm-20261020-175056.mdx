## 문제

정수 배열 `nums`가 주어졌을 때, 가장 큰 합을 갖는 연속된 부분 배열(subarray)을 찾고 그 합을 반환해야 합니다. 부분 배열은 배열의 원소들이 연속적으로 이어진 구간을 의미합니다.

예를 들어, 입력 `[-2,1,-3,4,-1,2,1,-5,4]`의 경우 `[4,-1,2,1]`이 최대 합인 6을 가집니다. 배열의 길이는 1 이상 10^5 이하이며, 각 원소의 값은 -10^4 이상 10^4 이하입니다.

## 접근 방법

이 문제는 '카데인 알고리즘(Kadane's Algorithm)'을 적용하여 해결할 수 있습니다. 각 인덱스 `i`에서의 최대 부분 배열 합은, 이전 인덱스 `i-1`까지의 최대 부분 배열 합에 현재 원소 `nums[i]`를 더한 값과 현재 원소 `nums[i]` 자체 중 더 큰 값과 동일합니다.

즉, `dp[i] = max(dp[i-1] + nums[i], nums[i])`라는 점화식을 사용할 수 있습니다. 이는 이전까지의 합이 음수라면 현재 원소부터 새로운 부분 배열을 시작하는 것이 유리하다는 논리에 기반합니다. 전체 배열을 한 번 순회하면서 이 과정을 반복하면 최대 합을 찾을 수 있습니다.

## 풀이

배열을 순회하며 현재까지의 부분 합(`current_sum`)과 최대 부분 합(`max_sum`)을 관리합니다. `current_sum`은 현재 원소를 포함하는 부분 배열의 최대 합을 의미하며, 음수가 되면 0으로 초기화하거나 현재 원소로 리셋하는 방식으로 처리합니다.

```python
class Solution:
    def maxSubArray(self, nums: list[int]) -> int:
        current_sum = nums[0]
        max_sum = nums[0]
        
        for i in range(1, len(nums)):
            # 이전 합이 음수면 현재 원소부터 새로 시작, 양수면 이어붙임
            if current_sum < 0:
                current_sum = nums[i]
            else:
                current_sum += nums[i]
            
            # 최대 합 갱신
            if current_sum > max_sum:
                max_sum = current_sum
                
        return max_sum
```

시간 복잡도: O(n) - 배열을 한 번 순회합니다.
공간 복잡도: O(1) - 상수 개의 변수만 사용합니다.

## 다른 풀이 방법

분할 정복(Divide and Conquer) 접근법을 사용할 수 있습니다. 배열을 두 부분으로 나누어, 최대 부분 배열이 왼쪽 부분에만 있는지, 오른쪽 부분에만 있는지, 또는 두 부분을 가로지르는지 세 경우로 나눕니다.

1. 왼쪽 부분의 최대 합
2. 오른쪽 부분의 최대 합
3. 중앙을 포함하는 최대 합 (왼쪽 끝에서 중앙으로, 중앙에서 오른쪽 끝으로 확장)

이 세 값 중 최댓값을 반환하며 재귀적으로 해결합니다.

```python
class Solution:
    def maxSubArray(self, nums: list[int]) -> int:
        def find_max_subarray(left, right):
            if left == right:
                return nums[left]
            
            mid = (left + right) // 2
            left_max = find_max_subarray(left, mid)
            right_max = find_max_subarray(mid + 1, right)
            
            # 중앙을 포함하는 최대 합 계산
            left_border_max = float('-inf')
            curr = 0
            for i in range(mid, left - 1, -1):
                curr += nums[i]
                left_border_max = max(left_border_max, curr)
                
            right_border_max = float('-inf')
            curr = 0
            for i in range(mid + 1, right + 1):
                curr += nums[i]
                right_border_max = max(right_border_max, curr)
                
            cross_max = left_border_max + right_border_max
            
            return max(left_max, right_max, cross_max)
        
        return find_max_subarray(0, len(nums) - 1)
```

시간 복잡도: O(n log n) - 재귀 깊이 log n, 각 단계에서 O(n) 작업 수행.
공간 복잡도: O(log n) - 재귀 호출 스택 사용.

## 추가 참고사항

문제 지문에는 분할 정복 접근법을 시도해 볼 것을 권장하는 Follow-up가 포함되어 있습니다. 이 방법은 O(n) 해법보다 구현이 복잡하지만, 병렬 처리가 가능한 구조라는 장점이 있어 알고리즘 설계 관점에서 의미가 있습니다.
