## 문제

알리스와 밥이 숫자 `n`을 사용하여 게임을 진행합니다. 알리스가 먼저 시작합니다.
매 턴마다 현재 숫자 `n`에 대해 다음 조건을 만족하는 정수 `x`를 선택합니다.
1. `0 < x < n`
2. `n % x == 0` (즉, `x`는 `n`의 약수)
선택한 `x`를 사용하여 칠판의 숫자를 `n - x`로 바꿉니다.
이동할 수 있는 수가 없게 되는 플레이어는 패배합니다.
두 플레이어가 최적의 전략을 사용할 때, 알리스가 이기면 `true`, 그렇지 않으면 `false`를 반환합니다.
제약 조건: `1 <= n <= 1000`

## 접근 방법

이 문제는 게임 이론(Game Theory) 또는 동적 계획법(Dynamic Programming)으로 접근할 수 있습니다.
각 상태 `n`에 대해 현재 턴을 가진 플레이어가 이길 수 있는지(`win[n]`)를 저장하는 배열을 고려합니다.
`n`의 모든 약수 `x`에 대해, `n - x`로 이동했을 때 상대방이 지는 상태(`win[n - x] == false`)라면, 현재 플레이어는 그 `x`를 선택하여 이길 수 있습니다.
즉, `win[n]`은 `true`가 됩니다.
반대로, 모든 가능한 이동(`n - x`) 후 상대방이 이기는 상태(`win[n - x] == true`)로만 이어진다면, 현재 플레이어는 무조건 지게 되므로 `win[n]`은 `false`가 됩니다.
기저 사례(Base Case)로 `n = 1`일 때는 약수가 없으므로 즉시 패배하여 `false`입니다.
이러한 점화식을 통해 작은 수부터 큰 수까지 순차적으로 계산하면 됩니다.

## 풀이

동적 계획법을 사용하여 `1`부터 `n`까지의 각 숫자에 대해 이길 수 있는지 여부를 계산합니다.
배열 `dp`의 인덱스 `i`는 숫자 `i`를 가졌을 때 현재 플레이어의 승패를 나타냅니다.

```python
class Solution:
    def divisorGame(self, n: int) -> bool:
        # dp[i]는 숫자 i를 가진 현재 플레이어가 이길 수 있는지 여부
        dp = [False] * (n + 1)
        
        # 기저 사례: 1은 약수가 없으므로 패배 (이미 False로 초기화됨)
        # 2부터 n까지 계산
        for i in range(2, n + 1):
            # i의 약수 x를 찾음
            # x는 1 <= x < i 이며 i % x == 0
            for x in range(1, i):
                if i % x == 0:
                    # x를 선택하면 다음 상태는 i - x
                    # 만약 i - x 상태에서 상대방이 진다면(dp[i-x] == False),
                    # 현재 플레이어는 이길 수 있음(dp[i] = True)
                    if not dp[i - x]:
                        dp[i] = True
                        break # 한 번이라도 이길 수 있는 수를 찾으면 종료
        
        return dp[n]
```

시간복잡도: $O(n^2)$입니다. 외부 루프가 $n$번, 내부 루프가 최대 $n$번 실행됩니다.
공간복잡도: $O(n)$입니다. 크기가 $n+1$인 배열을 사용합니다.

## 다른 풀이 방법

수학적 패턴을 이용한 접근입니다.
게임의 규칙을 분석하면 다음과 같은 성질을 관찰할 수 있습니다.
1. 짝수 `n`을 가진 플레이어는 반드시 `1`을 선택할 수 있습니다. `n - 1`은 홀수가 됩니다.
2. 홀수 `n`을 가진 플레이어의 약수 `x`는 반드시 홀수입니다. 홀수에서 홀수를 빼면 결과는 짝수가 됩니다.
즉, 짝수를 받으면 홀수를 넘겨주고, 홀수를 받으면 짝수를 넘겨주게 됩니다.
초기 숫자 `n`이 짝수라면, 알리스는 항상 짝수를 유지하며 밥에게 홀수를 넘길 수 있습니다.
반대로 `n`이 홀수라면, 알리스는 밥에게 짝수를 넘겨주게 되고, 결국 알리스는 홀수 상태(특히 1)에서 패배하게 됩니다.
따라서 `n`이 짝수이면 알리스가 이기고, 홀수이면 밥이 이깁니다.

```python
class Solution:
    def divisorGame(self, n: int) -> bool:
        return n % 2 == 0
```

시간복잡도: $O(1)$입니다.
공간복잡도: $O(1)$입니다.

## 추가 참고사항

참고 자료에 따르면 이 문제는 Math, Dynamic Programming, Brainteaser, Game Theory, Impartial Game 태그로 분류됩니다.
동적 계획법 풀이는 $n$이 작을 때(예: 1000 이하) 충분히 효율적이지만, 수학적 접근은 상수 시간에 해결합니다.
게임 이론 문제 중 'Impartial Game'(공정한 게임)의 대표적인 예시로, 상태가 유한하고 무승부 가능성이 없으며, 두 플레이어의 사용 가능한 수에 차이가 없는 게임입니다.
이러한 게임은 일반적으로 스프라그-그런디 정리(Sprague-Grundy theorem) 등으로 분석되지만, 이 문제의 경우 단순한 홀짝 규칙으로 귀결됩니다.
확실하지 않은 원인은 본문에서 '~로 추정됩니다'로 구분하지 않았으나, 홀짝 규칙은 수학적 귀납법으로 엄밀하게 증명 가능한 사실입니다.
