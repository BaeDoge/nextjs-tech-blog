## 문제

정수 배열 `arr`이 주어졌을 때, 두 인덱스 `i`와 `j`가 다음 조건을 모두 만족하는지 확인하는 함수를 작성해야 합니다.
- `i`와 `j`는 서로 달라야 합니다 (`i != j`).
- `arr[i]`의 값이 `arr[j]`의 값의 2배여야 합니다 (`arr[i] == 2 * arr[j]`).

배열의 길이는 2 이상 500 이하이며, 각 원소의 값은 -103에서 103 사이의 정수입니다. 조건을 만족하는 쌍이 존재하면 `true`, 그렇지 않으면 `false`를 반환합니다.

## 접근 방법

주어진 배열의 모든 서로 다른 두 원소의 쌍을 확인하여 조건을 만족하는지 검사하는 완전 탐색(Brute Force) 방식을 사용할 수 있습니다.
배열의 길이가 최대 500이므로, 두 중첩 루프를 사용하여 모든 조합을 확인하는 경우의 수는 약 125,000회로 제한적입니다.
이 경우 시간 복잡도는 $O(N^2)$이 되며, 제한 시간 내에 충분히 동작할 수 있습니다.
각 인덱스 `i`에 대해 나머지 모든 인덱스 `j`를 순회하면서 `arr[i] == 2 * arr[j]` 또는 `arr[j] == 2 * arr[i]` 조건을 체크합니다.
공간 복잡도는 추가적인 자료 구조를 사용하지 않으므로 $O(1)$이 됩니다.

## 풀이

두 중첩 루프를 사용하여 모든 가능한 인덱스 쌍 $(i, j)$에 대해 조건을 확인합니다.
`i`가 `j`와 같지 않은지 먼저 확인한 후, 곱셈 조건을 검사합니다.
조건을 만족하는 쌍이 발견되면 즉시 `true`를 반환하고, 모든 쌍을 확인한 후에도 조건을 만족하는 쌍이 없으면 `false`를 반환합니다.

```python
class Solution:
    def checkIfExist(self, arr: List[int]) -> bool:
        n = len(arr)
        for i in range(n):
            for j in range(n):
                if i != j and arr[i] == 2 * arr[j]:
                    return True
        return False
```

시간 복잡도: $O(N^2)$ (여기서 $N$은 배열의 길이)
공간 복잡도: $O(1)$

## 다른 풀이 방법

해시셋(Hash Set)을 활용하여 시간 복잡도를 $O(N)$으로 줄일 수 있습니다.
배열을 한 번 순회하면서 현재 숫자 `num`에 대해 `num * 2` 또는 `num / 2`가 이미 방문한 숫자 집합에 있는지 확인합니다.
`num / 2`의 경우 정수 나눗셈에서 나머지가 0인지 확인해야 합니다.
조건을 만족하면 `true`를 반환하고, 만족하지 않으면 현재 숫자를 집합에 추가하여 다음 순회에서 참조할 수 있게 합니다.
이 방법은 배열을 한 번만 순회하므로 시간 복잡도가 $O(N)$으로 개선되지만, 해시셋 저장으로 인해 공간 복잡도가 $O(N)$이 됩니다.

```python
class Solution:
    def checkIfExist(self, arr: List[int]) -> bool:
        seen = set()
        for num in arr:
            if num * 2 in seen or (num % 2 == 0 and num // 2 in seen):
                return True
            seen.add(num)
        return False
```

## 추가 참고사항

해시맵을 사용한 접근법은 배열의 크기가 매우 큰 경우(예: $10^5$ 이상) 더 효율적입니다.
하지만 문제의 제약 조건에서 배열 길이가 500 이하로 작게 주어졌기 때문에, 구현의 단순함과 추가 메모리 사용이 없는 $O(N^2)$ 풀이도 충분히 유효한 해결책입니다.
특히 `0`이 배열에 두 번 이상 존재하는 경우, `0 * 2 == 0`이 성립하므로 인덱스 중복 확인(`i != j`)이 반드시 필요합니다.
해시맵 접근법에서도 `seen` 집합에 추가하기 전에 조건을 먼저 확인함으로써 동일한 인덱스를 중복으로 사용하지 않도록 처리해야 합니다.
