## 문제

정수 배열 `nums`는 2n개의 정수 원소를 가진다. 이 원소들을 n개의 쌍 `(a1, b1), (a2, b2), ..., (an, bn)`으로 나누었을 때, 각 쌍의 최소값 `min(ai, bi)`들의 합을 최대화해야 한다. 주어진 예시 `[1, 4, 3, 2]`의 경우, (1, 2), (3, 4)로 쌍을 지으면 `min(1, 2) + min(3, 4)`의 합이 최대인 4가 된다. 제약 조건에 따라 n은 1부터 10^4까지이며, 각 원소의 값은 -10^4에서 10^4 사이이다.

## 접근 방법

최대한 큰 값을 최소값으로 포함시켜야 하므로, 큰 값은 가장 큰 값과 짝지어져 손실되는 것을 최소화해야 한다. 이를 위해 배열을 오름차순으로 정렬하면, 가장 큰 두 개의 수를 짝지어 최소값을 큰 값 중 하나로 만들 수 있고, 남은 수들 역시 동일하게 처리할 수 있다. 정렬된 배열에서 짝수 번째 인덱스(0, 2, 4...)에 있는 값들은 각각 바로 뒤의 홀수 인덱스 값보다 작거나 같으므로, 이 짝수 인덱스들의 합이 최대 최소값의 합이 된다.

## 풀이

먼저 배열을 정렬하고, 짝수 인덱스에 위치한 원소들을 합산한다.

```python
def arrayPairSum(nums):
    nums.sort()
    return sum(nums[::2])
```

시간 복잡도: `O(n log n)` (정렬에 소요되는 시간)
공간 복잡도: `O(1)` 또는 `O(n)` (정렬 알고리즘 구현에 따라 달라짐. Python의 Timsort는 `O(n)`)

## 다른 풀이 방법

값의 범위가 제한적이므로 카운팅 정렬을 사용하여 시간 복잡도를 줄일 수 있다. 값의 범위(-10^4 ~ 10^4)가 -10^4만큼 오프셋을 두어 20,001 크기의 빈도 배열을 생성하고 원소의 출현 횟수를 세었다. 빈도 배열을 순회하며 각 수의 출현 횟수를 처리할 때, 홀수 번째(0-based 기준으로 짝수 번째)로 등장하는 수들을 합산한다. 이는 정렬된 순서에서 짝수 인덱스에 해당하는 값들을 더하는 것과 같은 맥락이다.

```python
def arrayPairSum(nums):
    OFFSET = 10000
    freq = [0] * 20001
    for num in nums:
        freq[num + OFFSET] += 1
    
    total = 0
    is_skip = False
    for i in range(20001):
        count = freq[i]
        while count > 0:
            if not is_skip:
                total += i - OFFSET
                is_skip = True
            else:
                is_skip = False
            count -= 1
    return total
```

시간 복잡도: `O(n + K)` (n: 배열의 길이, K: 값의 범위인 20001)
공간 복잡도: `O(K)` (빈도 배열의 크기)

## 추가 참고사항

이 문제는 그리디 알고리즘의 전형적인 예시로, 정렬을 활용하는 것이 가장 직관적이고 일반적으로 널리 쓰이는 해법이다. 카운팅 정렬을 활용하면 값의 범위가 좁을 때 `O(n log n)`보다 빠른 `O(n)`에 해결할 수 있지만, 값의 범위가 넓어지면 공간 복잡도 및 상수 시간 요소가 커져 불리해진다.
