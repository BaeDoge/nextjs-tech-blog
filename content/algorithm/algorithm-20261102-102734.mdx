## 문제

주어진 '0'과 '1'로만 구성된 문자열 `s`를 비어 있지 않은 두 부분 문자열(왼쪽, 오른쪽)로 나누었을 때 얻을 수 있는 최대 점수를 구합니다. 점수는 왼쪽 부분 문자열에 포함된 '0'의 개수와 오른쪽 부분 문자열에 포함된 '1'의 개수를 합산한 값입니다.

문자열의 길이는 2 이상 500 이하이며, '0' 또는 '1'로만 구성됩니다. 예를 들어 `s = "011101"`인 경우, 왼쪽이 "0"이고 오른쪽이 "11101"일 때 점수는 1(왼쪽 '0') + 4(오른쪽 '1') = 5가 되어 최대값이 됩니다.

## 접근 방법

문자열을 모든 가능한 위치에서 나누어 점수를 계산하는 완전탐색이 가능합니다. 길이가 `n`인 문자열은 인덱스 1부터 `n-1`까지의 위치에서 나눌 수 있으며, 각 나누기마다 왼쪽과 오른쪽 부분의 '0'과 '1' 개수를 세어야 합니다.

각 위치마다 문자를 순회하면 시간 복잡도가 $O(N^2)$이 됩니다. 제약 조건에서 `s.length`가 500이므로 $O(N^2)$ 풀이도 통과 가능하지만, 더 효율적인 $O(N)$ 접근이 가능합니다.

먼저 전체 문자열에 포함된 '1'의 개수를 구해 둡니다. 이후 왼쪽부터 오른쪽으로 문자열을 슬라이딩하며, 현재 위치의 문자가 '0'이면 왼쪽 '0' 개수를, '1'이면 전체 '1' 개수(우측 '1' 개수 감소)를 업데이트하면서 각 위치에서의 점수를 계산합니다.

## 풀이

전체 '1'의 개수를 먼저 세고, 왼쪽 부분의 '0' 개수를 카운트하면서 우측 '1'의 개수를 전역에서 제외하여 점수를 계산합니다.

```python
def maxScore(s: str) -> int:
    # 전체 문자열에 포함된 '1'의 개수를 세어 우측 '1'의 초기값으로 설정
    total_ones = s.count('1')
    left_zeros = 0
    max_score = 0
    
    # 문자열을 나눌 수 있는 위치는 0번 인덱스부터 len(s)-2번 인덱스까지
    # 마지막 문자는 무조건 우측에 포함되므로 왼쪽 부분의 끝은 그 이전까지임
    for i in range(len(s) - 1):
        if s[i] == '0':
            left_zeros += 1
        else:
            # 현재 위치가 '1'이면 우측에 속하는 '1'의 수에서 하나 감소
            total_ones -= 1
            
        # 현재 위치에서 왼쪽 '0' 개수 + 오른쪽 '1' 개수 계산
        current_score = left_zeros + total_ones
        if current_score > max_score:
            max_score = current_score
            
    return max_score
```

시간 복잡도: $O(N)$ - 문자열을 두 번 순회합니다(전체 카운트 1회, 슬라이딩 1회).
공간 복잡도: $O(1)$ - 정수 변수들만 사용합니다.

## 다른 풀이 방법

접근 방식은 동일하나 구현 단에서 Prefix Sum(누적 합) 개념을 명시적으로 활용할 수 있습니다.

1. `left_ones[i]`: `s[0]`부터 `s[i]`까지의 '1' 개수를 저장한 배열을 미리 계산합니다.
2. 전체 '1' 개수 `total_ones`를 구합니다.
3. 각 분할 위치 `i`에서 왼쪽 '1'의 개수는 `left_ones[i]`, 오른쪽 '1'의 개수는 `total_ones - left_ones[i]`입니다.
4. 왼쪽 부분의 길이는 `i + 1`이므로, 왼쪽 '0'의 개수는 `(i + 1) - left_ones[i]`로 유도됩니다.
5. 점수 = `((i + 1) - left_ones[i]) + (total_ones - left_ones[i])` 공식을 사용하여 계산합니다.

이 방법 역시 시간 복잡도 $O(N)$, 공간 복잡도 $O(N)$을 가집니다. 슬라이딩 윈도우 방식($O(1)$ 공간)보다 메모리를 더 사용하지만, 배열을 한 번 만들어두고 수식으로 계산하는 코드의 가독성이 높을 수 있습니다.

## 추가 참고사항

이 문제는 Prefix Sum과 Sliding Window 기법의 기본 응용 사례입니다.
문자열을 한 번 더 나누지 않고, 현재 위치 기준 왼쪽과 오른쪽 정보를 상수 시간에 유지하면서 업데이트하는 것이 핵심입니다.
제약 조건에서 문자열 길이가 500으로 작으므로 $O(N^2)$ 코드도 통과하지만, 확장성을 고려하면 $O(N)$ 알고리즘을 숙지하는 것이 좋습니다.
Python의 `count()` 메소드를 사용하면 '1'의 개수를 한 번에 계산하여 코드를 간결하게 작성할 수 있습니다.
