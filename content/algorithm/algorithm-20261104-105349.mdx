## 문제

대학 입시 사무실에서 지원자들의 시험 점수를 실시간으로 관리해야 합니다. 점수 스트림이 주어지고, 새로운 점수가 추가될 때마다 현재까지의 점수들 중 k번째로 큰 값을 반환하는 클래스를 구현해야 합니다. 초기화 시 정수 k와 초기 점수 배열 `nums`를 받으며, `add` 메서드를 통해 새로운 점수를 추가하고 현재 k번째 큰 값을 반환합니다. k번째로 큰 값은 모든 점수를 내림차순으로 정렬했을 때 k번째 위치에 있는 값입니다. 예시 1에서 k가 3이고 초기 점수가 [4, 5, 8, 2]일 때, 내림차순 정렬하면 [8, 5, 4, 2]이며 3번째로 큰 값은 4입니다. 새로운 값 3이 추가되어 현재 점수가 [4, 5, 8, 2, 3]이 되면 정렬된 수는 [8, 5, 4, 3, 2]이며, 3번째로 큰 값은 여전히 4입니다.

## 접근 방법

모든 점수를 유지하며 매번 정렬하는 것은 `add` 연산마다 `O(N log N)`의 시간이 소요되어 비효율적입니다. 대신, k개의 가장 큰 값만을 추적하면 k번째로 큰 값은 이 k개 값 중 가장 작은 값(최소값)이 됩니다. 최소 힙(Min-Heap)을 사용하여 현재까지의 점수 중 가장 작은 값들을 제거하는 방식으로 k개의 값을 유지하면, `add` 연산 시 새로운 값을 힙에 삽입하고 힙의 크기가 k를 초과하면 루트(가장 작은 값)를 제거함으로써 k번째 큰 값을 빠르게 확인할 수 있습니다.

## 풀이

Python의 `heapq` 라이브러리를 사용하여 최소 힙을 구현합니다. 초기화 과정에서 초기 점수들을 힙에 삽입한 후, 힙의 크기가 k를 초과하면 가장 작은 값을 pop하여 k개의 값만 유지합니다. `heapq.heapify`를 사용하여 초기 배열을 O(N) 시간에 힙으로 변환할 수 있습니다. `add` 메서드에서는 새 값을 힙에 삽입한 후, 크기가 k를 초과하면 가장 작은 값을 제거합니다. 최종적으로 힙의 루트 값이 k번째로 큰 값이므로 이를 반환합니다.

```python
import heapq
from typing import List

class KthLargest:

    def __init__(self, k: int, nums: List[int]):
        self.k = k
        self.min_heap = nums
        # O(N) 시간에 힙 구성
        heapq.heapify(self.min_heap)
        # k보다 큰 경우 불필요한 작은 값 제거 (총 O((N-K) log K))
        while len(self.min_heap) > k:
            heapq.heappop(self.min_heap)

    def add(self, val: int) -> int:
        # O(log K) 시간의 삽입
        heapq.heappush(self.min_heap, val)
        # 힙 크기가 k를 초과하면 가장 작은 값 제거
        if len(self.min_heap) > self.k:
            heapq.heappop(self.min_heap)
        return self.min_heap[0]
```

시간복잡도: 초기화 시 `heapify`를 사용하여 `O(N)`에 수행되며, 이후 k개를 초과하는 요소를 제거하는 데 `O((N-K) log K)`가 추가로 소요됩니다. `add` 연산당 `O(log K)`의 시간이 소요됩니다. 공간복잡도: `O(K)`로 힙의 크기를 k로 제한합니다.

## 다른 풀이 방법

배열을 정렬된 상태로 유지하며 이진 탐색을 사용하여 새 값을 삽입하는 방법입니다. 이진 탐색으로 삽입 위치를 찾는 데 `O(log K)`가 소요되지만, 배열의 중간에 요소가 삽입되면 나머지 요소들을 이동시켜야 하므로 평균적으로 `O(K)`의 시간이 소요됩니다. 삽입 후 k번째 큰 값은 인덱스 `len(arr) - k`에 위치합니다. 균형 이진 탐색 트리를 직접 구현하여 k번째 큰 값을 찾는 방법도 있으나, 구현 복잡도가 높아 일반적이지 않습니다.

## 추가 참고사항

이 문제는 '데이터 스트림'에서 k번째 순위를 실시간으로 구하는 전형적인 패턴입니다. k번째 작은 값을 구해야 한다면 최대 힙(Max-Heap)을 사용하거나, 최소 힙의 크기를 N-k로 유지하는 방식으로 변형할 수 있습니다. 힙의 크기를 k로 유지함으로써 메모리 사용을 최소화하면서 빠른 연산을 보장하는 것이 핵심입니다. 제약 조건에서 `add` 호출 횟수가 최대 10^4이고, k와 초기 배열 길이가 10^4 이내이므로, 힙 기반 접근법은 충분한 성능을 발휘합니다.
