## 문제

두 정수 배열 `nums`와 `index`가 주어지면, 처음에는 빈 `target` 배열을 만든 뒤 `nums[i]`를 `index[i]` 위치에 삽입한다. 모든 원소를 처리한 후 반환할 `target` 배열의 최종 상태를 구하는 것이 목표다. Constraints에 따라 배열의 길이는 1 이상 100 이하이며, `index[i]`는 항상 `i` 이하의 값을 가짐으로써 유효한 삽입이 보장된다. Example 1에서 `nums=[0,1,2,3,4]`, `index=[0,1,2,2,1]`을 입력하면 output `[0,4,1,3,2]`이 도출된다.

## 접근 방법

주어진 순서대로 `nums`와 `index`를 순회하며, `Python`의 `list.insert()` 메서드를 사용해 `target` 배열에 요소를 삽입하는 직접 시뮬레이션 접근이다. 배열의 최대 길이가 100이므로 삽입 연산의 비용이 크지 않아 이 방식이 충분히 효율적이다. 이 방법은 문제의 규칙을 그대로 구현하는 가장 직관적인 방법이다.

## 풀이

파이썬 `list.insert`를 활용한 직접 구현이다. 각 단계에서 인덱스에 값을 삽입해 `target` 배열을 완성한다.

```python
def create_target_array(nums, index):
    target = []
    for i in range(len(nums)):
        target.insert(index[i], nums[i])
    return target
```

시간 복잡도는 삽입 연산에 따라 최악의 경우 O(n²), 공간 복잡도는 `target` 배열을 위해 O(n)이다.

## 다른 풀이 방법

배열의 크기가 100 이하로 작아 직접 삽입하는 시뮬이 가장 간단하고 빠른 구현이다. 다른 자료구조로 최적화해도 교환 비용이 커서 실제 코딩테스트에서는 이 방식을 선호한다.

## 추가 참고사항

`index[i] <= i`라는 제약조건에 의해 언제나 유효한 위치에 삽입할 수 있다. 제공된 예제와 동일한 로직으로 테스트할 수 있다.
