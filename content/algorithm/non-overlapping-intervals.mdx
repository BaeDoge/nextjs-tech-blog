## 문제

주어진 `intervals` 배열은 각 구간의 시작과 끝 좌표를 나타냅니다. 이 구간들 중 일부를 제거하여 남은 구간들이 서로 겹치지 않도록 만들고자 합니다. 이때 제거해야 하는 구간의 최소 개수를 반환해야 합니다.

두 구간이 단 하나의 점(경계)에서만 접하는 경우에는 겹치지 않는 것으로 간주합니다. 예를 들어 `[1, 2]`와 `[2, 3]`은 겹치지 않습니다. 입력된 구간의 길이는 최대 $10^5$이며, 좌표 범위는 $-5 \times 10^4$에서 $5 \times 10^4$ 사이입니다.

## 접근 방법

이 문제는 **그리디(Greedy) 알고리즘**을 사용하여 해결할 수 있습니다. 겹치는 구간 중 하나를 제거할 때, 미래에 발생할 수 있는 다른 구간들과의 충돌을 최소화하는 전략이 필요합니다.

구간이 끝나는 시점(`end`)이 빠른 순서로 정렬하면, 해당 구간을 유지할 때 다음 구간에 허용되는 공간이 가장 커집니다. 즉, 끝나는 시점이 빠른 구간을 우선으로 선택하면 더 많은 구간을 겹치지 않도록 담을 수 있습니다.

알고리즘의 핵심 단계는 다음과 같습니다.
1. 구간의 끝 좌표를 기준으로 오름차순 정렬합니다.
2. 첫 번째 구간을 무조건 선택합니다(이 구간이 가장 일찍 끝나므로 최적의 선택입니다).
3. 두 번째 구간부터 순회하며, 현재 선택된 구간의 끝 좌표보다 시작 좌표가 크거나 같은지 확인합니다.
   - 크거나 같다면 겹치지 않으므로 선택된 구간으로 업데이트합니다.
   - 작다면 겹치므로, 이 구간은 제거 대상이 됩니다(카운트 증가).

이 방식으로 전체 구간을 스캔하면 제거해야 하는 최소 구간 수를 구할 수 있습니다.

## 풀이

구간의 끝값을 기준으로 정렬한 후, 이전 선택 구간의 끝값과 비교하여 겹치는지 확인합니다. 겹치는 경우 현재 구간의 끝값이 이미 이전 구간보다 작거나 같으므로(오름차순 정렬), 이전 구간을 유지하는 것이 유리합니다. 따라서 `prev_end`는 갱신하지 않고 제거 카운트만 증가시킵니다.

```python
class Solution:
    def eraseOverlapIntervals(self, intervals: List[List[int]]) -> int:
        if not intervals:
            return 0
        
        # 끝값(end) 기준 오름차순 정렬
        # 정렬 시 안정 정렬이 보장되며, 기준 키가 같으면 원래 순서 유지
        intervals.sort(key=lambda x: x[1])
        
        # 첫 번째 구간은 무조건 유지 (가장 일찍 끝나므로)
        prev_end = intervals[0][1]
        remove_count = 0
        
        # 두 번째 구간부터 순회
        for i in range(1, len(intervals)):
            curr_start = intervals[i][0]
            
            # 현재 구간의 시작점이 이전 선택 구간의 끝점보다 작으면 겹침
            if curr_start < prev_end:
                # 겹치므로 현재 구간을 제거합니다.
                # 그리디 전략에 따라 끝나는 시점이 빠른 '이전 구간'을 유지하는 것이 이득이므로,
                # prev_end는 변경하지 않고 다음 구간을 확인합니다.
                remove_count += 1
            else:
                # 겹치지 않으므로 현재 구간을 선택합니다.
                prev_end = curr_start
                
        return remove_count
```

시간복잡도: $O(N \log N)$ (정렬 과정). 구간 탐색은 $O(N)$입니다.
공간복잡도: $O(N)$ (Python의 TimSort는 $O(N)$ 공간이 필요함).

## 다른 풀이 방법

**DP 기반 접근**
구간의 시작값 기준으로 정렬하고, 동적 계획법(DP)을 사용하여 '겹치지 않게 선택할 수 있는 최대 구간 수'를 구한 후, 전체 구간 수에서 이를 빼는 방법도 있습니다.
1. 끝값 기준으로 정렬한 후, 각 구간 $i$에 대해 그 구간과 겹치지 않고 직전에 선택된 마지막 구간의 끝값을 이분탐색 등으로 찾아 최대 개수를 업데이트합니다.
2. 최종적으로 `전체 구간 수 - 선택된 최대 구간 수`를 계산합니다.
시간복잡도: $O(N \log N)$입니다. 그리디 방식보다 구현이 복잡하며, 일반적으로 그리디 방식이 더 간결하고 효율적입니다.

## 추가 참고사항

- **경계 조건 처리**: 문제에서 `[1, 2]`와 `[2, 3]`은 겹치지 않는다고 명시했습니다. 따라서 코드에서 겹침 조건을 `curr_start < prev_end`로 설정해야 합니다. 만약 `<=`를 사용하면 경계점에서의 접촉도 제거 대상으로 간주하여 오답이 됩니다.
- **정렬 키**: 끝값(`x[1]`) 기준 정렬이 핵심입니다. 시작값(`x[0]`) 기준으로 정렬하면, 같은 시작점을 가진 구간 중 끝값이 작은(짧은) 구간을 먼저 처리해야 하므로 추가적인 처리가 필요해집니다.
- **예외 처리**: 입력 배열이 빈 경우나 구간이 1개인 경우, 제거해야 할 구간은 0개이므로 0을 반환해야 합니다.
