## 문제

문자열 `s`가 주어질 때, 다음 규칙에 따라 문자열을 변환하여 반환해야 합니다.

- 모든 비(非)영어 문자는 원래 위치를 유지해야 합니다.
- 영어 문자(대소문자 모두 포함)는 역순으로 배치해야 합니다.

예를 들어 입력 `s = "ab-cd"`의 경우, 영문자 `a, b, c, d`만 추출하여 역순으로 정렬한 `d, c, b, a`를 다시 비영문자 `-`가 있는 위치(`-` 앞 2글자, `d c - b a`)에 배치하면 `"dc-ba"`가 됩니다.

## 접근 방법

문자열 양쪽 끝에서부터 시작하여 서로 마주칠 때까지 탐색하는 '두 포인터(Two Pointers)' 기법을 적용할 수 있습니다.

- `left` 포인터는 문자열의 시작 인덱스(0)에서 우측으로 이동합니다.
- `right` 포인터는 문자열의 끝 인덱스에서 좌측으로 이동합니다.
- `left`가 가리키는 문자가 영문자가 아니면 `left`를 증가시키고, `right`가 가리키는 문자가 영문자가 아니면 `right`를 감소시킵니다.
- 두 포인터가 모두 영문자를 가리키고 있다면 해당 문자들을 서로 교환한 후 `left`는 증가, `right`는 감소시켜 다음 탐색을 진행합니다.

이 방법은 한 번의 순회(One-pass)로 조건을 만족하는 문자열을 완성할 수 있습니다.

## 풀이

문자열을 효율적으로 조작하기 위해 파이썬의 리스트를 활용하거나, 자바의 `StringBuilder`, 자바스크립트의 배열 등을 사용합니다. 각 언어별로 구현 시 문자가 영문자인지 판별하는 로직이 핵심입니다.

```python
class Solution:
    def reverseOnlyLetters(self, s: str) -> str:
        s_list = list(s)
        left, right = 0, len(s) - 1
        
        while left < right:
            if not s_list[left].isalpha():
                left += 1
            elif not s_list[right].isalpha():
                right -= 1
            else:
                s_list[left], s_list[right] = s_list[right], s_list[left]
                left += 1
                right -= 1
                
        return ''.join(s_list)
```

- 시간 복잡도: O(N)
  - 문자열의 길이 N에 비례하여 양쪽 끝에서 한 번씩 순회합니다.
- 공간 복잡도: O(N)
  - 문자열을 리스트로 변환하여 저장하거나 결과 문자열을 생성하는 데 N 크기의 공간이 소요됩니다. (불변 문자열인 경우)

## 다른 풀이 방법

영문자만 추출하여 역순으로 만든 후, 다시 원래 문자열의 구조(영문자 위치와 비영문자 위치)를 복원하는 방법도 있습니다.

1. `s`에서 영문자만 필터링하여 별도 리스트 `letters`에 저장합니다.
2. `letters`를 역순으로 정렬합니다.
3. 원래 문자열 `s`의 인덱스를 0부터 순회하며, 해당 위치의 문자가 영문자라면 `letters`의 다음 요소로 치환합니다. 비영문자라면 기존 문자를 그대로 유지합니다.

이 방법은 두 번의 순회가 발생하므로 상수 시간 차이는 있으나 점근적 복잡도는 O(N)으로 동일합니다. 단, 영문자 추출 과정과 치환 과정에서 추가적인 리스트 생성이 일어나므로 실제 실행 시간과 공간 사용량은 두 포인터 방식보다 다소 불리할 수 있습니다.

## 추가 참고사항

문자열 조작 문제에서는 불변성(Immutability)에 주의해야 합니다. 파이썬의 `str`은 변경이 불가능하므로, 문자 교환을 위해서는 반드시 리스트나 다른 가변 자료구조로 변환해야 합니다. 자바의 경우 `char[]` 배열을 사용하거나 `StringBuilder`를 활용하면 효율적으로 수정할 수 있습니다. 영문 판별은 `isalpha()`와 같은 내장 함수를 사용하면 ASCII 범위를 직접 계산(`'a' <= char <= 'z'` 등)하는 것보다 가독성이 좋고 간결합니다.
