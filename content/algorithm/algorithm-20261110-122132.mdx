## 문제

정수 배열 `nums`가 주어졌을 때, 가장 긴 연속 증가 부분 수열(Continuous Increasing Subsequence)의 길이를반환해야 합니다. 연속 증가 부분 수열은 인접한 원소들로 이루어진 부분 수열이며, 이 원소들은 인덱스가 연속적으로 이어져야 합니다. 또한 수열은 엄격하게 증가해야 하므로, 이웃한 두 원소 사이에 `nums[i] < nums[i + 1]` 관계가 성립해야 합니다. 일반적인 증가 부분 수열과는 달리, 원소의 인덱스가 연속하지 않아도 되는 비연속적인 부분 수열은 허용되지 않습니다.

배열의 길이는 최대 $10^4$이며, 원소의 값은 $-10^9$에서 $10^9$ 사이입니다. 예를 들어 `[1,3,5,4,7]`의 경우 `[1,3,5]`가 최대 길이를 가지며, `[2,2,2,2,2]`와 같이 모든 원소가 같거나 감소하는 경우 길이는 1이 됩니다.

## 접근 방법

이 문제는 배열을 한 번 순회하며 현재 연속 증가하는 수열의 길이를 추적하면 해결할 수 있습니다. 배열의 각 원소를 이전 원소와 비교하여 증가하는지 확인합니다. 만약 현재 원소가 이전 원소보다 크다면, 현재 진행 중인 연속 증가 수열의 길이를 1 증가시킵니다. 있지 않다면(같거나 작다면), 현재 수열이 끊어지므로 새로운 수열의 시작점으로 간주하여 길이를 1로 초기화합니다.

전체 과정을 거치면서 기록된 최대 길이를 업데이트하면 최종 답을 얻을 수 있습니다. 이 방식은 불필요한 자료 구조나 복잡한 계산을 배제하고, 배열의 각 요소를 상수 시간 내에 처리하므로 효율적입니다.

## 풀이

배열의 길이가 0인 경우는 제약 조건상 발생하지 않지만, 안전을 위해 기본값 1을 설정하고 루프를 돌립니다. `current_length` 변수로 현재 연속 증가 수열의 길이를, `max_length` 변수로 전체 최대 길이를 관리합니다.

```python
class Solution:
    def findLengthOfLCIS(self, nums: list[int]) -> int:
        if not nums:
            return 0
        
        max_length = 1
        current_length = 1
        
        for i in range(1, len(nums)):
            if nums[i] > nums[i - 1]:
                current_length += 1
                if current_length > max_length:
                    max_length = current_length
            else:
                current_length = 1
                
        return max_length
```

시간복잡도: O(N) (배열을 한 번 순회)
공간복잡도: O(1) (상수 개의 변수만 사용)

## 다른 풀이 방법

이 문제는 그리디(Greedy) 접근이 가장 자연스럽습니다. 동적 계획법(Dynamic Programming)을 적용할 수도 있습니다. `dp[i]`를 `nums[i]`로 끝나는 가장 긴 연속 증가 부분 수열의 길이라고 정의하면, `nums[i] > nums[i-1]`일 때 `dp[i] = dp[i-1] + 1`, 그렇지 않을 때 `dp[i] = 1`이 됩니다. 최종 답은 `dp` 배열의 최대값입니다.

## 추가 참고사항

<Callout type="tip" title="핵심 주의사항">
연속 증가 부분 수열(Continuous)과 일반적인 증가 부분 수열(Increasing Subsequence, LeetCode 300)을 혼동하지 않아야 합니다. 연속성은 인덱스가 이어져야 한다는 조건이며, 일반적인 증가 부분 수열은 인덱스가 비연속이어도 됩니다.

문제를 명확히 이해하기 위해 다음 두 가지 케이스를 구분해야 합니다.
1. 엄격한 증가: `nums[i] < nums[i+1]`이어야 함. 같은 값이 나오면 연속성이 끊어집니다.
2. 비감소 증가: `nums[i] <= nums[i+1]`인 경우를 허용하는 문제라면 조건식을 변경하면 되지만, 이 문제는 엄격한 증가를 요구합니다.
