## 문제

알리스는 `n`개의 과자를 가지고 있습니다. 각 과자는 `candyType` 배열의 정수 값으로 표현됩니다. 의사는 과자 `n/2`개까지만 먹으라고 조언합니다. `n`은 항상 짝수입니다. 알리스는 의사의 조언을 지키면서 최대한 많은 종류의 과자를 먹으려 합니다. `candyType` 배열이 주어졌을 때, 알리스가 먹을 수 있는 과자의 최대 종류 수를 반환해야 합니다.

- 입력: 정수 배열 `candyType`
- 출력: 정수 (먹을 수 있는 과자의 최대 종류 수)

## 접근 방법

알리스가 먹을 수 있는 과자의 최대 종류 수는 두 가지 제한 조건에 의해 결정됩니다.
첫째, 알리스는 전체 과자의 절반인 `n/2`개까지만 먹을 수 있습니다.
둘째, 알리스가 먹을 수 있는 과자의 종류 수는 실제로 존재하는 서로 다른 과자의 종류 수를 초과할 수 없습니다.
따라서 두 제한 조건 중 더 작은 값이 정답이 됩니다. 서로 다른 과자의 종류 수를 효율적으로 세기 위해 자료 구조를 활용할 수 있습니다.

## 풀이

과자의 종류를 중복 없이 세기 위해 집합(Set) 자료 구조를 사용합니다. Python의 `set`은 중복을 자동으로 제거하므로, 입력 배열을 집합으로 변환하면 서로 다른 과자의 종류 수를 얻을 수 있습니다.
구현한 함수의 이름은 `distributeCandies`로 합니다.
시간 복잡도는 입력 배열의 크기 `n`에 비례하므로 `O(n)`입니다. 공간 복잡도는 서로 다른 과자의 종류 수만큼 저장해야 하므로 `O(n)`입니다.

```python
def distributeCandies(candyType: list[int]) -> int:
    # 서로 다른 과자의 종류 수를 집합을 이용하여 계산
    unique_candy_types = len(set(candyType))
    
    # 의사가 허용하는 최대 개수 (전체 과자의 절반)
    max_eat_count = len(candyType) // 2
    
    # 허용 개수와 실제 가능한 종류의 수 중 작은 값이 정답
    return min(unique_candy_types, max_eat_count)
```

## 다른 풀이 방법

해시맵(딕셔너리)을 사용하여 각 과자 유형의 등장 횟수를 세는 방법도 있습니다.
과자 유형을 키로, 등장 횟수를 값으로 저장한 후, 키의 개수(유니크한 유형 수)를 세면 동일한 결과를 얻을 수 있습니다.
이 방법도 시간 복잡도 `O(n)`과 공간 복잡도 `O(n)`을 가집니다.
해시셋을 사용하는 것이 코드 구현 측면에서 더 간결하므로 일반적으로 더 선호됩니다.

## 추가 참고사항

- 해시셋은 중복 제거에 특화된 자료 구조로, 이 문제와 같이 유니크한 요소의 개수를 세는 작업에 적합합니다.
- 배열의 크기가 `10^4`로 제한되어 있으므로 `O(n)` 알고리즘은 충분히 빠르게 동작합니다.
- 과자 유형의 값 범위 `[-10^5, 10^5]`가 음수를 포함하므로, 정렬 기반 접근 시 주의가 필요할 수 있으나 해시셋은 부호 상관없이 동작합니다.
