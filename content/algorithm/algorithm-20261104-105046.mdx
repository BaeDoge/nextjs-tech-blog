## 문제

정수 배열 `nums`가 주어졌을 때, 이 배열에서 추출할 수 있는 서로 다른 '비감소(non-decreasing)' 부분수열을 모두 반환합니다. 이때 부분수열의 길이는 2 이상이어야 하며, 반환 순서는 상관없습니다.

제한 사항은 다음과 같습니다.
- 배열의 길이는 1 이상 15 이하로 매우 작습니다.
- 요소의 값은 -100 이상 100 이하입니다.

예를 들어 `nums = [4, 6, 7, 7]`인 경우, `[4, 6], [4, 6, 7], [7, 7]` 등이 정답에 포함됩니다. 단, 중복되는 값(인덱스는 달라도 값이 같아 같은 수열이 되는 경우)은 한 번만 포함됩니다.

## 접근 방법

이 문제는 배열의 각 원소를 '선택'하거나 '선택하지 않음'으로 나누어 가능한 모든 부분수열을 생성해야 합니다. 이를 위해 백트래킹(재귀) 기법을 사용합니다.

핵심 로직은 다음과 같습니다.
1. 현재까지 만들어진 수열 `path`의 마지막 원소보다 현재 고려하는 원소 `nums[i]`가 크거나 같아야 비감소 조건을 만족하므로, 이를 만족할 때만 재귀 호출을 진행합니다.
2. 중복 수열을 피하기 위해, 같은 재귀 깊이(동일한 단계)에서 동일한 값을 여러 번 사용하지 않도록 주의해야 합니다. 이를 위해 각 단계에서 사용된 숫자를 `HashSet`으로 추적하면 됩니다.
3. `path`의 길이가 2 이상이 되었을 때 결과 리스트에 추가합니다.
4. 제한 사항의 배열 길이가 최대 15이므로 $O(2^N)$ 수준의 완전탐색이라도 충분히 수행 가능합니다.

## 풀이

백트래킹 함수 `dfs`를 정의하여 재귀적으로 해를 찾습니다. `startIndex`는 다음에 고려할 배열의 인덱스를 의미합니다.

```python
class Solution:
    def findSubsequences(self, nums: List[int]) -> List[List[int]]:
        result = []
        
        def dfs(start_index: int, path: List[int]):
            # path의 길이가 2 이상이 되면 유효한 수열이므로 결과에 추가
            if len(path) >= 2:
                result.append(path.copy())
            
            # 중복 방지를 위한 집합: 같은 단계에서 같은 값은 한 번만 사용
            used_in_this_level = set()
            
            for i in range(start_index, len(nums)):
                # 비감소 조건: 현재 원소가 이전 마지막 원소보다 크거나 같아야 함
                if path and nums[i] < path[-1]:
                    continue
                
                # 이미 이 단계에서 같은 값을 사용했다면 스킵
                if nums[i] in used_in_this_level:
                    continue
                
                # 선택
                path.append(nums[i])
                used_in_this_level.add(nums[i])
                
                # 재귀
                dfs(i + 1, path)
                
                # 백트래킹
                path.pop()
                
        dfs(0, [])
        return result
```

- **시간복잡도**: $O(N \cdot 2^N)$. 부분수열의 수가 최대 $2^N$개이며, 각각의 수열을 복사하는 데 $O(N)$의 시간이 걸립니다.
- **공간복잡도**: $O(N)$. 재귀 호출 스택과 `path` 배열의 최대 깊이가 $N$입니다.

## 다른 풀이 방법

**Bit Manipulation (비트 매니퓰레이션)**

`nums`의 길이가 최대 15이므로, 모든 부분집합을 비트 마스크로 표현할 수 있습니다. $0$부터 $2^N - 1$까지의 모든 수에 대해 비트가 설정된 인덱스들의 값을 추출하여 비감소 조건을 확인합니다.

1. $i$를 $1$부터 $2^N - 1$까지 반복합니다.
2. $i$의 각 비트가 1인 인덱스들을 추출해 수열을 만듭니다.
3. 해당 수열이 비감소인지 확인합니다.
4. 생성된 수열을 `Set`에 담아 중복을 제거한 후, 크기가 2 이상인 것만 리스트로 반환합니다.

이 방식은 중복 제거 로직을 `Set`에 맡길 수 있어 코드가 단순해질 수 있으나, 부분수열 생성 후 조건 확인 및 집합 연산 overhead로 인해 백트래킹 방식보다 실제 실행 시간이 느릴 수 있습니다.

## 추가 참고사항

- **중복 처리 전략**: 백트래킹에서 중복을 처리하는 방법은 두 가지가 대표적입니다.
  1. **집합 활용 (이 문제 방식)**: 현재 재귀 깊이에서 사용된 숫자를 Set으로 추적하여, 같은 단계에서 같은 숫자를 다시 선택하지 못하게 막습니다. 이는 정렬되지 않은 배열에서도 자연스럽게 동작합니다.
  2. **정렬 + 인덱스 추적**: 배열을 정렬한 후, 이전 단계의 인덱스보다 큰 인덱스만 선택하되, `if i > start_index and nums[i] == nums[i-1]: continue`와 같은 조건으로 같은 값을 가진 원소들을 스킵합니다. 이 방법은 순열(Permutation) 문제나 중복이 있는 배열에서의 부분수열 문제에서 흔히 쓰입니다.
- **비감소 조건**: "비감소(non-decreasing)"는 $a_{i} \le a_{i+1}$를 의미하며, 등호가 포함되어 있음에 유의합니다. 이는 "증가(increasing)" $a_{i} < a_{i+1}$와 구별됩니다.
