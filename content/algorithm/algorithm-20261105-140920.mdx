## 문제

친구가 키보드로 이름을 입력할 때, 문자 키를 길게 누르면 해당 문자가 여러 번 입력될 수 있습니다. 주어진 입력 문자열 `typed`가 친구의 이름 `name`과 일치할 수 있는지 확인해야 합니다. `name`의 각 문자는 `typed`에 적어도 한 번 이상 나타나며, 같은 문자가 연속해서 입력된 경우 `typed`의 개수가 `name`의 개수보다 많거나 같아야 합니다. 이 조건을 만족하면 `true`를, 아니면 `false`를 반환해야 합니다.

## 접근 방법

두 포인터를 사용하여 `name`과 `typed`를 동시에 순회합니다. `name`의 포인터 `i`, `typed`의 포인터 `j`를 0으로 초기화합니다. `typed`를 순회하면서 현재 문자가 `name`의 현재 문자와 같으면 두 포인터를 모두 전진시킵니다. 다르다면 `typed`의 현재 문자가 직전 문자와 같은지(긴 누름) 확인하여 맞으면 `j`만 전진시키고, 아니면 `false`를 반환합니다. `typed` 순회가 끝나면 `name`도 모두 소모되었는지(`i == len(name)`) 확인하여 결과를 결정합니다.

## 풀이

다음은 Python으로 구현한 올바른 두 포인터 코드입니다.

```python
def isLongPressedName(name: str, typed: str) -> bool:
    i, j = 0, 0
    while j < len(typed):
        if i < len(name) and name[i] == typed[j]:
            i += 1
            j += 1
        elif j > 0 and typed[j] == typed[j - 1]:
            j += 1
        else:
            return False
    return i == len(name)
```

이 알고리즘의 시간 복잡도는 O(n + m)이며, 여기서 n은 `name`의 길이, m은 `typed`의 길이입니다. 공간 복잡도는 O(1)입니다.

## 다른 풀이 방법

그룹 단위로 문자를 압축하여 비교하는 방법이 있습니다. `name`과 `typed`를 각각 연속된 문자 그룹(문자, 개수)의 리스트로 변환한 후, 그룹의 개수가 같고 각 그룹의 문자가 일치하며 `typed`의 개수가 `name`의 개수보다 크거나 같은지 확인합니다. 이 방법 역시 O(n + m) 시간과 O(1) 추가 공간(그룹 저장을 제외)을 사용하지만, 구현이 다소 길어질 수 있습니다. 해시 맵을 사용해 각 문자의 총 출현 횟수를 세는 방법은 순서 정보를 잃어버려 이 문제에 부적합합니다.

## 추가 참고사항

제약 조건에 따라 `name`과 `typed`는 소문자 영어 문자로만 이루어져 있고, 길이는 1 이상 1000 이하입니다. 긴 누름은 최소 한 번 이상 입력된 경우를 허용하므로, `typed`에 `name`의 문자가 완전히 누락된 경우 `false`가 됩니다. 예를 들어 `name='saeed'`, `typed='ssaaedd'`는 'e'가 두 번 눌려야 하지만 `typed`에 충분한 개수가 없어 `false`입니다. 두 포인터 알고리즘은 각 문자를 한 번씩만 방문하므로 최적의 시간 복잡도를 달성합니다.
