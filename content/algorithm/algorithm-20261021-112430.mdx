## 문제

문자열 `s`가 주어졌을 때, 최대 한 문자를 삭제하여 팰린드롬이 될 수 있는지 확인하는 문제입니다. 팰린드롬은 앞뒤로 읽었을 때 동일한 문자열을 의미합니다.
예를 들어, `"aba"`는 이미 팰린드롬이므로 `true`를 반환합니다. `"abca"`의 경우 `'c'`를 삭제하면 `"aba"`가 되어 팰린드롬이 되므로 `true`를 반환합니다. 반면 `"abc"`는 어떤 한 문자를 삭제해도 팰린드롬이 될 수 없으므로 `false`를 반환합니다.
문자열의 길이는 1 이상 10^5 이하이며, 소문자 영어 알파벳으로만 구성됩니다.

## 접근 방법

문자열의 양쪽 끝에서부터 중앙으로 향해 두 포인터(`left`, `right`)를 사용하여 대칭 여부를 확인합니다.
`left`는 0부터 시작하고, `right`는 `s.length - 1`부터 시작합니다.
두 포인터가 가리키는 문자가 서로 다르면, 팰린드롬 조건을 만족시키기 위해 `left` 또는 `right` 중 하나의 문자를 삭제해야 합니다.
이때 삭제할 문자의 선택은 `left + 1`부터 `right`까지의 부분 문자열과 `left`부터 `right - 1`까지의 부분 문자열이 각각 팰린드롬인지 확인함으로써 결정할 수 있습니다.
두 부분 문자열 중 하나라도 팰린드롬이면 `true`를 반환하고, 둘 다 아니면 `false`를 반환합니다.
만약 두 포인터가 만나기 전까지 모든 문자가 대칭이면, 이미 팰린드롬이므로 `true`를 반환합니다.

## 풀이

두 포인터를 사용하여 대칭을 검증하는 헬퍼 함수를 작성하고, 불일치가 발생했을 때 두 가지 경우(왼쪽 삭제, 오른쪽 삭제)를 재귀 또는 반복적으로 확인합니다.

```java
class Solution {
    public boolean validPalindrome(String s) {
        int left = 0;
        int right = s.length() - 1;
        
        while (left < right) {
            if (s.charAt(left) != s.charAt(right)) {
                // 왼쪽 문자 삭제 또는 오른쪽 문자 삭제 후 팰린드롬 확인
                return isPalindrome(s, left + 1, right) || isPalindrome(s, left, right - 1);
            }
            left++;
            right--;
        }
        return true;
    }
    
    private boolean isPalindrome(String s, int left, int right) {
        while (left < right) {
            if (s.charAt(left) != s.charAt(right)) {
                return false;
            }
            left++;
            right--;
        }
        return true;
    }
}
```

시간복잡도: O(N). 각 문자는 최대 두 번 비교됩니다.
공간복잡도: O(1). 추가적인 공간 사용을 하지 않습니다.

## 다른 풀이 방법

완전탐색(Brute Force)을 통해 모든 위치의 문자를 하나씩 삭제한 후 팰린드롬인지 확인하는 방법이 있습니다.
문자열의 길이가 N일 때, N개의 위치 중 하나를 삭제하므로 N번의 검증이 필요합니다.
각 검증에는 O(N)의 시간이 걸리므로 전체 시간복잡도는 O(N^2)이 됩니다.
제약 조건에서 N이 10^5까지 가능하므로 O(N^2) 접근은 시간 초과(TLE)가 발생할 수 있어 비효율적입니다.
따라서 두 포인터를 활용한 O(N) 접근이 훨씬 효율적입니다.

## 추가 참고사항

이 문제는 그리디(Greedy) 접근과 두 포인터(Two Pointers) 기법을 결합한 예시입니다.
불일치가 발생했을 때, 왼쪽을 삭제할지 오른쪽을 삭제할지 결정하기 위해 두 가지 시나리오를 모두 확인해야 합니다.
이는 한 번의 삭제만으로 해결 가능한지 여부를 판단하는 데 필수적인 단계입니다.
문자열 조작 문제에서 대칭성을 확인할 때는 양쪽 끝에서부터 접근하는 것이 일반적인 패턴입니다.
Java의 `String.charAt()` 메서드는 O(1) 시간 복잡도를 가지므로, 반복문 내에서 안전하게 사용할 수 있습니다.
