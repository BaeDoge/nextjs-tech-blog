## 문제

정수 배열 `nums`와 정수 `k`가 주어진다. 길이 2 이상인 부분배열 중 원소의 합이 `k`의 배수인 경우가 존재하면 `true`, 그렇지 않으면 `false`를 반환한다. 부분배열은 배열의 연속된 요소들을 의미하며, 0은 항상 `k`의 배수로 간주한다.

## 접근 방법

부분배열의 합을 효율적으로 구하기 위해 `prefix_sum`(누적 합)을 활용한다. 인덱스 `j`까지의 누적 합을 `S[j]`, 인덱스 `i`까지의 누적 합을 `S[i]`라고 할 때, 부분배열 `nums[i+1...j]`의 합은 `S[j] - S[i]`이다. 이 값이 `k`의 배수라는 것은 `S[j] - S[i] = n * k`를 만족한다는 뜻이며, 이는 모듈로 연산에서 `S[j] % k == S[i] % k`임을 의미한다.

따라서 각 인덱스에서의 누적 합을 `k`로 나눈 나머지를 해시맵에 저장하며, 이전에 같은 나머지를 가진 인덱스가 존재하고 그 인덱스와의 거리가 2 이상인 경우(즉, 부분배열의 길이가 2 이상인 경우) 조건을 만족한다.

## 풀이

누적 합을 계산하면서 `k`로 나눈 나머지를 해시맵에 저장한다. 해시맵의 키는 나머지, 값은 해당 나머지를 가진 가장 첫 번째 인덱스를 저장한다. 초기 상태로 누적 합이 0인 상태(인덱스 -1)를 해시맵에 넣어두면, 배열의 시작부터 `k`의 배수가 되는 경우를 자연스럽게 처리할 수 있다.

```python
class Solution:
    def checkSubarraySum(self, nums: List[int], k: int) -> bool:
        # prefix_sum % k가 처음 등장한 인덱스를 저장하는 해시맵
        # 초기 상태: 누적합 0은 인덱스 -1에서 발생한다고 가정
        prefix_sum_map = {0: -1}
        current_sum = 0
        
        for i, num in enumerate(nums):
            current_sum += num
            remainder = current_sum % k
            
            if remainder in prefix_sum_map:
                # 이전에 같은 나머지를 가진 인덱스가 있고, 그 인덱스와 현재 인덱스의 차이가 2 이상이면
                # 부분배열의 길이가 2 이상이 된다.
                if i - prefix_sum_map[remainder] >= 2:
                    return True
            else:
                # 해당 나머지가 처음 등장하면 인덱스를 저장
                prefix_sum_map[remainder] = i
                
        return False
```

시간복잡도: $O(N)$, 배열을 한 번 순회하며 해시맵 조회가 상수 시간으로 수행된다.
공간복잡도: $O(\min(N, k))$, 해시맵에 저장되는 나머지 값의 최대 개수는 $k$개이며, 인덱스 개수는 $N$개이므로 이 중 작은 값이다.

## 다른 풀이 방법

완전탐색(Brute Force)을 사용할 수 있다. 모든 가능한 부분배열의 시작점과 끝점을 확인하여 합을 계산하고 `k`의 배수인지 검증한다. 이 경우 시간복잡도는 $O(N^2)$이 되어 제약 조건($N \le 10^5$)에서 시간 초과가 발생한다.

또한, `k`가 0인 특수 케이스를 별도로 처리해야 한다. 이 문제의 제약 조건에서 `k >= 1`이므로 모듈로 연산이 항상 유효하지만, 만약 `k=0`이 허용된다면 0으로 나누는 오류를 방지하기 위해 `k`의 배수 대신 부분배열의 합이 정확히 0인지 확인하는 로직으로 변경해야 한다.

## 추가 참고사항

이 문제는 'Pigeonhole Principle'(비둘기집 원리)과도 관련이 깊다. 배열의 길이가 `k`보다 크다면, 누적 합의 나머지가 $0$부터 $k-1$까지 $k$가지 경우의 수가 존재하므로, 비둘기집 원리에 의해 반드시 같은 나머지를 가진 두 인덱스가 존재하게 된다. 다만, 이 경우 두 인덱스의 차이가 2 이상인지 반드시 확인해야 하므로 비둘기집 원리만으로는 길이가 2 이상임을 보장할 수 없다.

또한, Python에서는 음수에 대한 모듈로 연산 결과가 양수로 반환되므로 `k`가 음수인 경우나 음수 요소가 포함된 경우에도 일관된 결과를 제공한다. 하지만 문제 제약 조건에서 `nums[i] >= 0`이므로 이 점은 고려하지 않아도 된다.
