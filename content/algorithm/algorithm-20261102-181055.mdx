## 문제

문자열 `s`가 주어졌을 때, 이 문자열이 자신의 어떤 부분 문자열(substring)을 반복하여 연결하여 만들 수 있는지 확인하는 문제입니다.

예를 들어, 입력 `s = "abab"`인 경우 부분 문자열 `"ab"`을 두 번 반복하여 `"abab"`을 만들 수 있으므로 `true`를 반환합니다.
반면, 입력 `s = "aba"`인 경우 어떤 부분 문자열을 반복하여 `"aba"`를 만들 수 없으므로 `false`를 반환합니다.

제약 조건은 다음과 같습니다.
- 문자열 `s`의 길이는 1 이상 10,000 이하입니다.
- `s`는 소문자 영어 알파벳으로만 구성됩니다.

## 접근 방법

가장 직관적인 접근은 부분 문자열의 길이를 다양하게 시도해 보는 것입니다.

1. 부분 문자열의 길이를 `len`이라고 합니다. `len`은 1부터 `s`의 전체 길이 절반(`n/2`)까지 가능합니다.
2. `len`이 전체 길이 `n`을 나누어 떨어져야 합니다. 나누어 떨어지지 않으면 부분 문자열을 정확히 반복하여 `s`를 만들 수 없으므로 다음 `len`을 시도합니다.
3. `s`의 첫 `len` 글자로 이루어진 부분 문자열을 `pattern`이라고 합니다.
4. `pattern`을 `n/len` 번 반복하여 만든 문자열과 `s`가 같은지 비교합니다.
5. 모든 가능한 `len`에 대해 조건을 만족하는 패턴이 없다면 `false`를 반환합니다.

이 접근 방식은 구현이 간단하지만, 문자열 비교와 생성 과정에서 시간이 다소 소요될 수 있습니다.

## 풀이

부분 문자열의 길이를 브루트포스로 확인하는 코드를 구현합니다.

```python
def repeatedSubstringPattern(s: str) -> bool:
    n = len(s)
    # 부분 문자열의 길이는 전체 길이의 절반까지만 확인하면 된다.
    for len_pattern in range(1, n // 2 + 1):
        # 전체 길이가 부분 문자열 길이의 배수여야 함
        if n % len_pattern != 0:
            continue
        
        # 부분 문자열 추출
        pattern = s[:len_pattern]
        # 부분 문자열을 반복하여 만든 문자열이 원본과 같은지 확인
        if pattern * (n // len_pattern) == s:
            return True
            
    return False
```

시간복잡도: O(N^2). 부분 문자열 길이를 구하는 루프가 O(N)이고, 내부에서 문자열 생성 및 비교에 O(N)이 소요되기 때문입니다.
공간복잡도: O(N). 새로운 문자열 객체를 생성하여 비교하므로 최대 N 크기의 공간이 추가로 필요합니다.

## 다른 풀이 방법

문자열 연결 기법을 이용한 O(N) 시간복잡도의 풀이가 존재합니다.

1. `s`의 길이 N에 대해, `s`와 `s`를 이어붙인 문자열 `ss = s + s`를 생각합니다.
2. `ss`에서 첫 글자(인덱스 0)와 마지막 글자(인덱스 N)를 제외한 부분 문자열, 즉 `ss[1:-1]`을 고려합니다.
3. 만약 `s`가 어떤 반복 부분 문자열로 이루어져 있다면, 이 `s`는 `ss[1:-1]`에 반드시 포함되어야 합니다.
4. 반대로 `ss[1:-1]`에 `s`가 포함되어 있다면, `s`는 반복 부분 문자열로 이루어져 있다고 판별할 수 있습니다.

```python
def repeatedSubstringPattern(s: str) -> bool:
    ss = (s + s)[1:-1]
    return s in ss
```

시간복잡도: O(N). CPython의 `in` 연산자는 Boyer-Moore-Horspool 알고리즘을 사용하여 문자열 탐색을 수행합니다.
공간복잡도: O(N). 새로운 문자열 `ss`를 생성하므로 O(N) 공간이 소요됩니다.

## 추가 참고사항

문자열 매칭 알고리즘인 Z-Algorithm이나 KMP 알고리즘을 활용하면 부분 문자열의 반복성을 더 효율적으로 분석할 수 있습니다.
- Z-Algorithm을 사용하면 문자열의 접두사가 얼마나 반복되는지 정보를 얻을 수 있습니다.
- KMP 알고리즘에서 사용되는 실패 함수(Pi array)의 마지막 값을 활용하여 최소 주기를 찾는 방법도 가능합니다.

이 문제의 제약 조건이 작기 때문에 브루트포스 풀이도 충분히 통과할 수 있으나, 대규모 데이터에서는 연결 기법이나 고급 문자열 알고리즘이 유리합니다.
