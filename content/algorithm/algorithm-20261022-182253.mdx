## 문제

주어진 연결된 무방향 그래프의 특정 노드 참조를 받아, 해당 그래프의 완전한 깊은 복사본을 반환해야 합니다.
각 노드는 정수 값과 이웃 노드들의 리스트를 포함하며, 노드 값은 1부터 N까지의 고유한 인덱스를 가집니다.
입력은 인접 리스트 형식으로 제공되며, 시작 노드는 항상 값이 1인 노드입니다.
그래프가 비어 있는 경우([])나 단일 노드로 구성된 경우([[]])도 고려해야 합니다.
제약 조건에 따라 노드 수는 최대 100개이며, 사이클이나 자기 자신과의 연결은 존재하지 않습니다.

## 접근 방법

그래프의 깊은 복사를 위해서는 모든 노드를 방문하며 새로운 노드를 생성하고, 기존 그래프의 간선 구조를 그대로 유지해야 합니다.
새로운 노드를 생성할 때 이미 방문한 노드라면 새로운 객체를 만들지 않고 기존에 생성된 복사본을 참조해야 합니다.
이러한 중복 생성을 방지하고 빠른 참조를 위해 해시맵(딕셔너리)을 사용하여 '원본 노드 참조 -> 복사 노드 참조'의 매핑을 저장합니다.
탐색 방식으로는 깊이 우선 탐색(DFS) 또는 너비 우선 탐색(BFS)을 사용할 수 있습니다.
DFS를 재귀적으로 구현하면 코드가 간결하며, 스택 오버플로우 위험이 있는 매우 깊은 그래프가 아닌 이상 안전합니다.

## 풀이

해시맵을 사용하여 방문한 노드와 그 복사본을 매핑하고, DFS를 통해 그래프를 순회하며 복사를 수행합니다.
기저 사례로 null 노드를 처리하며, 이미 해시맵에 있는 노드는 해당 복사본을 반환합니다.
새로운 노드를 생성한 후 해시맵에 저장하고, 이웃 노드들을 재귀적으로 호출하여 복사된 이웃 리스트를 연결합니다.

```java
import java.util.*;

class Node {
    public int val;
    public List<Node> neighbors;
    public Node() {
        val = 0;
        neighbors = new ArrayList<Node>();
    }
    public Node(int _val) {
        val = _val;
        neighbors = new ArrayList<Node>();
    }
    public Node(int _val, ArrayList<Node> _neighbors) {
        val = _val;
        neighbors = _neighbors;
    }
}

class Solution {
    // 해시맵: 원본 노드 -> 복사 노드 매핑
    private Map<Node, Node> visitedMap = new HashMap<>();

    public Node cloneGraph(Node node) {
        if (node == null) {
            return null;
        }

        // 이미 방문한 노드라면 복사본 반환
        if (visitedMap.containsKey(node)) {
            return visitedMap.get(node);
        }

        // 새로운 노드 생성 및 매핑 저장
        Node cloneNode = new Node(node.val);
        visitedMap.put(node, cloneNode);

        // 이웃 노드들 순회 및 복사
        for (Node neighbor : node.neighbors) {
            cloneNode.neighbors.add(cloneGraph(neighbor));
        }

        return cloneNode;
    }
}
```

시간복잡도: O(N + E). 모든 노드(N)와 간선(E)을 정확히 한 번씩 방문합니다.
공간복잡도: O(N). 해시맵에 N개의 노드 참조를 저장하며, 재귀 호출 스택 깊이는 최대 N입니다.

## 다른 풀이 방법

너비 우선 탐색(BFS)을 사용하여 풀이할 수 있습니다.
큐를 사용하여 시작 노드를 넣고, 방문한 노드를 해시맵에 저장하며 진행합니다.
BFS는 재귀 호출의 스택 오버플로우 위험이 없으며, 레벨 순서대로 그래프를 복제합니다.
단, 인접 리스트를 채우는 과정에서 두 번의 순회 또는 별도의 큐 관리가 필요하여 코드가 DFS보다 다소 복잡해질 수 있습니다.
시간복잡도와 공간복잡도는 DFS와 동일하게 O(N + E) 및 O(N)입니다.

## 추가 참고사항

해시맵의 키로 노드 객체를 사용할 경우, 해당 클래스에서 `hashCode()`와 `equals()` 메서드가 올바르게 구현되어 있어야 합니다.
LeetCode의 Java 환경에서는 객체 참조 자체가 고유한 식별자로 작용하므로 기본 구현으로도 정상 동작합니다.
그래프가 연결되어 있다는 제약 조건이 있으므로, 시작 노드 하나만 방문하면 모든 노드를 커버할 수 있습니다.
노드 값이 1부터 시작하므로 인덱스를 배열의 인덱스로 사용할 수도 있으나, 노드 값과 인덱스가 일치하지 않는 일반 그래프 문제에서는 해시맵 방식이 더 일반적입니다.
