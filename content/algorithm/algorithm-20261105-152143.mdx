## 문제

길이가 $n$인 문자열 $s$가 주어졌을 때, $0$부터 $n$까지의 정수로 이루어진 길이 $n+1$인 순열 $perm$을 찾아야 합니다. 순열은 문자열의 인덱스 $i$에 따라 다음과 같은 조건을 만족해야 합니다.

- $s[i]$가 `'I'`이면 $perm[i] < perm[i + 1]$
- $s[i]$가 `'D'`이면 $perm[i] > perm[i + 1]$

여러 가지 순열 중 하나만 반환하면 됩니다. 문자열 $s$의 길이는 $1$ 이상 $10^5$ 이하이며, 모든 문자는 `'I'` 또는 `'D'`로만 구성됩니다.

## 접근 방법

두 개의 포인터를 사용하는 탐욕적(greedy) 접근법을 활용할 수 있습니다. $0$부터 $n$까지의 숫자 중 가장 작은 값을 가리키는 `low` 포인터와 가장 큰 값을 가리키는 `high` 포인터를 준비합니다. 초기 상태에서 `low`는 0, `high`는 $n$입니다.

문자열 $s$의 각 문자를 앞에서부터 순회하며 다음과 같은 규칙으로 값을 선택합니다.

- `'I'`가 나타나면 현재 사용 가능한 숫자 중 가장 작은 값(`low`)을 선택하고 `low`를 증가시킵니다. 이렇게 하면 다음 값은 현재 선택한 값보다 반드시 크게 되므로 조건을 만족합니다.
- `'D'`가 나타나면 현재 사용 가능한 숫자 중 가장 큰 값(`high`)을 선택하고 `high`를 감소시킵니다. 이렇게 하면 다음 값은 현재 선택한 값보다 반드시 작게 되므로 조건을 만족합니다.

모든 문자를 처리한 후 마지막으로 남은 숫자(마지막 `'I'` 처리 시 `low`가, 마지막 `'D'` 처리 시 `high`가 가리키는 값)를 배열의 마지막 요소에 추가하면 완성됩니다.

## 풀이

아래는 두 포인터를 활용한 Python 구현입니다.

```python
def diStringMatch(s: str) -> list[int]:
    n = len(s)
    low, high = 0, n
    result = []
    
    for char in s:
        if char == 'I':
            result.append(low)
            low += 1
        else: # char == 'D'
            result.append(high)
            high -= 1
            
    # 마지막 남은 숫자 추가
    result.append(low) # 또는 result.append(high), low == high임
    
    return result
```

시간복잡도: $O(n)$ — 문자열 $s$의 길이에 비례하여 한 번만 순회하며 각 단계에서 상수 시간 연산을 수행합니다.
공간복잡도: $O(n)$ — 결과 순열을 저장하기 위해 길이 $n+1$인 배열을 사용합니다. 반환하는 배열을 제외하면 추가적인 공간은 $O(1)$입니다.

## 다른 풀이 방법

### 스택(Stack) 활용
`'I'`가 나올 때까지 숫자를 증가시키면서 스택에 쌓아두다가, `'I'`가 나오면 스택에 쌓인 모든 숫자를 결과에 꺼내어 역순으로 추가합니다. 이렇게 하면 `'I'`가 나타난 지점 직전까지 쌓인 숫자들은 내림차순으로 배치되어 직전 문자가 `'D'`였을 때의 조건을 만족하게 됩니다. 마지막까지 스택이 비어있지 않으면 남은 숫자를 역순으로 추가합니다.
- 시간복잡도: $O(n)$, 공간복잡도: $O(n)$ (스택 사용)

### 직접 시뮬레이션
단순히 조건을 만족하는 숫자를 찾기 위해 $0$부터 $n$까지의 숫자를 순회하며 사용되지 않은 숫자 중 조건을 만족하는 것을 선택하는 방식입니다. 매 단계마다 사용 가능한 숫자를 찾는 과정에서 추가적인 탐색이 필요할 수 있어 구현이 복잡해지고, 최적화가 되지 않으면 시간복잡도가 $O(n^2)$에 가까워질 수 있습니다. 따라서 효율적인 접근은 아닙니다.

## 추가 참고사항

- 이 문제는 두 포인터 기법(Two Pointers)을 사용하여 문제를 단순화할 수 있는 대표적인 예시입니다.
- 반환하는 순열이 유일하지 않으므로, 어떤 valid한 순열이든 정답 처리됩니다.
- 제약 사항에서 $s$의 길이가 $10^5$까지 가능하므로, $O(n^2)$ 알고리즘은 시간 초과가 발생할 수 있습니다. 반드시 $O(n)$ 또는 $O(n \log n)$ 알고리즘을 선택해야 합니다.
- 언어에 따라 정수형 배열의 초기화나 인덱스 처리 시 주의가 필요할 수 있습니다.
