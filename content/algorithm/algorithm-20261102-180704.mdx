## 문제

중복 값을 허용하는 이진 탐색 트리(BST)의 루트 노드가 주어진다. 트리에서 가장 높은 빈도(최빈도)로 나타나는 모든 원소, 즉 모드(mode)를 반환해야 한다. 복수의 모드가 존재할 경우, 임의의 순서로 반환하면 된다.

트리의 노드 개수는 1에서 $10^4$ 사이이며, 노드의 값은 $-10^5$에서 $10^5$ 사이이다. 트리는 왼쪽 서브트리의 키가 현재 노드 키보다 작거나 같고, 오른쪽 서브트리의 키가 현재 노드 키보다 크거나 큰 정의를 따른다.

## 접근 방법

이진 탐색 트리의 주요 성질인 '중위 순회(In-order Traversal) 시 정렬된 순서로 방문'이라는 특징을 활용할 수 있다. 중위 순회를 수행하면 노드 값들이 오름차순으로 나열되므로, 동일한 값들은 반드시 연속되어 방문된다.

따라서 중위 순회 과정에서 현재 방문하는 노드 값과 직전에 방문한 노드 값이 같다면 현재 값의 카운트를 증가시키고, 다르다면 카운트를 1로 초기화한다. 이 과정에서 최대 카운트를 업데이트하며 모드를 수집하면 된다.

추가 메모리 공간을 사용하지 않고 상수 공간 복잡도를 달성하려면, 전역 변수 또는 참조를 통해 현재 상태(`currentCount`, `prev`, `maxCount`, `modes`)를 유지하는 재귀적 중위 순회를 구현하면 된다.

## 풀이

재귀적 중위 순회를 통해 노드를 오름차순으로 방문한다. 각 노드마다 이전 노드와의 비교를 통해 연속된 동일 값의 횟수를 계산한다. 현재 값의 빈도수가 최대 빈도수와 같으면 결과 리스트에 추가하고, 최대 빈도수를 갱신하면 리스트를 초기화한 후 현재 값을 추가한다.

```python
class Solution:
    def findMode(self, root: Optional[TreeNode]) -> List[int]:
        # 상태 변수 정의
        self.max_count = 0
        self.current_count = 0
        self.prev = None
        self.modes = []

        def inorder(node):
            if node is None:
                return
            
            inorder(node.left)
            
            # 현재 노드 값 처리
            if self.prev is not None and node.val == self.prev:
                self.current_count += 1
            else:
                self.current_count = 1
            
            # 최대 카운트 업데이트 및 모드 리스트 관리
            if self.current_count > self.max_count:
                self.max_count = self.current_count
                self.modes = [node.val]
            elif self.current_count == self.max_count:
                self.modes.append(node.val)
                
            self.prev = node.val
            inorder(node.right)

        inorder(root)
        return self.modes
```

시간 복잡도: 각 노드를 정확히 한 번 방문하므로 $O(N)$이다. ($N$: 노드의 개수)
공간 복잡도: 재귀 호출 스택이 사용되므로 최악의 경우(편향 트리) $O(N)$, 균형 잡힌 트리의 경우 $O(\log N)$이다. 문제의 Follow-up 조건인 명백한 보조 공간(해시맵 등)은 사용하지 않는다.

## 다른 풀이 방법

해시맵(딕셔너리)을 사용하여 각 노드 값의 출현 횟수를 저장한 후, 가장 높은 빈도를 가진 키들을 필터링하는 방법이 있다.

1. 중위 순회 또는 어떤 순회 방식이든 상관없이 모든 노드를 순회하며 값의 빈도수를 해시맵에 기록한다.
2. 해시맵의 최대 값(최빈도)을 찾는다.
3. 최대 빈도와 동일한 값을 가진 키들을 리스트로 추출하여 반환한다.

시간 복잡도: $O(N)$
공간 복잡도: 해시맵을 사용하므로 $O(N)$이다. Follow-up의 공간 복잡도 제한 조건($O(1)$ 추가 메모리)을 만족하지 못하지만, 구현이 간단하고 직관적인 장점이 있다.

```python
class Solution:
    def findMode(self, root: Optional[TreeNode]) -> List[int]:
        freq = {}
        
        def traverse(node):
            if not node:
                return
            freq[node.val] = freq.get(node.val, 0) + 1
            traverse(node.left)
            traverse(node.right)
            
        traverse(root)
        
        max_count = max(freq.values())
        return [num for num, count in freq.items() if count == max_count]
```

## 추가 참고사항

이진 탐색 트리의 중위 순회는 항상 정렬된 배열을 생성한다는 점이 이 문제의 핵심 아이디어이다. 만약 일반 이진 트리였다면 정렬 성질을 이용할 수 없으므로 해시맵을 사용한 $O(N)$ 공간 복잡도 풀이가 유일한 효율적인 방법이 된다.

재귀 호출 스택은 문제의 제약 조건에서 '추가 메모리로 간주하지 않는다'고 명시하고 있으므로, 재귀적 중위 순회를 사용한 풀이는 Follow-up 조건을 충족하는 것으로 간주된다. 반복문과 Morris Traversal을 사용하면 재귀 스택 공간까지 포함하여 엄격한 $O(1)$ 공간 복잡도를 달성할 수 있지만, 구현이 복잡하여 실제 코딩 테스트에서는 재귀적 접근이 일반적으로 선호된다.
