## 문제

정수 배열 `arr`이 주어졌을 때, 해당 배열이 유효한 산형 배열(Mountain Array)인지 판별하는 함수를 작성해야 합니다. 유효한 산형 배열의 조건은 다음과 같습니다.
먼저, 배열의 길이는 3 이상이어야 합니다.
둘째, 인덱스 `i` (`0 < i < arr.length - 1`)가 존재하여, `arr[0] < arr[1] < ... < arr[i]`인 증가 구간과 `arr[i] > arr[i + 1] > ... > arr[arr.length - 1]`인 감소 구간이 명확히 존재해야 합니다.
즉, 배열은 정확히 한 번의 피크(Peak)를 가지며, 피크는 배열의 양 끝(첫 인덱스나 마지막 인덱스)에 위치할 수 없습니다.
평탄한 구간(인접한 원소가 같은 경우)이 존재하거나, 증가만 하거나 감소만 하는 배열은 유효하지 않습니다.

## 접근 방법

가장 직관적인 접근법은 배열의 왼쪽 끝에서부터 시작하여 증가하는 구간을 탐색한 후, 그 지점이 산의 꼭대기인지 확인하는 것입니다.
1. 인덱스 `i`를 0부터 시작하여 `arr[i] < arr[i+1]`인 동안 증가합니다.
2. 이때, `i`가 0이거나 `i`가 배열의 마지막 인덱스에 도달했다면 산형 배열의 조건(피크가 중간에 존재해야 함)을 만족하지 않으므로 `false`를 반환합니다.
3. 증가 구간을 지나면 이제 감소 구간을 확인해야 합니다. `i`가 배열의 마지막 인덱스가 될 때까지 `arr[i] > arr[i+1]`인 동안 진행합니다.
4. 최종적으로 `i`가 배열의 마지막 인덱스에 도달했다면 유효한 산형 배열이므로 `true`를 반환하고, 그렇지 않다면 `false`를 반환합니다.

## 풀이

두 개의 포인터를 사용하거나 단일 반복문으로 증가 구간과 감소 구간을 연속적으로 탐색하여 구현할 수 있습니다. 아래 코드는 단일 반복문을 사용하여 증가 구간을 지나고 감소 구간을 확인하는 방식입니다.

```python
class Solution:
    def validMountainArray(self, arr: List[int]) -> bool:
        n = len(arr)
        if n < 3:
            return False
        
        i = 0
        
        # 증가 구간 탐색
        while i + 1 < n and arr[i] < arr[i + 1]:
            i += 1
            
        # 피크가 첫 번째나 마지막 원소인 경우 유효하지 않음
        if i == 0 or i == n - 1:
            return False
            
        # 감소 구간 탐색
        while i + 1 < n and arr[i] > arr[i + 1]:
            i += 1
            
        # 감소 구간을 다 지나고 마지막 원소까지 도달했는지 확인
        return i == n - 1
```

- 시간 복잡도: $O(N)$ - 배열을 한 번만 순회합니다.
- 공간 복잡도: $O(1)$ - 추가적인 공간 사용을 하지 않습니다.

## 다른 풀이 방법

양쪽에서 동시에 탐색하는 방법도 있습니다.
1. 왼쪽 끝에서부터 증가하는 구간을 탐색하여 피크의 왼쪽 경계 `left`를 찾습니다.
2. 오른쪽 끝에서부터 증가하는 구간(감소 방향 역순)을 탐색하여 피크의 오른쪽 경계 `right`를 찾습니다.
3. 만약 `left`와 `right`가 같은 인덱스를 가리키고, 그 인덱스가 배열의 양 끝이 아니라면 유효한 산형 배열입니다.
이 방법도 시간 복잡도 $O(N)$, 공간 복잡도 $O(1)$을 가지며, 증가 구간과 감소 구간의 경계점을 각각 독립적으로 찾는다는 점에서 차이가 있습니다.

## 추가 참고사항

- 평탄한 구간(`arr[i] == arr[i+1]`)이 포함되면 즉시 `false`를 반환해야 합니다. 위 풀이에서는 비교 연산자(`<` 또는 `>`)를 사용했기 때문에 평탄한 구간이 나오면 루프가 종료되며, 이후 조건 검사에서 이를 걸러낼 수 있습니다.
- 배열의 길이가 3 미만인 경우 즉시 `false`를 반환하는 예외 처리가 필요합니다.
- 이 문제는 배열의 순차적 탐색과 경계 조건 처리를 연습하기 좋은 문제입니다.
