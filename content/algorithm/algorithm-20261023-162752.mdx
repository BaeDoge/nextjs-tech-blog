## 문제

피크 요소는 인접한 이웃 원소보다 엄격하게 큰 원소를 의미합니다. 0부터 시작하는 정수 배열 `nums`가 주어졌을 때, 피크 요소의 인덱스를 반환해야 합니다. 배열에 여러 피크 요소가 존재하면 그중 하나의 인덱스를 반환하면 됩니다.

배열의 양 끝은 음의 무한대(`-∞`)로 간주됩니다. 즉, `nums[-1]`과 `nums[n]`은 배열의 어떤 원소보다 작으므로, 양 끝 원소도 조건에 따라 피크 요소가 될 수 있습니다. 알고리즘은 O(log n) 시간 복잡도를 만족해야 합니다.

```python
# 입력 예시
nums = [1, 2, 3, 1]
# 출력: 2 (원소 3이 피크)
```

## 접근 방법

문제의 핵심 제약 조건인 O(log n) 시간 복잡도는 선형 탐색(O(n))이 아닌, 이진 탐색(Binary Search)의 적용을 시사합니다.

배열의 중간 지점 `mid`를 확인했을 때, `nums[mid]`가 `nums[mid + 1]`보다 크다면, 오른쪽 끝은 음의 무한대이므로 `mid`를 기준으로 오른쪽 구간에는 반드시 피크 요소가 존재합니다. 반대로 `nums[mid]`가 `nums[mid + 1]`보다 작다면, `mid + 1`은 현재 `mid`보다 크므로 왼쪽 끝(음의 무한대)을 향해 올라가는 경로가 열려 있으며, 이 구간에도 피크 요소가 존재합니다.

따라서 매 단계마다 비교 결과를 통해 탐색 범위를 절반으로 줄여나가면 됩니다.

## 풀이

이진 탐색을 구현합니다. `left`와 `right` 포인터를 사용하여 탐색 범위를 좁혀갑니다. 중간값 `mid`와 그 다음 값 `mid + 1`을 비교하여 피크가 존재하는 구간으로 이동합니다.

```python
from typing import List

class Solution:
    def findPeakElement(self, nums: List[int]) -> int:
        left, right = 0, len(nums) - 1
        
        while left < right:
            mid = (left + right) // 2
            
            # nums[mid]와 nums[mid+1] 비교
            # nums[mid] < nums[mid+1] 이면 피크는 오른쪽에 있음
            if nums[mid] < nums[mid + 1]:
                left = mid + 1
            # nums[mid] > nums[mid+1] 이면 피크는 왼쪽(또는 mid 자신)에 있음
            else:
                right = mid
                
        return left
```

- 시간 복잡도: O(log n) - 매 반복마다 탐색 범위가 절반으로 줄어듭니다.
- 공간 복잡도: O(1) - 추가적인 자료 구조를 사용하지 않습니다.

## 다른 풀이 방법

동일한 O(log n) 시간 복잡도를 만족하는 재귀적 이진 탐색 구현이 있습니다.

재귀 함수를 사용하여 `left`와 `right` 범위를 전달하며 탐색합니다. 종료 조건은 `left == right`일 때이며, 이때의 `left`가 피크 요소의 인덱스가 됩니다. 반복문 방식과 논리는 동일하지만, 함수 호출 스택을 사용하므로 공간 복잡도가 O(log n)으로 증가할 수 있습니다.

```python
from typing import List

class Solution:
    def findPeakElement(self, nums: List[int]) -> int:
        def binary_search(left: int, right: int) -> int:
            if left == right:
                return left
            
            mid = (left + right) // 2
            
            if nums[mid] < nums[mid + 1]:
                return binary_search(mid + 1, right)
            else:
                return binary_search(left, mid)
                
        return binary_search(0, len(nums) - 1)
```

## 추가 참고사항

- 문제의 제약 조건에서 `nums[i] != nums[i + 1]`로 명시되어 있으므로, 평탄한 구간(인접한 원소가 같은 경우)을 고려할 필요가 없습니다.
- 배열의 길이가 1인 경우, `while` 루프 조건(`left < right`)이 즉시 거짓이 되므로 `left` (즉, 0)을 반환하여 올바르게 처리됩니다.
- 이진 탐색의 변형 문제 중 하나로, "어떤 조건을 만족하는 첫 번째/마지막 인덱스"를 찾는 패턴과 유사하게 `left == right`가 될 때까지 범위를 좁히는 구조를 가집니다.
