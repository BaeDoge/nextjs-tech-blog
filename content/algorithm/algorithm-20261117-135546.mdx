## 문제

배열 nums가 [x1, x2, ..., xn, y1, y2, ..., yn] 형태일 때, [x1, y1, x2, y2, ..., xn, yn] 형태의 배열을 반환하는 문제입니다. 즉, 첫 번째 요소와 n+1번째 요소, 두 번째 요소와 n+2번째 요소를 교차하여 순서를 바꾸는 과정입니다. Constraints에 따르면 1 ≤ n ≤ 500이며, nums.length는 항상 2n이고 원소는 1 이상 10^3 이하의 정수입니다. 예를 들어 nums = [2,5,1,3,4,7], n = 3인 경우 결과는 [2,3,5,4,1,7]이 됩니다.

## 접근 방법

가장 직관적인 접근은 인덱싱입니다. nums의 i번째 요소(0 ≤ i &lt; n)와 i+n번째 요소를 각각 꺼내어 결과 배열에 순서대로 추가하면 됩니다. 추가적인 자료 구조 없이 순회하며 채우면 구현이 간단합니다.

## 풀이

```python
from typing import List

class Solution:
    def shuffle(self, nums: List[int], n: int) -> List[int]:
        result = []
        for i in range(n):
            result.append(nums[i])
            result.append(nums[i + n])
        return result
```

시간 복잡도는 O(n)이며, 공간 복잡도는 결과를 저장하기 위해 O(n)입니다.

## 다른 풀이 방법

파이썬의 리스트 컴프리헨션을 이용하면 구현을 간소화할 수 있습니다. `result = [nums[i//2] if i % 2 == 0 else nums[n + i//2] for i in range(2*n)]`와 같은 식으로 표현 가능하며, 알고리즘적 시간 복잡도는 여전히 O(n)이며, 인덱싱 로직은 앞선 반복문 방식과 동일합니다.
