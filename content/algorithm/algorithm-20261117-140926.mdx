## 문제

n개의 서로 다른 점이 평면에 주어집니다. 각 점은 [xi, yi] 쌍으로 표현됩니다. 부메랑(i, j, k)은 i와 j 사이의 거리가 i와 k 사이의 거리와 같은 점의 순서쌍으로, 순서가 중요합니다. 주어진 점들에 대해 가능한 모든 부메랑의 개수를 구해야 합니다. 예를 들어 점이 [0,0], [1,0], [2,0]이면 두 개의 부메랑이 존재합니다. n은 500 이하이고, 각 좌표는 -10^4에서 10^4 사이입니다.

## 접근 방법

각 점 i를 기준으로 다른 모든 점 j까지의 거리를 계산합니다. 거리의 제곱을 사용하여 부동소수점 오차를 피합니다. 각 거리별로 점 j의 개수를 해시 맵에 기록합니다. 같은 거리에 해당하는 점이 m개라면, i를 중심으로 하는 부메랑은 m개 중 순서대로 고르는 경우의 수인 m*(m-1)개가 생깁니다. 모든 i에 대해 이 값을 합산하면 전체 부메랑 개수를 얻을 수 있습니다. 시간 복잡도는 O(n^2)이고, 공간 복잡도는 O(n)입니다.

## 풀이

먼저 각 점 i에 대해 다른 모든 점 j와의 거리 제곱을 계산하고, 각 거리별 개수를 해시 맵에 기록합니다. 그 다음 같은 거리가 m개인 경우 m*(m-1)을 결과에 더합니다. 아래는 Python으로 구현한 코드입니다.

```python
def numberOfBoomerangs(points):
    ans = 0
    for i in points:
        dist_cnt = {}
        for j in points:
            if i == j:
                continue
            dx = i[0] - j[0]
            dy = i[1] - j[1]
            d = dx*dx + dy*dy
            dist_cnt[d] = dist_cnt.get(d, 0) + 1
        for cnt in dist_cnt.values():
            ans += cnt * (cnt - 1)
    return ans
```

이 알고리즘의 시간 복잡도는 O(n^2)이고, 공간 복잡도는 O(n)입니다.

## 다른 풀이 방법

가장 단순한 방법은 모든 세 점의 조합에 대해 i를 고정하고 j, k를 순서대로 선택하며 거리를 비교하는 완전 탐색입니다. 이 경우 시간 복잡도는 O(n^3)으로 n=500일 때 약 1.25억 연산이 필요해 시간 초과가 우려됩니다. 따라서 위와 같은 해시 맵을 활용한 O(n^2) 방법이 더 효율적입니다. 또한 각 점에 대해 거리별로 정렬한 후 같은 거리 그룹을 찾는 방법도 존재하지만, 복잡도 측면에서 해시 맵 사용이 우수합니다.

## 추가 참고사항

거리 계산 시 정수 제곱을 사용하여 정확한 비교가 가능합니다. n이 1일 때는 부메랑이 존재하지 않으므로 0을 반환해야 합니다. 좌표 범위가 -10^4 ~ 10^4이므로 거리 제곱은 최대 약 2*10^8이며, 정수형으로 처리할 수 있습니다. Python의 딕셔너리를 사용하면 평균 O(1)에 삽입, 조회가 가능해 전체 O(n^2) 시간 내에 동작합니다.
