## 문제

단일 연결 리스트의 헤드 노드가 주어진다. 이列表는 첫 번째 노드, 두 번째 노드, ..., 마지막 노드 순서로 연결되어 있다. 주어진 순서를 첫 노드, 마지막 노드, 두 번째 노드, 뒤에서 두 번째 노드, 세 번째 노드, 뒤에서 세 번째 노드, ... 와 같이 재정렬해야 한다. 노드의 값은 변경할 수 없으며, 노드 자체의 연결만 조정할 수 있다. 예를 들어 [1,2,3,4]는 [1,4,2,3]으로, [1,2,3,4,5]는 [1,5,2,4,3]으로 재정렬된다.

## 접근 방법

가장 간단한 방법은列表를 반으로 나누고, 뒤쪽 절반을 뒤집어 앞쪽 절반과 교차로 연결하는 것이다. 먼저 느린 포인터와 빠른 포인터를 사용해 중간 노드를 찾는다. 그 다음 뒤쪽 절반의 헤드를 얻고, 이를 뒤집는다. 마지막으로 두 절반을 번갈아 가며 병합한다. 이 과정은 선형 시간 복잡도와 상수 공간 복잡도를 요구한다.

## 풀이

다음은 두 포인터를 이용한 풀이이다. 중간 노드를 찾고 뒤쪽 절반을 뒤집은 후, 두 절반을 교차로 병합한다. 시간 복잡도는 선형이고, 공간 복잡도는 상수이다.

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def reorderList(self, head: ListNode) -> None:
        if not head or not head.next:
            return
        
        # 1. 중간 노드 찾기
        slow, fast = head, head
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
        
        # 2. 뒤쪽 절반 뒤집기
        prev, curr = None, slow
        while curr:
            nxt = curr.next
            curr.next = prev
            prev = curr
            curr = nxt
        
        # 3. 두 절반 병합
        first, second = head, prev
        while second.next:
            tmp1, tmp2 = first.next, second.next
            first.next = second
            second.next = tmp1
            first, second = tmp1, tmp2
```

이 방법은 추가 자료 구조를 사용하지 않고 원지적으로 작업한다.

## 다른 풀이 방법

스택을 사용하는 방법도 있다. 먼저 모든 노드를 스택에 넣고, 앞쪽 절반만큼 팝하면서 교차 연결하면 동작하지만 선형 공간이 필요하다. 재귀를 활용한 방법도 존재하지만, 스택 오버플로우 위험이 있어 비추천한다. 두 포인터 기반 풀이가 공간 효율성 측면에서 가장 우수하다.

## 추가 참고사항

리스트의 길이가 1 또는 2인 경우는 별도 처리가 필요하다. 중간 노드를 찾을 때 포인터가 정확히 반을 나누도록 조정해야 한다. 문제 제약 상 노드 값은 1 이상 1000 이하이며, 노드 개수는 최대 5×10^4개다.
