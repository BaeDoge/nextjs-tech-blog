## 문제

단일 연결 리스트의 헤드 노드가 주어진다. 이연결 리스트는 첫 번째 노드, 두 번째 노드, ..., 마지막 노드 순서로 연결되어 있다. 주어진 순서를 첫 노드, 마지막 노드, 두 번째 노드, 뒤에서 두 번째 노드, 세 번째 노드, 뒤에서 세 번째 노드, ... 와 같이 재정렬해야 한다. 노드의 값은 변경할 수 없으며, 노드 자체의 연결만 조정할 수 있다. 예를 들어 [1,2,3,4]는 [1,4,2,3]으로, [1,2,3,4,5]는 [1,5,2,4,3]으로 재정렬된다.

## 접근 방법

가장 간단한 방법은연결 리스트를 반으로 나누고, 뒤쪽 절반을 뒤집어 앞쪽 절반과 교차로 연결하는 것이다. 먼저 느린 포인터와 빠른 포인터를 사용해 중간 노드를 찾는다. 그 다음 뒤쪽 절반의 헤드를 얻고, 이를 뒤집는다. 마지막으로 두 절반을 번갈아 가며 병합한다. 이 과정은 선형 시간 복잡도와 상수 공간 복잡도를 요구한다.

## 풀이

다음은 두 포인터를 이용한 풀이이다. 중간 노드를 찾고 뒤쪽 절반을 뒤집은 후, 두 절반을 교차로 병합한다. 시간 복잡도는 선형이고, 공간 복잡도는 상수이다.

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

class Solution:
    def reorderList(self, head: ListNode) -> None:
        if not head or not head.next:
            return
        
        # 1. 첫 번째 절반의 끝 찾기
        slow, fast = head, head.next
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next
        
        # 2. 두 번째 절반을 분리한 뒤 뒤집기
        second = slow.next
        slow.next = None
        prev = None
        while second:
            nxt = second.next
            second.next = prev
            prev = second
            second = nxt
        second = prev
        
        # 3. 두 절반을 번갈아 병합
        first = head
        while second:
            tmp1 = first.next
            tmp2 = second.next
            first.next = second
            second.next = tmp1
            first = tmp1
            second = tmp2
```

이 방법은 별도의 노드 배열이나 리스트를 만들지 않고 연결 관계를 제자리에서 수정한다.

## 다른 풀이 방법

모든 노드 참조를 배열에 저장한 뒤 양 끝에서 번갈아 연결할 수도 있습니다.

```python
def reorderList_with_array(head: ListNode) -> None:
    nodes = []
    current = head
    while current:
        nodes.append(current)
        current = current.next

    left, right = 0, len(nodes) - 1
    while left < right:
        nodes[left].next = nodes[right]
        left += 1
        if left >= right:
            break
        nodes[right].next = nodes[left]
        right -= 1

    if nodes:
        nodes[left].next = None
```

시간 복잡도는 O(N), 공간 복잡도는 노드 참조 배열을 저장하는 O(N)입니다. 첫 번째 방법은 노드 연결을 직접 조정하므로 O(1) 보조 공간을 사용합니다.

## 추가 참고사항

리스트의 길이가 1 또는 2인 경우는 별도 처리가 필요하다. 중간 노드를 찾을 때 포인터가 정확히 반을 나누도록 조정해야 한다. 문제 제약 상 노드 값은 1 이상 1000 이하이며, 노드 개수는 최대 5×10^4개다.
