## 문제

이진 탐색 트리(BST)의 루트 노드와 정수 값 `val`이 주어집니다. BST 내에서 값이 `val`과 같은 노드를 찾아야 하며, 해당 노드를 루트로 하는 부분 트리를 반환해야 합니다. 만약 해당 값을 가진 노드가 존재하지 않으면 `null`을 반환합니다.

- 입력: BST의 `root`, 정수 `val`
- 출력: 찾은 노드를 루트로 하는 서브트리 또는 `null`
- 제약 조건:
  - 노드 수: 1부터 5000
  - 노드 값 범위: 1부터 $10^7$
  - `root`는 유효한 이진 탐색 트리입니다.

## 접근 방법

이진 탐색 트리(BST)의 핵심 속성인 "왼쪽 서브트리의 모든 노드 값은 루트보다 작고, 오른쪽 서브트리의 모든 노드 값은 루트보다 크다"는 성질을 활용합니다. 따라서 현재 노드의 값과 `val`을 비교하여 탐색 경로를 결정할 수 있습니다.

- 현재 노드가 `null`이면 값이 없으므로 탐색 종료하고 `null` 반환
- 현재 노드 값과 `val`이 같으면 해당 노드 반환
- `val`이 현재 노드 값보다 작으면 왼쪽 자식으로 이동
- `val`이 현재 노드 값보다 크면 오른쪽 자식으로 이동

이 과정을 재귀적으로 반복하면 효율적으로 탐색할 수 있습니다.

## 풀이

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def searchBST(self, root: Optional[TreeNode], val: int) -> Optional[TreeNode]:
        if root is None:
            return None
        
        if root.val == val:
            return root
        elif val < root.val:
            return self.searchBST(root.left, val)
        else:
            return self.searchBST(root.right, val)
```

- 시간 복잡도: $O(H)$. 여기서 $H$는 BST의 높이입니다. 최선의 경우 균형이 잡힌 트리는 $O(\log N)$, 최악의 경우 편향된 트리는 $O(N)$입니다.
- 공간 복잡도: $O(H)$. 재귀 호출 스택의 깊이만큼 공간이 사용됩니다.

## 다른 풀이 방법

반복문(Iterative) 방식으로 구현할 수 있습니다. 재귀 호출 대신 `while` 루프를 사용하여 노드를 이동하며 탐색합니다.

- 구현 방식:
  - 현재 노드를 가리키는 포인터 `curr`를 `root`로 초기화
  - `curr`가 `null`이 아니고 `curr.val != val`인 동안 반복
  - `val`이 `curr.val`보다 작으면 `curr`를 왼쪽 자식으로 이동
  - 그렇지 않으면 `curr`를 오른쪽 자식으로 이동
  - 반복 종료 후 `curr` 반환

```python
class Solution:
    def searchBST(self, root: Optional[TreeNode], val: int) -> Optional[TreeNode]:
        curr = root
        while curr is not None and curr.val != val:
            if val < curr.val:
                curr = curr.left
            else:
                curr = curr.right
        return curr
```

- 시간 복잡도: $O(H)$
- 공간 복잡도: $O(1)$. 추가적인 메모리를 사용하지 않습니다.

## 추가 참고사항

- 이진 탐색 트리의 구조에 따라 시간 복잡도가 달라지므로, 트리의 균형 상태를 고려해야 합니다.
- 재귀적 접근은 코드가 간결하지만, 트리가 깊을 경우 스택 오버플로우 위험이 있습니다.
- 반복적 접근은 메모리 사용이 적어 안정적인 경우가 많습니다.
- 문제에서 주어진 제약 조건에 따라 노드 값의 범위가 넓지만, BST 속성 덕분에 값의 크기보다는 트리 구조가 탐색 속도에 영향을 미칩니다.
