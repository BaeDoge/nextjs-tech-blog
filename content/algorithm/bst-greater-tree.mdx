## 문제

이진 검색 트리(BST)의 루트 노드가 주어졌을 때, 각 노드의 값을 원래 값에 자신보다 큰 모든 키의 합을 더한 값으로 변환하는 Greater Tree를 만들어야 합니다. BST의 정의에 따라 왼쪽 서브트리의 키는 노드 키보다 작고, 오른쪽 서브트리의 키는 노드 키보다 큽니다. 트리의 노드 수는 최대 $10^4$개이며, 노드 값은 $-10^4$에서 $10^4$ 사이의 고유한 정수입니다.

## 접근 방법

BST의 특성을 활용하면, 노드 값을 큰 순서대로 처리할 때 누적 합을 유지하며 변환할 수 있습니다. 일반적인 중위 순회(In-order Traversal)는 작은 값부터 큰 값의 순서로 방문하지만, 역중위 순회(Right-Node-Left)를 수행하면 큰 값부터 작은 값의 순서로 방문하게 됩니다. 이 순서로 방문하면서 누적된 합을 현재 노드에 더하면, 현재 노드보다 큰 모든 노드의 합을 쉽게 계산할 수 있습니다.

## 풀이

역중위 순회(우측 -> 현재 -> 좌측)를 구현하여 전역 변수 또는 참조 변수로 누적 합을 관리합니다. 각 노드를 방문할 때 현재까지의 누적 합을 노드 값에 더하고, 업데이트된 노드 값을 새로운 누적 합으로 갱신합니다. 이 과정을 재귀적으로 수행하여 트리의 모든 노드를 변환합니다.

```python
class Solution:
    def convertBST(self, root: Optional[TreeNode]) -> Optional[TreeNode]:
        self.cumulative_sum = 0
        
        def reverse_inorder(node):
            if not node:
                return
            
            # 1. 오른쪽 서브트리 방문 (큰 값부터 처리)
            reverse_inorder(node.right)
            
            # 2. 현재 노드 처리
            self.cumulative_sum += node.val
            node.val = self.cumulative_sum
            
            # 3. 왼쪽 서브트리 방문
            reverse_inorder(node.left)
            
        reverse_inorder(root)
        return root
```

시간복잡도: $O(N)$ (모든 노드를 한 번씩 방문)
공간복잡도: $O(H)$ (재귀 호출 스택, $H$는 트리의 높이)

## 다른 풀이 방법

재귀 대신 스택을 사용한 반복문 방식이 있습니다. 역중위 순회의 로직을 스택을 이용해 구현하면 재귀 호출로 인한 스택 오버플로우 위험을 줄일 수 있습니다. 스택에 노드를 푸시하고, 오른쪽 자식이 있는 한 계속 오른쪽으로 내려가며 노드를 스택에 저장합니다. 이후 스택에서 노드를 꺼내 처리하고, 왼쪽 자식으로 이동하는 과정을 반복합니다. 이 방법 역시 시간복잡도는 $O(N)$이지만, 공간복잡도는 재귀 방식과 동일하게 $O(H)$를 유지합니다.

## 추가 참고사항

이 문제는 LeetCode 1038번과 동일한 문제입니다. BST의 정렬된 순서 특성을 이용한 역중위 순회는 관련 문제에서 자주 등장하는 패턴이므로 숙지하는 것이 좋습니다. 노드 값의 범위가 제한되어 있어 정수 오버플로우를 고려해야 할 수 있으나, Python의 정수형은 자발적으로 큰 정수를 지원하므로 별도의 처리가 필요하지 않습니다.
