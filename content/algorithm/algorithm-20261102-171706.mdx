## 문제

입력은 길이 1 이상 100000 이하의 유효한 괄호 문자열이다. 이 문자열은 비어 있지 않은 원시 파생 문자열들을 순서대로 연결한 형태이다. 각 원시 파생 문자열의 가장 바깥쪽 '('와 ')'를 제거한 뒤, 전체 문자열을 반환한다.

## 접근 방법

문자열을 한 번 순회하면서 현재 깊이 값을 유지한다. 깊이가 1보다 클 때만 현재 문자를 결과에 추가하면 외곬 괄호가 제외된다. 이때 '('를 만나면 깊이 값을 1 증가시키고 ')'를 만나면 1 감소시키는 방식으로 관리한다.

## 풀이

깊이를 카운터 변수로 유지하면서 각 문자를 순회하면 문자열 길이만큼의 시간 복잡도와 상수 공간 복잡도로 문제를 해결할 수 있다. 깊이가 1보다 크면 현재 문자를 결과에 추가하고, '('이면 깊이 값을 1 증가시키고 ')'이면 1 감소시킨다. 이 알고리즘은 문자열을 한 번만 통과하므로 문자열 길이만큼의 시간 복잡도와 상수 공간 복잡도로 동작한다.

```python
def remove_outer_parentheses(s: str) -> str:
    result = []
    depth = 0
    for ch in s:
        if ch == '(':
            if depth > 0:
                result.append(ch)
            depth += 1
        else:  # ch == ')'
            depth -= 1
            if depth > 0:
                result.append(ch)
    return ''.join(result)
```

## 다른 풀이 방법

스택을 이용해 괄호 균형을 맞추는 방법을 사용할 수 있지만, 깊이 카운터만으로도 동일하게 문자열 길이만큼의 시간 복잡도와 상수 공간 복잡도를 확보한다. 두 접근법 모두 입력 문자열을 한 번만 읽으므로 효율적이다.

## 추가 참고사항

제약 조건에 따라 문자열 길이가 최대 100000이므로 선형 시간 알고리즘이 필요하다. 입력은 반드시 유효한 괄호 문자열이므로 균형이 맞지 않는 경우는 고려하지 않아도 된다. 이 문제의 해는 문자열 연산을 최소화하면서도 메모리 사용량을 최소화한다.
