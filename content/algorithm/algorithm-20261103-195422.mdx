## 문제

정수 배열 `nums`가 주어졌을 때, 배열 내에 중복된 요소가 하나라도 존재하면 `true`를, 모든 요소가 고유하다면 `false`를 반환하는 문제이다.
예를 들어 입력 `[1, 2, 3, 1]`의 경우 값 1이 두 번 나타나므로 `true`를 반환한다.
반면 입력 `[1, 2, 3, 4]`의 경우 모든 값이 다르므로 `false`를 반환한다.
배열의 길이는 1 이상 10^5 이하이며, 각 요소의 값 범위는 -10^9에서 10^9 사이이다.
이 문제는 배열 내에 동일한 값이 반복되는지를 효율적으로 탐지하는 것이 핵심 목표이다.

## 접근 방법

가장 직관적인 방법은 해시 집합(`HashSet`)을 활용하는 것이다.
배열의 요소를 순회하며 각 값을 집합에 추가하기 전에 이미 존재하는지 확인한다.
만약 해당 값이 집합에 이미 포함되어 있다면 중복이 발견되었으므로 즉시 `true`를 반환한다.
순회 중 중복을 찾지 못하면 모든 요소가 고유하다는 의미이므로 `false`를 반환한다.
이 방법은 값을 저장하고 탐색하는 데 상수 시간 복잡도를 가지므로 전체적인 시간 효율이 우수하다.
다른 접근으로 정렬을 이용할 수 있으며, 정렬 후 인접한 두 요소만 비교하면 중복을 확인할 수 있다.

## 풀이

해시 집합을 사용하여 중복 여부를 확인하는 Python 코드는 다음과 같다.

```python
class Solution:
    def containsDuplicate(self, nums: List[int]) -> bool:
        seen = set()
        for num in nums:
            if num in seen:
                return True
            seen.add(num)
        return False
```

이 코드의 시간 복잡도는 O(N)이다.
여기서 N은 배열 `nums`의 길이이며, 집합의 삽입과 검색 연산이 평균 O(1)이므로 전체 선형 시간이 소요된다.
공간 복잡도는 O(N)이다.
최악의 경우 모든 요소가 고유하므로 집합에 N개의 요소를 저장해야 하기 때문이다.

## 다른 풀이 방법

정렬을 이용한 방법은 O(N log N)의 시간 복잡도를 가진다.
먼저 배열을 정렬한 후, 인덱스 `i`와 `i+1`이 서로 다른지 비교하는 과정을 전체 배열 길이에 대해 수행한다.
인접한 두 요소가 동일하다면 중복이 존재함을 알 수 있다.

```python
class Solution:
    def containsDuplicate(self, nums: List[int]) -> bool:
        nums.sort()
        for i in range(len(nums) - 1):
            if nums[i] == nums[i + 1]:
                return True
        return False
```

정렬 기반 접근법의 공간 복잡도는 정렬 알고리즘 구현에 따라 O(log N) 또는 O(N)이 될 수 있다.
시간 복잡도 측면에서는 해시 집합 방법(O(N))이 정렬 방법(O(N log N))보다 일반적으로 더 빠르다.
하지만 정렬 방법은 추가적인 자료 구조(해시 집합)를 사용하지 않고 배열 자체를 조작한다는 장점이 있다.

## 추가 참고사항

해시 집합 방식은 평균적인 경우 매우 효율적이지만, 해시 충돌이 빈번하게 발생할 경우 성능이 저하될 수 있다.
일반적인 프로그래밍 언어의 표준 라이브러리에서 제공하는 집합 자료 구조는 이러한 충돌을 잘 처리하도록 설계되어 있다.
배열의 크기가 매우 클 때 메모리 제약이 엄격하다면 정렬 방식을 고려해볼 수 있다.
두 방법 모두 최악의 시간 복잡도에서 안정적으로 동작하므로, 제약 조건인 10^5 크기 내에서 모두 통과한다.
