## 문제

두 개의 이진트리 `root`와 `subRoot`가 주어졌을 때, `root` 트리 내에 `subRoot`와 구조와 노드 값이 완전히 동일한 부분트리(subtree)가 존재하는지 확인하는 문제입니다. 부분트리는 특정 노드와 그 모든 후손으로 구성되며, 트리 자신도 자신의 부분트리로 간주합니다.

예를 들어, `root`가 `[3,4,5,1,2]`이고 `subRoot`가 `[4,1,2]`인 경우, `root`의 왼쪽 자식 노드 4를 루트로 하는 서브트리가 `subRoot`와 정확히 일치하므로 `true`를 반환합니다. 반면, `root`에 추가적인 노드가 있거나 값이 다르면 `false`를 반환합니다.

주어진 제약 조건은 `root`의 노드 수가 최대 2000개, `subRoot`의 노드 수가 최대 1000개이며, 노드 값의 범위는 -10^4에서 10^4 사이입니다.

## 접근 방법

이 문제는 두 가지 하위 문제로 나누어 해결할 수 있습니다.

1. **동일 트리 판별**: 두 트리가 루트부터 모든 노드까지 구조와 값이 완전히 동일한지 확인하는 함수가 필요합니다.
2. **부분트리 탐색**: `root` 트리의 각 노드를 방문하며, 해당 노드를 루트로 하는 서브트리가 `subRoot`와 동일한지 확인합니다.

`root` 트리의 모든 노드를 순회하면서, 현재 노드가 `subRoot`의 루트와 값이 같다면 해당 서브트리가 `subRoot`와 같은지 깊이 우선 탐색(DFS)으로 확인합니다. 만약 값이 같지 않거나, 값이 같더라도 구조가 다르면 `root` 트리의 왼쪽 및 오른쪽 자식 노드로 재귀적으로 탐색을 이어갑니다.

## 풀이

`isSameTree` 함수로 두 트리의 동등성을 확인하고, `isSubtree` 함수로 `root`의 각 노드에서 부분트리 검사를 수행합니다.

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def isSubtree(self, root: Optional[TreeNode], subRoot: Optional[TreeNode]) -> bool:
        # subRoot가 비어있다면 빈 트리는 모든 트리의 부분트리임
        if not subRoot:
            return True
        # root가 비어있지만 subRoot는 비어있지 않다면 부분트리가 될 수 없음
        if not root:
            return False
        
        # 현재 노드를 루트로 하는 서브트리가 subRoot와 같은지 확인
        if self.isSameTree(root, subRoot):
            return True
        
        # 왼쪽 자식 또는 오른쪽 자식 노드에서 부분트리를 찾음
        return self.isSubtree(root.left, subRoot) or self.isSubtree(root.right, subRoot)

    def isSameTree(self, p: Optional[TreeNode], q: Optional[TreeNode]) -> bool:
        # 두 노드 모두 비어있으면 동일함
        if not p and not q:
            return True
        # 한쪽만 비어있거나 값이 다르면 동일하지 않음
        if not p or not q or p.val != q.val:
            return False
        
        # 왼쪽 서브트리와 오른쪽 서브트리가 모두 동일해야 함
        return self.isSameTree(p.left, q.left) and self.isSameTree(p.right, q.right)
```

시간복잡도: 최악의 경우 `root` 트리의 모든 노드에 대해 `isSameTree`를 호출하므로 $O(N \times M)$입니다. 여기서 $N$은 `root`의 노드 수, $M$은 `subRoot`의 노드 수입니다.
공간복잡도: 재귀 호출 스택의 깊이에 비례하므로 $O(N + M)$입니다.

## 다른 풀이 방법

**시리얼라이즈(Serialization) 및 문자열 매칭**

트리를 전위 순회 등을 통해 문자열로 변환한 후, `subRoot`의 문자열이 `root`의 문자열 부분문자열인지 확인하는 방법입니다.

1. `root`와 `subRoot`를 각각 고유한 문자열로 직렬화합니다. 이때 null 노드도 명시적으로 표현하여 구조적 구별이 가능해야 합니다.
2. `subRoot`의 직렬화 결과가 `root`의 직렬화 결과 안에 포함되는지 확인합니다.

이 방법은 해시 함수를 사용하여 직렬화 문자열의 해시값을 비교하는 방식으로 최적화할 수 있습니다. 해시 충돌을 고려해야 하므로, 해시값이 일치할 때 실제 트리를 비교하는 검증 단계를 추가하는 것이 안전합니다.

시간복잡도: 직렬화 과정이 $O(N + M)$이며, 문자열 매칭 또는 해시 탐색에 $O(N + M)$이 소요되므로 전체적으로 $O(N + M)$로 기대됩니다.
공간복잡도: 직렬화된 문자열 또는 해시값을 저장하는 데 $O(N + M)$의 공간이 필요합니다.

## 추가 참고사항

- **null 처리**: 직렬화 기반 접근법에서는 null 노드를 명확히 표시해야 합니다. 예를 들어, `#`나 `null` 문자를 사용하여 빈 자식을 표현하지 않으면 구조가 왜곡될 수 있습니다.
- **해시 충돌**: 해시 기반 접근법에서는 서로 다른 트리가 같은 해시값을 가질 확률(해시 충돌)이 존재합니다. 따라서 해시값이 일치하는 경우에만 실제 트리 비교를 수행하여 정확도를 보장해야 합니다.
- **제약 조건**: 노드 수가 2000개 이하이므로, 단순한 DFS 기반 $O(N \times M)$ 접근법으로도 충분히 허용 가능한 시간 내에 해결할 수 있습니다.
