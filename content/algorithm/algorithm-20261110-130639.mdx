## 문제

입력으로 정수 배열 `arr`가 주어집니다. 배열 안에 있는 정수 중, 해당 정수의 값과 배열 내 빈도수가 동일한 정수를 행운수(lucky integer)라고 정의합니다. 주어진 배열에서 가장 큰 행운수를 반환해야 하며, 행운수가 존재하지 않으면 `-1`을 반환합니다.

배열의 길이는 최대 500이며, 배열의 원소는 1 이상 500 이하입니다.

```python
arr = [1, 2, 2, 3, 3, 3]
```

위 예시에서는 1은 빈도 1, 2는 빈도 2, 3은 빈도 3을 가지므로 모두 행운수입니다. 이 중 가장 큰 값인 3을 반환해야 합니다.

## 접근 방법

가장 직관적이고 효율적인 접근은 각 숫자의 출현 빈도를 세는 것입니다. 배열을 순회하며 각 숫자의 출현 횟수를 해시 맵(딕셔너리)에 저장합니다. 이후 맵에 저장된 모든 항목을 확인하여 '값 == 빈도'인 경우를 찾습니다.

조건을 만족하는 숫자가 여러 개라면 그중 최대값을 구하면 됩니다. 배열 내 원소가 500 이하로 작으므로 해시 맵 조회는 매우 빠르며, 전체 배열을 한 번 또는 두 번 순회하므로 효율적입니다.

<Callout type="tip" title="핵심 조건">
행운수의 조건은 `해당 숫자 == 배열 내 그 숫자의 개수`입니다.
</Callout>

## 풀이

해시 맵을 사용하여 각 정수의 빈도를 계산하고, 조건을 만족하는 가장 큰 정수를 찾습니다.

```python
def findLucky(arr: list[int]) -> int:
    freq = {}
    
    # 각 숫자의 빈도수 세기
    for num in arr:
        freq[num] = freq.get(num, 0) + 1
        
    lucky = -1
    # 빈도수가 숫자 자체와 같은지 확인하며 최대값 찾기
    for num, count in freq.items():
        if num == count:
            lucky = max(lucky, num)
            
    return lucky
```

- **시간 복잡도**: $O(N)$
  배열의 길이만큼 순회하여 빈도를 세고, 해시 맵의 항목 수(최대 500)만큼 반복하므로 선형 시간입니다.
- **공간 복잡도**: $O(N)$
  고유한 숫자의 개수만큼 해시 맵에 데이터를 저장해야 합니다.

## 다른 풀이 방법

정렬을 활용한 접근이 가능합니다. 배열을 내림차순으로 정렬한 후, 각 숫자의 연속된 출현 횟수를 세며 조건을 만족하는지 확인합니다. 처음 조건을 만족하는 숫자가 가장 큰 숫자가 되므로 즉시 해당 숫자를 반환할 수 있습니다.

## 추가 참고사항

제한 사항으로 `arr.length`와 `arr[i]`가 모두 500 이하입니다. 이 경우 배열의 크기가 매우 작으므로, 빈도를 세기 위해 별도의 해시 맵 대신 크기가 501인 일반 배열을 카운트 배열로 사용할 수도 있습니다. 이 경우 해시 맵의 오버헤드를 제거하여 상수 시간 접근이 가능하지만, Python에서는 해시 맵이 충분히 빠르고 메모리 사용량도 문제되지 않으므로 해시 맵 방식이 권장됩니다.

```python
# 카운트 배열 활용 예시 (참고용)
count = [0] * 501
for num in arr:
    count[num] += 1

for i in range(500, 0, -1):
    if count[i] == i:
        return i
return -1
```

위 코드와 해시 맵 방식은 모두 $O(N)$ 시간 복잡도를 가지며, 카운트 배열 방식은 공간 복잡도 측면에서 배열의 최대값에 의존하는 한계가 있습니다.
