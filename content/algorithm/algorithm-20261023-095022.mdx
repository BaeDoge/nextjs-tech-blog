## 문제

정수 `n`이 주어졌을 때, `k`개의 행으로 구성된 계단을 만들려고 합니다. `i`번째 행에는 정확히 `i`개의 동전이 필요합니다. 마지막 행은 불완전할 수 있습니다. 주어진 `n`개의 동전으로 완성할 수 있는 계단의 완전한 행의 개수를 반환해야 합니다.

예를 들어 `n = 5`인 경우, 1행에 1개, 2행에 2개를 사용하여 총 3개를 소모하고, 3행에는 3개가 필요하지만 2개만 남으므로 3행은 완성되지 않습니다. 따라서 완성된 행의 수는 2입니다. 제약 조건으로 `n`의 범위는 `1` 이상 `2^31 - 1` 이하입니다.

## 접근 방법

완성된 행의 수를 `k`라고 할 때, `k`개의 행을 완성하는 데 필요한 동전의 총 개수는 `1 + 2 + ... + k`로 표현됩니다. 이는 등차수열의 합 공식에 따라 `k * (k + 1) / 2`가 됩니다.

우리는 `k * (k + 1) / 2 <= n`을 만족하는 가장 큰 정수 `k`를 찾아야 합니다. `k`가 증가함에 따라 필요한 동전 수도单调하게 증가하므로, 이분 탐색(Binary Search)을 적용할 수 있습니다. 탐색 범위는 최소 `1`, 최대 `n` (또는 더 효율적으로 `sqrt(2n)` 근사치)으로 설정합니다.

또한, 이차방정식 `k^2 + k - 2n = 0`의 양의 해를 구하는 수학적 접근도 가능합니다. 근의 공식에 따라 `k = (-1 + sqrt(1 + 8n)) / 2`가 되며, 이 값을 내림하여 정수로 만들면 정답이 됩니다.

## 풀이

이분 탐색을 사용하여 정답을 구하는 Python 코드는 다음과 같습니다. 탐색 공간에서 `mid`번째 행까지 완성했을 때 필요한 동전 수가 `n`보다 작거나 같다면, `mid`가 가능한 정답 후보이므로 `left`를 `mid + 1`로 늘려 더 큰 값을 탐색합니다. 반대의 경우 `right`를 `mid - 1`로 줄입니다.

```python
class Solution:
    def arrangeCoins(self, n: int) -> int:
        left = 1
        right = n
        
        while left <= right:
            mid = (left + right) // 2
            # mid개의 행을 완성하는 데 필요한 동전 수: mid * (mid + 1) / 2
            coins_needed = mid * (mid + 1) // 2
            
            if coins_needed == n:
                return mid
            elif coins_needed < n:
                left = mid + 1
            else:
                right = mid - 1
                
        return right
```

시간 복잡도: O(log n). 이분 탐색을 사용하므로 로그 시간이 소요됩니다.
공간 복잡도: O(1). 추가적인 메모리를 사용하지 않습니다.

## 다른 풀이 방법

수학적 접근(이차방정식 해법)을 사용할 수 있습니다. `k(k+1)/2 <= n` 부등식을 `k^2 + k - 2n <= 0`으로 변형하고 근의 공식을 적용합니다. 양의 해는 `(-1 + sqrt(1 + 8n)) / 2`입니다. 이 값을 정수로 변환하면 정답이 됩니다.

```python
import math

class Solution:
    def arrangeCoins(self, n: int) -> int:
        return int((-1 + math.sqrt(1 + 8 * n)) / 2)
```

시간 복잡도: O(1) 또는 O(log n) (제곱근 연산의 구현에 따라 다르나 일반적으로 상수 시간으로 간주).
공간 복잡도: O(1).
이분 탐색에 비해 코드 구현이 간단하지만, `n`이 매우 클 때 부동소수점 연산의 정밀도 문제가 발생할 수 있어 주의가 필요합니다. 이 문제의 제약 조건(`n <= 2^31 - 1`)에서는 부동소수점 오차가 발생하지 않아 안전하게 사용할 수 있습니다.

## 추가 참고사항

이 문제는 `n`의 범위가 `int`의 최대값에 가까우므로, `mid * (mid + 1)` 계산 시 오버플로우가 발생할 수 있는 언어(C/C++ 등)에서는 주의해야 합니다. Python은 큰 정수를 자동으로 처리하므로 문제가 없지만, 다른 언어를 사용할 경우 `long` 타입을 사용하거나 `mid` 계산 시 오버플로우를 방지하는 로직이 필요합니다.

또한, 이분 탐색의 종료 조건에서 `left > right`가 되면 `right`가 마지막 조건을 만족하는 가장 큰 값이 되므로, `right`를 반환하는 것이 올바른 패턴입니다.
