## 문제

LeetCode 485번 문제인 'Max Consecutive Ones'입니다.
이진 정수 배열 `nums`가 주어졌을 때, 배열 내에 존재하는 가장 긴 연속된 1의 길이(개수)를 반환해야 합니다.
배열의 요소는 0 또는 1로만 구성되며, 배열의 길이는 최대 10만입니다.
예를 들어, 입력이 `[1,1,0,1,1,1]`인 경우 첫 두 자리와 마지막 세 자리에 연속된 1이 있습니다.
이때 연속된 1의 최대 길이는 마지막 세 자리에 해당하는 3이 됩니다.
입력이 `[1,0,1,1,0,1]`인 경우, 가장 긴 연속된 1의 길이는 2입니다.

## 접근 방법

배열의 모든 요소를 순서대로 한 번만 방문하며 현재 연속된 1의 개수와 최대 길이를 추적합니다.
현재 요소가 1인 경우, 현재 연속된 1의 카운터를 1 증가시킵니다.
현재 요소가 0인 경우, 지금까지 기록한 최대 길이를 업데이트한 후 현재 카운터를 0으로 초기화합니다.
반복문 중간에 최댓값을 계속 갱신하면 반복문 종료 후 추가적인 비교 없이 최종 결과를 얻을 수 있습니다.
이 방식은 배열의 모든 원소를 한 번만 참조하므로 매우 효율적입니다.

## 풀이

배열을 한 번 순회하며 최대 연속 1의 길이를 계산하는 구현은 다음과 같습니다.
시간 복잡도는 모든 원소를 한 번씩 방문하므로 O(N)입니다.
공간 복잡도는 정수 변수 두 개만 사용하므로 O(1)입니다.

```python
class Solution:
    def findMaxConsecutiveOnes(self, nums: List[int]) -> int:
        max_count = 0
        current_count = 0
        
        for num in nums:
            if num == 1:
                current_count += 1
                if current_count > max_count:
                    max_count = current_count
            else:
                current_count = 0
                
        return max_count
```

## 다른 풀이 방법

문자열 처리 기능을 활용하여 반복문을 직접 구현하지 않고 해결할 수 있습니다.
배열의 정수들을 문자열로 변환한 후 '0'을 기준으로 분할합니다.
이렇게 생성된 부분 문자열들의 길이 중 최댓값을 구하면 됩니다.
구체적으로 `"".join(map(str, nums)).split('0')`을 수행하면 연속된 1들만 포함된 문자열 리스트를 얻을 수 있습니다.
이 후 `max` 함수로 가장 긴 문자열의 길이를 계산하되, 빈 문자열인 경우의 예외 처리를 위해 기본값 0을 설정합니다.
시간 복잡도는 여전히 O(N)이지만, 문자열 생성 및 분할 과정에서 추가적인 상수 시간이 소요됩니다.

```python
class Solution:
    def findMaxConsecutiveOnes(self, nums: List[int]) -> int:
        return max(map(len, "".join(map(str, nums)).split('0')), default=0)
```

## 추가 참고사항

알고리즘 풀이에서는 일반적으로 문자열 변환보다 직접적인 배열 순회가 메모리 오버헤드가 적어 선호됩니다.
배열의 끝에 연속된 1이 존재하는 경우를 대비하여 루프 내부에서 최대 값을 업데이트하는 방식이 안전합니다.
문제의 제약 조건에 따라 모든 요소가 0인 경우에도 최댓값 0을 정상적으로 반환합니다.
실제 코딩 테스트에서는 문자열 연산보다 직접적인 배열 순회 알고리즘의 가독성과 성능 안정성을 고려하는 것이 좋습니다.
