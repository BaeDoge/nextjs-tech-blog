## 문제

이진트리의 루트 노드가 주어졌을 때, 트리의 지름(diameter)을 반환해야 합니다. 트리의 지름은 임의의 두 노드 사이의 가장 긴 경로의 길이로 정의되며, 이 경로는 반드시 루트를 지나야 할 필요는 없습니다. 경로의 길이는 두 노드 사이에 있는 간선의 수로 계산됩니다. 트리의 노드 수는 1에서 10,000 사이이며, 노드의 값은 -100에서 100 사이의 정수입니다.

## 접근 방법

지름은 특정 노드를 기준으로 왼쪽 서브트리의 깊이와 오른쪽 서브트리의 깊이를 더한 값 중 최댓값입니다. 따라서 모든 노드를 방문하면서 각 노드를 루트로 하는 부분 트리에서의 지름을 계산하고, 그중 가장 큰 값을 찾으면 됩니다. 이를 위해 깊이 우선 탐색(DFS)을 사용합니다. 재귀적으로 각 노드의 왼쪽 자식과 오른쪽 자식의 깊이를 구한 후, 현재 노드를 경유하는 경로 길이(왼쪽 깊이 + 오른쪽 깊이)를 전역 변수 또는 참조 변수로 업데이트합니다.

## 풀이

DFS 함수는 현재 노드를 기준으로 서브트리의 높이를 반환합니다. 함수 실행 중 `diameter` 변수를 갱신하여 최대 지름을 추적합니다.

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def diameterOfBinaryTree(self, root: Optional[TreeNode]) -> int:
        self.diameter = 0
        
        def dfs(node: Optional[TreeNode]) -> int:
            if not node:
                return 0
            
            # 왼쪽 서브트리의 깊이
            left_depth = dfs(node.left)
            # 오른쪽 서브트리의 깊이
            right_depth = dfs(node.right)
            
            # 현재 노드를 경유하는 지름 업데이트
            self.diameter = max(self.diameter, left_depth + right_depth)
            
            # 현재 노드를 루트로 하는 서브트리의 높이 반환
            return 1 + max(left_depth, right_depth)
        
        dfs(root)
        return self.diameter
```

시간복잡도: $O(N)$. 모든 노드를 정확히 한 번 방문합니다.
공간복잡도: $O(H)$. 재귀 호출 스택의 깊이는 트리의 높이 $H$에 비례합니다. 최악의 경우 $O(N)$, 균형 잡힌 트리의 경우 $O(\log N)$입니다.

## 다른 풀이 방법

이 문제는 DP on Trees 관점에서도 해석할 수 있습니다. 각 노드에 대해 `(높이, 지름)` 쌍을 반환하는 재귀 함수를 구현할 수 있습니다. 이 경우 전역 변수나 클래스 멤버 변수를 사용하지 않고 순수하게 함수의 반환값만으로 상태를 관리할 수 있습니다.

```python
class Solution:
    def diameterOfBinaryTree(self, root: Optional[TreeNode]) -> int:
        def dfs(node: Optional[TreeNode]) -> tuple:
            if not node:
                return 0, 0
            
            left_height, left_diameter = dfs(node.left)
            right_height, right_diameter = dfs(node.right)
            
            current_height = 1 + max(left_height, right_height)
            current_diameter = max(left_diameter, right_diameter, left_height + right_height)
            
            return current_height, current_diameter
        
        _, max_diameter = dfs(root)
        return max_diameter
```

이 방법도 시간복잡도 $O(N)$, 공간복잡도 $O(H)$를 가집니다. 전역 변수 사용 여부만 다를 뿐 알고리즘의 핵심 로직과 효율성은 동일합니다.

## 추가 참고사항

지름의 정의를 명확히 이해해야 합니다. 지름은 '루트를 지나는 가장 긴 경로'가 아니라 '임의의 두 노드 사이의 가장 긴 경로'입니다. 따라서 루트를 지나지 않는 경로가 더 길 수 있으므로, 각 노드를 경유하는 경우를 모두 고려해야 합니다. 또한, 트리의 높이는 루트에서 리프 노드까지의 간선 수로 정의되는 경우가 많지만, 이 문제에서는 노드 수나 간선 수의 일관성을 위해 깊이 계산 시 기준을 명확히 해야 합니다. 본 풀이에서는 리프 노드의 깊이를 0으로 보고, 자식 노드의 깊이에 1을 더하는 방식을 사용했습니다.
