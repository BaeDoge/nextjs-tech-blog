## 문제

조화로운 배열은 최댓값과 최솟값의 차이가 정확히 1인 배열을 의미합니다. 정수 배열 `nums`가 주어졌을 때, 가능한 부분 수열(subsequence) 중 가장 긴 조화로운 부분 수열의 길이를 반환해야 합니다. 부분 수열은 원래 배열의 요소를 순서를 유지하면서 일부 제거하여 얻을 수 있는 배열입니다. 배열의 길이는 최대 20,000이며, 요소 값의 범위는 -10^9에서 10^9입니다. 모든 요소가 동일한 경우 조화로운 부분 수열이 존재하지 않으므로 0을 반환합니다.

## 접근 방법

조화로운 부분 수열의 조건은 '최댓값과 최솟값의 차이가 1'입니다. 이는 부분 수열에 포함되는 숫자가 정확히 두 가지이며, 그 값이 `x`와 `x+1`로 이어지는 정수여야 함을 의미합니다. 따라서 배열 내 각 숫자의 등장 횟수를 세어두면, `x`와 `x+1`의 등장 횟수의 합이 가장 큰 경우를 찾으면 됩니다. 이때 각 숫자의 등장 횟수를 저장하기 위해 해시맵을 사용하면 효율적으로 해결할 수 있습니다. 배열을 정렬하거나 슬라이딩 윈도우를 사용할 수도 있으나, 해시맵 기반 접근이 구현이 가장 간단하고 명확합니다.

## 풀이

먼저 `Counter`를 사용하여 배열 `nums`에 있는 각 숫자의 등장 횟수를 계산합니다. 이후 해시맵을 순회하며 현재 숫자 `num`과 `num + 1`이 모두 존재하는지 확인합니다. 두 숫자가 모두 존재하면, 두 숫자의 등장 횟수를 합친 값이 현재까지의 최대 길이보다 큰지 비교하여 갱신합니다. 최종적으로 계산된 최대 길이를 반환합니다.

```python
from collections import Counter

class Solution:
    def findLHS(self, nums: List[int]) -> int:
        count = Counter(nums)
        longest = 0
        
        for num in count:
            if num + 1 in count:
                longest = max(longest, count[num] + count[num + 1])
                
        return longest
```

시간복잡도: O(N). 요소의 등장 횟수를 세는 데 O(N)이 소요되며, 해시맵을 순회하는 데에도 고유한 요소 수인 최악의 경우 O(N)이 소요됩니다.
공간복잡도: O(N). 각 고유한 숫자의 등장 횟수를 저장하기 위한 해시맵의 크기는 고유 요소 수에 비례합니다.

## 다른 풀이 방법

**정렬 후 투 포인터(Two Pointers)** 기법을 사용할 수 있습니다. 배열을 정렬하면 동일한 숫자들이 연속되어 배치되고, 숫자가 증가하는 순서대로 정렬됩니다. 이후 투 포인터를 사용하여 `nums[right] - nums[left]`의 차이가 1이 되는 구간을 찾습니다. 차이가 1보다 작으면 `right`를 증가시키고, 차이가 1보다 크면 `left`를 증가시킵니다. 차이가 1일 경우 현재 구간의 길이를 갱신합니다. 이 방법은 해시맵 사용 시 추가 공간을 필요로 하지 않아 공간복잡도 측면에서 유리할 수 있으나, 정렬 과정에서 O(N log N)의 시간이 소요되어 일반적인 경우 해시맵 방식보다 느릴 수 있습니다.

시간복잡도: O(N log N)
공간복잡도: O(1) 또는 O(N) (정렬 알고리즘 구현에 따라 다름)

## 추가 참고사항

조화로운 부분 수열은 배열의 순서를 유지하면서 요소를 선택해야 하므로, 정렬이나 슬라이딩 윈도우를 사용할 때는 주의가 필요합니다. 하지만 이 문제의 핵심 조건인 '최댓값과 최솟값의 차이'는 부분 수열을 구성하는 숫자들의 집합(set)에만 의존하므로, 배열의 원본 순서는 결과에 영향을 주지 않습니다. 따라서 요소의 등장 횟수만 정확히 세면 문제의 조건을 만족하는 가장 긴 부분 수열의 길이를 쉽게 구할 수 있습니다.
