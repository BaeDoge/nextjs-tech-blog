## 문제

정수 배열 `nums`가 주어집니다. 이 배열에서 다수 요소(Majority Element)를 반환하는 함수를 구현해야 합니다. 다수 요소란 배열의 크기 `n`에 대해 `n / 2`번보다 더 많이 등장하는 요소를 의미합니다. 입력 배열에는 항상 다수 요소가 존재한다고 가정합니다.

예를 들어, 길이가 3인 배열 `[3, 2, 3]`에서 다수 요소는 3이며, 길이가 7인 배열 `[2, 2, 1, 1, 1, 2, 2]`에서 다수 요소는 2입니다. 제약 조건으로 배열의 길이는 최대 50,000이며, 요소의 값 범위는 -10^9에서 10^9 사이입니다.

## 접근 방법

가장 직관적인 방법은 해시맵이나 정렬을 이용하는 것이지만, 추가 요구사항인 `O(1)` 공간 복잡도를 만족하려면 별도의 자료 구조를 사용할 수 없습니다. 이때 보이어-모어 다수결 투표 알고리즘(Boyer–Moore Majority Vote Algorithm)을 적용할 수 있습니다.

이 알고리즘의 핵심 아이디어는 '상대방과 대립하여 소멸'하는 것입니다. 서로 다른 두 요소를 만나면 둘 다 제거한다고 가정하면, 최종적으로 남아있는 요소가 다수 요소가 됩니다. 다수 요소가 전체의 절반을 초과하므로, 나머지 모든 요소가 다수 요소를 모두 제거하더라도 다수 요소는 최소 하나 남게 됩니다.

따라서 현재 후보 요소와 그 요소가 등장한 횟수(카운트)를 변수로 유지하며 배열을 순회합니다. 카운트가 0이 되면 새로운 후보를 설정하고, 현재 요소가 후보와 같으면 카운트를 증가시킵니다. 다르면 카운트를 감소시킵니다.

## 풀이

보이어-모어 알고리즘을 사용하여 다수 요소를 찾는 코드는 다음과 같습니다. 배열을 한 번 순회하며 후보와 카운트를 업데이트합니다.

```python
class Solution:
    def majorityElement(self, nums: list[int]) -> int:
        candidate = None
        count = 0
        
        for num in nums:
            if count == 0:
                candidate = num
            if num == candidate:
                count += 1
            else:
                count -= 1
                
        return candidate
```

이 코드는 배열의 길이 `n`에 대해 한 번의 반복문으로 처리되므로 시간 복잡도는 `O(n)`입니다. 추가적인 배열이나 해시맵을 사용하지 않고 두 개의 정수 변수만 사용하므로 공간 복잡도는 `O(1)`입니다. 문제에서 다수 요소가 항상 존재함을 보장하므로, 최종적으로 `candidate`에 저장된 값이 정답입니다.

## 다른 풀이 방법

다른 접근법으로는 정렬(Sorting)을 이용하는 방법이 있습니다. 배열을 정렬하면 다수 요소는 항상 중간 인덱스(`n // 2`)에 위치하게 됩니다. 따라서 정렬 후 해당 인덱스의 값을 반환하면 됩니다.

시간 복잡도는 정렬 알고리즘에 따라 `O(n log n)`이 되며, 공간 복잡도는 언어의 정렬 구현에 따라 `O(1)` 또는 `O(n)`이 될 수 있습니다. 하지만 추가 요구사항인 `O(n)` 시간 복잡도를 만족하지 못합니다.

또 다른 방법으로는 해시맵(Hash Table)을 사용하여 각 요소의 등장 횟수를 세는 방법이 있습니다. 모든 요소의 등장 횟수를 기록한 후, `n / 2`를 초과하는 요소를 찾습니다. 시간 복잡도는 `O(n)`이지만, 최악의 경우 `O(n)`의 공간 복잡도가 소요되어 `O(1)` 공간 조건을 만족하지 못합니다.

## 추가 참고사항

보이어-모어 다수결 투표 알고리즘은 다수 요소가 반드시 존재한다는 전제 하에 정확합니다. 만약 다수 요소가 존재하지 않을 가능성이 있는 문제라면, 알고리즘을 통해 찾은 후보 요소가 실제로 다수 요소인지 확인하기 위해 한 번 더 배열을 순회하여 등장 횟수를 세는 검증 과정이 필요합니다. 이 경우에도 시간 복잡도는 `O(n)`, 공간 복잡도는 `O(1)`을 유지합니다.

이 알고리즘은 다수 요소뿐만 아니라, 등장 횟수가 `n / k` 이상인 요소를 찾는 확장 문제(k-majority element)로도 적용될 수 있습니다. 이 경우 `k-1`개의 후보와 카운트를 유지하며 알고리즘을 확장할 수 있습니다.
