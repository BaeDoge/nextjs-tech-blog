## 문제

정수 배열 `nums`가 주어집니다. 배열의 'degree'는 배열 내에서 가장 자주 등장하는 원소의 빈도수입니다. 이 문제에서는 주어진 배열 `nums`와 동일한 degree를 갖는 가장 짧은 길이의 연속 부분배열(subarray)의 길이를 반환해야 합니다. 부분배열은 배열의 연속된 요소들의 모임입니다.

## 접근 방법

먼저 입력 배열 `nums`의 degree를 결정하는 요소들을 찾아야 합니다. 이를 위해 각 숫자의 등장 횟수를 세어야 합니다. 등장 횟수가 최대인 숫자들(여러 개일 수 있음)이 degree를 결정합니다.

그 다음, 각 'degree 결정자' 숫자에 대해 그 숫자가 처음 등장하는 인덱스와 마지막으로 등장하는 인덱스를 기록합니다. 해당 숫자를 포함하는 가장 짧은 연속 부분배열의 길이는 `마지막 인덱스 - 처음 인덱스 + 1`로 계산할 수 있습니다.

모든 degree 결정자에 대해 이 길이를 계산한 후, 그 중 최솟값을 구하면 정답이 됩니다. 이 과정을 효율적으로 수행하기 위해 해시맵을 사용하여 한 번의 순회로 필요한 정보를 모두 수집할 수 있습니다.

## 풀이

`first`, `last`, `count` 세 가지 해시맵을 사용합니다.
1. 배열을 순회하며 각 숫자의 등장 횟수를 `count`에 저장합니다.
2. 첫 등장 시점이라면 `first`에 인덱스를 저장합니다.
3. 마지막 등장 시점이라면 `last`에 인덱스를 업데이트합니다.
4. 순회 후 `count` 해시맵을 반복하며, 최대 빈도수(`degree`)를 찾습니다.
5. 해당 빈도수를 갖는 숫자들의 `last[key] - first[key] + 1` 중 최솟값을 구합니다.

시간복잡도: O(n) - 배열을 두 번 순회합니다(한 번은 정보 수집, 한 번은 결과 계산).
공간복잡도: O(n) - 해시맵에 최대 n개의 키를 저장합니다.

```python
class Solution:
    def findShortestSubArray(self, nums: List[int]) -> int:
        from collections import defaultdict
        
        first = {}
        last = {}
        count = defaultdict(int)
        
        for i, x in enumerate(nums):
            if x not in first:
                first[x] = i
            last[x] = i
            count[x] += 1
            
        degree = max(count.values())
        min_length = len(nums)
        
        for x in count:
            if count[x] == degree:
                length = last[x] - first[x] + 1
                if length < min_length:
                    min_length = length
                    
        return min_length
```

## 다른 풀이 방법

전체 배열을 순회하지 않고 슬라이딩 윈도우 기법을 사용할 수 있습니다. 그러나 이 문제의 경우 '최종적인 degree가 무엇인지'를 사전에 알 수 없기 때문에, 일반적인 슬라이딩 윈도우(두 포인터) 접근법은 적합하지 않습니다. 슬라이딩 윈도우는 보통 조건을 만족하는 가장 큰/작은 범위를 찾을 때 유용하며, 여기서는 최대 빈도수라는 전제 조건이 필요합니다. 따라서 해시맵을 사용한 방법이 가장 명확하고 효율적인 접근입니다.

완전 탐색으로 모든 부분배열을 검사하는 방법은 O(n^3) 또는 O(n^2)의 시간복잡도를 가지므로, 제약 조건(n <= 50,000)에서 시간 초과가 발생합니다.

## 추가 참고사항

- 입력 배열 `nums`의 길이는 1 이상 50,000 이하이며, 요소 값은 0 이상 49,999 이하입니다.
- degree를 결정하는 원소가 여러 개일 수 있으므로, 모든 경우를 고려하여 최단 길이를 찾아야 합니다.
- 해시맵 대신 고정 크기 배열(크기 50,000)을 사용하여 빈도수와 인덱스를 저장할 수도 있으나, 메모리 사용량이 증가할 수 있으므로 해시맵이 일반적으로 선호됩니다.
- Python에서는 `collections.defaultdict`를 사용하면 빈도수 카운팅 코드를 간결하게 작성할 수 있습니다.
