## 문제

정수 배열 `nums`와 정수 `target`이 주어집니다. 배열에서 두 수를 선택해 그 합이 `target`이 되도록 하고, 해당 두 수의 인덱스를 반환해야 합니다. 각 입력에는 정확히 하나의 해답만 존재하며, 같은 원소를 두 번 사용할 수 없습니다. 반환 순서는 상관없습니다.

예를 들어 `nums = [2, 7, 11, 15]`, `target = 9`일 때, `nums[0] + nums[1] == 9`이므로 `[0, 1]`을 반환합니다. 제약 조건으로 배열 길이는 2 이상 10^4 이하이며, 숫자와 타겟 값의 범위는 -10^9에서 10^9 사이입니다.

## 접근 방법

두 수의 합을 찾는 문제는 일반적으로 완전 탐색(Brute Force)을 통해 접근할 수 있습니다. 두 개의 중첩 루프를 사용하여 모든 쌍의 합을 확인하면 해답을 찾을 수 있지만, 이 방법은 시간 복잡도가 O(n^2)으로 비효율적입니다.

따라서 시간 복잡도를 줄이기 위해 해시맵(Hash Map)을 활용하는 방법을 고려합니다. 배열을 순회하면서 현재 숫자 `num`에 대해 `target - num`인 값이 이전에 등장했는지 확인합니다. 해시맵에는 이미 방문한 숫자와 그 인덱스를 저장하므로, 필요한 숫자가 존재하면 즉시 해답을 찾을 수 있습니다.

이 방식은 각 원소를 한 번씩만 탐색하며 해시맵 조회가 평균 O(1)에 수행되므로 전체 시간 복잡도를 O(n)으로 개선할 수 있습니다. 공간 복잡도는 저장되는 해시맵의 크기만큼 O(n)이 소요됩니다.

## 풀이

해시맵을 사용하여 현재 숫자와 필요한 보충 숫자를 관리하는 Python 코드입니다.

```python
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        num_map = {}
        
        for i, num in enumerate(nums):
            complement = target - num
            
            if complement in num_map:
                return [num_map[complement], i]
            
            num_map[num] = i
            
        return []
```

위 코드의 시간 복잡도는 배열을 한 번 순회하므로 O(n)입니다. 공간 복잡도는 최악의 경우 모든 원소를 해시맵에 저장해야 하므로 O(n)입니다.

## 다른 풀이 방법

완전 탐색(Brute Force) 방식을 사용할 수 있습니다. 두 개의 인덱스 `i`와 `j`에 대해 모든 가능한 조합을 확인합니다.

```python
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        n = len(nums)
        for i in range(n):
            for j in range(i + 1, n):
                if nums[i] + nums[j] == target:
                    return [i, j]
        return []
```

이 방법은 추가적인 자료 구조를 사용하지 않아 공간 복잡도가 O(1)이지만, 모든 쌍을 확인해야 하므로 시간 복잡도가 O(n^2)입니다. 제약 조건에서 배열 길이가 최대 10^4이므로 n^2은 10^8에 달해 시간 초과 가능성이 높습니다. 따라서 해시맵을 이용한 O(n) 접근법이 더 효율적입니다.

## 추가 참고사항

해시맵을 이용한 풀이는 정렬된 배열이나 중복 원소가 있는 경우에도 동일하게 적용 가능합니다. 문제에서 '정확히 하나의 해답만 존재한다'는 조건이 있으므로, 해답을 찾으면 즉시 루프를 종료하고 반환하면 됩니다.

추가적으로, 배열이 이미 정렬되어 있다면 투 포인터(Two Pointer) 기법을 사용할 수도 있습니다. 왼쪽 포인터와 오른쪽 포인터를 시작하여 합이 타겟보다 작으면 왼쪽을 늘리고, 크면 오른쪽을 줄이는 방식입니다. 하지만 원본 인덱스를 반환해야 하므로 별도의 인덱스 저장 과정이 필요하며, 정렬된 상태가 아닌 일반 배열에는 직접 적용하기 어렵습니다.
