## 문제

정수 배열 `nums`가 주어졌을 때, 해당 배열을 정렬한 상태에서 인접한 두 요소 간의 최대 차이(maximum gap)를 반환해야 합니다. 배열의 요소 수가 2개 미만인 경우 0을 반환합니다. 알고리즘은 선형 시간(linear time)과 선형 보조 공간(linear extra space)을 사용해야 합니다. 예시로 `[3, 6, 9, 1]`을 정렬하면 `[1, 3, 6, 9]`가 되며, 인접 요소 간 차이는 2, 3, 3이므로 최대 차이는 3입니다. 제약 조건으로 배열의 길이는 10^5까지, 요소의 값은 10^9까지 가능하지만, 단순 정렬을 사용하면 O(N log N)의 시간이 걸리므로 버킷 정렬이나 라디정렬 등 선형 시간 정렬 기법을 사용해야 합니다.

## 접근 방법

선형 시간 O(N)에 정렬된 상태의 인접 요소 간 최대 차이를 찾기 위해 버킷 정렬(Bucket Sort) 원리를 활용합니다. 최대 간격은 최소 값(`min`)과 최대 값(`max`) 사이에 균일하게 분포된 버킷을 만들어 계산할 수 있습니다. 배열의 크기 N이 n개일 때, 최대 간격의 하한값은 `(max - min) / (n - 1)` 이상입니다. 따라서 버킷의 크기를 이 하한값으로 설정하면, 최대 간격은 반드시 같은 버킷 내부가 아닌 서로 다른 버킷 사이에 존재하게 됩니다. 이를 통해 각 버킷의 최소값과 최대값만 추적하면 되므로, 전체 정렬 없이 최대 간격을 계산할 수 있습니다.

## 풀이

최소값 `min_val`과 최대값 `max_val`을 찾은 후, 버킷의 개수와 크기를 계산합니다. 버킷의 크기는 `(max_val - min_val) // (n - 1)`로 구하고 0보다 크도록 조정합니다. 버킷의 개수는 전체 범위를 버킷 크기로 나눈 값에 1을 더합니다. 각 버킷에는 해당 범위에 속하는 최소값과 최대값을 저장합니다. 빈 버킷은 건너뛰고, 이전 버킷의 최대값과 현재 버킷의 최소값의 차이와 현재 버킷 내부의 차이를 비교하여 최대 간격을 구합니다.

```python
import math

class Solution:
    def maximumGap(self, nums: list[int]) -> int:
        if len(nums) < 2:
            return 0
        
        min_val, max_val = min(nums), max(nums)
        if min_val == max_val:
            return 0
        
        n = len(nums)
        # 버킷 크기 계산: 최소 간격의 하한값을 정수로 계산
        # 이 값보다 작은 버킷 크기를 쓰면 버킷 개수가 너무 늘어나 O(N) 공간 제약 위반 가능
        bucket_size = (max_val - min_val) // (n - 1)
        if bucket_size == 0:
            bucket_size = 1
            
        # 버킷 개수 계산
        bucket_count = (max_val - min_val) // bucket_size + 1
        
        # 버킷 초기화: 각 버킷은 [min, max]를 담으며 초기값은 None
        buckets_min = [None] * bucket_count
        buckets_max = [None] * bucket_count
        
        # 각 값을 해당 버킷에 배정
        for num in nums:
            idx = (num - min_val) // bucket_size
            if buckets_min[idx] is None:
                buckets_min[idx] = num
                buckets_max[idx] = num
            else:
                buckets_min[idx] = min(buckets_min[idx], num)
                buckets_max[idx] = max(buckets_max[idx], num)
        
        max_gap = 0
        prev_max = min_val
        
        # 버킷을 순회하며 최대 간격 계산
        for i in range(bucket_count):
            if buckets_min[i] is None:
                continue
            # 현재 버킷의 최소값과 이전 버킷의 최대값 사이의 차이
            max_gap = max(max_gap, buckets_min[i] - prev_max)
            prev_max = buckets_max[i]
            
        return max_gap
```

시간복잡도: O(N) - 배열을 두 번 순회하고 버킷 개수는 N에 비례합니다.
공간복잡도: O(N) - 버킷 배열을 위해 N 크기의 공간을 사용합니다.

## 다른 풀이 방법

라디정렬(Radix Sort)을 사용할 수 있습니다. 라디정렬은 자릿수 단위(1의 자리, 10의 자리 등)로 정렬을 반복하며, 안정 정렬 기법(Counting Sort 등)을 사용합니다. 전체 정렬이 완료된 후 인접 요소의 차이를 계산하면 최대 간격을 구할 수 있습니다. 시간복잡도는 O(D * N)이며, 여기서 D는 최대 값의 자릿수(최대 10)이므로 사실상 O(N)으로 볼 수 있습니다. 공간복잡도는 O(N + K)(K는 자릿수의 기수, 보통 10)입니다. 버킷 정렬보다는 구현이 다소 복잡할 수 있으나, 정수 정렬에 특화된 선형 시간 정렬 기법으로 유효합니다.

## 추가 참고사항

버킷 정렬을 사용한 해법에서 버킷 크기가 `(max - min) / (n - 1)`인 이유는, 만약 이보다 작은 크기로 버킷을 나누면 푸아즈홀 원리에 의해 어떤 버킷에 두 개 이상의 요소가 들어갈 수밖에 없으며, 이는 최대 간격이 버킷 외부(서로 다른 버킷 사이)에 존재한다는 성질과 모순될 수 있습니다. 실제로 최대 간격은 같은 버킷 내부가 아닌 인접한 빈 버킷을 건너뛴 두 버킷 사이에 발생한다는 점을 이용해 효율적으로 계산합니다. 이 접근법은 정렬 기반 O(N log N) 해법보다 제약 조건인 선형 시간 요구사항을 명확히 만족합니다.
