## 문제

주어진 문자열 `paragraph`와 금지된 단어들의 배열 `banned`가 입력으로 주어집니다. `paragraph` 내에서 `banned`에 포함되지 않은 단어 중 가장 많이 등장하는 단어를 반환해야 합니다.

문제는 다음과 같은 조건을 따릅니다.
- 단어는 대소문자를 구별하지 않으며, 반환 값은 소문자여야 합니다.
- 구두점 기호는 단어의 일부가 될 수 없으므로 무시해야 합니다.
- 정답은 항상 유일하게 존재하며, 최소 한 개 이상의 금지되지 않은 단어가 존재합니다.

예를 들어, `paragraph`가 "Bob hit a ball, the hit BALL flew far after it was hit."이고 `banned`가 ["hit"]인 경우, "hit"은 3번 등장하지만 금지되었으므로 제외됩니다. "ball"은 2번 등장하므로 정답이 됩니다.

## 접근 방법

문제를 해결하기 위해서는 문자열을 처리하고 단어의 등장 횟수를 세는 과정이 필요합니다. 핵심 단계는 다음과 같습니다.

1. **정규화**: 입력 `paragraph`를 소문자로 변환하여 대소문자 구분을 없앱니다.
2. **단어 추출**: 구두점 기호를 공백으로 대체하거나 정규식을 사용하여 영문 알파벳으로만 구성된 단어들을 분리합니다.
3. **빈도 계산**: 분리된 단어들의 등장 횟수를 `HashMap`을 사용하여 기록합니다.
4. **최대값 탐색**: `HashMap`을 순회하며 `banned` 집합에 포함되지 않은 단어 중 가장 높은 빈도를 가진 단어를 찾습니다.

<Callout type="tip" title="구두점 처리">
구두점을 공백으로 치환한 후 공백을 기준으로 split하면, 구두점이 단어 양옆에 붙어 있어도 자연스럽게 단어로 분리할 수 있습니다.
</Callout>

## 풀이

먼저 `banned` 배열을 빠른 조회를 위한 `HashSet`으로 변환합니다. `paragraph`는 소문자로 변환한 후, 영문 알파벳이 아닌 문자를 공백으로 대체합니다. 이후 공백을 기준으로 단어를 분리하고, 각 단어의 등장 횟수를 카운팅합니다. 마지막으로 금지된 단어를 제외하고 가장 빈도가 높은 단어를 선택합니다.

```python
import re
from collections import Counter

class Solution:
    def mostCommonWord(self, paragraph: str, banned: list[str]) -> str:
        # banned 배열을 빠른 조회를 위한 집합으로 변환
        banned_set = set(banned)
        
        # 소문자로 변환하고, 영문 알파벳이 아닌 문자를 공백으로 대체
        # re.sub(r'[^a-z]', ' ', paragraph.lower())와 동일
        words = re.findall(r'\b[a-z]+\b', paragraph.lower())
        
        # 단어 빈도 계산
        word_counts = Counter(words)
        
        # most_common(1)은 가장 빈도가 높은 (단어, 빈도) 튜플을 반환
        # banned 목록에 없는 단어를 찾기 위해 필터링
        for word, count in word_counts.most_common():
            if word not in banned_set:
                return word
                
        return ""
```

- **시간 복잡도**: $O(N + M)$, 여기서 $N$은 `paragraph`의 길이, $M$은 `banned`의 길이입니다. 문자열 처리와 해시맵 삽입/조회가 선형 시간에 수행됩니다.
- **공간 복잡도**: $O(N + M)$, 단어들을 저장하기 위한 해시맵과 집합의 크기에 비례합니다.

## 다른 풀이 방법

정규식 대신 문자열의 각 문자를 직접 순회하며 단어를 구성하는 방법도 있습니다.

1. `paragraph`를 소문자로 변환합니다.
2. 문자를 하나씩 읽으며 알파벳인 경우 현재 단어에 추가합니다.
3. 알파벳이 아닌 경우, 현재까지 모은 단어가 비어있지 않다면 카운터에 추가하고 단어를 초기화합니다.
4. 루프 종료 후 마지막 단어도 처리합니다.

이 방법은 라이브러리 의존성을 줄일 수 있지만, 코드가 길어지고 구두점 처리 로직을 직접 구현해야 하므로 가독성과 유지보수성에서 정규식 기반 접근보다 떨어질 수 있습니다. 시간 복잡도는 동일하게 $O(N)$입니다.

## 추가 참고사항

- **입력 제약 조건**: `paragraph`의 길이는 최대 1000, `banned`의 길이는 최대 100입니다. 이는 $O(N)$ 또는 $O(N^2)$ 알고리즘 모두 허용되지만, 해시맵을 사용한 $O(N)$ 접근이 최적입니다.
- **단어 정의**: 문제에서 'word'는 영문 알파벳으로만 구성된 문자열을 의미합니다. 숫자나 특수문자는 단어로 간주되지 않습니다.
- **대소문자**: 입력과 비교 시 모두 소문자로 통일하는 것이 중요합니다. `banned` 배열의 단어들도 소문자로 주어지므로, 직접 비교할 때 대소문자 변환이 필요하지 않습니다.
