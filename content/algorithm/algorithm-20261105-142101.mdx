## 문제

문자열 s가 주어집니다. 단어의 순서는 유지하면서 각 단어에 포함된 문자만 역순으로 바꿔야 합니다. 단어 사이의 공백도 입력과 동일하게 유지합니다.

예를 들어 "Let's take LeetCode contest"는 "s'teL ekat edoCteeL tsetnoc"로 바뀝니다.

## 접근 방법

Python 문자열은 immutable이므로 먼저 문자열을 문자 리스트로 변환합니다. 이후 두 포인터로 각 단어의 시작과 끝을 찾고, 단어 내부의 양 끝 문자를 교환합니다. 공백을 만나면 해당 단어 처리를 마치고 다음 단어로 이동합니다.

## 풀이

~~~~python
def reverseWords(s: str) -> str:
    chars = list(s)
    n = len(chars)
    i = 0

    while i < n:
        start = i

        while i < n and chars[i] != " ":
            i += 1

        left, right = start, i - 1
        while left < right:
            chars[left], chars[right] = chars[right], chars[left]
            left += 1
            right -= 1

문자열을 리스트로 변환한 뒤 두 포인터로 각 단어 내부의 문자를 교환합니다. 시간 복잡도는 O(n), 추가 공간 복잡도는 O(n)입니다. Python 문자열은 불변 객체이므로 리스트 변환과 결과 문자열 생성을 위한 공간이 필요합니다.

    return "".join(chars)
~~~~

문자열을 문자 리스트로 복사하고 마지막에 다시 문자열로 결합하므로 시간 복잡도와 추가 공간 복잡도는 모두 O(n)입니다.

## 다른 풀이 방법

공백을 기준으로 단어를 나눈 뒤 각 단어를 슬라이스로 뒤집어 다시 결합할 수 있습니다.

~~~~python
def reverseWords(s: str) -> str:
    return " ".join(word[::-1] for word in s.split(" "))
~~~~

이 방법 역시 단어를 나누고 새 문자열을 생성하므로 시간 복잡도와 추가 공간 복잡도는 O(n)입니다. 구현이 간결하다는 장점이 있습니다.

## 추가 참고사항

- 이 문제에서 뒤집는 대상은 단어의 순서가 아니라 각 단어 안의 문자 순서입니다.
- Python의 문자열은 immutable이므로 문자 리스트를 사용하거나 슬라이스 결과를 새 문자열로 결합해야 합니다.
- 입력에 연속 공백이 존재할 수 있는 일반적인 상황에서도 공백을 보존하려면 split(" ")처럼 구분자를 명시하거나 문자 단위로 처리해야 합니다. 기본 split()은 연속 공백을 하나로 취급해 원래 공백 구조를 바꿀 수 있습니다.
