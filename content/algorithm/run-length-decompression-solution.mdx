## 문제

주어진 `nums` 배열은 런-엔코딩 방식으로 압축된 정수들의 목록입니다. 인덱스 0과 1은 첫 번째 쌍, 인덱스 2와 3은 두 번째 쌍, 이와 같이 짝수 인덱스와 홀수 인덱스가 한 쌍을 이루며 각 쌍은 `(freq, val)`로 해석됩니다. 여기서 `freq`는 `val`이 반복되는 횟수이고, 각 쌍에 대해 `freq`개의 `val`을 이어 붙여 부분 배열을 생성합니다. 모든 부분 배열을 순서대로 연결하면 해독된 배열이 됩니다. 이 과정을 통해 원본 배열을 복원하고 그 결과를 반환해야 합니다.

## 접근 방법

주어진 배열을 2개씩 묶어 순회하며 각 쌍을 처리하는 기본적인 접근 방식을 사용합니다. 인덱스를 2씩 증가시키며 `freq`와 `val`을 추출한 뒤, `extend`를 통해 결과를 누적합니다. 이 방법은 문제의 구조를 그대로 반영하며 구현이 직관적입니다. 또한 `zip`이나 `enumerate`를 활용한 더 간결한 패턴도 고려할 수 있습니다.

## 풀이

```python
def decompressRLElist(nums):
    result = []
    for i in range(0, len(nums), 2):
        freq, val = nums[i], nums[i+1]
        result.extend([val] * freq)
    return result
```

이 구현은 `range`를 2씩 건너뛰어 쌍을 처리하고, `extend`를 통해 각 쌍의 값을 결과 리스트에 추가합니다. 시간 복잡도는 O(n)이며, 추가로 생성된 결과 배열의 크기가 n과 동일하므로 공간 복잡도도 O(n)입니다.

## 다른 풀이 방법

더 파이썬스러운 패턴으로, `zip`을 활용해 동시에 인덱스와 값을 추출할 수 있습니다. 또한 미리 전체 길이를 계산하여 미리 할당된 배열에 채우는 두 단계 방식도 가능합니다. 두 번째 방법은 내부 루프를 사용하므로 동일한 O(n) 시간 복잡도를 가지지만, 메모리 할당 시점에서 차이가 있습니다. 첫 번째 방법이 코드 가독성과 성능 모두에서 유리하며, 두 번째 방법은 미리 크기를 알 때 유용할 수 있습니다.

## 추가 참고사항

문제 제약에 따라 `nums`의 길이는 2 이상 100 이하의 짝수이며, 원소는 1 이상 100 이하입니다. 따라서 해독된 배열의 최대 길이는 10000으로 추가 메모리 사용에 제한이 없습니다. 입력은 항상 쌍으로 구성되어 있으므로 인덱스 범위 체크가 필요하지 않습니다.
