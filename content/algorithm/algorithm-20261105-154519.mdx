## 문제

길이가 n인 정수 배열 `nums`가 주어지며, 모든 요소는 1부터 n 사이의 정수이다. 각 정수는 최대 두 번 등장하며, 두 번 등장하는 모든 정수를 반환하는 것이 목표이다. 알고리즘은 O(n) 시간복잡도를 가져야 하며, 출력 배열을 제외하고 O(1) 추가 공간만 사용해야 한다. 배열의 요소가 한 번만 등장하는 경우와 두 번 이상 등장하는 경우를 정확히 구분해야 한다.

## 접근 방법

배열의 값을 배열의 인덱스로 활용하여 중복을 검출한다. 값 `nums[i]`는 1-based 인덱스 `nums[i] - 1`에 해당한다. 배열을 순회하며 각 요소가 가리키는 인덱스의 부호를 반전시켜 해당 값이 이미 방문되었음을 표시한다. 만약 부호를 반전시킬 때 해당 인덱스의 값이 이미 음수라면, 해당 값은 두 번째로 등장한 것이므로 중복 요소로 판단한다. 이 기법은 별도의 자료구조를 사용하지 않고 입력 배열의 상태를 마킹 상태로 활용한다.

## 풀이

배열을 한 번 순회하며 각 요소의 절대값 `num`에 해당하는 인덱스 `num - 1`의 부호를 확인한다. 해당 인덱스의 값이 양수이면 부호를 음수로 바꾸고, 음수이면 해당 `num`을 중복 요소로 저장한다. 반환된 중복 요소들을 결과로 내놓는다.

```python
def findDuplicates(nums):
    result = []
    for num in nums:
        index = abs(num) - 1
        if nums[index] < 0:
            result.append(abs(num))
        else:
            nums[index] *= -1
    return result
```

시간복잡도: O(n) - 배열을 정확히 한 번 순회한다.
공간복잡도: O(1) (출력 배열 제외) - 입력 배열을 직접 수정하여 마킹한다.

## 다른 풀이 방법

해시 맵(Hash Map) 또는 집합(Set)을 사용하여 요소를 저장하는 방법이 있다. 이 방법은 모든 요소를 한 번 삽입하며 중복을 확인할 수 있어 시간복잡도는 O(n)이다. 그러나 해시 맵에는 모든 요소를 저장해야 하므로 공간복잡도가 O(n)으로 증가한다. 이는 문제에서 요구하는 상수 공간 제약 조건을 충족하지 못한다. 정렬을 이용한 방법은 시간복잡도가 O(n log n)이 되므로 시간 효율성 측면에서 부적합하다.

## 추가 참고사항

인덱스 마킹 기법은 배열 요소가 0부터 n-1 또는 1부터 n 범위 내에 있을 때 효과적으로 적용할 수 있다. 이 방법은 입력 배열을 직접 변경하므로, 호출 측에서 원본 배열의 보존이 필요할 경우 데이터 손상이 발생할 수 있다. 배열 수정이 금지된 경우, 이 문제를 상수 공간과 O(n) 시간 내에 해결하는 일반적인 방법은 존재하지 않으며, 제약 조건 완화(공간 복잡도 증가 허용 등)가 필요하다.
