## 문제

소괄호 `()`, 중괄호 `{}`, 대괄호 `[]`로만 구성된 문자열 `s`가 입력됩니다. 이 문자열이 유효한지 확인하는 함수를 구현해야 합니다.

**유효성의 조건:**
1. 여는 괄호는 같은 타입의 닫는 괄호로 닫혀야 합니다.
2. 여는 괄호는 올바른 순서로 닫혀야 합니다. (예: `([)]`은 불 유효)
3. 닫힌 괄호는 반드시 매칭되는 여는 괄호가 존재해야 합니다.

**제약 사항:**
- 문자열 길이는 1 이상 10,000 이하입니다.
- 문자열은 지정된 괄호 문자로만 구성됩니다.

<Callout type="info" title="핵심 조건">
닫힌 괄호가 등장했을 때, 스택에 남아있는 가장 최근 여는 괄호의 타입과 일치해야 하며, 스택이 비어 있다면 즉시 불 유효 처리해야 합니다.
</Callout>

## 접근 방법

이 문제는 **스택(Stack)** 자료구조의 후입선출(LIFO) 성질을 활용하면 효율적으로 해결할 수 있습니다.

**알고리즘 단계:**
1. 문자열을 왼쪽에서 오른쪽으로 순차적으로 탐색합니다.
2. 여는 괄호(`(`, `{`, `[`)가 등장하면 스택에 푸시합니다.
3. 닫는 괄호(`)`, `}`, `]`)가 등장하면 스택에서 가장 최근의 여는 괄호를 팝합니다.
   - 이때 스택이 비어 있거나, 팝된 괄호와 타입이 일치하지 않으면 `false`를 반환합니다.
4. 탐색이 완료된 후, 스택이 비어 있으면 모든 괄호가 올바르게 닫힌 것이므로 `true`를 반환합니다.

## 풀이

해시맵을 사용하여 닫힌 괄호의 타입과 매칭되는 여는 괄호의 관계를 정의하면 코드 로직을 단순화할 수 있습니다. 입력 문자열의 길이가 홀수인 경우 즉시 `false`를 반환하는 최적화를 적용합니다.

```python
def is_valid(s: str) -> bool:
    # 길이가 홀수이면 유효할 수 없음
    if len(s) % 2 != 0:
        return False

    # 스택 초기화
    stack = []
    # 닫힌 괄호를 키로, 매칭되는 여는 괄호를 값으로 하는 해시맵
    # 시간 복잡도: 해시맵 조회는 O(1)
    mapping = {')': '(', '}': '{', ']': '['}

    for char in s:
        if char in mapping:
            # 스택에서 최상위 요소 팝. 스택이 비어있으면 '#' 가짜 값 반환
            top_element = stack.pop() if stack else '#'
            
            # 매칭되지 않으면 불 유효
            if mapping[char] != top_element:
                return False
        else:
            # 여는 괄호는 스택에 푸시
            stack.append(char)

    # 모든 처리 후 스택이 비어 있어야 유효함
    return not stack
```

**시간 복잡도:** $O(N)$
- 문자열의 길이 $N$만큼 순회하며, 스택의 삽입/삭제 연산은 상수 시간 $O(1)$이므로 총 $O(N)$이 됩니다.

**공간 복잡도:** $O(N)$
- 최악의 경우 모든 문자가 여는 괄호일 때 스택에 저장되므로 $O(N)$의 메모리가 소요됩니다.

## 다른 풀이 방법

**재귀 함수**를 사용하여 괄호를 처리하는 방법도 있습니다. 여는 괄호를 만나면 재귀 호출을 통해 내부의 괄호 처리를 수행하고, 닫힌 괄호를 만나면 현재 호출의 유효성을 판단합니다.

- **시간 복잡도:** $O(N)$
  - 문자열의 각 문자를 한 번씩 방문하므로 $O(N)$입니다.
- **공간 복잡도:** $O(N)$
  - 재귀 호출 스택이 문자열의 길이만큼 쌓일 수 있으므로 $O(N)$입니다.

## 추가 참고사항

1. **빈 문자열 처리:** 문제 제약 조건상 길이 1 이상이므로 빈 문자열은 고려하지 않아도 되나, 일반적인 유효성 검사에서는 빈 문자열을 `true`로 처리하는 것이 관례입니다.
2. **가짜 값 활용:** 스택이 비어있을 때 `pop()`을 호출하여 발생하는 예외를 방지하기 위해, 스택이 비어있으면 매칭되지 않는 가짜 값(`'#'` 등)을 반환하는 패턴을 사용하면 코드가 간결해집니다.
