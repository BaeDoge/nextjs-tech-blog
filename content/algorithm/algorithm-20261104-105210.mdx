## 문제

문자 배열 `chars`가 주어졌을 때, 연속된 반복 문자를 압축하는 알고리즘을 구현해야 합니다. 각 반복 그룹의 길이가 1인 경우 해당 문자를 그대로 저장하고, 2 이상인 경우 문자 뒤에 해당 숫자를 연결하여 저장합니다. 압축된 결과는 새로운 문자열로 반환하는 것이 아니라, 입력 배열 `chars` 자체를 수정(in-place)하여 저장해야 합니다. 함수는 압축된 문자열의 새로운 길이를 반환하며, 반환된 길이 이후의 배열 내용은 무시됩니다. 구현 시 상수 크기 O(1)의 추가 메모리만 사용하여야 합니다.

## 접근 방법

두 개의 포인터를 활용하여 문제를 해결할 수 있습니다. `write` 포인터는 현재 압축된 데이터를 배열에 쓸 위치를 나타내고, `read` 포인터는 현재 확인하고 있는 원본 문자를 가리킵니다. `read` 포인터가 배열 끝까지 이동하면서 문자가 변경될 때마다, 그전에 모았던 문자와 그 카운트를 `write` 포인터 위치부터 배열에 덮어씁니다.

문자열의 길이가 10 이상일 경우 숫자를 여러 글자로 표현해야 하므로, 카운트를 문자 배열에 저장하기 전에 문자열로 변환하여 각 자릿수를 순차적으로 저장해야 합니다. 이 과정을 통해 원본 배열의 앞부분을 덮어쓰면서 공간을 효율적으로 사용할 수 있습니다.

## 풀이

```python
class Solution:
    def compress(self, chars: list[str]) -> int:
        write = 0
        n = len(chars)
        read = 0
        
        while read < n:
            char = chars[read]
            count = 0
            
            # 현재 문자(char)와 동일한 문자의 그룹 길이를 셉니다.
            while read < n and chars[read] == char:
                read += 1
                count += 1
            
            # 현재 그룹의 문자를 write 위치에 저장합니다.
            chars[write] = char
            write += 1
            
            # 그룹 길이가 2 이상인 경우, 길이를 문자열로 변환하여 저장합니다.
            if count > 1:
                for digit in str(count):
                    chars[write] = digit
                    write += 1
                    
        return write

# 시간복잡도: O(N), 여기서 N은 chars 배열의 길이입니다. read 포인터는 배열을 한 번 순회하며, write 포인터는 압축된 결과의 길이만큼 이동합니다. str(count) 변환 비용은 자릿수(최대 4자리)에 비례하므로 전체적으로 상수 시간이 됩니다.
# 공간복잡도: O(1). 입력 배열을 직접 수정하며 추가적인 데이터 구조를 사용하지 않습니다. str(count) 변환 시의 임시 문자열은 최대 4바이트로 상수 크기로 간주합니다.
```

## 다른 풀이 방법

입력 배열을 변경하지 않고 별도의 배열에 압축 결과를 먼저 저장한 뒤, 이를 다시 원본 배열에 복사하는 방법이 있습니다. 이 방식은 코드가 단순해 보일 수 있지만, 압축된 결과물을 저장하기 위해 별도의 배열 공간이 필요하므로 공간 복잡도가 O(N)이 됩니다. 따라서 문제에서 요구하는 O(1)의 추가 공간 조건을 만족하지 못하므로 이 방식은 부적합합니다. 상수 공간 조건 하에서는 두 포인터를 이용한 원본 배열 직접 수정 방식이 유일한 효율적인 접근법입니다.

## 추가 참고사항

문자열 압축 시 숫자가 10이 되는 경우, 예를 들어 12개의 'b'가 있다면 'b', '1', '2'로 배열의 3칸을 차지하게 됩니다. 이는 단순히 숫자 하나를 배열의 다음 위치로 이동시키는 것이 아니라, 각 자릿수를 별도의 문자로 취급하여 순서대로 채워넣어야 함을 의미합니다. 또한, Python의 리스트는 크기가 고정되어 있지 않아 인덱스를 통한 할당이 가능하나, Java나 C++의 char 배열의 경우 크기 재할당이 불가능하므로 write 포인터가 가리키는 인덱스에 직접 대입하는 방식이 필수적입니다.
