## 문제

양의 정수 `n`이 주어질 때, 이진법 표현에서 '1'로 설정된 비트의 수를 반환하는 함수를 작성한다. 이 값은 해밍 무게(Hamming weight)라고도 한다. 입력은 1 이상 $2^{31}-1$ 이하의 정수이며, 결과 예시는 11(이진: 1011, 출력: 3), 128(이진: 10000000, 출력: 1) 등이다.

## 접근 방법

가장 직관적인 방법은 정수를 2로 계속 나누거나, LSB(Least Significant Bit)부터 확인하며 1의 개수를 세는 것이다. `n`이 0이 될 때까지 반복하며 `n % 2`가 1인 경우 카운터를 증가시키고, `n`을 2로 나누면 된다. 이 방법은 정수의 비트 수에 비례하는 시간복잡도를 가진다.

## 풀이

정수 연산을 사용하여 LSB가 1인지 확인하고, 2로 나누며 모든 비트를 확인하는 풀이다.

```python
def solution(n: int) -> int:
    count = 0
    while n > 0:
        if n % 2 == 1:
            count += 1
        n = n // 2
    return count
```

시간복잡도: $O(\log n)$ (정수의 비트 수에 비례)
공간복잡도: $O(1)$

## 다른 풀이 방법

비트 연산자를 사용하여 접근하는 방법이다. 먼저 `n & 1`로 LSB가 1인지 확인하고, `n >>= 1`로 비트를 우측 시프트하여 다음 비트를 확인하는 방식이 있다. 또한, Brian Kernighan's Algorithm처럼 `n &= n - 1`을 사용하면 1인 비트 중 가장 낮은 것만 제거할 수 있어 1의 개수만큼만 반복하게 되어 더 효율적이다.

```python
def solution_kernighan(n: int) -> int:
    count = 0
    while n > 0:
        n &= n - 1
        count += 1
    return count
```

시간복잡도: $O(k)$ (1의 개수 $k$에 비례, $k \le 31$)
공간복잡도: $O(1)$

## 추가 참고사항

이 문제는 다중 호출 시 성능 최적화가 요구되는 Follow-up가 있다. Brian Kernighan's Algorithm은 1의 개수만큼만 반복하므로 0이 많은 숫자에서 효율적이다. 또한, 미리 계산된 테이블을 활용한 룩업 테이블 기법을 사용하면 상수 시간 처리가 가능하며, 병렬 비트 연산을 통해 더 빠르게 처리할 수도 있다.
