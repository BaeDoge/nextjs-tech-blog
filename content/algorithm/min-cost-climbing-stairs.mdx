## 문제

주어진 정수 배열 `cost`는 각 계단의 비용을 나타냅니다.
이 비용은 해당 계단에 발을 딛을 때 지불해야 하는 비용이며, 이후 한 칸 또는 두 칸을 앞으로 올라갈 수 있습니다.
시작 지점은 인덱스 0 또는 인덱스 1 중 하나를 선택할 수 있습니다.
목표는 계단의 맨 위(마지막 계단의 다음 위치)에 도달하는 데 드는 최소 비용을 구하는 것입니다.
제약 조건으로 배열의 길이는 2 이상 1,000 이하이며, 각 비용은 0에서 999 사이의 정수입니다.

## 접근 방법

이 문제는 특정 지점에 도달하는 최소 비용을 구하는 문제로, 동적 계획법(Dynamic Programming)을 적용하기에 적합합니다.
배열 `dp`를 생성하여 `dp[i]`에 `i` 번째 계단까지 도달하는 데 필요한 최소 비용의 누적치를 저장합니다.
상태 전이식은 현재 계단 `i`에 도달하기 직전인 `i-1`과 `i-2`에서 각각 올 수 있으므로, 두 경우의 비용 중 최소값에 현재 계단의 비용을 더한 값이 됩니다.
수식으로 표현하면 `dp[i] = min(dp[i-1], dp[i-2]) + cost[i]`가 됩니다.
이러한 점화식을 기반으로 배열의 끝까지 계산한 후, 최상단으로 도달하기 위해 마지막으로 밟는 계단이 마지막 계단(`n-1`)이거나 마지막 계단 직전(`n-2`)이므로, 이 두 값 중 최소값을 반환하면 됩니다.

## 풀이

```python
class Solution:
    def minCostClimbingStairs(self, cost: list[int]) -> int:
        n = len(cost)
        
        # dp[i]는 i번째 계단에 도달하기 위해 지불해야 하는 누적 최소 비용
        dp = [0] * n
        
        # 초기값 설정: 인덱스 0과 1은 시작점이 될 수 있으므로 비용 그대로 저장
        dp[0] = cost[0]
        dp[1] = cost[1]
        
        # 점화식 적용: min(dp[i-1], dp[i-2]) + cost[i]
        for i in range(2, n):
            dp[i] = min(dp[i - 1], dp[i - 2]) + cost[i]
            
        # 최상단으로 가기 위해 마지막 또는 마지막 전 계단 중 최소 비용 선택
        return min(dp[n - 1], dp[n - 2])
```

시간복잡도: `O(N)` (N은 `cost` 배열의 길이로, 한 번의 순회가 필요합니다.)
공간복잡도: `O(N)` (최적의 경우 `O(1)`로 줄일 수 있으나, 위 코드에서는 `dp` 배열을 사용했습니다.)

## 다른 풀이 방법

공간복잡도를 `O(1)`로 최적화하여 풀 수 있습니다.
`dp` 배열 전체를 저장할 필요 없이, 직전 두 계단의 최소 비용값(`prev2`, `prev1`)만 유지하며 반복문을 수행하면 됩니다.
반복문이 끝난 후에도 동일한 논리로 `min(prev1, prev2)`를 계산하면 결과를 얻을 수 있습니다.
또한, 별도의 `dp` 배열 대신 입력 배열 `cost` 자체를 누적 최소 비용 배열로 변형하여 풀 수도 있습니다.
이 경우 추가 배열 할당이 필요 없지만, 원본 데이터를 변경한다는 단점이 있을 수 있습니다.
모든 방법은 시간복잡도 `O(N)`을 유지하며, 공간복잡도만 `O(N)` 또는 `O(1)`로 차이가 납니다.

## 추가 참고사항

이 문제는 재귀적 구조를 가집니다. 특정 지점까지의 최소 비용은 바로 앞 두 지점의 최소 비용에 의존합니다.
초기 조건 처리가 중요한데, 시작점이 `0`번이나 `1`번 계단에서 가능하므로 두 경우를 모두 고려해야 합니다.
반면, 목표 지점은 계단의 마지막이 아닌 마지막 계단의 다음 위치이므로, 결과 도출 시 마지막 요소 하나만 보는 것이 아니라 두 번째로 마지막 요소와 비교하여 최소값을 선택해야 합니다.
제약 조건이 작으므로 재귀에 메모이제이션을 추가하는 방식(Top-Down DP)으로도 충분히 빠르게 동작합니다.
