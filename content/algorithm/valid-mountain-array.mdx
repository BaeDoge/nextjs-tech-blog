## 문제

정수 배열 `arr`이 주어졌을 때, 유효한 산형 배열(Mountain Array)인지 판별합니다. 배열 길이는 3 이상이어야 하며, 중간에 피크가 하나 존재해야 합니다. 피크까지는 엄격히 증가하고, 피크 이후에는 엄격히 감소해야 합니다.

예를 들어 `[0, 3, 2, 1]`은 유효하지만 `[3, 5, 5]`, `[0, 1, 2]`, `[3, 2, 1]`은 유효하지 않습니다.

## 접근 방법

1. 배열 길이가 3 미만이면 `False`를 반환합니다.
2. 왼쪽에서 시작해 값이 증가하는 동안 포인터를 이동합니다.
3. 포인터가 첫 원소에 있거나 마지막 원소에 도달했다면 피크가 내부에 없으므로 `False`를 반환합니다.
4. 이후 값이 감소하는 동안 포인터를 이동하고, 마지막 인덱스에 도달했는지 확인합니다.

## 풀이

```python
from typing import List

class Solution:
    def validMountainArray(self, arr: List[int]) -> bool:
        n = len(arr)
        if n < 3:
            return False

        i = 0
        while i + 1 < n and arr[i] < arr[i + 1]:
            i += 1

        # 피크는 첫 원소나 마지막 원소일 수 없음
        if i == 0 or i == n - 1:
            return False

        while i + 1 < n and arr[i] > arr[i + 1]:
            i += 1

        return i == n - 1
```

## 복잡도 분석

- **시간 복잡도:** `O(N)`. 증가 구간과 감소 구간을 합쳐 각 원소를 최대 한 번씩 확인합니다.
- **공간 복잡도:** `O(1)`. 입력 배열 외에 상수 크기의 변수만 사용합니다.

## 자주 하는 실수

- 증가만 하거나 감소만 하는 배열을 허용하는 경우
- 피크가 배열의 첫 번째 또는 마지막 원소인 경우를 놓치는 경우
- 같은 값이 연속되는 평탄한 구간을 허용하는 경우

비교 연산자로 `<`와 `>`를 사용하므로 같은 값이 나타나면 해당 구간 탐색이 멈춥니다. 이후 마지막 인덱스에 도달했는지 검사해 유효하지 않은 배열을 걸러냅니다.
