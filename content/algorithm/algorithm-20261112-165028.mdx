## 문제

정수 n이 주어졌을 때, 길이 n+1인 배열 ans를 반환해야 합니다. 각 인덱스 i(0 ≤ i ≤ n)에 대해 ans[i]는 i의 이진 표현에서 1의 비트 개수입니다. 내장 함수(예: `__builtin_popcount`)를 사용하지 않고 풀어야 합니다. 제약 조건은 0 ≤ n ≤ 10^5입니다.

## 접근 방법

가장 직관적인 방법은 각 숫자마다 비트를 순회하며 1을 세는 것인데, 이는 O(n log n) 시간이 걸립니다. 선형 시간 O(n)을 달성하려면 이미 계산된 결과를 재사용해야 합니다. 핵심 관찰은 `i`의 1의 개수가 `i >> 1`(i를 2로 나눈 값)의 1의 개수에 `i & 1`(최하위 비트)을 더한 것과 같다는 점입니다. 즉, `ans[i] = ans[i >> 1] + (i & 1)` 점화식이 성립합니다. 이를 1부터 n까지 순회하며 채우면 단일 패스로 해결됩니다.

## 풀이

```python
def countBits(n: int) -> list[int]:
    ans = [0] * (n + 1)
    for i in range(1, n + 1):
        ans[i] = ans[i >> 1] + (i & 1)
    return ans
```

- 시간복잡도: O(n) — 각 인덱스를 한 번씩만 방문합니다.
- 공간복잡도: O(n) — 결과 배열을 저장합니다.

## 다른 풀이 방법

**Brian Kernighan 알고리즘 활용**  
`i & (i - 1)` 연산은 최하위 1비트를 0으로 만듭니다. 따라서 `ans[i] = ans[i & (i - 1)] + 1` 점화식도 성립합니다. 이 역시 O(n) 시간, O(n) 공간으로 동작하며 비트 조작 관점에서 더 직관적일 수 있습니다.

```python
def countBits_kernighan(n: int) -> list[int]:
    ans = [0] * (n + 1)
    for i in range(1, n + 1):
        ans[i] = ans[i & (i - 1)] + 1
    return ans
```

두 방법 모두 선형 시간이지만, 시프트 기반 풀이가 연산 횟수가 약간 더 적어 실무에서 미세하게 빠를 수 있습니다.

## 추가 참고사항

- Follow-up 요구사항인 O(n) 시간, 단일 패스, 내장 함수 미사용을 모두 충족합니다.
- `i >> 1`은 `i // 2`와 동일하며, `i & 1`은 `i % 2`와 동일합니다. 비트 연산이 상수 시간에서 더 빠릅니다.
- 메모리 최적화가 필요하면 제너레이터로 스트리밍할 수 있으나, 문제 조건상 배열 반환이 필수입니다.
