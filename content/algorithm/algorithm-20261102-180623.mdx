## 문제

문자열 배열 `operations`이 주어집니다. 각 문자열은 야구 기록장에 적용해야 할 연산을 나타냅니다. 연산의 종류는 다음과 같습니다.

- 정수 `x`: 점수 `x`를 기록장에 추가합니다.
- `"+"`: 기록장에 있는 직전 두 점수의 합계를 새로운 점수로 추가합니다.
- `"D"`: 기록장에 있는 직전 점수의 2배를 새로운 점수로 추가합니다.
- `"C"`: 기록장에 있는 직전 점수를 무효화하여 제거합니다.

모든 연산을 적용한 후 기록장에 남은 점수의 합계를 반환합니다. 테스트 케이스는 항상 유효하며, 중간 계산 결과와 최종 답은 32비트 정수 범위를 벗어납니다.

## 접근 방법

이 문제는 기록장에 점수를 순차적으로 추가하거나 제거하는 과정을 시뮬레이션해야 합니다. 점수의 마지막 추가와 마지막 제거가 자주 발생하므로, Last-In First-Out(LIFO) 구조를 가진 스택(Stack) 데이터 구조를 사용하면 효율적으로 처리할 수 있습니다.

1. 빈 스택을 생성합니다.
2. `operations` 배열을 순회하며 각 연산을 처리합니다.
3. 연산이 숫자일 경우 스택에 푸시합니다.
4. 연산이 `"C"`일 경우 스택에서 가장 위(top)의 요소를 팝합니다.
5. 연산이 `"D"`일 경우 스택의 top 요소를 2배로 만들어 푸시합니다.
6. 연산이 `"+"`일 경우 스택의 top 두 요소를 추출하여 합친 후 푸시합니다.
7. 모든 연산 처리 후 스택에 남은 요소들의 합을 계산하여 반환합니다.

## 풀이

스택을 사용하여 각 연산을 O(1) 시간에 처리할 수 있습니다. 최종 합계는 스택의 크기가 N일 때 O(N) 시간에 계산됩니다.

```python
def calPoints(operations: list[str]) -> int:
    record = []
    
    for op in operations:
        if op == "C":
            record.pop()
        elif op == "D":
            record.append(record[-1] * 2)
        elif op == "+":
            record.append(record[-1] + record[-2])
        else:
            record.append(int(op))
            
    return sum(record)
```

- 시간복잡도: O(N). 여기서 N은 `operations`의 길이입니다. 각 연산을 처리하는 데 O(1) 시간이 걸리며, 최종 합계 계산에도 O(N) 시간이 걸립니다.
- 공간복잡도: O(N). 기록장에 최대 N개의 점수가 저장될 수 있습니다.

## 다른 풀이 방법

배열을 직접 인덱스로 관리하여 스택을 구현할 수도 있습니다. `record` 배열의 `top` 인덱스를 유지하며, 추가 시 `top`을 증가시키고 제거 시 감소시키는 방식입니다. Python의 리스트가 내부적으로 동적 배열을 사용하므로, 위 코드와 실질적으로 동일한 성능을 가집니다. 다른 언어에서 고정 크기의 배열을 사용할 경우 메모리 할재 비용을 줄일 수 있다는 장점이 있습니다.

```python
def calPoints_alternative(operations: list[str]) -> int:
    record = [0] * len(operations)
    top = 0
    
    for op in operations:
        if op == "C":
            top -= 1
        elif op == "D":
            record[top] = record[top - 1] * 2
            top += 1
        elif op == "+":
            record[top] = record[top - 1] + record[top - 2]
            top += 1
        else:
            record[top] = int(op)
            top += 1
            
    return sum(record[:top])
```

이 방법 역시 시간복잡도 O(N), 공간복잡도 O(N)입니다.

## 추가 참고사항

- 입력 제약 조건에 따라 `"+"` 연산 시 반드시 두 개 이상의 점수가 존재하며, `"C"` 및 `"D"` 연산 시 반드시 하나 이상의 점수가 존재함이 보장됩니다. 따라서 스택이 비어 있는 상태에서 pop이나 접근 오류가 발생하지 않도록 예외 처리 코드를 추가할 필요는 없습니다.
- 정수 범위가 32비트 정수 내에 머무른다고 명시되었으므로, Python의 경우 큰 정수를 자동으로 처리해주지만 Java나 C++ 등에서는 `int`형 변수를 사용할 때 오버플로우가 발생하지 않도록 주의해야 합니다.
