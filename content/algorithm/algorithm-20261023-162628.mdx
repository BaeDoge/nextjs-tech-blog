## 문제

정렬된 정수 배열 `nums`와 정수 `target`이 주어집니다. `target`이 배열에 존재하면 해당 인덱스를 반환하고, 존재하지 않으면 `-1`을 반환하는 함수를 작성해야 합니다. 이때 알고리즘의 시간 복잡도는 $O(\log n)$이어야 합니다. 배열의 길이는 1 이상 10,000 이하이며, 배열의 요소와 `target`은 -10,000 초과 10,000 미만의 정수입니다. 배열의 모든 요소는 고유하며 오름차순으로 정렬되어 있습니다.

## 접근 방법

이진 탐색(Binary Search)은 정렬된 데이터 구조에서 효율적으로 검색을 수행하는 알고리즘입니다. 검색 범위를 나타내는 두 포인터 `left`와 `right`를 초기화한 후, 중앙값 `mid`를 계산하여 `target`과 비교합니다. `target`이 `mid`보다 크면 오른쪽 구간으로, 작으면 왼쪽 구간으로 탐색 범위를 좁혀갑니다. 이 과정을 `left`가 `right`보다 작거나 같을 때까지 반복하며, `target`을 찾으면 인덱스를 반환하고 반복문이 종료될 때까지 찾지 못하면 `-1`을 반환합니다.

## 풀이

```python
class Solution:
    def search(self, nums: List[int], target: int) -> int:
        left, right = 0, len(nums) - 1
        
        while left <= right:
            mid = (left + right) // 2
            
            if nums[mid] == target:
                return mid
            elif nums[mid] < target:
                left = mid + 1
            else:
                right = mid - 1
                
        return -1
```

시간 복잡도: $O(\log n)$
공간 복잡도: $O(1)$

## 다른 풀이 방법

1. **재귀적 이진 탐색**: 함수를 재귀적으로 호출하여 구현할 수 있습니다. 로직은 반복문과 동일하지만, 재귀 호출로 인해 호출 스택에 메모리가 할당됩니다.
   - 시간 복잡도: $O(\log n)$
   - 공간 복잡도: $O(\log n)$ (재귀 호출 스택)
2. **이진 탐색 모듈 함수 사용**: Python의 `bisect` 모듈이나 Java의 `Arrays.binarySearch()`와 같은 표준 라이브러리를 사용할 수 있습니다. 이는 내부적으로 이진 탐색 알고리즘을 구현하고 있으므로 시간 복잡도는 동일하지만, 코드 작성 시간을 단축할 수 있습니다.
   - 시간 복잡도: $O(\log n)$
   - 공간 복잡도: $O(1)$

## 추가 참고사항

- 이진 탐색은 배열이 **정렬되어 있어야** 적용할 수 있습니다. 정렬되지 않은 배열에서는 사용할 수 없으며, 이 경우 선형 탐색($O(n)$)이나 정렬 후 탐색($O(n \log n)$)이 필요합니다.
- 중간값 계산 시 `mid = (left + right) // 2` 방식은 `left`와 `right`가 매우 큰 값일 경우 오버플로우가 발생할 수 있습니다. 안전성을 위해 `mid = left + (right - left) // 2`로 계산하는 것이 권장됩니다.
- 문제의 제약 조건에서 배열의 길이가 10,000으로 비교적 작지만, $O(\log n)$ 알고리즘은 데이터 규모가 매우 커질 때 선형 탐색 대비 효율적인 성능을 보장합니다.
