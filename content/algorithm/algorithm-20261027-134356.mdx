## 문제

레몬ade 한 잔의 가격은 5달러입니다. 고객들은 줄을 서서 한 명씩 구매하며, 각 고객은 5달러, 10달러, 20달러 중 하나의 지폐로 결제합니다. 초기에는 거스름돈이 없으며, 각 고객에게 정확한 거스름돈을 줄 수 있어야 합니다. 주어진 결제 금액 배열에서 모든 고객에게 거스름돈을 제공할 수 있으면 `true`, 그렇지 않으면 `false`를 반환해야 합니다.

## 접근 방법

이 문제는 **그리디 알고리즘**을 적용할 수 있습니다. 20달러 지폐를 받은 경우 거스름돈으로 15달러를 돌려줘야 하는데, 이는 10달러 지폐 1장과 5달러 지폐 1장, 또는 5달러 지폐 3장으로 구성할 수 있습니다. 이때 10달러 지폐는 20달러 지폐를 받을 때만 거스름돈으로 사용할 수 있으므로, 5달러 지폐보다 가치가 높고 활용도가 낮습니다. 따라서 10달러 지폐가 있다면 반드시 10달러 지폐를 먼저 사용하고, 없으면 5달러 지폐 3장을 사용하는 것이 최선의 선택입니다. 이렇게 하면 5달러 지폐를 최대한 아껴두어 이후의 다양한 거스름돈 상황에 유연하게 대응할 수 있습니다.

## 풀이

5달러, 10달러, 20달러 지폐의 개수를 각각 카운터로 관리합니다.
1. 5달러 지폐가 오면 카운터를 증가시킵니다.
2. 10달러 지폐가 오면 거스름돈으로 5달러 지폐가 있는지 확인하고, 있다면 5달러 카운터를 감소시키고 10달러 카운터를 증가시킵니다. 없으면 실패합니다.
3. 20달러 지폐가 오면 거스름돈 15달러를 만들어야 합니다. 먼저 10달러 지폐가 있다면 10달러 1장과 5달러 1장을 사용합니다. 10달러 지폐가 없거나 부족하면 5달러 지폐 3장을 사용합니다. 거스름돈을 줄 수 없으면 실패합니다.

```python
class Solution:
    def lemonadeChange(self, bills: list[int]) -> bool:
        five_dollar = 0
        ten_dollar = 0
        
        for bill in bills:
            if bill == 5:
                five_dollar += 1
            elif bill == 10:
                if five_dollar == 0:
                    return False
                five_dollar -= 1
                ten_dollar += 1
            else:  # bill == 20
                # 20달러 거스름돈은 15달러
                # 10달러 지폐가 있으면 10 + 5로 거스름돈
                if ten_dollar > 0 and five_dollar > 0:
                    ten_dollar -= 1
                    five_dollar -= 1
                # 10달러 지폐가 없으면 5달러 3장으로 거스름돈
                elif five_dollar >= 3:
                    five_dollar -= 3
                else:
                    return False
                    
        return True
```

시간복잡도: $O(N)$ (지폐 배열을 한 번 순회하므로)
공간복잡도: $O(1)$ (고정된 수의 변수만 사용하므로)

## 다른 풀이 방법

이 문제는 그리디 접근이 최적의 해를 보장하므로, 다른 알고리즘 패러다임(예: 동적 계획법, 완전 탐색)을 적용하기 어렵거나 불필요합니다. 동적 계획법을 적용하려 하면 상태 공간이 지폐의 조합으로 인해 복잡해지고, 현재 지폐의 조합만으로 다음 상태가 결정되는 특성상 그리디가 가장 간결하고 효율적입니다. 따라서 이 문제에서는 그리디 알고리즘 외의 실용적인 대체 풀이 방법은 존재하지 않습니다.

## 추가 참고사항

- 20달러 지폐 자체는 거스름돈으로 사용되지 않으므로, 20달러 지폐의 개수를 별도로 카운터할 필요는 없습니다.
- 10달러 지폐는 20달러 지폐를 받을 때만 거스름돈으로 쓰이므로, 5달러 지폐보다 '유연성'이 낮습니다. 따라서 10달러 지폐를 먼저 사용하는 것이 5달러 지폐를 아끼는 전략과 일치합니다.
- 입력 배열의 길이는 최대 $10^5$이므로, $O(N)$ 시간복잡도를 만족하는 그리디 알고리즘이 적합합니다.
