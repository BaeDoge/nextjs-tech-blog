## 문제

주어진 N진트리(root)의 최대 깊이를 구하는 문제이다. 최대 깊이는 루트 노드에서 가장 멀리 떨어진 리프 노드까지의 경로에 있는 노드의 수로 정의된다. 트리의 노드 수는 0 이상 10^4 이하이며, 최대 깊이는 1000 이하이다.

## 접근 방법

루트 노드부터 시작하여 자식 노드들을 순회하며 깊이를 계산하는 재귀(DFS) 방식을 사용한다. 현재 노드의 깊이는 자식 노드들의 최대 깊이 중 가장 큰 값에 1을 더한 것과 같다. 자식 노드가 없는 리프 노드의 경우 깊이를 1로 반환한다.

## 풀이

현재 노드가 없으면 깊이를 0으로 반환한다. 자식 노드가 있는 경우, 각 자식에 대해 재귀적으로 깊이를 구한 뒤 그중 최댓값을 찾는다. 최댓값에 1을 더하여 현재 노드의 깊이를 결정한다.

```python
"""
# Definition for a Node.
class Node:
    def __init__(self, val=None, children=None):
        self.val = val
        self.children = children if children is not None else []
"""

class Solution:
    def maxDepth(self, root: 'Node') -> int:
        if root is None:
            return 0
        
        max_child_depth = 0
        for child in root.children:
            max_child_depth = max(max_child_depth, self.maxDepth(child))
        
        return max_child_depth + 1
```

시간복잡도: $O(N)$ (모든 노드를 한 번씩 방문하므로).
공간복잡도: $O(H)$ (재귀 호출 스택의 최대 깊이는 트리의 높이 $H$에 비례함).

## 다른 풀이 방법

너비 우선 탐색(BFS)을 사용할 수 있다. 큐를 사용하여 레벨 순서로 노드를 탐색하고, 각 레벨을 처리할 때마다 깊이를 1씩 증가시킨다. 최종적으로 처리된 레벨의 수가 최대 깊이가 된다.
BFS의 시간복잡도는 $O(N)$, 공간복잡도는 $O(N)$ (큐에 레벨의 최대 노드 수만큼 공간을 차지함)이다.

## 추가 참고사항

DFS 방식은 재귀 호출 스택을 사용하므로 트리의 깊이가 매우 깊을 경우 스택 오버플로우 가능성이 있다. 트리의 깊이가 제한(1000)되어 있으므로 이 문제에서는 DFS가 안정적으로 동작한다.
