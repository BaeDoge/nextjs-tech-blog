## 문제

주어진 N진트리(root)의 최대 깊이를 구하는 문제이다. 최대 깊이는 루트 노드에서 가장 멀리 떨어진 리프 노드까지의 경로에 있는 노드의 수로 정의된다. 트리의 노드 수는 0 이상 10^4 이하이며, 최대 깊이는 1000 이하이다.

## 접근 방법

루트 노드부터 시작하여 자식 노드들을 순회하며 깊이를 계산하는 재귀(DFS) 방식을 사용한다. 현재 노드의 깊이는 자식 노드들의 최대 깊이 중 가장 큰 값에 1을 더한 것과 같다. 자식 노드가 없는 리프 노드의 경우 깊이를 1로 반환한다.

## 풀이

현재 노드가 없으면 깊이를 0으로 반환한다. 자식 노드가 있는 경우, 각 자식에 대해 재귀적으로 깊이를 구한 뒤 그중 최댓값을 찾는다. 최댓값에 1을 더하여 현재 노드의 깊이를 결정한다.

```python
"""
# Definition for a Node.
class Node:
    def __init__(self, val=None, children=None):
        self.val = val
        self.children = children if children is not None else []
"""

class Solution:
    def maxDepth(self, root: 'Node') -> int:
        if root is None:
            return 0
        
        max_child_depth = 0
        for child in root.children:
            max_child_depth = max(max_child_depth, self.maxDepth(child))
        
        return max_child_depth + 1
```

시간복잡도: $O(N)$ (모든 노드를 한 번씩 방문하므로).
공간복잡도: $O(H)$ (재귀 호출 스택의 최대 깊이는 트리의 높이 $H$에 비례함).

## 다른 풀이 방법

너비 우선 탐색(BFS)을 사용하면 재귀 호출 없이 레벨 단위로 노드를 처리할 수 있습니다. 큐에 현재 노드를 넣고, 각 레벨의 노드 수만큼 자식을 큐에 추가하면 레벨 수가 최대 깊이가 됩니다.

```python
from collections import deque

def maxDepth_bfs(root: 'Node') -> int:
    if root is None:
        return 0

    queue = deque([root])
    depth = 0
    while queue:
        for _ in range(len(queue)):
            node = queue.popleft()
            queue.extend(node.children)
        depth += 1
    return depth
```

시간 복잡도는 O(N), 공간 복잡도는 큐에 저장되는 최대 레벨 너비 W에 비례하는 O(W)입니다. 재귀 DFS는 O(H)의 호출 스택을 사용합니다. 문제의 높이 상한 1,000은 Python 기본 재귀 제한에 가까울 수 있으므로, 깊은 트리에서는 BFS 또는 명시적 스택 DFS가 더 안전합니다.

## 추가 참고사항

DFS 방식은 재귀 호출 스택을 사용하므로 트리의 깊이가 매우 깊을 경우 스택 오버플로우 가능성이 있다. 문제의 최대 깊이 1,000은 Python의 기본 재귀 제한에 근접하므로, 환경에 따라 재귀 DFS가 `RecursionError`를 일으킬 수 있습니다. 깊은 입력을 고려하면 BFS나 반복형 DFS가 더 안전합니다.
