## 문제

이진 트리의 루트 노드가 주어졌을 때, 트리의 마지막 행(가장 깊은 레벨)에 있는 가장 왼쪽에 위치한 노드의 값을 반환해야 합니다.

예를 들어, 트리가 `[2,1,3]`인 경우 마지막 행은 `[1,3]`이며, 가장 왼쪽 값인 `1`을 반환합니다. 트리가 `[1,2,3,4,null,5,6,null,null,7]`인 경우 마지막 행에는 노드 `7`만 존재하므로 `7`을 반환합니다.

트리의 노드 수는 `1`에서 `10^4` 사이이며, 노드 값의 범위는 `-2^31`에서 `2^31 - 1`입니다.

## 접근 방법

이 문제를 해결하기 위해서는 트리의 레벨(깊이) 정보를 고려해야 합니다. 마지막 행의 왼쪽 값을 찾기 위해 두 가지 주요 접근이 가능합니다.

첫째, 너비 우선 탐색(BFS)을 사용하는 방법입니다. BFS는 레벨 순서로 노드를 방문하므로, 각 레벨의 첫 번째 노드를 기록하거나 마지막 레벨에 도달했을 때 첫 번째 노드를 찾으면 됩니다.

둘째, 깊이 우선 탐색(DFS)을 사용하는 방법입니다. DFS를 통해 모든 노드를 방문하면서 현재 노드의 깊이와 이전에 기록된 최대 깊이를 비교합니다. 만약 현재 노드의 깊이가 최대 깊이보다 깊거나 같다면(왼쪽부터 방문하므로 같을 경우에도 갱신 필요), 값을 업데이트합니다.

## 풀이

BFS를 사용하여 레벨 순서로 탐색하는 풀이를 제시합니다. 큐를 사용하여 각 레벨의 노드를 처리하고, 각 레벨의 시작 시점의 노드 값을 저장합니다. 마지막 레벨에 도달했을 때 저장된 값이 정답이 됩니다.

```python
from collections import deque

class Solution:
    def findBottomLeftValue(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
        
        queue = deque([root])
        leftmost_value = root.val
        
        while queue:
            level_size = len(queue)
            # 각 레벨의 첫 번째 노드 값 저장
            leftmost_value = queue[0].val
            
            for _ in range(level_size):
                node = queue.popleft()
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
                    
        return leftmost_value
```

시간복잡도: O(N). 모든 노드를 한 번씩 방문합니다.
공간복잡도: O(N). 최악의 경우(완전 이진 트리의 마지막 레벨 등) 큐에 최대 N/2개의 노드가 저장될 수 있습니다.

## 다른 풀이 방법

DFS(재귀)를 이용한 방법도 있습니다. 전위 순서(루트 -> 왼쪽 -> 오른쪽)로 탐색하며, 현재 깊이가 이전에 본 최대 깊이보다 깊을 때 값을 갱신합니다. 같은 깊이라면 왼쪽에서 먼저 방문하므로 값을 갱신하지 않아도 되지만, 구현의 편의상 깊이가 같을 때도 갱신하거나, 깊이 비교 로직을 명확히 할 수 있습니다. 일반적으로 깊이 비교 시 `current_depth > max_depth`일 때만 갱신하면 왼쪽 우선 탐색 특성에 의해 마지막에 갱신되는 값이 해당 깊이의 가장 왼쪽 노드가 됩니다.

```python
class Solution:
    def findBottomLeftValue(self, root: Optional[TreeNode]) -> int:
        self.max_depth = -1
        self.leftmost_value = 0
        
        def dfs(node, depth):
            if not node:
                return
            
            # 왼쪽 자식부터 방문하므로, 현재 깊이가 최대 깊이보다 깊을 때만 갱신
            if depth > self.max_depth:
                self.max_depth = depth
                self.leftmost_value = node.val
            
            dfs(node.left, depth + 1)
            dfs(node.right, depth + 1)
            
        dfs(root, 0)
        return self.leftmost_value
```

시간복잡도: O(N). 모든 노드를 방문합니다.
공간복잡도: O(H). 재귀 호출 스택의 깊이로, H는 트리의 높이입니다. 균형 잡힌 트리인 경우 O(log N), 편향된 트리의 경우 O(N)입니다.

## 추가 참고사항

- BFS는 레벨 단위의 처리가 직관적이지만 큐의 공간 오버헤드가 있을 수 있습니다.
- DFS는 추가적인 자료구조(큐 등)를 사용하지 않고 재귀 스택을 활용하므로 공간 효율적일 수 있으나, 트리가 매우 깊으면 재귀 한계(Recursion Limit)에 도달할 수 있습니다.
- 문제의 제약 조건에서 노드 값의 범위가 정수형 범위이므로, 초기화 값 설정 시 주의가 필요합니다. BFS 방식은 첫 노드 값을 기본값으로 설정하면 안전합니다.
- 이 문제는 트리의 구조적 특성(왼쪽 우선, 레벨 정보)을 활용하는 전형적인 예시입니다.
