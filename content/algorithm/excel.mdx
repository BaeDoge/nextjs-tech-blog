## 문제

Excel 시트의 열 제목을 나타내는 문자열 `columnTitle`이 주어졌을 때, 해당 열의 10진수 번호를 반환하는 문제이다.

열 제목은 영문 대문자로 구성되며, A는 1, B는 2, ..., Z는 26에 대응된다. AA는 27, AB는 28과 같이 26진법과 유사하지만 0이 없는 1-based 시스템으로 동작한다.

입력 문자열의 길이는 1 이상 7 이하이며, 대문자 영문자만으로 구성된다.

## 접근 방법

이 문제는 본질적으로 26진수를 10진수로 변환하는 문제이다.

각 문자는 해당 위치의 가중치를 가지며, 오른쪽에서 왼쪽으로 갈수록 자릿수가 1씩 증가한다.

예를 들어 "AB"의 경우, B는 1의 자리(26^0), A는 26의 자리(26^1)에 해당한다.

각 문자를 숫자로 변환할 때 'A'는 1, 'Z'는 26이므로, 문자의 ASCII 값에서 'A'의 ASCII 값을 빼고 1을 더하면 된다.

## 풀이

문자열의 왼쪽부터 오른쪽으로 순회하며 누적값을 계산하는 방식을 사용한다.

누적값은 현재까지 처리한 문자열의 값에 26을 곱하고, 현재 문자의 숫자 값을 더하는 방식으로 진행된다.

이 방식은 26진법 변환 공식을 순차적으로 적용하는 것과 동일하다.

```python
class Solution:
    def titleToNumber(self, columnTitle: str) -> int:
        result = 0
        for char in columnTitle:
            # 문자를 숫자로 변환: 'A' -> 1, 'B' -> 2, ..., 'Z' -> 26
            value = ord(char) - ord('A') + 1
            # 기존 결과에 26을 곱하고 현재 값 추가
            result = result * 26 + value
        return result
```

시간복잡도: O(N) - 문자열의 길이 N만큼 한 번 순회한다.
공간복잡도: O(1) - 추가적인 공간을 사용하지 않는다.

## 다른 풀이 방법

재귀 함수를 이용해 오른쪽 끝 문자부터 처리하는 방식이다.

문자열의 마지막 문자를 현재 자릿값으로 계산하고, 나머지 문자열에 대해 재귀 호출로 상위 자릿값을 구해 26을 곱한 뒤 더한다.

```python
class Solution:
    def titleToNumber(self, columnTitle: str) -> int:
        if not columnTitle:
            return 0
        # 마지막 문자의 값 계산
        last_char_value = ord(columnTitle[-1]) - ord('A') + 1
        # 나머지 문자열에 대한 재귀 호출 결과에 26을 곱하고 현재 값 더함
        return self.titleToNumber(columnTitle[:-1]) * 26 + last_char_value
```

시간복잡도: O(N^2) - 문자열 슬라이싱이 매 호출마다 새 문자열을 복사하여 발생한다.
공간복잡도: O(N) - 재귀 호출 스택 깊이가 N만큼 소모된다.

반복문 기반 풀이가 꼬리 재귀 최적화가 없는 언어에서 스택 오버플로 위험 없이 더 효율적이다.

## 추가 참고사항

26진법 변환 시 주의할 점은 0이 없는 1-based 시스템이라는 것이다.

일반적인 26진수는 0~25를 사용하지만, 이 문제는 1~26을 사용하므로 문자 변환 시 1을 더해야 한다.

제약 조건상 최대 입력인 "FXSHRXW"의 값은 2^31-1(약 21억) 이내이므로, 32비트 정수형(int)으로도 표현할 수 있다.

Python은 임의 정밀도 정수를 지원하므로 문제없으나, Java나 C++ 등에서도 32비트 정수 범위 내에 들어맞으므로 `int`를 그대로 사용하면 된다.

<Callout type="tip" title="핵심 포인트">
문자열을 왼쪽에서 오른쪽으로 순회하며 `result = result * 26 + value` 공식을 적용하면 효율적으로 변환할 수 있다.
</Callout>
