## 문제

주어진 이진 트리의 루트 노드를 받아 level order traversal을 수행하여 각 레벨의 노드 값을 왼쪽에서 오른쪽으로 순서대로 담은 리스트의 리스트를 반환한다. 레벨은 루트부터 시작하며, 노드가 없는 경우 빈 리스트를 반환한다. 노드 개수는 0~2000개이며, 값은 -1000~1000이다.

## 접근 방법

BFS 전략을 사용해 큐에 현재 레벨 노드를 저장하고, 레벨별로 순환하면서 값을 수집한다. 매 레벨에서 큐의 현재 길이를 기록한 뒤, 해당 길이만큼 노드를 꺼내어 값을 리스트에 추가하고 자식 노드를 다음 레벨 큐에 삽입한다. 이렇게 하면 각 레벨을 한 번에 처리할 수 있다.

## 풀이

아래 코드는 deque를 이용해 BFS를 구현한 파이썬 함수이다. 루트 노드가 없으면 빈 리스트를 반환하고, 각 레벨마다 새로운 리스트를 만들어 값을 채운다.  

```python
from collections import deque
from typing import List, Optional

# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val: int = 0, left: Optional['TreeNode'] = None, right: Optional['TreeNode'] = None):
        self.val = val
        self.left = left
        self.right = right

def levelOrder(root: Optional[TreeNode]) -> List[List[int]]:
    if not root:
        return []
    result = []
    queue = deque([root])
    while queue:
        level_size = len(queue)
        level_vals = []
        for _ in range(level_size):
            node = queue.popleft()
            level_vals.append(node.val)
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
        result.append(level_vals)
    return result
```

시간 복잡도는 O(n)이고, 추가 공간 복잡도는 O(n)이다.

## 다른 풀이 방법

재귀 DFS를 사용해도 같은 레벨 순서의 결과를 만들 수 있습니다. 재귀 함수에 현재 깊이를 전달하고, 처음 방문한 깊이라면 결과 배열에 새 리스트를 추가합니다. 이후 현재 노드의 값을 해당 깊이의 리스트에 추가하고 왼쪽, 오른쪽 자식을 순서대로 방문합니다.

```python
from typing import List, Optional

def levelOrder_dfs(root: Optional[TreeNode]) -> List[List[int]]:
    result = []

    def dfs(node: Optional[TreeNode], depth: int) -> None:
        if node is None:
            return
        if depth == len(result):
            result.append([])
        result[depth].append(node.val)
        dfs(node.left, depth + 1)
        dfs(node.right, depth + 1)

    dfs(root, 0)
    return result
```

시간 복잡도는 O(n)입니다. 결과 리스트를 제외한 재귀 호출 스택의 추가 공간은 O(h)이며, h는 트리 높이입니다. 트리가 한쪽으로 치우치면 재귀 깊이가 O(n)이 될 수 있으므로, 매우 깊은 트리에서는 큐를 사용하는 BFS가 Python의 재귀 제한에 더 안전합니다.
