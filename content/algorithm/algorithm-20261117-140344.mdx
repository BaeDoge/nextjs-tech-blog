## 문제

정수 `num`이 주어졌을 때, 다음 규칙을 반복하여 0으로 만드는 데 필요한 단계 수를 구하라.  
현재 수가 짝수이면 2로 나누고, 홀수이면 1을 뺀다.  
예를 들어 `num = 14`이면 6단계, `num = 8`이면 4단계, `num = 123`이면 12단계가 필요하다.  
제약 조건은 `0 <= num <= 10^6` 이다.

## 접근 방법

가장 직관적인 해결책은 시뮬레이션이다. `num`이 0이 될 때까지 루프를 반복하며, 짝수 여부에 따라 나누기 2 또는 빼기 1을 수행하고 단계 수를 누적한다.  
이 방법의 시간 복잡도는 O(log num)이며, 공간 복잡도는 O(1)이다.  
또한 이진 표현을 이용하면 비트 길이와 1의 개수를 활용해 단계 수를 O(1)에 계산할 수도 있다.

## 풀이

시뮬레이션을 구현한 코드는 다음과 같다.

```python
class Solution:
    def numberOfSteps(self, num: int) -> int:
        steps = 0
        while num > 0:
            if num % 2 == 0:
                num //= 2
            else:
                num -= 1
            steps += 1
        return steps
```

이 알고리즘은 `num`이 0이 될 때까지 반복하므로, 최대 반복 횟수는 이진 자리 수와 같으며 시간 복잡도는 O(log num)이다.  
추가 메모리를 사용하지 않으므로 공간 복잡도는 O(1)이다.

## 다른 풀이 방법

비트 연산을 이용하면 단계 수를 직접 계산할 수 있다. `num`의 이진 표현 길이(`bit_length`)와 1의 개수(`popcount`)를 구하면, 단계 수는 `bit_length + popcount - 1`이 된다.  
이를 구현한 코드는 다음과 같다.

```python
class Solution:
    def numberOfSteps(self, num: int) -> int:
        if num == 0:
            return 0
        return num.bit_length() + num.bit_count() - 1
```

이 방법은 내장 함수를 이용하므로 시간 복잡도는 O(1)에 가까우며, 공간 복잡도도 O(1)이다.  
하지만 가독성과 유지보수 측면에서 시뮬레이션 방식이 더 이해하기 쉬울 수 있다.

## 추가 참고사항

`num = 0`인 경우는 단계가 0이므로 바로 0을 반환해야 한다.  
제약 조건상 `num`은 최대 10^6이므로, 시뮬레이션 기반 풀이도 충분히 빠르게 동작한다.  
이 문제는 Math 및 Bit Manipulation 카테고리에 속하며, 비트 연산을 알기 좋은 예시이다.
