## 문제

정수 num이 주어졌을 때 다음 규칙을 반복하여 0으로 만드는 데 필요한 단계 수를 구합니다.

- 현재 수가 짝수이면 2로 나눕니다.
- 현재 수가 홀수이면 1을 뺍니다.

예를 들어 num = 14라면 14 → 7 → 6 → 3 → 2 → 1 → 0으로 총 6단계가 필요합니다.

## 접근 방법 1: 시뮬레이션

가장 직관적인 방법은 값이 0이 될 때까지 조건에 따라 연산을 반복하는 것입니다.

~~~python
def number_of_steps(num: int) -> int:
    steps = 0

    while num > 0:
        if num % 2 == 0:
            num //= 2
        else:
            num -= 1
        steps += 1

    return steps


print(number_of_steps(14))   # 6
print(number_of_steps(8))    # 4
print(number_of_steps(123))  # 12
print(number_of_steps(0))    # 0
~~~

매 단계에서 수가 절반 이하로 줄어들거나 1 감소하므로 시간 복잡도는 O(log num), 추가 공간 복잡도는 O(1)입니다.

## 접근 방법 2: 이진수의 비트 수 활용

양의 정수의 이진 표현에서 가장 왼쪽의 1을 제외한 각 비트는 다음과 같이 한 번씩 처리됩니다.

- 비트가 0이면 오른쪽 시프트(2로 나누기) 한 번이 필요합니다.
- 비트가 1이면 1을 빼고 오른쪽 시프트하는 두 단계가 필요합니다.

따라서 0보다 큰 정수의 단계 수는 이진 표현의 비트 길이와 1의 개수를 이용해 계산할 수 있습니다.

~~~python
def number_of_steps_bits(num: int) -> int:
    if num == 0:
        return 0
    return num.bit_length() + num.bit_count() - 1


print(number_of_steps_bits(14))   # 6
print(number_of_steps_bits(8))    # 4
print(number_of_steps_bits(123))  # 12
~~~

int.bit_count()는 Python 3.10 이상에서 사용할 수 있습니다.

## 복잡도 비교

두 방법 모두 입력 정수의 비트 수에 비례하는 O(log num) 시간에 동작합니다. 비트 연산 방식도 Python 정수가 임의 정밀도 정수이므로 입력 크기와 무관하게 항상 O(1)이라고 표현하는 것은 정확하지 않습니다. 두 방식 모두 추가 공간은 O(1)입니다.
