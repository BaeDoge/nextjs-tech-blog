## 문제

정수 배열 `nums`가 주어졌을 때, 초기 양수 값 `startValue`을 설정합니다. `startValue`에 `nums`의 원소를 왼쪽에서 오른쪽으로 더해가는 과정을 반복하며, 각 단계에서의 누적합이 항상 1 이상이어야 합니다. 이 조건을 만족하는 가장 작은 양수 `startValue`를 반환하는 것이 목표입니다.

## 접근 방법

`startValue`를 하나씩 증가시키며 시뮬레이션하는 방법도 가능하지만, 효율적으로 접근하기 위해 누적합(Prefix Sum)의 개념을 사용합니다. `startValue`를 `x`라고 하면, `x`와 `nums`의 누적합의 합이 모든 단계에서 1 이상이 되어야 합니다. 즉, `x + (누적합의 최솟값) >= 1`을 만족해야 하므로, 필요한 `x`의 값은 `1 - (누적합의 최솟값)`이 됩니다. 단, `startValue`는 반드시 양수여야 하므로 최소 누적합이 1보다 작은 경우에만 해당 값을 계산하여 반환합니다.

## 풀이

배열의 각 원소를 순회하며 누적합을 계산하고, 그 과정에서 발생한 최소 누적합을 기록합니다. 구한 최소 누적합이 1보다 작다면, 이를 1로 끌어올리기 위해 필요한 초기 값(`1 - min_prefix_sum`)을 반환합니다. 최소 누적합이 1 이상이라면 초기 값이 1로 충분하므로 1을 반환합니다.

```python
class Solution:
    def minStartValue(self, nums: list[int]) -> int:
        current_sum = 0
        min_prefix_sum = 0
        
        for num in nums:
            current_sum += num
            if current_sum < min_prefix_sum:
                min_prefix_sum = current_sum
                
        return 1 - min_prefix_sum
```

시간복잡도: $O(N)$으로 배열의 길이에 비례합니다.
공간복잡도: $O(1)$로 추가 공간을 거의 사용하지 않습니다.

## 다른 풀이 방법

누적합의 최솟값을 찾지 않고, 매 단계마다 시뮬레이션하여 조건을 만족하는지 검사하는 완전탐색 기법을 사용할 수 있습니다. 초기값을 1부터 시작해 조건 위반 시 초기값을 1씩 증가시키며 조건 만족 시 반환합니다. 이 방법은 초기값의 범위가 작은 제약조건에서는 구현이 간단하지만, 초기값이 커질 경우 불필요한 반복 계산을 수행하여 비효율적입니다. 반면 누적합을 이용하는 방법은 한 번의 순회로 해결하므로 계산 횟수를 최소화합니다.

## 추가 참고사항

제약조건에 따라 `nums`의 길이는 최대 100, 원소의 값은 -100에서 100 사이입니다. 따라서 누적합의 최솟값은 -10000에서 10000 범위 내에 존재합니다. 필요한 최소 초기값은 이 범위를 벗어나지 않으므로 정수형 변수로 충분히 처리할 수 있습니다. 이 문제는 단순한 누적합 계산뿐만 아니라, 부등식 조건을 만족하는 최소 값을 찾는 논리가 핵심입니다.
