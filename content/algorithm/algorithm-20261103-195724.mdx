## 문제

두 정수 배열 `nums1`과 `nums2`가 주어질 때, 두 배열의 교집합을 반환해야 합니다. 결과에 포함된 각 요소는 고유해야 하며, 반환되는 배열의 순서는 상관없습니다.
배열의 길이는 1,000 이하이며, 배열 요소의 값은 0부터 1,000 사이의 정수입니다.

예시:
- `nums1 = [1,2,2,1]`, `nums2 = [2,2]`인 경우, 교집합은 `[2]`입니다.
- `nums1 = [4,9,5]`, `nums2 = [9,4,9,8,4]`인 경우, 교집합은 `[9,4]`가 됩니다. `[4,9]`와 같은 순서로 반환해도 정답으로 인정됩니다.

## 접근 방법

두 배열의 공통 요소를 찾기 위해 한 배열의 존재 여부를 빠르게 확인할 수 있는 자료구조가 필요합니다. 해시셋(HashSet)을 활용하면 요소의 존재 여부를 O(1) 시간에 확인할 수 있습니다.
먼저 첫 번째 배열 `nums1`의 요소를 해시셋에 삽입합니다. 이 과정에서 배열 내의 중복 요소는 자동으로 제거되어 집합의 고유성을 확보합니다.
다음으로 두 번째 배열 `nums2`를 순회하며 각 요소가 `nums1`의 해시셋에 포함되어 있는지 검증합니다.
검증된 공통 요소들은 결과 집합에 추가됩니다. 결과 집합 또한 해시셋으로 관리하여 반환되는 결과값의 중복을 방지합니다.
최종적으로 결과 집합을 리스트로 변환하여 반환합니다.

## 풀이

첫 번째 배열 `nums1`의 모든 요소를 `set_nums1` 해시셋에 추가하여 고유한 요소 집합을 구성합니다.
두 번째 배열 `nums2`의 요소를 하나씩 순회하며, 해당 요소가 `set_nums1`에 포함되어 있는지 확인합니다.
포함되어 있으면 `intersection_set`에 추가합니다. 이 과정은 자연스럽게 결과의 고유성을 보장합니다.
마지막으로 교집합 집합을 리스트 형식으로 변환하여 함수의 반환값으로 리턴합니다.

```python
from typing import List

class Solution:
    def intersection(self, nums1: List[int], nums2: List[int]) -> List[int]:
        set_nums1 = set(nums1)
        intersection_set = set()
        
        for num in nums2:
            if num in set_nums1:
                intersection_set.add(num)
                
        return list(intersection_set)
```

시간복잡도: O(N + M)입니다. 여기서 N은 `nums1`의 길이, M은 `nums2`의 길이입니다. 해시셋 생성에 O(N), `nums2`의 순회와 조회에 O(M)이 소요됩니다.
공간복잡도: O(N + min(N, M))입니다. `set_nums1`에 최대 N개의 요소가 저장되며, 교집합 집합에는 최대 min(N, M)개의 요소가 저장됩니다.

## 다른 풀이 방법

정렬(Sorting)과 투포인터(Two Pointers) 기법을 사용할 수 있습니다.
먼저 두 배열을 정렬합니다. 정렬이 완료되면 두 배열에 각각 포인터를 두고 값을 비교하며 이동할 수 있습니다.
현재 두 포인터가 가리키는 값이 같으면 교집합에 추가하고, 두 포인터를 모두 전진시킵니다.
값이 다르면 값이 더 작은 쪽 포인터만 전진합니다.
이 방식에서 시간복잡도는 정렬에 O(N log N + M log M)이 소요되므로, 해시테이블 방식에 비해 데이터가 클 경우 더 느릴 수 있습니다.

## 추가 참고사항

문제의 제약 조건에서 배열 요소 값이 0부터 1,000까지만 제한되므로, 해시테이블 대신 크기가 1,001인 정수 배열을 사용한 빈도 배열로도 구현이 가능합니다.
하지만 일반적인 정수 범위를 다루거나 코드 구현의 간결함을 고려할 때 해시셋을 사용하는 것이 가장 직관적인 접근법입니다.
결과 반환 시 순서가 지정되지 않았으므로, 해시셋에서 리스트로 변환하는 순서가 매 실행마다 다를 수 있으나 이는 문제 요구사항에 부합합니다.
