## 문제

정수 배열 `nums`가 비감소 순서로 주어집니다. 각 요소의 제곱을 계산한 후, 비감소 순서로 정렬된 배열을 반환해야 합니다. 입력은 최대 10^4개의 요소를 가질 수 있으며, 각 요소의 범위는 -10^4에서 10^4까지입니다. 이 문제는 제곱 후 정렬을 다시 수행하지 않고도 선형 시간 내에 해결할 수 있는 방법을 요구합니다.

## 접근 방법

배열이 이미 정렬되어 있으므로, 가장 큰 절대값부터 제곱하여 결과 배열을 역순으로 채울 수 있습니다. 왼쪽 포인터는 시작 위치에서, 오른쪽 포인터는 끝 위치에서 시작합니다. 각 단계에서 양쪽 끝의 제곱값을 비교하고, 더 큰 값을 결과의 마지막 위치에 저장한 후 해당 포인터를 이동시킵니다. 이 방법은 각 요소를 한 번씩 처리하므로 O(n) 시간 내에 완료됩니다.

```python
def sortedSquares(nums):
    n = len(nums)
    result = [0] * n
    left, right = 0, n - 1
    idx = n - 1
    while left <= right:
        left_sq = nums[left] ** 2
        right_sq = nums[right] ** 2
        if left_sq > right_sq:
            result[idx] = left_sq
            left += 1
        else:
            result[idx] = right_sq
            right -= 1
        idx -= 1
    return result
```

## 풀이

위 코드에서 `sortedSquares` 함수는 입력 배열을 수정하지 않고, 제곱된 값을 역순으로 채워 정렬된 결과를 생성합니다. `while left <= right` 루프는 각 요소를 정확히 한 번씩 처리하므로 전체 시간 복잡도는 **O(n)**입니다. 결과 배열을 위해 추가 공간이 필요하므로 공간 복잡도는 **O(n)**입니다. 이 방법은 음수와 양수를 모두 처리하며, 중복된 제곱값도 올바르게 유지합니다.

```python
# 예시 사용법
print(sortedSquares([-4, -1, 0, 3, 10]))  # [0, 1, 9, 16, 100]
print(sortedSquares([-7, -3, 2, 3, 11])) # [4, 9, 9, 49, 121]
```

## 다른 풀이 방법

가장 간단한 방법은 각 요소를 제곱한 후 기본 정렬 함수를 사용하여 배열을 정렬하는 것입니다. 이 방법은 각 요소를 한 번 제곱하므로 O(n) 시간 소요되지만, 정렬 단계에서 O(n log n) 시간이 추가로 필요합니다. 구현은 간단하지만, 선형 시간 해결책보다 비효율적입니다.

```python
def sortedSquares_naive(nums):
    return sorted(x * x for x in nums)
```

시간 복잡도: **O(n log n)**, 공간 복잡도: **O(n)** (정렬 시 추가 공간 발생).

## 추가 참고사항

- 이 문제는 음수와 0을 포함할 수 있지만, 제곱 후 모든 값이 비음수가 되므로 결과 배열은 자동으로 정렬됩니다.
- 두 포인터 접근법은 정렬된 입력에서만 작동하며, 무작위 배열에는 적용할 수 없습니다.
- 매우 큰 입력 크기(예: 10^6)의 경우에도 O(n) 방법은 여전히 효율적이며, O(n log n) 방법은 noticeably 더 느려질 수 있습니다.
