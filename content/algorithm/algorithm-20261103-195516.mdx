## 문제

이진트리의 최대 깊이는 루트 노드에서 가장 멀리 떨어진 리프 노드까지 내려가는 경로에 있는 노드의 개수이다. 주어진 이진트리의 `root`를 입력받아 최대 깊이를 반환한다. 트리의 노드 개수는 0에서 10,000 사이이다.

## 접근 방법

각 노드의 최대 깊이는 왼쪽 서브트리와 오른쪽 서브트리 중 더 깊은 깊이보다 1 큰 값과 동일하다. 이 재귀적 특성을 활용해 현재 노드의 왼쪽과 오른쪽 자식 노드의 깊이를 각각 구한 후, 더 큰 값에 1을 더해 반환하는 방식으로 풀 수 있다. 루트가 없는 경우 깊이는 0이다.

## 풀이

재귀 함수를 사용해 깊이 우선 탐색(DFS)을 수행한다. 현재 노드가 null이면 0을 반환하고, 그렇지 않으면 왼쪽과 오른쪽 서브트리의 깊이를 재귀적으로 계산한다.

```python
class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        if root is None:
            return 0
        left = self.maxDepth(root.left)
        right = self.maxDepth(root.right)
        return max(left, right) + 1
```

시간복잡도: O(N). 트리의 모든 노드를 한 번씩 방문한다.
공간복잡도: O(H). 재귀 호출 스택의 최대 깊이에 비례하며, H는 트리의 높이이다.

## 다른 풀이 방법

큐를 사용하는 너비 우선 탐색(BFS)을 통해 레벨 순회 방식으로 최대 깊이를 구할 수 있다. 루트를 큐에 넣고, 현재 레벨의 노드 수만큼 반복하며 자식 노드를 추가한다. 레벨이 끝날 때마다 깊이를 1씩 증가시킨다.

```python
import collections

class Solution:
    def maxDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0
        
        queue = collections.deque([root])
        depth = 0
        
        while queue:
            depth += 1
            for _ in range(len(queue)):
                node = queue.popleft()
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
                    
        return depth
```

시간복잡도: O(N). 모든 노드를 한 번 방문한다.
공간복잡도: O(N). 큐에 저장되는 노드 수를 차지한다. DFS는 트리가 기울어져 있을 때 스택 크기가 커질 수 있지만, BFS는 레벨 폭에 따라 메모리를 사용한다.

## 추가 참고사항

재귀 방식은 구현이 단순하지만 트리가 매우 깊으면 스택 오버플로우가 발생할 수 있다. BFS는 메모리 사용량이 레벨 폭에 따라 달라지며, 불균형한 트리에서도 안정적인 깊이를 구할 수 있다. Python의 `collections.deque`는 양쪽 끝에서의 삽입과 삭제를 O(1) 시간에 처리한다.
