## 문제

`file.txt` 파일에는 한 줄에 하나씩 전화번호가 저장되어 있습니다. 이 파일에서 유효한 전화번호만 출력하는 Bash 스크립트를 작성해야 합니다. 유효한 전화번호는 다음 두 가지 형식 중 하나여야 합니다.
1. `(xxx) xxx-xxxx`
2. `xxx-xxx-xxxx`

여기서 `x`는 숫자를 의미합니다. 각 줄은 앞뒤 공백이 없으며, 형식에 맞지 않는 전화번호는 무시해야 합니다.

## 접근 방법

이 문제는 줄 단위의 텍스트 필터링이 필요하므로, `grep` 명령어와 정규식(Regular Expression)을 활용하는 것이 적합합니다. `grep -E` 옵션을 사용하면 확장 정규식을 지원하여 `|`(OR 조건)을 쉽게 처리할 수 있습니다. 유효한 전화번호 형식은 두 가지이므로, 각 형식에 대한 정규식을 조합하여 패턴을 구성합니다. 줄의 시작과 끝을 정확히 매칭하기 위해 `^`와 `$`를 사용하여 공백이나 다른 문자가 섞이는 것을 방지합니다.

## 풀이

`grep -E`를 사용하여 두 가지 형식을 동시에 매칭하는 정규식을 적용합니다.

```bash
grep -E '^(\([0-9]{3}\) [0-9]{3}-[0-9]{4}|[0-9]{3}-[0-9]{3}-[0-9]{4})$' file.txt
```

이 명령어는 `file.txt`를 읽으며 정규식 패턴과 일치하는 줄만 표준 출력합니다. 패턴은 `^`로 시작하여 `(xxx) xxx-xxxx` 또는 `xxx-xxx-xxxx` 형식을 매칭하고, `$`로 끝나는 구조입니다.

- **시간복잡도**: 파일의 각 라인을 한 번씩 스캔하므로 O(N)입니다. (N은 파일의 총 라인 수)
- **공간복잡도**: 현재 라인을 저장하는 버퍼 외의 추가 메모리를 사용하지 않으므로 O(1)입니다.

## 다른 풀이 방법

`grep -P`를 사용하여 Perl 호환 정규식(PCRE)의 문법적 편의성을 활용할 수 있습니다.

```bash
grep -P '^(\(\d{3}\) \d{3}-\d{4}|\d{3}-\d{3}-\d{4})$' file.txt
```

- **차이점**: `grep -P`는 `\d`를 사용하여 숫자를 표현할 수 있어 정규식 가독성이 높습니다. 또한 `grep -E`와 달리 문자 클래스(`[]`) 내부의 특수 문자 처리에 대한 유연성이 다를 수 있습니다.
- **단점**: 시스템에 따라 `grep -P`가 지원되지 않을 수 있습니다. `grep -E`는 대부분의 POSIX 준수 시스템에서 표준으로 지원되므로, 이 문제에서는 `grep -E`가 더 안전한 선택입니다.

## 추가 참고사항

정규식 매칭 시 주의할 점은 패턴의 범위를 명확히 하는 것입니다.

<Callout type="warning" title="정규식 범위 제한">
`^`와 `$`를 사용하여 전체 줄 매칭을 강제하지 않으면, 전화번호와 동일한 패턴을 포함하는 더 긴 문자열(예: `abc(123) 456-7890xyz`)도 부분 일치로 매칭될 수 있습니다. 항상 시작과 끝을 명시해야 합니다.
</Callout>

또한, 소괄호 `(`와 `)`는 정규식에서 그룹화를 위해 예약된 특수 문자이므로, 리터럴 소괄호를 매칭하려면 반드시 이스케이프(`\(`, `\)`) 처리해야 합니다.

```bash
# (xxx) 형식의 괄호는 특수문자이므로 반드시 이스케이프해야 합니다
\(
\)
```

`file.txt`가 존재하지 않거나 읽기 권한이 없으면 `grep`은 오류를 출력하고 종료되므로, 실제 배포 스크립트에서는 파일 존재 여부를 확인하는 과정이 추가될 수 있습니다.
