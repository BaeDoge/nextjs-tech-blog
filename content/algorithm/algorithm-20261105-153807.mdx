## 문제

정수 배열 `nums`가 매개변수로 주어집니다. 이 배열에 포함된 정수들 중 자릿수의 개수가 짝수인 정수의 개수를 반환하는 알고리즘을 구현해야 합니다.

예를 들어 입력이 `[12, 345, 2, 6, 7896]`인 경우:
- `12`: 2자리(짝수)
- `345`: 3자리(홀수)
- `2`: 1자리(홀수)
- `6`: 1자리(홀수)
- `7896`: 4자리(짝수)
자릿수가 짝수인 정수는 `12`와 `7896`으로 총 2개입니다.

예 2: `[555, 901, 482, 1771]` → 유일하게 `1771`이 4자리(짝수)이므로 출력은 `1`입니다.

제약 조건은 다음과 같습니다:
- 배열의 길이는 1 이상 500 이하입니다.
- 각 정수는 1 이상 $10^5$ 이하입니다.

## 접근 방법

배열의 각 정수를 순회하며 자릿수를 확인합니다. 자릿수가 짝수인지 판단하는 방법은 두 가지로 나뉩니다.

첫째, 정수를 문자열로 변환하여 길이를 확인합니다. 이 방법은 구현이 간단하고 가독성이 높습니다.

둘째, 수학적 연산을 통해 자릿수를 계산합니다. 정수를 10으로 계속 나누어 나머지가 0이 될 때까지 반복하거나, 자릿수가 2, 4, 6인 경우를 명시적으로 체크합니다. 주어진 제약 조건상 정수는 최대 6자리이므로, 3자리(100~999)와 5자리(10,000~99,999)를 제외한 경우가 짝수 자릿수임을 활용합니다.

## 풀이

문자열 변환 방식을 사용한 구현입니다. Python의 `len()`과 `str()`을 활용하면 코드를 간결하게 작성할 수 있습니다.

```python
def findNumbers(nums: list[int]) -> int:
    count = 0
    for num in nums:
        digit_count = len(str(num))
        if digit_count % 2 == 0:
            count += 1
    return count
```

- 시간 복잡도: $O(N \cdot D)$. $N$은 배열의 길이, $D$는 정수의 최대 자릿수입니다. 제약 조건에서 $D$는 상수(최대 6)이므로 $O(N)$입니다.
- 공간 복잡도: $O(D)$. 정수를 문자열로 변환할 때 일시적으로 필요한 공간입니다. $D$는 상수이므로 $O(1)$로 간주하기도 합니다.

## 다른 풀이 방법

수학적 연산을 사용하여 자릿수를 계산하는 방법입니다. 정수를 10으로 반복적으로 나누어 자릿수를 구한 후, 짝수인지 확인합니다. 이 방법은 문자열 할당 비용을 줄일 수 있습니다.

```python
def findNumbers(nums: list[int]) -> int:
    count = 0
    for num in nums:
        digits = 0
        temp = num
        while temp > 0:
            temp //= 10
            digits += 1
        if digits % 2 == 0:
            count += 1
    return count
```

- 시간 복잡도: $O(N \cdot D)$. 각 정수마다 자릿수($D$)만큼 나누기 연산이 수행됩니다.
- 공간 복잡도: $O(1)$. 추가적인 메모리 사용을 필요로 하지 않습니다.

## 추가 참고사항

- 입력 정수는 양수만 포함하므로, 음수 처리나 0에 대한 특수 케이스를 고려할 필요가 없습니다.
- 문자열 변환 방식은 대부분의 언어에서 내장 함수를 제공하므로 실수를 줄이고 빠르게 구현하기에 유리합니다.
- 수학 방식은 문자열 할당 오버헤드가 없으므로 메모리 측면에서 이점이 있을 수 있습니다.
- 제약 조건에서 최댓값이 $10^5$로 6자리이므로, 자릿수 계산 루프의 반복 횟수는 최대 6회로 고정됩니다.
