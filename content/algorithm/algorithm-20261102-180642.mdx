## 문제

주어진 정수 배열 `triangle`은 삼각형 형태를 이루고 있습니다. 각 행의 길이는 인덱스에 따라 1씩 증가하며, `triangle[i].length == triangle[i - 1].length + 1`을 만족합니다. 상단부터 하단까지 내려올 때 경로에 포함된 숫자의 합을 최소화해야 합니다.

현재 위치가 `i`일 때, 다음 단계로 이동할 수 있는 위치는 하단 행의 `i` 또는 `i + 1`입니다. 예를 들어 입력이 `[[2],[3,4],[6,5,7],[4,1,8,3]]`일 때, 최단 경로는 `2 -> 3 -> 5 -> 1`이며 합은 11입니다. 삼각형의 행 개수는 최대 200개이며, 각 원소의 값은 -10^4에서 10^4 사이입니다.

## 접근 방법

이 문제는 하위 문제가 중첩되는 구조이므로 동적 계획법(Dynamic Programming)을 적용할 수 있습니다. 상단에서 하단으로 내려가며 최소합을 계산하는 방식(bottom-up)보다는, 하단에서 상단으로 올라가며 최소합을 누적하는 방식(top-down의 역방향)이 구현하기 더 직관적입니다.

각 행의 각 원소에 대해, 그 위치에서 하단까지 내려갈 때의 최소 경로를 계산합니다. 특정 위치 `(i, j)`에서 하단까지의 최소 경로는 `triangle[i][j]`에 하단 행의 인접한 두 위치 `(i+1, j)`와 `(i+1, j+1)`에서의 최소 경로 중 작은 값을 더한 것과 같습니다. 이를 행 단위에서 위로 올라가며 반복하면 최상단 원소에 도달했을 때의 값이 전체 최소 경로 합이 됩니다.

공간 복잡도를 줄이기 위해 별도의 2차원 DP 테이블을 사용하지 않고, 입력 배열 `triangle` 자체를 최소합 값을 저장하는 용도로 재사용하거나, 하단 행의 크기인 `O(n)` 크기의 1차원 배열을 사용합니다. 여기서는 입력 배열을 직접 수정하여 공간 복잡도를 O(1)에 가깝게 만드는 접근을 보입니다.

## 풀이

하단 행부터 시작하여 위쪽으로 올라가며 각 원소의 값을 '현재 원소의 값 + 다음 행의 인접한 두 원소 중 최소값'으로 갱신합니다. 마지막에 `triangle[0][0]`에 저장된 값이 정답입니다.

```python
class Solution:
    def minimumTotal(self, triangle: list[list[int]]) -> int:
        # 삼각형의 행 개수
        rows = len(triangle)
        
        # 하단 행부터 시작하여 위로 올라감
        for row in range(rows - 2, -1, -1):
            for col in range(len(triangle[row])):
                # 현재 위치에서 하단까지의 최소 경로 합은
                # 현재 값 + (아래 왼쪽, 아래 오른쪽 중 작은 값)
                triangle[row][col] += min(triangle[row + 1][col], triangle[row + 1][col + 1])
                
        return triangle[0][0]
```

시간 복잡도: 각 원소를 정확히 한 번씩 방문하며 상수를 수행하므로 O(N)입니다. 여기서 N은 삼각형 내 원소의 총 개수입니다. 삼각형의 행이 $R$개일 때 $N \approx R^2/2$입니다.
공간 복잡도: 입력 배열을 직접 수정하여 추가 공간을 사용하지 않으므로 O(1)입니다.

## 다른 풀이 방법

1차원 배열을 사용하여 공간 복잡도를 O(R)로 최적화할 수 있습니다. `dp` 배열의 길이를 하단 행의 길이인 $R$로 초기화하고, 하단 행의 값을 복사한 후 위쪽으로 올라가며 값을 갱신합니다. 이때 왼쪽에서 오른쪽으로 순회하면 갱신되지 않은 하단 행의 값이 필요하므로, 혹은 별도의 변수를 이용해 이전 값 보존이 필요합니다. 보통은 하단 행 값으로 `dp`를 초기화하고, 각 행을 처리할 때 `dp[col] = triangle[row][col] + min(dp[col], dp[col+1])`로 갱신하면 됩니다. 이 방법은 입력 배열을 변경하지 않아야 할 때 유용하며, 추가 공간은 삼각형의 높이 $R$에 비례합니다.

## 추가 참고사항

문제에서 요구하는 Follow-up는 O(n) extra space(n은 삼각형의 행 수)로 풀 수 있는지입니다. 위의 풀이 중 입력 배열을 수정하지 않는 1차원 DP 배열 방식이 이에 해당합니다. 만약 입력 배열의 원소가 음수일 경우에도 로직은 동일하게 동작하며, 최소값을 찾는 과정이므로 음수 처리에 특별히 주의할 필요는 없습니다. 제약 조건에서 $R \le 200$이므로 $O(R^2)$ 알고리즘은 충분히 빠르게 동작합니다.
