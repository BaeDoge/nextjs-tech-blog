## 문제

임의의 숫자 배열이 주어질 때, 이를 재배열하여 등차수열(Arithmetic Progression)을 만들 수 있는지 판별하는 문제입니다. 등차수열은 임의의 두 인접한 원소 간의 차이가 일정한 수열을 의미합니다. 배열의 길이는 2 이상 1000 이하이며, 원소 값의 범위는 -10^6에서 10^6 사이입니다.

## 접근 방법

주어진 배열을 오름차순 또는 내림차순으로 정렬하면, 등차수열이 가능한 경우 원소들은 일정한 간격으로 배치됩니다. 정렬된 배열에서 첫 번째 원소와 두 번째 원소의 차이(공차)를 구한 후, 이 공차가 모든 인접한 원소 쌍에 대해 동일한지 확인하면 됩니다. 만약 모든 인접 원소의 차이가 공차와 일치한다면 `true`를, 하나라도 다르다면 `false`를 반환합니다.

## 풀이

먼저 배열을 정렬합니다. 그 후, 첫 번째와 두 번째 원소의 차이를 공차로 설정합니다. 이후 배열의 끝까지 순회하며 인접한 원소의 차이가 공차와 일치하는지 검증합니다. 검증 과정에서 불일치가 발견되면 즉시 `false`를 반환하고, 모든 검증을 통과하면 `true`를 반환합니다.

```python
class Solution:
    def canMakeArithmeticProgression(self, arr: List[int]) -> bool:
        arr.sort()
        diff = arr[1] - arr[0]
        
        for i in range(2, len(arr)):
            if arr[i] - arr[i-1] != diff:
                return False
                
        return True
```

시간복잡도: 정렬에 $O(N \log N)$, 순회 검증에 $O(N)$이므로 전체 $O(N \log N)$입니다.
공간복잡도: 정렬 알고리즘의 구현에 따라 다르나 일반적으로 $O(1)$ 또는 $O(N)$입니다.

## 다른 풀이 방법

정렬 없이 최소값과 최대값을 찾아 공차를 계산한 후, 모든 원소가 등차수열의 항으로 존재하는지 확인하는 방법도 있습니다. 등차수열의 항 개수가 $N$이므로 공차는 $(max - min) / (N - 1)$이 됩니다. 공차가 정수가 아니거나, 배열에 중복 원소가 있거나, 주어진 공차로 생성되는 모든 항이 배열에 정확히 한 번씩 존재하는지 집합(Set)을 사용하여 확인합니다. 이 방법은 정렬을 사용하지 않아 시간복잡도 $O(N)$을 달성할 수 있습니다.

```python
class Solution:
    def canMakeArithmeticProgression(self, arr: List[int]) -> bool:
        min_val = min(arr)
        max_val = max(arr)
        
        if (max_val - min_val) % (len(arr) - 1) != 0:
            return False
            
        diff = (max_val - min_val) // (len(arr) - 1)
        if diff == 0:
            return len(set(arr)) == 1
            
        seen = set()
        for num in arr:
            if (num - min_val) % diff != 0:
                return False
            if num in seen:
                return False
            seen.add(num)
            
        return len(seen) == len(arr)
```

시간복잡도: $O(N)$
공간복잡도: $O(N)$ (집합 저장용)

## 추가 참고사항

- 정렬 기반 접근법은 구현이 매우 간단하며, $N=1000$이라는 제약 조건 하에서 충분히 빠른 속도를 보장합니다.
- 등차수열의 정의상 공차가 0인 경우(모든 원소가 동일한 상수 수열)도 등차수열로 간주됩니다.
- 배열의 길이가 2인 경우, 두 원소 간의 차이는 항상 일정하므로 항상 `true`를 반환합니다.
