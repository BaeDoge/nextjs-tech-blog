## 문제

정수 배열 `arr`이 주어집니다. 배열의 각 원소를 이진수로 나타낼 때, 1의 개수가 적은 순서대로 오름차순 정렬해야 합니다. 만약 1의 개수가 같으면 원소의 값 자체를 오름차순으로 정렬합니다. 정렬된 배열을반환합니다. 예를 들어 `arr = [0,1,2,3,4,5,6,7,8]`이면 1의 개수별로 묶여 `[0,1,2,4,8,3,5,6,7]`이 됩니다.

## 접근 방법

각 숫자의 이진수에서 1의 개수를 센 후, 정렬 기준으로 사용합니다. Python에서는 `bin(x).count('1')`이나 Brian Kernighan 알고리즘으로 1의 개수를 구할 수 있습니다. 정렬 시 키를 (1의 개수, 숫자) 튜플로 설정하면 간단하게 구현됩니다. 시간 복잡도는 정렬에 O(n log n), 1 카운트에 O(log x)가 소모됩니다.

## 풀이

```python
def sortByBits(arr):
    def popcount(x):
        # Brian Kernighan's algorithm
        cnt = 0
        while x:
            x &= x - 1
            cnt += 1
        return cnt
    return sorted(arr, key=lambda x: (popcount(x), x))
```

시간 복잡도: O(n log n) (정렬 기준 계산 포함)  
공간 복잡도: O(n) (정렬 결과 저장)

## 다른 풀이 방법

1의 개수별로 그룹을 나눈 후, 각 그룹 내에서만 정렬하는 버uckets 방식입니다.  

```python
def sortByBits(arr):
    buckets = [[] for _ in range(15)]  # 1의 개수는 최대 14개
    for num in arr:
        cnt = bin(num).count('1')
        buckets[cnt].append(num)
    result = []
    for b in buckets:
        result.extend(sorted(b))
    return result
```

이 방법도 기본적으로 O(n log n) 시간이 들지만, 그룹별 정렬로 인해 실제 러닝타임이 더 짧을 수 있습니다. 공간 복잡도는 O(n)입니다.

## 추가 참고사항

`arr`의 길이는 최대 500, 원소는 최대 10^4이므로 이진수 표현의 1의 개수는 최대 14개입니다. 따라서 미리 1의 개수를 계산해 두거나, 내장 함수를 사용해 최적화할 수 있습니다. Python의 `sort`는 안정 정렬이므로 동일한 1의 개수를 가진 원소의 원래 순서가 유지됩니다. 다른 언어에서는 `__builtin_popcount` 같은 내장 함수를 사용하면 더 빠를 수 있습니다.
