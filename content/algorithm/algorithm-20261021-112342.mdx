## 문제

문자열의 '힘(power)'은 오직 하나의 고유한 문자로만 구성된 비어 있지 않은 부분 문자열의 최대 길이를 의미합니다. 주어진 문자열 `s`에 대해 그 힘의 값을 반환하는 함수를 구현해야 합니다.

예를 들어, 입력이 `"leetcode"`인 경우 `"ee"`가 길이가 2인 가장 긴 단일 문자 부분 문자열이므로 반환 값은 2입니다. 입력이 `"abbcccddddeeeeedcba"`인 경우 `"eeeee"`가 길이가 5이므로 반환 값은 5입니다.

문자열의 길이는 1 이상 500 이하이며, 소문자 영어 알파벳으로만 구성되어 있습니다.

## 접근 방법

문자열의 각 문자를 앞에서부터 순회하며 연속된 동일한 문자의 길이를 추적하면 됩니다. 이전 문자와 현재 문자가 같으면 현재 연속 길이를 1 증가시키고, 다르면 현재 연속 길이를 1로 초기화합니다.

이 과정에서 기록된 최대 길이를 갱신하면 됩니다. 문자열의 길이가 매우 작으므로(최대 500), 단순한 순회 방식으로 충분히 효율적으로 해결할 수 있습니다.

## 풀이

문자열을 한 번 순회하며 현재 연속되는 문자의 개수를 세고, 최대값을 업데이트하는 방식으로 구현합니다.

```python
class Solution:
    def maxPower(self, s: str) -> int:
        if not s:
            return 0
        
        max_len = 1
        current_len = 1
        
        for i in range(1, len(s)):
            if s[i] == s[i - 1]:
                current_len += 1
            else:
                current_len = 1
            
            if current_len > max_len:
                max_len = current_len
                
        return max_len
```

시간복잡도: O(N) (N은 문자열의 길이)
공간복잡도: O(1)

## 다른 풀이 방법

`itertools.groupby`를 사용하여 연속된 동일한 문자를 그룹화하는 방법도 있습니다. 이 함수는 연속된 동일한 원소들을 그룹으로 묶어주므로, 각 그룹의 길이를 계산한 후 최대값을 찾으면 됩니다.

```python
from itertools import groupby

class Solution:
    def maxPower(self, s: str) -> int:
        if not s:
            return 0
        
        return max(len(list(group)) for char, group in groupby(s))
```

시간복잡도: O(N)
공간복잡도: O(N) (그룹화 과정에서 임시 리스트가 생성될 수 있음)

## 추가 참고사항

문자열의 길이가 1인 경우, 루프가 실행되지 않을 수 있으므로 초기값 설정에 주의해야 합니다. 위 풀이에서는 `max_len`을 1로 초기화하고 루프를 1번 인덱스부터 시작하여 이를 처리했습니다.

이 문제는 단순한 시뮬레이션 문제이므로, 조건 분기나 예외 처리만 정확히 하면 쉽게 해결할 수 있습니다.
