## 문제

정수 배열 `nums`가 주어집니다. 이 배열에서 세 수를 선택했을 때 삼각형의 세 변이 될 수 있는 조합의 개수를 반환해야 합니다.

세 수 `a`, `b`, `c`가 삼각형의 세 변이 되기 위해서는 다음 세 부등식을 모두 만족해야 합니다.
- `a + b > c`
- `a + c > b`
- `b + c > a`

예를 들어, `nums = [2, 2, 3, 4]`인 경우, 유효한 조합은 `(2, 3, 4)`, `(2, 3, 4)`, `(2, 2, 3)`으로 총 3개입니다.

## 접근 방법

세 수의 부등식을 모두 확인하는 것은 복잡하므로, 배열을 정렬하여 조건을 단순화할 수 있습니다.
배열을 오름차순으로 정렬하면 `nums[i] <= nums[j] <= nums[k]` (`i < j < k`)가 성립합니다.
이때 가장 큰 변은 `nums[k]`이므로, 나머지 두 변의 합이 가장 큰 변보다 크면 삼각형이 성립합니다.
즉, `nums[i] + nums[j] > nums[k]` 조건만 확인하면 충분합니다.

이 조건을 효율적으로 찾기 위해 투 포인터 기법을 사용할 수 있습니다.
고정된 `k`에 대해 `i`와 `j`를 움직이며 조건을 만족하는 쌍의 개수를 세면 됩니다.

## 풀이

배열을 정렬한 후, 가장 큰 변 `c` (`nums[k]`)를 뒤에서부터 고정합니다.
`k`보다 작은 인덱스 범위에서 두 포인터 `left`와 `right`를 사용하여 `nums[left] + nums[right] > nums[k]`를 만족하는 쌍을 찾습니다.

1. `nums`를 정렬합니다.
2. `k`를 `n-1`부터 `2`까지 감소시키며 가장 큰 변을 고정합니다.
3. `left = 0`, `right = k - 1`로 설정합니다.
4. `nums[left] + nums[right] > nums[k]`이면, `left`부터 `right`까지의 모든 원소는 `nums[right]`와 합쳐져도 조건을 만족합니다.
   - 따라서 `right - left`개의 조합이 추가됩니다.
   - `right`를 왼쪽으로 이동하여 다음 후보를 확인합니다.
5. 조건을 만족하지 않으면, 합을 키우기 위해 `left`를 오른쪽으로 이동합니다.
6. `k`가 `2`가 될 때까지 반복합니다.

```python
class Solution:
    def triangleNumber(self, nums: List[int]) -> int:
        nums.sort()
        n = len(nums)
        count = 0
        
        # 가장 큰 변 nums[k]를 고정
        for k in range(n - 1, 1, -1):
            left = 0
            right = k - 1
            
            while left < right:
                if nums[left] + nums[right] > nums[k]:
                    # nums[left] ~ nums[right-1] 모두 nums[right]와 합쳐져서 조건 만족
                    count += (right - left)
                    right -= 1
                else:
                    # 합이 작으므로 더 큰 수를 찾아야 함
                    left += 1
                    
        return count
```

- 시간 복잡도: 정렬에 $O(N \log N)$, 투 포인터 순회에 $O(N^2)$이므로 전체 $O(N^2)$입니다.
- 공간 복잡도: 정렬 알고리즘 구현에 따라 다르나 일반적으로 $O(\log N)$ 또는 $O(N)$입니다.

## 다른 풀이 방법

이분 탐색(Binary Search)을 사용할 수도 있습니다.
`nums[i]`와 `nums[j]` (`i < j`)를 고정했을 때, `nums[i] + nums[j] > nums[k]`를 만족하는 `k`의 범위를 이분 탐색으로 찾습니다.
배열이 정렬되어 있으므로, `nums[i] + nums[j] - 1`보다 큰 첫 번째 인덱스를 찾으면 됩니다.
이 경우 시간 복잡도는 $O(N^2 \log N)$으로, 투 포인터 방법보다 느립니다.

## 추가 참고사항

- 입력 배열에 `0`이 포함될 수 있습니다. 삼각형의 변의 길이는 양수여야 하므로, `0`은 삼각형 만들기에 기여하지 않습니다.
- 정렬 후 투 포인터를 사용하면 중복 계산을 피하고 효율적으로 조합의 개수를 셀 수 있습니다.
- 제약 조건에서 `nums.length`는 최대 1000이므로 $O(N^2)$ 알고리즘이 충분히 통과 가능합니다.
