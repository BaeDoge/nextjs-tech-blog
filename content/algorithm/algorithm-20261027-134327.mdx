## 문제

정수 배열 `nums`가 주어질 때, 선택된 부분수열의 원소 합이 선택되지 않은 나머지 원소의 합보다 엄격하게 크도록 하는 부분수열을 찾아야 합니다. 이때 조건을 만족하는 부분수열 중 원소의 개수가 가장 작은 것을 선택하며, 원소의 개수가 동일한 경우 원소의 합이 가장 큰 것을 선택합니다. 마지막으로 반환할 부분수열은 내림차순으로 정렬된 상태여야 합니다. 주어진 제약 조건 하에서 해는 유일하게 존재하며, 배열의 길이는 500 이하, 원소의 값은 100 이하입니다.

## 접근 방법

나머지 원소의 합보다 큰 합을 만들려면, 전체 합에서 작은 원소부터 제외하고 큰 원소부터 선택하는 것이 효율적입니다. 큰 원소일수록 적은 개수로 합을 빠르게 늘릴 수 있기 때문입니다. 따라서 배열을 내림차순으로 정렬한 후, 앞에서부터 원소를 하나씩 선택하며 현재 선택된 원소의 합과 나머지 원소의 합을 비교합니다. 선택된 원소의 합이 나머지 원소의 합을 초과하는 시점에서 멈추면, 최소 개수와 최대 합을 동시에 만족하는 부분수열을 얻을 수 있습니다.

## 풀이

배열을 내림차순으로 정렬한 후, 전체 원소의 합을 구합니다. 정렬된 배열을 앞에서부터 순회하며 원소를 선택하고, 선택된 원소의 합을 누적합니다. 이 과정에서 선택된 원소의 합이 전체 합에서 현재 선택된 원소의 합을 뺀 나머지 합보다 커지면 루프를 종료합니다. 이때까지 선택된 원소들의 리스트가 정답입니다. Python의 `sort` 메서드는 안정 정렬이며 내림차순 정렬 시 시간복잡도는 O(N log N)입니다.

```python
class Solution:
    def minSubsequence(self, nums: List[int]) -> List[int]:
        # 배열을 내림차순으로 정렬
        nums.sort(reverse=True)
        
        # 전체 원소의 합 계산
        total_sum = sum(nums)
        
        current_sum = 0
        result = []
        
        # 원소를 앞에서부터 선택
        for num in nums:
            current_sum += num
            result.append(num)
            
            # 선택된 원소의 합이 나머지 원소의 합보다 큰지 확인
            # 나머지 원소의 합은 total_sum - current_sum
            if current_sum > total_sum - current_sum:
                break
                
        return result
```

시간복잡도: O(N log N). 정렬에 O(N log N)이 소요되고, 순회에는 O(N)이 소요됩니다.
공간복잡도: O(N). 정렬 알고리즘의 공간 복잡도 및 결과 리스트 생성을 위해 O(N)의 보조 공간이 필요합니다.

## 다른 풀이 방법

원소의 값의 범위가 작으므로(1 <= nums[i] <= 100), 카운팅 정렬을 활용할 수 있습니다. 원소의 빈도수를 세어 배열에 저장한 후, 값이 큰 순서부터 원소를 선택합니다. 이 경우 정렬 과정이 O(N + K)로 수행되므로, K(원소의 최대값)가 N에 비해 작을 때 효율적일 수 있습니다. 전체 시간복잡도는 O(N + K)이며, K=100이므로 사실상 O(N)으로 간주할 수 있습니다. 공간복잡도는 값의 범위인 O(K)입니다.

```python
class Solution:
    def minSubsequence(self, nums: List[int]) -> List[int]:
        # 원소 값의 빈도수 계산 (카운팅 정렬 기반)
        count = [0] * 101
        for num in nums:
            count[num] += 1
            
        total_sum = sum(nums)
        current_sum = 0
        result = []
        
        # 큰 값부터 선택
        for val in range(100, 0, -1):
            # 해당 값의 원소가 count[val]개 있음
            for _ in range(count[val]):
                current_sum += val
                result.append(val)
                
                if current_sum > total_sum - current_sum:
                    return result
```

## 추가 참고사항

이 문제는 그리디 알고리즘의 전형적인 예시입니다. '최소 크기'와 '최대 합'이라는 두 가지 조건이 동시에 주어졌을 때, 큰 원소부터 선택하는 전략이 두 조건을 모두 만족시킵니다. 작은 원소를 선택하면 합을 늘리기 위해 더 많은 원소가 필요해져 부분수열의 크기가 증가하거나, 같은 크기라도 합이 작아지기 때문입니다. 또한, 문제에서 반환 순서를 내림차순으로 명시했으므로 정렬 과정이 필수적입니다.
