## 문제

두 문자열 `s`와 `t`가 입력될 때, `t`가 `s`의 아나그램(Anagram)인지 판별해야 합니다.
아나그램이란 두 단어가 동일한 알파벳으로 구성되어 있는 경우를 의미합니다.
`true`이면 아나그램이며, `false`이면 그렇지 않습니다.
문자열은 소문자 영문자로만 구성되며 길이는 최대 50,000자입니다.

## 접근 방법

두 문자열이 아나그램이 되려면 다음 세 가지 조건을 모두 만족해야 합니다.
첫째, 두 문자열의 길이가 같아야 합니다.
둘째, 각 문자의 등장 횟수가 완전히 동일해야 합니다.
셋째, 문자의 종류에 제한이 없으므로 모든 문자를 아우를 수 있는 구조가 필요합니다.

<Steps>
<Step title="길이 비교">두 문자열의 길이가 다르면 즉시 아나그램이 될 수 없으므로 `false`를 반환합니다.</Step>
<Step title="빈도수 저장">문자의 등장 횟수를 저장하기 위해 배열이나 해시맵을 사용합니다.</Step>
<Step title="빈도수 비교">문자를 탐색하며 카운트를 업데이트하고, 최종적으로 두 구조체의 카운트가 일치하는지 검증합니다.</Step>
</Steps>

## 풀이

두 문자열의 길이가 다르면 즉시 `false`를 반환합니다.
소문자 영문자만 고려하므로 길이가 26인 배열을 사용할 수 있습니다.
첫 번째 문자열 `s`를 순회하며 각 문자의 등장 횟수를 카운트합니다.
두 번째 문자열 `t`를 순회하며 카운트를 감소시킵니다.
이후 전체 배열을 순회하여 0이 아닌 값이 있으면 `false`, 모두 0이면 `true`를 반환합니다.

```python
class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        if len(s) != len(t):
            return False
        
        count = [0] * 26
        
        for char in s:
            count[ord(char) - ord('a')] += 1
            
        for char in t:
            count[ord(char) - ord('a')] -= 1
            
        for c in count:
            if c != 0:
                return False
                
        return True
```

- 시간 복잡도: $O(n + k)$ - 문자열 길이만큼 두 번 순회하고, 26개의 배열을 한 번 순회합니다. $n$은 문자열 길이, $k$는 알파벳 수(26)입니다.
- 공간 복잡도: $O(1)$ - 26개의 고정된 크기의 배열을 사용하므로 상수 공간입니다.

## 다른 풀이 방법

정렬을 활용한 방법이 있습니다.
두 문자열을 각각 오름차순으로 정렬한 후, 두 문자열이 동일한지 비교하면 됩니다.
이 방식은 별도의 빈도수 구조를 만들지 않고도 해결할 수 있습니다.

```python
class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        if len(s) != len(t):
            return False
        
        return sorted(s) == sorted(t)
```

## 추가 참고사항

유니코드 문자가 포함된 입력이 주어지면 26 크기의 배열을 사용할 수 없습니다.
이 경우, 언어에서 제공하는 해시맵(Map)이나 딕셔너리(Dict) 구조를 사용해야 합니다.
해시맵을 사용하면 문자열의 길이만큼의 공간을 사용할 수 있으므로 공간 복잡도가 $O(n)$이 됩니다.
시간 복잡도는 여전히 $O(n)$으로 유지됩니다.
아나그램 판별 문제에서는 입력의 성격에 따라 가장 적합한 자료구조를 선택하는 것이 중요합니다.
