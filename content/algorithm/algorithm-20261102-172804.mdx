## 문제

양의 정수로 이루어진 배열 `arr`이 주어질 때, `arr`의 모든 가능한 홀수 길이 부분배열(subarray)의 합을 반환해야 합니다. 부분배열은 배열에서 연속된 요소들의 서열을 의미합니다.

예를 들어 입력이 `arr = [1,4,2,5,3]`일 때, 홀수 길이의 부분배열은 다음과 같습니다:
- 길이 1: `[1], [4], [2], [5], [3]` (합: 1, 4, 2, 5, 3)
- 길이 3: `[1,4,2], [4,2,5], [2,5,3]` (합: 7, 11, 10)
- 길이 5: `[1,4,2,5,3]` (합: 15)
이 모든 합을 더한 값인 58을 반환합니다.

배열의 길이와 각 원소의 값은 `1 <= arr.length <= 100`, `1 <= arr[i] <= 1000`으로 제한됩니다.

## 접근 방법

가장 직관적인 접근법은 배열의 시작 인덱스와 끝 인덱스를 모두 순회하며 부분배열을 생성하고, 해당 부분배열의 길이가 홀수인지 확인한 후 원소들의 합을 누적하는 것입니다.

구체적으로 시작 인덱스 `i`와 종료 인덱스 `j`를 고정하여 부분배열의 범위를 정합니다. 부분배열의 길이는 `j - i + 1`이며, 이 값이 홀수라면 해당 부분배열의 원소 합을 구하여 전체 결과에 더합니다.

이 방법은 구현이 간단하며 제한된 입력 크기에서는 효율적으로 동작합니다.

## 풀이

두 개의 반복문을 사용하여 시작 인덱스와 끝 인덱스를 결정하고, 내부에서 해당 범위의 원소들을 더하는 방식으로 구현합니다.

```python
class Solution:
    def sumOddLengthSubarrays(self, arr: list[int]) -> int:
        total_sum = 0
        n = len(arr)
        
        # 시작 인덱스 i 설정
        for i in range(n):
            # 현재 시작 인덱스에서 끝까지의 부분배열 탐색
            for j in range(i, n):
                # 부분배열의 길이 계산
                length = j - i + 1
                
                # 길이가 홀수인 경우에만 합산
                if length % 2 == 1:
                    # 부분배열의 원소 합 계산 및 누적
                    current_sum = sum(arr[i:j+1])
                    total_sum += current_sum
                    
        return total_sum
```

시간복잡도: O(N^3)
배열 길이 `N`에 대해 시작 인덱스와 끝 인덱스 조합이 O(N^2)이며, 각 부분배열의 합을 계산하는 데 O(N)이 소요되므로 총 O(N^3)입니다.

공간복잡도: O(1)
추가적인 자료구조를 사용하지 않으므로 상수 공간입니다.

## 다른 풀이 방법

각 원소가 몇 개의 홀수 길이 부분배열에 포함되는지 수학적으로 계산하여 O(N) 시간에 해결할 수 있습니다.

인덱스 `i`에 있는 원소가 포함되는 부분배열의 개수는 `(왼쪽 선택지 수 * 오른쪽 선택지 수)`로 계산됩니다. `i`의 왼쪽에 있는 요소의 개수는 `i`개, 오른쪽에 있는 요소의 개수는 `n - i - 1`개입니다. 전체 부분배열의 개수는 `(i + 1) * (n - i)`이며, 이 중 홀수 길이인 부분배열의 개수는 `((i + 1) * (n - i) + 1) // 2`로 구할 수 있습니다.

```python
class Solution:
    def sumOddLengthSubarrays(self, arr: list[int]) -> int:
        total_sum = 0
        n = len(arr)
        
        for i in range(n):
            # i번째 원소가 포함될 수 있는 총 부분배열의 개수
            total_subarrays = (i + 1) * (n - i)
            # 그 중 홀수 길이인 부분배열의 개수
            odd_subarrays = (total_subarrays + 1) // 2
            
            total_sum += odd_subarrays * arr[i]
            
        return total_sum
```

시간복잡도: O(N)
배열을 한 번만 순회하며 각 원소의 기여도를 계산합니다.

공간복잡도: O(1)
추가적인 배열을 생성하지 않습니다.

## 추가 참고사항

문제 지문의 Follow up에서는 O(N) 시간복잡도 해결을 제시합니다. 위에서 제시한 수학적 접근법이 바로 이 요구사항을 충족하는 방식입니다. 각 원소가 포함되는 부분배열의 개수를 직접 세는 대신, 조합론적 원리를 이용하여 각 인덱스의 기여도를 즉시 산출하는 것이 핵심입니다.
