## 문제

두 이진 트리의 루트 노드 p와 q가 주어졌을 때, 두 트리가 같은지 판단하는 기능을 구현해야 합니다. 두 이진 트리는 트리의 구조가 동일하고, 각 위치의 노드 값이 모두 같아야 같은으로 간주합니다. 예를 들어 p = [1,2,3], q = [1,2,3] 이면 true를, p = [1,2], q = [1,null,2] 는 false를 반환합니다. 문제의 제약 조건으로는 노드 개수가 0 이상 100 이하이고, 노드 값은 -10^4 이상 10^4 이하입니다.

## 접근 방법

가장 직관적인 해결책은 재귀를 이용한 깊이 우선 탐색입니다. 먼저 두 루트 노드의 값을 비교하고, 값이 다르면 즉시 false를 돌려줍니다. 그 다음 왼쪽 자식과 오른쪽 자식에 대해 각각 재귀적으로 같은지 확인합니다. 기저 조건으로 두 노드가 모두 null이면 true를, 한쪽만 null이면 false를 반환합니다. 이 방법은 각 노드를 한 번씩만 방문하므로 시간 복잡도는 O(n)이며, 재귀 스택을 위해 O(h)의 공간을 사용합니다.

## 풀이

재귀를 사용한 풀이 코드는 다음과 같습니다. 이 알고리즘은 각 노드를 한 번씩만 방문하므로 시간 복잡도는 O(n)이고, 재귀 스택의 최대 깊이에 따라 공간 복잡도는 O(h)입니다.

```python
# Definition for a binary tree node.
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

class Solution:
    def isSameTree(self, p: TreeNode, q: TreeNode) -> bool:
        if not p and not q:
            return True
        if not p or not q:
            return False
        if p.val != q.val:
            return False
        return self.isSameTree(p.left, q.left) and self.isSameTree(p.right, q.right)
```

## 다른 풀이 방법

스택을 이용한 반복식 DFS는 재귀를 사용하지 않아 추가 스택 오버플로우 위험이 없습니다. 두 노드를 한 쌍씩 스택에 넣고, 꺼내어 값과 구조를 비교합니다. 시간 복잡도는 O(n)이고, 스택에 모든 노드가 들어갈 경우 공간 복잡도는 O(n)입니다.

```python
class Solution:
    def isSameTree(self, p: TreeNode, q: TreeNode) -> bool:
        stack = [(p, q)]
        while stack:
            node1, node2 = stack.pop()
            if not node1 and not node2:
                continue
            if not node1 or not node2:
                return False
            if node1.val != node2.val:
                return False
            stack.append((node1.left, node2.left))
            stack.append((node1.right, node2.right))
        return True
```

## 추가 참고사항

이 문제는 두 트리가 모두 비어 있는 경우도 true로 처리해야 합니다. 재귀 해결책은 트리의 높이가 100 이하이므로 스택 오버플로우 우려가 없습니다. 반복식 해결책은 최대 O(n)의 보조 공간을 사용합니다. 문제의 노드 값 범위는 -10^4에서 10^4까지이므로 정수 비교만 수행하면 됩니다.
